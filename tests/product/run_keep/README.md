# Retained run products

Run `python3 tests/product/run_keep/check.py --omega <fresh-omega-binary>`
on Windows, macOS or Linux. No shell-specific launcher is required.

The public CLI reviews a private copy of the correlated-store parameter fact,
runs it with `--both --keep`, checks both exit-0 observations, and executes the
retained native image again. The canonical Terminal product, native identity
and comparison streams must exist; an eagerly expanded native-object Debug dump
must not. This small program retains less than 10 MiB.

Only this pure local project's measurement acceptance is automated; this is
not an audit or authorization of external packages. Temporary inputs and the
reported retained directory are removed after the assertions.
