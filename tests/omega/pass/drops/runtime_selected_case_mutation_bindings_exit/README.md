# Stored selection after a call write

A scalar-returning call installs a borrowed payload before a selection moves
its complete carrier. Local publication and replacement assignment retain the
same completed operand custody as a direct return. Both choices execute once
for each binding, and all four installed leaves must run their cleanup.

`omega run --both main.omg` must exit 0. The direct-return variation is
`../runtime_selected_case_mutation_complement_exit`.
