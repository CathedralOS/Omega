Named generic record and array containers clean live linear descendants at normal local and parameter exits. Partial transfer consumes the selected child in its callee and preserves exactly the remaining child for containing cleanup. An explicitly constructed zero-valued child still owns its claim. Deferred field initialization accepts both direct construction and a factory result while retaining the original claim. An abandoned deferred construction cleans only the initialized prefix. Untouched reserved storage, including a container with only an implicitly initialized scalar field, retires without inventing a linear child obligation. Native and Terminal execution must both exit 0.
