Linux x86-64/glibc div returns two i32 fields packed in one 8-byte integer result register. Distinct results pass through owned helper returns; borrowing and rereading the first retains all four authored fields. This passed on both the exact base and candidate and remains a preservation control.

It exits through the canonical `ProcessExit::exit_process`, which both engines observe as termination; a returning libc `exit` import would not be.
