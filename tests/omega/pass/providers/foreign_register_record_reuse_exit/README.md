Linux x86-64/glibc ldiv returns a 16-byte integer pair. Two distinct results pass through owned helper returns; the first is passed onward and read again after the second call. All four fields and the observation must retain their authored values.

It exits through the canonical `ProcessExit::exit_process`, which both engines observe as termination; a returning libc `exit` import would not be.

Run `omega run --both tests/omega/pass/providers/foreign_register_record_reuse_exit/main.omg`; expected exit 70 on both engines.
