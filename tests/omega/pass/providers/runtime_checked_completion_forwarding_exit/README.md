# Checked completion forwarding

The consumer supplies a field value to a named inline implementation. Its
checked body transports that exact status through a local, a scalar call result,
two helpers and both state branches to the original target leaf. Native and
Terminal execution must exit 70. The implementation is not itself a native leaf.

Sibling invalid controls reject a returning branch, service redispatch, an
ordinary same-named leaf and a helper that replaces the status. Package review
must establish completion before the consumer accepts the selected provider.
