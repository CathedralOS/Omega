# Source-decided Boolean views

`omega run --both main.omg` returns 0 in both engines. A helper reads an
established 0/1 byte through a Boolean view beneath short-circuit evaluation;
false, true and skipped observations retain their authored meanings.

With `OMEGA_DUMP_OBLIGATIONS=1`, the Boolean landing consumes the source recast
decision rather than appearing in the pending certificate-search roster.
Construction's field contract is a separate obligation.
