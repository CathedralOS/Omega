# requires_bridge_telescope

A ranged member's own proven range invariant is established-site
evidence at a subordinate call: `outer`'s judgment re-proves
`0 <= pending <= bound` on every `hold` arrival through the
`pending -> remaining, bound -> cap` telescope, so `inner`'s public
`requires n <= limit` is discharged without a respelled guard.

Compile-checked only: no standard-library dependency and
no `Main::exit` — run a check target, not native.
