# Captured source generates a checked, sealed artifact

The build reads an immutable source asset, copies its bytes into a required
output, seals it and includes it for ordinary Product checking. Generated
scalar constants use normal typing and initializer evidence, not a private
structured-value recognizer. No authored body references the later stratum.

Run `omega tests/omega/pass/build/captured_source_generated_constant/main.omg`.
Explicit selection needs `--build-input main.omg --build-input build.omg
--build-input asset.txt`; already-required source members cannot be omitted.
Successful publication contains `files/generated.omg` with the asset's bytes.

## Terminal Build execution

This witness also covers the orchestration migration: one Terminal activation
reads `asset.txt` from captured Source, writes and seals `generated.omg`, completes
its required-output obligation and hands the exact generated bytes to Product
compilation. `cargo run -p compiler --example build_charge` exercises this path
across single-fuel pauses and refuses before file creation when the fourth I/O
operation exceeds its sponsor. This does not close the broader Terminal Build
or production-discovery migration.

`cargo run -p compiler --example build_charge -- --anonymous-generator` also
acquires this fixture before its package is named, deletes the live files, and
runs Build plus Product completion from retained custody. Its controls keep
explicit input narrowing and caller-required output obligations intact. The
application discovery route exercises the same program without replay.
