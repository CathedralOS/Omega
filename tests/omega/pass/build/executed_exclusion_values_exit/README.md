# Executed Build exclusions

Build returns only executed selections on its original receiver. Helper parameters
carry evaluated crash and physical vocabulary; duplicate selections union without
changing admission. The untaken branch and uncalled helper impose no Trap ban.
Service identity resolves in the final Product namespace.

Every hosted entry returns normally. The focused test also inspects the returned
selection ledger, so an accidentally selected Trap cannot hide behind a quiet entry.
The existing `fail/targets/distinct_roots_exclusion_selected_body` is the
fact-sensitive control: its executed Trap selection must reject its trapping
macOS entry while allowing the Windows sibling.
