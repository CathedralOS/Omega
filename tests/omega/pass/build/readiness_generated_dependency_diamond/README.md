# Generated helper dependencies at a readiness pause

The suspended root requests one explicit `ProgramImage` backing. That backing
calls two ordinary Product dependencies which share a leaf package. The leaf's
Build publishes the `value` declaration as generated source; both branches must
receive its Build-purpose bundle before the backing is compiled to Terminal Psi.
The provider returns 64 only when both branches agree. Only that result binds the
hosted Product entries, whose native and Terminal executions exit 0.

This pins dependency-first helper preparation and shared dependency reuse, not a
new language feature. The existing private-backing readiness fixture remains the
negative authority control. `PIPELINE-ARCHITECTURE-ENFORCEMENT` also retains the
separate, unfinished work of eliminating recursive source/checker traversal.
