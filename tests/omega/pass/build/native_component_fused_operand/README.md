An internal loop step constructs a record and borrows its array field into a
scalar-returning call. The step is fused into the entry machine, so its computation
namespace still supplies operand carriers even though it has no separate emitted
function. Both callable discovery and structural type collection must follow the
same authored owners.

The independent component checks the observed payload on every iteration; a bad
read exits the loop early and the consumer traps unless all sixteen visits occur.
Before the repair, native package lowering rejected this with `computed producer
has no structural type namespace`. This pins the owner-control reply path in
Cathedral's standalone Omega runtime.
