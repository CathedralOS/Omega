# Owned initialization completion

`attempt` is an embedding entry, not a hosted application. The host supplies an
admitted `Granted & Vacant` extent, its actual read/write allocation and profile.
The selected profile provider runs normally. Initialization retains `Word { 17 }`
with that exact window, and the source returns the resident through a state and
the ordinary `carry` helper. Vacant host handback must refuse this result.

Export with `omega inspect-terminal --machine attempt --output <artifact>
main.omg`. The current public embedding probe uses base 4096 and length 16;
its producer, artifact and run are recorded in the resident continuation.
The companion rejection fixture checks insufficient capacity, misalignment and
insufficient actual access, preserving both inputs and every original byte.

This witness observes Ready, its continued ownership and refused vacant
handback. It does not yet observe the written bytes through a resident view or
extraction, and does not claim native or Cathedral boot acceptance. Non-runtime fields still require an
authored custody agreement; carried references require live loan forwarding.
The current private primitive refuses both unsupported paths before writing.

An initial probe placed `carry(view)` directly in the Ready successor argument;
it exposed a separate `call operation: projected operand support` lowering
refusal. This fixture isolates initialization by calling the same helper in the
destination state. The inline successor spelling remains unverified, not fixed.
