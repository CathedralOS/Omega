An owned formal contains a shared descriptor in a nested carrier. Extraction
and an ordinary-state consuming transform move that descriptor without moving
its backing. The returned carrier's named home remains available to the final
scalar observation; the original formal disposes only its residual frontier.

After package review, `omega run --both main.omg` must return 42 in native and
Terminal execution. This is the owned-input control for borrowed restoration;
matching descriptor types do not authorize a second copy of affine custody.
