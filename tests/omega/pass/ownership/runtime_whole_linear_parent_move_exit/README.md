# Whole linear owner transport

A nominal linear parent contains a linear child. Establishing the ordinary
`Moved` domain on the complete value exercises `MoveStructuralValue`; an
unqualified forwarding local only exercises continuation argument transport.
The parent moves through a parameter/local, an affine carrier's field, and a
call result. Both engines must finish with exit 0 and preserve values 29 and 17.

Whole-owner transport retains the parent's claim and its contained obligation.
It must not apply the descendant accounting used when destroying a parent.
The reject control is
`tests/omega/fail/ownership/whole_linear_parent_move_keeps_unique_custody`:
the old owner cannot be consumed again after its move.
