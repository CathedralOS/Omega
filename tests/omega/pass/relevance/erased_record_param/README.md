# erased_record_param

A closed checked-shape record whose fields are term-expressible is a
contract term carrier: `witness [erased]: Proof` rides the erased
proof-term lane — the literal publishes as a Construction with Scalar
leaves and occupies no runtime signature position; the retained `n`
reaches the callee intact.

Compile-checked only: no standard-library dependency and
no `Main::exit` — run a check target, not native.
