# Indexed record state argument

`omega run --both main.omg` must produce native and Terminal exit 70.
Prepare the bundled std dependency with `omega update --project .` and its
normal capability review when the checkout has no accepted lock.

The selected index copies a record containing a closed sum into a named state.
An unselected out-of-bounds index performs no copy. The caller's shared view
then ends at a closed-sum transition unrelated to that view.
