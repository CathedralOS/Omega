A runtime console byte is formatted through decimal state loops that reuse the dividend and divisor in successive wrapping division/remainder operations. Input A has numeric value 65: stdout is exactly 65, exit 0. x86 fixed-use operand preparation must preserve the original values independently of each instruction's RAX/RCX carriers. The pre-repair compiler rejects this complete control with NoCommonCandidate { function: 1, register: 12 }.
