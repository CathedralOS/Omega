A named successor borrows an affine value completed on its selected edge.
Whole readonly forwarding preserves that home, and each recurrent replacement
retires the previous home only after the new operand completes. The final
rankless state leaves the loan chain. Each iteration checks the current value;
three replacements and immediate completion must both produce zero.

Run `omega run main.omg --both`. The Build binds all four hosted entry targets.
