# Constructed payload arguments

The false short-circuit must skip construction. The selected construction
evaluates fields in authored order, and the returning case arm observes both
record payloads before the sum's selected cleanup. Native and Terminal execution
must both return exit 0, with exactly two `tick` calls.

From this directory, with `omega` on PATH:

```sh
omega update --project . --target macos_arm64 --offline
omega run --both main.omg
```

If preparation requests review, accept the named decisions and resume with
`omega update --resume --project . --offline`. Select the matching target on
another supported host.
