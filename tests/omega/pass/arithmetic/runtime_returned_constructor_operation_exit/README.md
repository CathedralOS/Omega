# Returned constructor operation

`omega run --both main.omg` exits 0 natively and through Terminal Psi.

The helper returns a record whose byte array is computed from its checked
parameter. Each Exact addition retains its own representability requirement;
nesting the completed array must not lose its storage on construction or return.
`fail/arithmetic/array_constructor_divisor_requires_nonzero` remains an invalid
control: a receiving array cannot authorize an undefined intermediate operation.
