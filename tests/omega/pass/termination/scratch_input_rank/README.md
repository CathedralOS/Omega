# scratch_input_rank

`count` is a mutable input outside every ranking premise: not the
subject, not the pinned view bound, not a range endpoint, named by
no requires fact. Its complete write frame is disjoint from those
carriers, so the store before the transition leaves the
entry-relative ranking intact.

Compile-checked only: no standard-library dependency and
no `Main::exit` — run a check target, not native.
