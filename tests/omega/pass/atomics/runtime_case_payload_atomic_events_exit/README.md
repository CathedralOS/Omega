# Atomic events on a selected case payload

Run from the repository root:

```sh
omega run --both tests/omega/pass/atomics/runtime_case_payload_atomic_events_exit/main.omg
```

Both engines must exit 0. The returned case guarantee licenses the exact
borrowed subject. Independent helper calls observe priors 3 and 8 and a final
resident 16 in the original atomic cell. A copied discriminator payload cannot
satisfy these observations. Ordinary shared field writes and illegal atomic
orderings remain rejected by the atomics fail fixtures; the proof controls
reject a different subject, replacement of the selected case, and a false
return guarantee.
