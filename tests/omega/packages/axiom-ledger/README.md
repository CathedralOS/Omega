# axiom-ledger

Accepted-claim fixture. Its bodyless boundary machine is a compiler-visible,
trust-bearing claim rather than a proof. It is intended to test that imported
accepted claims are disclosed for explicit review. The current admission tests
require root acceptance of the claim set; that promotion machinery is being
simplified into recorded baseline decisions trusted to whoever lands the lock.
Open compiler proof obligations still require discharge independently of
installation.

Expected package evidence:

- accepted proposition/boundary claim identity and exact argument are recorded;
- the accepted callable emits a distinct blocking trust row and initial source
  review packet;
- open proof deferrals remain unresolved compiler obligations and cannot be
  discharged by a lock decision;
- imported claims cannot self-approve.
