# Bootstrap-chain tests

Only tests whose subject spans more than one language rung live here. Tests of
one accepted language or compiler live under `tests/<language>/` instead.

| Retained file | Role | Deletion condition |
| --- | --- | --- |
| `chain-hygiene.sh` | Checks cross-rung owner inventory in source archives and Git checkouts, including empty relocation leftovers and actual alternate owners. | Delete only when another topology regression test covers both forms of source custody. |
| `alpha-beta-edge.sh` | Checks the selected Alpha seed, all three audited seed containers' native structure, Alpha conformance, exact trusted Beta compiler reconstruction, and finite root audit. | Delete only when a stronger Alpha-to-Beta edge gate subsumes all observations. |
| `source-closure.sh`, `source-closure.py` | Checks ordered Delta/Epsilon source materialization, exact evaluator and D reproduction, malformed or noncanonical manifests, closed source inventories, and output preservation on rejection. | Delete only when the selected lower compilers consume and verify the same member manifests directly. |
| `alpha-identity.sh` | Checks exact audited seed stamping and refusal of corrupted, truncated, appended, or substituted containers before writing. | Delete when replacement invocation covers the same identities and refusals. |
| `beta-identity.sh` | Checks exact source/tape stamping, corrupted or truncated source/tape/seed refusal before writing, and agreement with the independent root-audit pins. | Delete when replacement invocation covers the same identities and refusals. |
| `gamma-identity.sh` | Checks exact evaluator source/tape stamping, corrupted or truncated source/tape/seed refusal before writing, and agreement with the heap-boundary, composed, and evaluator-development records. | Delete when replacement invocation covers the same identities and refusals. |
| `delta-identity.sh` | Checks exact compiler and support materialization, entry/manifest/member/composed-record refusal before writing, gate-local driver and controls refusals, and agreement with consuming gates' pins. | Delete when replacement invocation covers the same identities and refusals. |
| `epsilon-identity.sh` | Checks exact evaluator materialization, manifest/member refusal before writing, driver/entry/receipt/controls refusals, and agreement with consuming gates' pins. | Delete when replacement invocation covers the same identities and refusals. |
| `omega-identity.sh` | Checks exact D and packed customer bytes, manifest/member refusal before writing, gate-local entry/fixture refusals, and agreement with consuming gates' pins. | Delete when replacement invocation covers the same identities and refusals. |
| `proofs-identity.sh` | Checks exact checker and Beta-encoding closure materialization, manifest/member refusal before writing, and definition-package corruption/truncation/extension refusals. | Delete when replacement invocation covers the same identities and refusals. |
| `omega-parser/` | Checks and executes a complete-D parser customer through the selected lower chain, including guard failures and parser reuse. Explicit slow gate; see its README. | Delete only when a stronger full-D gate subsumes these observations. |
| `omega-outcome/` | Checks the complete-D OCOUT outcome machinery through the selected lower chain: embedded table projections, exact and refused frame encodings, bounded publication arithmetic, declared-extent provisions, and the scalar failure paths' recorded outcome tuples. | Delete only when the sealed request edge covers the same outcome controls directly. |
| `omega-request/` | Serves one sealed OCREQ V1 request through the selected lower chain using D's canonical request entry: canonical request reaches the coverage provision, each malformed stream publishes its computed `malformed_request` frame, and an oversized request publishes `request_staging_bytes`. | Delete only when the sealed request edge binds a stronger request entry. |
| `omega-executable/` | Compiles one single-source `.omg` application to an Alpha tape through the complete manifested Epsilon-written compiler on the canonical OCREQ V1 request route, stamps the tape into the selected seed container, and executes it to the recorded result; also holds the retired raw-source `--diagnostic` lane and the ten-part controls matrix of acceptances and refusals. | Delete only when a stronger source-to-executable gate subsumes the same request-route and emission observations. |
| `ocreq-tables.sh` | Host-free agreement gate between the OCREQ/OCOUT contract tables in `wiki/spec/build/compiler_request.md` and their embedded projections in `bootstrap/5_omega/` (identity bytes, common-header layout, scalar-resource limits and spaces, lexical and literal Reject tuples, internal-failure space, invocation product tags) plus the asserted copies in `omega-outcome`; pins the projected-code boundary so spec provisions the implementation has not reached trip the gate instead of drifting. | Delete only when the V1 boundary claim covers the same tables by execution. |
