# Terminal production

Public contract: [Terminal Psi product](../../../../../wiki/spec/terminal-psi/product.md).

The [accepted-source factory](src/accepted.rs) retains the exact frozen typed
owner before the lowered-form checker judges its whole compilation. It publishes
the same module and evidence, then binds genuinely emitted Build request rows,
source-record correspondence and application roots to that exact code owner.
Structural reading refuses unserved selection, query, native-formation and
filesystem constructs before publication can lose their meaning.

This factory does not supply missing source preparation or Build evaluation.
Nonempty 04 preparation and other unserved authority requests still refuse with
`no product route yet`. Publication of an independently served typed frontier
establishes no default-Build or native capability beyond that actual product.

The obsolete checked-source and Build-provider production request interfaces
and checked-provider inventory reexport are removed. Their lowering stage and
intermediate Lowered Psi, optimization and publication wrappers are deleted.
Missing capabilities belong on the lowered-form route; no old checker supplies
a fallback artifact.

[src/lib.rs](src/lib.rs) exposes the production and application contracts.
[custody.rs](src/custody.rs) retains code, evidence, companions and source
correspondence for portable reuse and invocation-local production. Companion
records remain in [build_bindings.rs](src/build_bindings.rs).

The [codec entry-receipt owner](../../representations/terminal-psi/codec/src/entry_receipt.rs)
checks the unique Unit entry in a published artifact and binds its exact
semantic identity. Application attachment and later reuse consume that same
receipt without reopening source trees.
