# Native program planning

Omega 00 binds the accepted program's closed provider choices to one target.
The scoped entry checks the canonical program identity, matches exact checked
bodies, resolves installation reach and issues the selected execution. The
unscoped entry checks each actual invocation root for boundary demand.
Calling policy evaluation uses admitted canonical Psi and the target profile.
Root-grant admission resolves the Build selectors against the same selected
plans and the prepared trust declarations. Products retain the resulting
commitments when they publish executable inputs.
