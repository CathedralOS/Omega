# Path prefix -> corpus fixture families the corpus gate always samples first
# when a pull request changes that path (`cargo xtask corpus-gate plan`).
#
# A family is a fixture-name fragment, matched the way the runner's filter
# matches (`pass/packages/` selects every pass fixture in that group). A path
# that reaches the compiler also gets the corpus-wide sample, so a missing
# line here narrows nothing; a line only moves its families to the front.
# Families get at most two thirds of the gate's budget; when they hold more,
# they are sampled evenly across their groups.
