# Alpha tools

This directory contains optional construction and inspection tools for Alpha
tapes. Nothing here is a bootstrap language rung or a premise of an admitted
compiler edge.

| Retained child | Role | Deletion condition |
| --- | --- | --- |
| `tape-assembly/` | Readable Alpha tape assembly, exact assembler tape, materialization, and tests. | Delete when no retained construction or inspection workflow needs it. |
| `beta-evaluator/` | Readable construction and audit source for in-progress Beta evaluator slices. | Delete when the complete direct evaluator audit no longer benefits from readable reconstruction. |
