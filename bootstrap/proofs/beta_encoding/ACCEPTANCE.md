# Complete Beta encoding acceptance

The first complete certificate establishes the independently reconstructed root:

```text
encode_Beta(S, source_limit, output_limit) = Success(T)
```

`S` is the entire selected Gamma evaluator's raw Beta source, including comments
and whitespace; `T` is its entire persisted Alpha tape. The
[evaluator profile](../../2_gamma/EVALUATOR_PROFILE.md) owns current identities.
The artifact owner fixes both subjects, the complete transparent Beta definition
package, encoding profile, and root independently of the certificate producer.
Neither a formed theory nor a producer-supplied theory identity authenticates
the definitions as Beta.

## Meaning of success

The encoder is an ordinary total error-valued definition, not a primitive
invoking Beta. `Success(T)` holds exactly for valid bounded source encoding
those bytes under [Beta's complete language](../../1_beta/LANGUAGE.md).
There is no unchecked well-formedness premise. Invalid source and exhausted
encoding capacity are distinct results; neither is generic checker Incomplete.

The theorem projects admission and encoding from Beta's partial relation. It
need not reproduce rejected stdout prefixes, process status, diagnostic payloads,
or invalid-byte coordinates through successful traversal. That projection does
not change the compiler's envelope-first, exact-offset failure contract.
Every raw byte, malformed form, limit, and EOF obligation still belongs to the
total definitions. No unexamined suffix may reach Success.

The complete theory covers ASCII, separators, comments, EOF, complete-token
lowercase registers/words, all 21 opcode/operand/width rows, little-endian words,
`dw`, address assertions, malformed input, source/output provisions, arithmetic
overflow, and exact/adjacent exhaustion. Do not formalize only cases occurring
in the customer. Fixed finite constructor words may represent limits without
unary millions; no trusted arithmetic, assembler, or hash shortcut is introduced.

Equal tapes have identical deterministic Alpha behavior under the same input
and resource profile. This is not a proof that the Beta-written evaluator
implements Gamma. Byte comparison, assembler agreement, a digest, or an isolated
instruction proof cannot discharge the complete encoding root.

## Composition and custody

The [generic checker](../checker/README.md) owns conservative definitions and
explicit equality rules. Artifact-specific definitions, independent root
reconstruction, and untrusted production stay here. Definitions are source-owned
and production runs through the selected chain, not a host semantic script.

Closed intermediate equalities may retain source tails, encoder states, and
output fragments. Their composition establishes source and tape adjacency
separately, zero initial offsets, agreed intermediate states, exact endpoints,
and complete exhaustion. Trivia and assertions consume source but emit no bytes.
Cuts are witnesses; the owner fixes the composition theorem and endpoints.
There is no gap, overlap, dropped assertion, or historical two-pass label/fixup
requirement. Recursive definitions consume unchanged immediate constructor
children; a computed cursor is not a structural-decrease witness.

Accepted closure retains exact owner, theory, checker, source/tape subjects,
profiles, derivation, and admissions. Each retained proof rule requires actual
full-certificate use, positive/mutation controls, and measured size consequences.
Unused convenience rules should not enlarge the checker.

## Acceptance and feasibility

Full-subject mutations cover source, tape, assertions, theory identity, rules,
clauses, substitution, premises, sorts, arities, partition joints, endpoints,
and final-root selection. Invalid or exhausted input cannot accept after a valid
prefix. Small generic rule tests are not this acceptance gate.

Measure exact certificate/request bytes, retained proof state, comparison and
substitution scratch, semantic stack, cumulative allocation, production and
checking time. The checker's profile is distinct from Gamma's; raw evaluator
failures, host timeouts, and short observations are not proof verdicts. A complete
profile must fit all conjunctive requirements, not just the output tape.

If proofs are too large, compare sharing and checked closed-lemma composition
before adding rules. A weaker root, unchecked recursion, trusted assembly rule,
or host stage requires [owner escalation](../../MINIMIZATION.md#owner-escalation).
The [encoder candidate](ENCODER_CANDIDATE.md) records the paused integration
approach; it is neither an accepted theory nor demonstrated resource fit.
