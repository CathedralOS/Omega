# Bootstrap Owner Questions

Only the owner answers, closes, removes or rewrites question entries. Agents may
add unresolved questions and report research without treating their recommendation
as a ruling. Use consecutive question numbers as queue positions and a stable
named decision for durable references, as in [OWNER_QUESTIONS.md](OWNER_QUESTIONS.md).

The [bootstrap mandate](bootstrap/MINIMIZATION.md) delegates architecture, stage
count, language facilities, representation, execution targets, documented
acceleration and capacity choices. These do not require approval merely because
they differ from the interpreted variant. Formal bootstrap correctness certificates
are outside current acceptance. Ordinary Omega semantics remain required.

Questions here concern unresolved changes to required semantics, trust claims or
the goal itself. Each entry names the concrete compiler customer, contracts that
leave the issue unresolved, available evidence (distinguishing measurements from hypotheses), alternatives,
recommendation and
work dependent on the answer. Continue independent work while answers are pending.
Do not convert a failed experiment or private limit into an owner question without
first investigating the mechanism and authorized remedies.
