# Extent contracts

Programs and receivers carry nonzero extent coordinates, normalized rights sets and content interpretations. Constructing these records validates their shape. The [arena](../../../../foundation/arena) supplies the generic normalized set.

The [interpreter’s extent ledger](../../../interpreter/memory/extents/) checks grants, loans, translations and ordering when operating on storage. [Storage bounds](../storage-bounds/) composes the static sizes of claims for an activation.
