# Extent contracts

Nonzero semantic coordinates, rights sets, content-interpretation commitments
and diagnostics are immutable carried data. Their constructors validate shape;
they confer no authority over storage. Generic set operations belong to arena.

Live extents, grants, lending, translation and ordering admission belong to
`psi/runtime/extents`. Activation-bound composition belongs to
`psi/compilation/representations/terminal-psi/storage-bounds`; checking a bound does not create a live claim.
