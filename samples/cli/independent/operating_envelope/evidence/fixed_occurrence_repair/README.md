and complete intended-valid decimal formatting witnesses. The repair moves
fixed operands and their symmetric tied components onto instruction-local
carriers, using the target-admitted CopyI64 row. Resident semantic registers
keep their original CFG transports. Homes are independently reanalysed after
rewriting; no predecessor, fixed view, tie, early clobber, class, scalar type,
fuel schedule, custody check or budget limit is removed.

The required recovery route now composes this realization after either home
pressure or unresolved entry transitions. Optional fixed-segment tree policy
remains optional. The removed default leaf/tree fallback is not a correctness
requirement. A manifest transformation (wire tag 17) retains the selected
identity; actual storage transformations alone determine spill status.

when all references are confined to one occurrence window, all outgoing
scalar/structural/case transports are clear, and no intervening destructive
operation exists. Sorted construction rosters prepare references and escapes
once; prefix counts inspect complete gaps. Work charging bounds sorting,
lookups, actual operand tie closure and settlement scans, with unchanged
required-rewrite extent entitlement and budget enforcement.
