**OPAQUE-BY-VALUE-BOUNDARY-ABI**. This row carries the remaining qualified
independent-component input/result requirement under
[opaque representations](../../../../wiki/spec/build/opaque_representations.md),

A checked issued opaque result retains its exact Issued membership across independent component result and input transport while observing host 66051 and distinct sibling host 513.

The private `mint` machine is the exact authorized issuer. A checked public
bridge returns that qualified value through its declared result type. The
consumer retains two distinct live occurrences, transports the first through
its place, and sends both to independent `host` invocations requiring `Issued`.
The provider explicitly erases membership with `as InternetAddress` before the
raw C operation. It does not grant the foreign adapter authority to mint a
qualification. The same closed nested Inert C carrier and actual host values
are used in every place.

Positive and twin consumers are byte-identical. The twin producer omits only
the bridge's qualified output contract, matching the implementation signature
and explicitly erasing the private issuer's membership before returning the
same C payload. The private issuer, carrier, inputs, host operation and runtime
oracle remain unchanged. Its ordinary program entry uses the raw bindings and
remains valid under either bridge contract. Thus a twin rejects the consuming
place's missing membership rather than malformed issuer formation.

Construction establishes one owned affine occurrence and its private authorized
provenance. Moves, fields and calls must preserve that exact occurrence. A
completed independent result must transfer the producing execution's actual
membership, translating artifact-local domain keys through exact checked
semantic-domain and callable identities. A matching spelling, C payload or
layout cannot establish membership. Component inputs must retain the same
proof across the selected provider edge. Explicit erasure changes the value's
displayed contract without copying its ownership or external content authority.

The original two live values are intentional: consuming the first does not
replace the unrelated second home. Unknown opaque content stays in the
declared signature/authority ceiling, using its exact carrier coordinate; it
does not supply arbitrary declared-storage replacement authority or an empty
effect set. No call-order rewrite or caller guard substitutes for preservation.

All nine twins reject their own missing qualification. Controlled reverse-order
probes lose whichever local is consumed second; interleaved and two-parameter
controls compile and execute natively at 0, then Terminal refuses the qualified
component result. Exact sources, hashes, commands and raw diagnostics are
retained under the owning claim's `build/opaque-copy/qualified-2add-baseline/`
and `qualified-peer-probes-2add/` records. The current row is unfinished.

All authored positives and producer entries bind the four hosted targets and
