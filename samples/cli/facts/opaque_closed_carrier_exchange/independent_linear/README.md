The ownership path retains the following requirements:

- Establishment comes from the selected closed carrier and the actual completed
  host call. Neither equal bits nor an opaque token establishes another value.
- Identity includes the exact opaque application and multiplicity. The invocation
  store never recycles a consumed address ordinal.
- Storage retains the actual unchanged opaque host value; guest source cannot
  inspect or manufacture its representation.
- Consumption validates application and mode before taking the Linear slot.
  Wrong identities or modes leave the valid occurrence available.
- Input transfer rejoins each actual caller claim to the selected child's whole
  entry claim. The caller commits its staged remainder only after child admission.
- Partial moves preserve every disjoint sibling; consuming and replacing
  `pair.first` leaves `pair.second` owed until its own consumption.
- Return transfer authenticates the producing instance's actual returned claim
  bindings, stages the receiving claims, then publishes and acknowledges once.
  A failed publication retains the pending producing instance.
- Native replay retains the entire admitted result claim list beside the ABI
  home and compares it exactly with the source result. Physical placement neither
  discards nor creates a semantic occurrence.
