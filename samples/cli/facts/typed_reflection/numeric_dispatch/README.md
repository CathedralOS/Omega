# Numeric callback dispatch

This is another production of the typed reflection fact: the exact emitted
field type controls ordinary signed, unsigned and Boolean callback branches.
The same forty fields, five types, one call per field, sum and order oracle
are checked across the nine places. Signed fields replace two unsigned carriers without
changing their values. Exact coercions in impossible type branches have no
executable proof obligation; reachable coercions retain all range obligations.
Each reject twin excludes the actual u8 fields from the callback contract.
