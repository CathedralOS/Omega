# Active cases

Authorized sum visitation reports one exact active case, then common fields and only that case payload in declaration order using ordinary field loans.

The case callback seeds the accumulator; the two field callbacks append common then payload values. Inverting a branch, omitting a callback, or changing field order changes the observed result and traps. The match alternative is a distinct nullary case. Each reject twin excludes the actual field type.

The [selected-layout composition](compositions/selected_layout/README.md) exercises
an explicit const-parameterized policy in common and active-payload fields.
Its exact application control shares geometry with the rejected application.
