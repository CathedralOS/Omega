# Unsigned 8-bit saturating multiplication bound

Fact: 8-bit unsigned saturating multiplication lhs *| rhs with bounded interval 40u8 <= prod <= 150u8 establishes 40u8 <= prod <= 150u8 across all nine places so exact subtractions 150u8 - prod and prod - 40u8 are safe.

The original root reproduction is preserved in [main.omg](main.omg) and [build.omg](build.omg).

## Discrimination

- **Runtime oracle discrimination:** Perturbing a single token in [main.omg](main.omg) (`transition check == 0` -> `transition check == 1`) causes both engines under `omega run --both` to trap at runtime (`native exit -1073741795`, `interp crash: Trap (host presentation agrees)`), confirming the `0` exit oracle actively discriminates the computed saturating product (`12u8 * 8u8 == 96u8` in `u8 in Saturating`, `(150 - 96) + (96 - 40) - 110 == 0`).
- **Static proof discrimination:** Widening the operands in each `<place>/invalid/main.omg` to `lhs = 16, rhs = 10` (producing `prod == 160u8 > 150u8`) causes static verification to fail closed with `cannot prove ... contract ... <= 150`.

## Requirements and Evidence

- **Parent outcome:** `NUMERIC-VALUES` / `INTEGER-CERTIFICATES` / `INSTRUCTION-SELECTION` ([TASKS.md](../../../../TASKS.md)).
- **Requirement established:** 8-bit unsigned integer saturating multiplication arithmetic bounds proof and realization (`Psi 05–07` / `Omega 00–09`), verifying that saturating multiplication `lhs * rhs` (denoted `lhs *| rhs`) on bounded `u8 in Saturating` operands produces a bounded product `40u8 <= prod <= 150u8`, which proves that exact 8-bit unsigned subtractions `150u8 - prod` and `prod - 40u8` are provably overflow-free across all nine standard places.

Full 8-layer specification and lowering evidence:

- **Establishment:** The 8-bit unsigned saturating multiplication `lhs * rhs` on `lhs: u8 in Saturating` and `rhs: u8 in Saturating` operates in the saturating arithmetic domain, clamping results to `[0, 255]` on overflow rather than trapping or wrapping ([numeric values](../../../../wiki/spec/language/numeric_values.md), [invocation contracts](../../../../wiki/spec/language/state_contracts.md), [proof contracts](../../../../wiki/spec/proofs/contracts.md), [domains](../../../../wiki/spec/language/domains.md)). With bounded operands `lhs = 12` and `rhs = 8`, the evaluated product `96u8` resides strictly in `[40, 150]` without reaching the saturation threshold (255). The consuming helper `verify_prod(prod: u8) -> i32 requires prod >= 40 && prod <= 150` discharges exact unsigned subtractions `150 - prod` (evaluating to 54) and `prod - 40` (evaluating to 56), verifying `headroom + margin == 110` without post-hoc caller guards.
- **Identity and lifetime:** The evaluated 8-bit unsigned scalar preserves its invariant `[40, 150]` across all standard value carriers ([fact validity](../../../../wiki/spec/terminal-psi/fact_validity.md), [lifetimes](../../../../wiki/spec/language/lifetimes.md), [ownership](../../../../wiki/spec/language/ownership.md)): local bindings, record fields, machine parameters, call return results, match convergence joins, compile-time named constants, state machine transition arguments, intermediate machine forwarding, and target-scoped execution bodies.
- **Composition:** The saturating multiplication bound composes across all 9 standard places to satisfy the consuming requirement `prod >= 40 && prod <= 150` and discharge `150 - prod` and `prod - 40` ([machines](../../../../wiki/spec/language/machines.md), [evaluation](../../../../wiki/spec/language/evaluation.md), [patterns](../../../../wiki/spec/language/patterns.md), [structural predicates](../../../../wiki/spec/terminal-psi/structural_predicates.md)):
