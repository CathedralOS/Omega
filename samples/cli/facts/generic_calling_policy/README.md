and nested data operands before admitted plan evaluation and boundary execution.

This is static implementation selection, not a runtime value-transport fact.
A local/field/parameter/result/join/state matrix would repeat the same selection
and add no mechanism evidence. Witnesses instead distinguish inline const

and private constant projection. The authored plan is specifically Linux System V;
other ABI policies and matching-host execution remain broader requirements.
