# Unsigned 16-bit saturating subtraction bound

Fact: 16-bit unsigned saturating subtraction lhs -| rhs with bounded interval 200u16 <= diff <= 450u16 establishes 200u16 <= diff <= 450u16 across all nine places so exact subtractions 450u16 - diff and diff - 200u16 are safe.

The original root reproduction is preserved in [main.omg](main.omg) and [build.omg](build.omg).

## Discrimination

- **Runtime oracle discrimination:** Perturbing a single token in [main.omg](main.omg) (`transition check == 0` -> `transition check == 1`) causes both engines under `omega run --both` to trap at runtime (`native exit -1073741795`, `interp crash: Trap (host presentation agrees)`), confirming the `0` exit oracle actively discriminates the computed saturating difference (`400u16 - 80u16 == 320u16` in `u16 in Saturating`, `(450 - 320) + (320 - 200) == 250`).
- **Static proof discrimination:** Widening the operands in each `<place>/invalid/main.omg` to `lhs = 520, rhs = 50` (producing `diff == 470u16 > 450u16`) causes static verification to fail closed with `cannot prove ... contract ... <= 450`.

Full 8-layer specification and lowering evidence:

- **Establishment:** The 16-bit unsigned saturating subtraction `lhs - rhs` on `lhs: u16 in Saturating` and `rhs: u16 in Saturating` operates in the saturating arithmetic domain, clamping results to `[0, 65535]` on underflow rather than wrapping or trapping ([numeric values](../../../../wiki/spec/language/numeric_values.md), [invocation contracts](../../../../wiki/spec/language/state_contracts.md), [proof contracts](../../../../wiki/spec/proofs/contracts.md), [domains](../../../../wiki/spec/language/domains.md)).
