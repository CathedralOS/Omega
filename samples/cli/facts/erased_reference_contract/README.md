# Erased shared-reference contracts

An erased `&i32` witness whose referent is 7 discharges `witness == 7` at `keep` without a runtime witness argument, read, storage or cleanup.

The original root probe is retained. Nine positive/control pairs transport the same fact through local, field, parameter, call result, match join, const name, another state, another machine and target body. Each control supplies 8 and must fail the precondition at its contract operation. Both match arms execute; the ordinary runtime result remains 41 or 42. The Linux binding executes native and Terminal witnesses; checking also validates foreign target bodies.

Canonical authority: [explicit erased bindings](../../../../wiki/spec/proofs/contracts.md#explicit-erased-bindings), including binding identity, no runtime contribution, exact argument substitution, scope and write invalidation. Reviewed contract blob: `0551b01c0d931150f979d6ea295d3bafd99629bf`.

The initial compiler refused the unchanged root because `witness` was not scalar. The repair preserves its reference declaration while carrying a primitive referent observation in the existing erased contract lane. Exact source admission remains responsible for type, scope, borrow, validity and preconditions. Immutable descriptor aliases and closed constructor/scalar leaves retain exact declarations; mutable initializers, captured calls and recasts are not unfolded. This bounded static slice does not complete erased record/array contracts or dynamic dispatch.
