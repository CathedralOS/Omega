# Unsigned 8-bit bitwise AND mask bound

Fact: 8-bit unsigned bitwise AND mask raw & 63u8 with bounded interval 40u8 <= masked <= 63u8 establishes 40u8 <= masked <= 63u8 across all nine places so exact subtractions 63u8 - masked and masked - 40u8 are safe.

The original root reproduction is preserved in [main.omg](main.omg) and [build.omg](build.omg).

## Discrimination

- **Runtime oracle discrimination:** Perturbing a single token in [main.omg](main.omg) (`transition check == 0` -> `transition check == 1`) causes both engines under `omega run --both` to trap at runtime (`native exit -1073741795`, `interp crash: Trap (host presentation agrees)`), confirming the `0` exit oracle actively discriminates the computed bitwise AND mask value (`116u8 & 63u8 == 52u8`, `(63 - 52) + (52 - 40) - 23 == 0`).
- **Static proof discrimination:** Widening the mask in each `<place>/invalid/main.omg` from `63u8` to `127u8` (producing `masked == 116u8 > 63u8`) causes static verification to fail closed with `cannot prove ... contract ... <= 63`.
