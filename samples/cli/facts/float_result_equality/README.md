# Returned float equality

A returned f64 equals the live field it came from.

`read_kept` records the returned float equal to the live field and to 7.0. `agree` reads that record. Local, field, parameter, call result, match join, const name, other state, other machine, and target body carry that sentence. Each reject twin returns the other field, and the diagnostic is `cannot prove ensures contract` for the recorded equality.
