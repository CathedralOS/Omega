# Constant predicate controls

These controls protect the declaration-site default-domain gate used by the
standing-field row. They add no transport matrix.

- `coupled_const` admits the complete conjunction from two actual fields;
  `coupled_false` breaks the first relation while retaining the second.
- `nested_const` follows both a nested record and an array index under the same
  logical subject; `nested_false` breaks the indexed conjunct.
- `scalar_false` rejects a concrete field value above 60.
- `missing_field_shadow` refuses a missing structural const field before
  predicate proof; the same-spelled outer constant cannot supply that field.
- `missing_member_shadow` keeps an unknown logical-subject member undecidable;
  an outer constant with that name cannot discharge the data predicate.

The two positive controls require native/Terminal exit 0 and bind all four
hosted entries. The five rejects pin their relevant formation or predicate
refusal under `tests/omega/fail/facts`. Existing provider-endpoint runtime and
machine-contract `self` rejects remain focused consumers of the lexical scope
fence; this change does not admit `self` into executable or machine-contract scope.
