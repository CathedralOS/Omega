# Address/count interval partition

The fact is that an address base and a count length partition into disjoint
intervals with exactly the original content. The operation is a checked split,
with the requested count bounded by the input length and the input endpoint
bounded by a separately formed address ceiling. No host address width is assumed.

Run `omega run samples/cli/facts/address_count_partition/main.omg --both`.
Expected exit: 0 in native and Terminal execution.

This is the numeric prerequisite of TASKS.md **BUMP-ALLOCATOR-CANARY** and
Cathedral's backed allocator, not an authority issuer or a functioning allocator.
The local `Region::Owned` qualification grants no storage rights. Real `Extent`
partition still needs checked custody transfer and retirement of the parent.

The root and nine places exercise local, field, parameter, call result,
match join, const name, another state, another machine, and another target
body. Each has the same exit-0 oracle in native and Terminal execution and
an invalid twin removing the requested-count bound. The corpus additionally
rejects overlap, missing address fit, wrong count carriers, nested overflow,
and conservation against mutated or replaced entry values.
