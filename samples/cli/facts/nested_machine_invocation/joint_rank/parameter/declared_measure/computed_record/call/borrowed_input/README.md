`distance(&value)`; its ordinary helper accepts `&Progress` and publishes the
same exact distance equation after independently requiring ordered endpoints.
The complete owned entry input supplies the initialized backing. Scalar proof
reads cannot reconstruct a record, manufacture a loan, or supply a statement
occurrence. The shared call finishes before the invocation's body effects.

Every program runs the seven-step path (counter 3→10) and the empty path
(counter remains 10), checking endpoint equality and canary 641. The exact twin
changes only increment 1→0. The matching and fallback paths have different
observable counter effects, so losing a call, taking the wrong path, or adding
an iteration traps.

The governing rules are [independent invocation formation and exact actuals](../../../../../../../../../../wiki/spec/language/state_contracts.md),
[joint termination measures](../../../../../../../../../../wiki/spec/language/termination.md),
and [explicit nested-machine inputs](../../../../../../../../../../wiki/spec/language/machines.md#nested-machines-and-identity).

completed primitive conversion lost its symbolic denotation. Completed runtime
prefixes now retain an opaque result and their effects when no conversion
equation is available; proof-only evaluation still requires justified meaning.
This preserves the later record snapshot without treating a reference descriptor
as a scalar observation.

- Establishment: independently form the selected helper's complete public input
  contract before consuming its result equation. The desired rank supplies no
  precondition or arithmetic premise.
- Identity and lifetime: retain the complete entry snapshot separately from its
  scalar reads; the exact initialized, borrow-free owned input owns the short
  shared window. No caller fact or reference descriptor becomes an owned value.
- Composition: both private participants use the same declared measure and exact
  actuals. Every cycle owes strict progress. Shared arguments may overlap while
  exclusive access and owned transfer remain distinct obligations.
- Soundness: the selected call's pure, total, crash-free contract and the whole
  input's Copy/unrestricted/borrow-free receipt are independent. Missing
  formation, nonprogress and an explicit loan supplied to an owned formal refuse.
- Psi05–07: retain SharedBorrow on the ordinary structural argument plan and
  consume that checked access in shared scalar-call lowering. No synthetic

- Omega00–02: ordinary record geometry and calling plans transport the complete

- Omega03–06: the ordinary scalar call, structural backing, counter and canary
