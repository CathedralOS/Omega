# scalar alias

A private helper preserves the invocation rank on a tail edge, and every complete cycle strictly descends while advancing the explicit counter once.

[Positive](main.omg) keeps the seven/empty inputs and original writeback oracle.
It exercises `scalar_alias` through the same stored-reference rank. [Twin](invalid/main.omg)
removes only strict descent. Parent acceptance and the reference/loan, Terminal,
native and target obligations remain in the [stored-reference witness](../README.md).
