# Borrowed rank composition: alias move

A private helper preserves the invocation rank on a tail edge, and every complete cycle strictly descends while advancing the explicit counter once.

Owner: `NESTED-MACHINE-UNIFICATION`; this is a composition of the
[borrowed-value row](../README.md), with the same seven-step and empty inputs,
counter3→10 and caller-visible original-record/canary checks.
[Positive](main.omg) must agree in native and Terminal execution.
[Twin](invalid/main.omg) removes only descent and must refuse at the joint rank.

The independent native receiver must also accept the loop's loan custody.
An edge explicitly disposes the temporary alias after capturing the successor
address. The next formation uses the restored original borrowed entry authority;
it does not keep the disposed alias as its own parent. Live descendants,
provider validity, stored-descriptor backing and placed interpretations retain
their separate obligations. Neither source acceptance nor CLI execution alone
establishes this independent receiver result.
