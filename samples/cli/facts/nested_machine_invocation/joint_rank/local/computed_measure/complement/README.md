Requirement evidence:

- **Establishment:** the closed builtin complement takes the exact selected integer width. Operand formation is proved before its produced value or requested rank bounds enter the application judgment.
- **Identity and lifetime:** the captured selected cell and measure identity survive delivery and the indexed write; the same selector is not reinterpreted after mutation. Caller-visible counters, neighbor cells and canaries distinguish changes to the exact storage.
- **Composition:** delivery preserves the produced rank, increment decreases it, and every complete SCC cycle includes that edge. Zero increments and decreasing inputs reject their different ranking failures.
- **Soundness boundaries:** unsigned complement is carrier maximum minus the operand; signed complement is minus one minus it. Child overflow remains an independent failure, full-width results are not Boolean bounds, and an admitted policy child supplies its actual finite payload before complement.
- **Checked to Terminal Psi:** the checked rank and tail edges lower to the same terminating constant-stack loop. Both active and zero-cycle paths execute under the Terminal interpreter with the authored counters and restored borrowed storage.
- **Provider/layout/ABI:** all four hosted targets have authored `ProgramEntry` bindings. The executed target passes explicit mutable references and selectors; record/array projections preserve neighbor storage. No target-specific compiler rule is added.
- **Instructions/activation:** native indexed increments, mutable counter calls and returning continuations preserve the same visible values. The additional direct control executes complement at unsigned/narrow/signed extremes, including signed minimum, double complement and policy-valued children.
- **Encoding/native image:** direct macOS arm64 execution agrees with Terminal Psi. Other hosted targets are authored but have not been executed by this run.
