# Changed-source review recovery

This two-file project exercises the bounded package-review workflow prerequisite
of **ASSUMED-BINDING-CONTRACTS**. It reuses the existing scalar result-bound fact;
it is neither a new semantic repair nor another transport row.

Copy the project to an isolated origin. Run ordinary `omega update`, read and
accept the exact displayed high-risk relationship, then resume. Change only the
private local name `retained` to `forwarded` in the honest supplier. The old lock
must reject compilation; update must show the real source diff and require the
changed relationship's exact decision. Resuming the previous review must reject
without changing the accepted lock. Accepting the new row must restore audit
and `omega run --both` with exit 0 in both engines. Decisions and locks belong
to that copied project origin.

For new-format snapshot publications, changed update and accepted resume must
each finish within ten seconds, selecting and fully verifying one historical
snapshot without enumerating the collection. A malformed direct snapshot must
report unavailable old source, retain policy comparison and preserve the lock;
it must not fall back to an older copy. Restore any controlled fault afterward.
Legacy publications retain the original bounded verified search and have no
ten-second acceptance claim. Other-host execution and the full parent capability
remain separate.
