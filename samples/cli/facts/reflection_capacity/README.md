# Reflected capacity

A pure source reflection query computes the complete capacity of the exact selected schema, and its foreign nominal result retains that bound through every value transport.

The source library returns ScalarBound, an owned foreign nominal value. Every positive consumes its valid seven-byte result. Each twin selects a two-field schema whose complete bound is thirteen bytes, violating the same seven-byte obligation.


Each positive's `sample.json` selects its own `main.omg` and `build.omg` as the
invocation's immutable source inventory. The nested reject control has its own
package invocation; adding that control to the positive's inventory would make
its duplicate declarations part of the positive package too.

Run a positive directly with the same caller selection:

```sh
omega run --both --build-input main.omg --build-input build.omg samples/cli/facts/reflection_capacity/local/main.omg
```
