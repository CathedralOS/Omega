# Equivalent runtime subjects

A runtime limit from 9 to 10 binds `Index<limit>`, retaining payload 8 below the exact captured limit.

Every place supplies an independent immutable alias to `forward`, then stores
its result under the original subject. The constructor/argument and result
checks must prove their equality; selection cannot use a runtime value as a
second specialization key. Each twin increments only the supplied alias and
must reject exact index equality. Exact mirrors and all four entry bindings are
authored. Qualification, host execution and whole-item acceptance remain open.
