Parent: WIRE-CODEC-LIBRARY / SEMANTIC-REFLECTION.

Fact: Owned semantic schemas retain complete numbered mixed-data descriptions and graph-local relationships under the query author's authority.

The nearest row is `typed_reflection/generic_owner`, which elaborates typed
callbacks over a live subject. This row materializes the complete owned
description graph without a runtime subject, then transports that graph to an
ordinary runtime inspector. Its twin tests lexical query authority rather than
callback type coverage: only the selected helper changes to a foreign-authored

The mixed carrier distinguishes authored order from stable-number order,
common fields from cases, payload numbering from enclosing numbering, retired
numbers from live members, and complete qualified field type from plain u64.

immutable storage contains no compiler/evaluator handle and grants no access.
Node views and relationship lists borrow graph records under ordinary custody.
Runtime disagreement traps, including reordered cases, synthetic fields,
misowned payloads, dropped qualifications or retirement, and changed canaries.
