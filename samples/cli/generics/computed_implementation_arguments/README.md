# Computed implementation arguments

Run `omega run samples/cli/generics/computed_implementation_arguments/main.omg`.
The selected implementations must return seven and eight, producing exit zero.
`omega run --both` exercises the same authored result through Terminal Psi.

Computed arguments retain their authored expression until the selected
implementation supplies the const carrier. The same checked evaluation route
serves grouped arithmetic, named constants, and admitted machine calls; it must
not truncate anonymous fractional intermediates or accept runtime values.
