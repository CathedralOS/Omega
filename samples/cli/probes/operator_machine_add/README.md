# operator_machine_add

`pub machine + Wrapped::add` — a fixed token after `machine` binds `+` on borrowed test-owned operands; `left + right` invokes the declaration body (wrapped sum 250+10=260 past u8 range); the same declaration stays callable as `Wrapped::add`.

Compile-checked only: no standard-library dependency and
no `Main::exit` — run a check target, not native.
