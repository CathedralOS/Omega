# extent_qualifier_field

First sample importing `omega::language::core::extent`
depend-free: `Extent in Granted & Vacant` carries the
dormant-content qualification into a Vacant-qualified field
(only the qualifier-free shape strengthens implicitly), and
`held.e as Extent` erases both qualifications.

Compile-checked only: no standard-library dependency and no
`Main::exit` — run a check target, not native.
