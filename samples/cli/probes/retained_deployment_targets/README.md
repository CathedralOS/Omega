# retained_deployment_targets

Deployment tags beyond the bound four: `archive_target`/`reserved_target` bodies are checked and retained without supplying execution demand. `boundary trait Unused { machine read(helper: &Helper) -> u32 reaches; }` one-member boundary-trait requirement; `satisfies Value<Helper>::unrealized, Unused::read` multi-requirement roster on one body; `uefi_x86_64` same-target caller resolves its own family's `Helper::internal`; unrequested cyclic bodies retained.

Compile-checked only: no standard-library dependency and
no `Main::exit` — run a check target, not native.
