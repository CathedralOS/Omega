# service_slice_entry

First sample lending a fixed array field from a Fused
entry receiver: `Binding<Ping>` rides provider selection
while `Worker::drain(&mut main.items, ...)` projects
`[u64; 3]` into `buf: &mut [u64]` through the ordinary
borrowed-view presentation.

Compile-checked only: no standard-library dependency and no
`Main::exit` — run a check target, not native.
