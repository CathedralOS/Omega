# numbered_case_data

Canonical case numbering: `#1 case Found(#1 value: T, retired #2)` numbers case, payload member, retired slot; `retired #3` retires a case identity. Stable data metadata, not the runtime discriminant.

This probe's source and parser still require migration under
`PREFIX-CASE-IDENTITIES` in [TASKS.md](../../../../TASKS.md); the canonical
spelling above is not a fresh compile result.

Compile-checked only: run a check target, not native.
