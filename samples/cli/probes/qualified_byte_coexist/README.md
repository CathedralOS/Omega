# qualified_byte_coexist

Plain `[u8; 4]` and `[u8; 4] in Utf8` of the same
extent coexist in one owner — independent structural
plans: `head(&plain)` lends bounded, `text == "gate"`
compares a qualified array to a byte literal whole.

Compile-checked only: no standard-library dependency and
no `Main::exit` — run a check target, not native.
