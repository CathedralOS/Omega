# suspend_param_binding

First sample suspending through a `Binding<Scheduler>`
PARAMETER — `machine inspect(...) suspends; reaches
Scheduler` — proving the Fused-provider gate that blocks
`Binding<T>` carrier FIELDS does not apply to parameter
positions at --check. `boundary data Lease` opaque payload
rides the message.

Compile-checked only: freestanding target — run a check
target, not native.
