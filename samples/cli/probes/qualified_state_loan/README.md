# Qualified state loan

A local record carries a proven nonzero identity. A state borrows the record
and observes 73 through that qualified loan. Expected exit: 0.

The loan keeps the owner's address and qualification. Membership does not
require another native representation, and lending storage does not extract
or reissue its contents.

Run `omega run --both samples/cli/memory/qualified_state_loan/main.omg`.
