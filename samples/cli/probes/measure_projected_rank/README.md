# measure_projected_rank

`countdown.remaining -> Countdown::Doubled in 0..=limit` — a computed
measure over a projected member coordinate with the telescope ceiling
pinned from a `requires`-bound parameter; two-state form transports the
coordinate and bound through `state step(current, bound) requires ...`.

Compile-checked only: no standard-library dependency and
no `Main::exit` — run a check target, not native.
