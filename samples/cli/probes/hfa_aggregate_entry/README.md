# hfa_aggregate_entry

Homogeneous floating aggregate entry arg: `boundary machine Main::main(main, pair: Pair{f64,f64})` — flat HFA arrives by value under freestanding build; field projection reads it (AAPCS64 v0/v1 classification at native).

Compile-checked only: no standard-library dependency and
no `Main::exit` — run a check target, not native.
