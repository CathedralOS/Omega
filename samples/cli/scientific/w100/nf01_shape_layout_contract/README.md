# NF01 shape/layout contract

Two complete consumer projects use the numerics package and existing Linux
Console provider. `EXPECTED.txt` freezes the mathematical oracles before runs.
The separate invalid control violates the documented checked-index contract;
runtime invalid layouts are handled separately by the consumer try operations.

From the repository root, for each consumer:

```
omega update --project samples/cli/scientific/w100/nf01_shape_layout_contract/readonly_consumer --target linux_x86_64
omega --check samples/cli/scientific/w100/nf01_shape_layout_contract/readonly_consumer/main.omg
omega run samples/cli/scientific/w100/nf01_shape_layout_contract/readonly_consumer/main.omg
omega run --both samples/cli/scientific/w100/nf01_shape_layout_contract/readonly_consumer/main.omg < /dev/null
```

Repeat with `mutable_consumer`. Check `invalid_control/main.omg` expecting
rejection. Review package decisions generated by update before accepting.
