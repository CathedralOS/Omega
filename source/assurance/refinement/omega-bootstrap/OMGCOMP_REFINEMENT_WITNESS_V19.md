OMGRFN19 is a two-component structural carrier. Its 32-byte little-endian
header has magic `OMGRFNJ\0`, major 19, minor zero, flags zero, header size 32,
exact total length, exact OMGCOMP3 length, exact OMGRSW9 length, and one zero
reserved word. Exact nonempty OMGCOMP3 bytes immediately precede exact nonempty

The OMGCOMP3 build role is authoritative only for deciding which source inside
this requested structural envelope may contribute build selections. The frame
does not establish that the envelope or source closure was accepted. That
requires the separately unpublished accepted-closure projection and expected
envelope SHA-256 join.

## Selected relation

The OMGRSW9 component is exactly 2,304 bytes with magic `OMGRSW9\0`, major 9,
minor zero, flags zero, and a 144-byte header. It reconstructs one selected

ranked `console_write_bytes` helper, two checked adapters, four target-qualified
compiler-intrinsic leaves, one explicit BuildOverride selection, one complete

Requirement calls continue to target exact requirements. Selection maps them
to rows in one complete plan; source syntax never rewrites a requirement call
directly to the sole visible realization. The selected plan is structural
policy data, not provider admission.

## Evidence and exclusions

The exhaustive platform-neutral oracle is split into responsibility-local
Python owners and mutations. Representative persisted-Beta projections compile
through both persisted `bc` and self-produced `bc`, require identical assembly,
accept the canonical frame, reject one locally owned mutation, and stay below
the 262,140-byte tape ceiling. The actual native/self OMGCOMP3-to-OMGRSW9
producer composite remains a separate obligation; handcrafted/reference bytes
never substitute for it.

Malformed identity, framing, source custody, role, signature, reach, ranking,
candidate, selection, plan, call, ordering, span, or EOF state selects 251.
Inherited public OMGCOMP3 exhaustion and declared frame/component exhaustion
select 252. Neither failure publishes bytes.

This carrier does not lower or execute an adapter, authorize an intrinsic,
establish a runtime `Service<Console>` installation, admit a provider or
package, reconstruct an artifact, or claim compilation authority.
