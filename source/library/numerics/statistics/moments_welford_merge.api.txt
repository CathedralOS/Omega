Contract:
  reset makes the canonical empty state (0,0,0). No allocation or backing copy.
  m2 is sum((x-mean)^2), maintained by Welford, not E[x^2]-E[x]^2.
  push: delta=x-mean; n'=n+1; mean'=mean+delta/n';
        m2'=m2+delta*(x-mean').
  merge: delta=source.mean-destination.mean; n'=nA+nB;
         weight=nB/n'; mean'=meanA+delta*weight;
         m2'=m2A+m2B+delta*(delta*weight)*nA.
  Source is immutable, destination is exclusive. Self-merge requires an
  explicit scalar snapshot; simultaneous aliasing borrows are not allowed.
  Empty source is identity. Empty destination explicitly copies three scalars.
  There is no hidden heap allocation, source element copy, or matrix ownership.
  Exact integer-to-f64 counts stop at 2^53. Checked count guards precede all
  Wrapping arithmetic; no count rollover is intended to be accepted.
  Nonfinite observations/intermediates are refused; finite-range overflow may
  return NonFinite even when a rearranged mathematical formula is finite.
  Every mutation error leaves destination unchanged. No silent NaN output.
  Malformed state returns InvalidState first. Fields cannot prove historical
  provenance; callers must initialize/reset and mutate through this API.
  m2 must be nonnegative and finite; count=0 requires mean=m2=0;
  count=1 requires m2=0. No silent clipping of negative m2.
  Empty mean/population variance => Empty.
  Sample variance for count<2 => InsufficientSample, including singleton.
  Population variance divides m2/n; sample variance divides m2/(n-1).
  These normalization names are explicit; there is no default ddof.
  Scalar outputs are returned inside MomentValue and must be matched.
  NonFinite is reserved on MomentValue for future policy/adapters; current
  validated scalar query division cannot overflow and does not emit it.
