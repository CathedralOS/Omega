Caller supplies finite initial time, value, positive finite step, and a pure
finite-valued RHS for every stage. This is a mathematical caller obligation,
not a checked finite-value guarantee until NF02's interface is available.
Raw step applies classical RK4 with four RHS calls at t,t+h/2,t+h/2,t+h.
Try trace preflights positive step, steps <= budget and both lengths > steps;
failures return the initial state, completed=0, leave traces untouched and
invoke no RHS. Errors have the preceding priority. No allocation or implicit
copy. Success records initial state plus all steps; untouched suffix is retained.
Zero steps needs one trace slot, returns initial state, calls no RHS.
No adaptive step, interpolation, event detection or endpoint clamping.
