All allocations are caller-visible. factor is an explicit copy of the original;

Algorithm and report contract

For column k, gather the active column into separate reflector scratch. Get its
stable norm from NF09. beta = -copysign(norm, alpha), with alpha == 0 choosing
negative beta. For nonzero norm, tau = 1 - alpha/beta and
v_tail = (x_tail/norm) / (alpha/norm - beta/norm). This scaled form avoids
materializing alpha - beta, which can overflow while beta is representable.
A zero active column produces identity reflector (tau = 0); test the rank
cutoff before division. Apply H = I - tau v v^T to remaining factor columns and
the RHS; store beta on the diagonal and v tails below. Q = H0 H1 ... H(n-1),
Q^T b uses forward reflector order, explicit Q uses reverse application to I.
Use NF12 on the leading n by n upper triangle for full-rank solutions.

QrStatus: FullRank { columns } or RankDeficientUnsupported {
 first_small_pivot, independent_prefix, cutoff }. The prefix is a count of
previously accepted unpivoted pivots, NOT the matrix's numerical rank. A zero
first column followed by nonzero columns demonstrates the distinction. Do not
return a minimum-norm solution, silently perturb a pivot, or solve normal
equations. Unpivoted QR does not supply a rank-revealing guarantee.

LeastSquaresReport: residual = A*x - b using original backing; explicit
residual_norm2; transformed_tail_norm2 (last m-n entries of Q^T b);
normal_residual_norm2 = ||A^T residual||2. Square systems have empty transformed
tail with norm 0. QrReport: ||Q^T Q-I||F, ||A-Q R||F, and rank status.
Report construction requires a completed FullRank factorization; do not read
uninitialized tau tails from a stopped factorization. Report calculations are
explicit work, not free metadata; thin Q materialization
and its output backing are requested by the caller. Finite result checks follow
NF02. Absolute diagnostics and any relative versions must be named distinctly.
