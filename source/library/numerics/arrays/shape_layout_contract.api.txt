NF01 API checkpoint v1 — rank two, explicit caller-owned slices
Layout2 [copy] { rows:u64; columns:u64; origin:u64; row_stride:u64; column_stride:u64; }
IndexResult [copy] = Invalid | Ok(index:u64)
ReadResult [copy] = Invalid | Ok(value:i32)
try_offset(layout:&Layout2, backing_length:u64, row:u64, column:u64)->IndexResult
valid_readonly(layout:&Layout2, backing_length:u64)->bool
valid_mutable(layout:&Layout2, backing_length:u64)->bool
transpose(layout:&Layout2)->Layout2
read_checked(backing:&[i32], index:u64)->i32 requires index < backing.len
try_read(backing:&[i32], layout:&Layout2, row:u64, column:u64)->ReadResult
try_write(backing:&mut [i32], layout:&Layout2, row:u64, column:u64, value:i32)->bool

Offsets are origin + row*row_stride + column*column_stride. Strides are
nonnegative; all admitted elements must be within the supplied backing slice.
Empty layouts admit no coordinates; origin may equal backing_length.
Readonly layouts may alias; mutable layouts require distinct offsets. For
positive strides gcd gives the smallest collision delta:
(column_stride/gcd, -row_stride/gcd). It fits iff rows exceeds its first
magnitude and columns exceeds its second. Zero strides reject when repeated.
No allocation or implicit copies. Descriptor copies do not copy backing data.
try functions report runtime invalid data. read_checked exposes the proof
boundary; a statically out-of-bounds call must reject, not return Invalid.

try_read admits the entire readonly layout before selecting a coordinate.
try_write admits the entire injective mutable layout before selecting a coordinate.
try_offset checks one coordinate independently and is element-type independent.
