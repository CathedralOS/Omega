NF03 complex carrier operations — connected public contract

Module: numerics::complex::complex_carrier_ops (requester alias numerics).
Carrier: pub data Complex<T [copy]> [copy] { real: T; imaginary: T; }
No implicit operators, conformance, allocation, matrices, backing slices,
precision promotion or hidden copies. Only f32 and f64 operations are served.

For Format=F32/T=f32 or Format=F64/T=f64:
ComplexFormat::add(destination: &mut Complex<T>, left: &Complex<T>, right: &Complex<T>)
ComplexFormat::multiply(destination: &mut Complex<T>, left: &Complex<T>, right: &Complex<T>)
ComplexFormat::conjugate(destination: &mut Complex<T>, input: &Complex<T>)
ComplexFormat::norm_squared(input: &Complex<T>) -> T
ComplexFormat::try_magnitude(input: &Complex<T>) -> ComplexMagnitude<T>

ComplexMagnitude<T [copy]> [copy] = Value(value: T) | NonFiniteInput | Overflow.
This outcome is specific to complex magnitude. Scalar input/result classification
uses numeric::numeric_accuracy_policy::classify_f32/f64 and NumericClass;
Finite, PositiveZero and NegativeZero are admitted. NaN and either infinity
reject as component inputs. A nonfinite final magnitude after finite input
admission is Overflow. This does not create a shared numerical error carrier.
Shared inputs may alias one another. Destination must be disjoint from every
input for the call duration. Callers needing an in-place update explicitly copy
the input into a separate carrier first. Fields are public and mutable.

Numerical policy:
- Format remains unchanged. Each +, -, *, / and sqrt uses the selected core
  floating provider and its IEEE binary32/binary64 nearest-even semantics.
- Multiply uses four rounded products, then one rounded subtract and add.
  No fused multiply-add or reassociation is requested. Results may overflow
  or contain NaN; raw add/multiply/norm_squared do not report errors.
- Conjugate copies real and applies core negate to imaginary, preserving
  the sign-change semantics for signed zero and exceptional values.
- norm_squared is re*re + im*im, not magnitude, and can overflow even if
  magnitude is finite. It is not claimed to be a robust scaled norm.
- try_magnitude refuses NaN/infinity components, takes absolute values,
  orders high>=low, handles zero before division, then evaluates
  high*sqrt(1+(low/high)*(low/high)). A nonfinite final value is Overflow.
  Scaling prevents avoidable square overflow; small ratios may underflow.
  No correctly-rounded hypot guarantee, relative-error bound for all inputs,
  NaN payload guarantee, or sign-of-zero magnitude guarantee is promised.
- Fixed fixture tolerances live in the samples' ORACLES.md; those checks
  do not constitute a general numerical accuracy theorem.

The two real consumers select these exact public declarations and apply the

No universal accuracy guarantee or alternative comparison policy is inferred.
