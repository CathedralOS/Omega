This program reads and updates two cells of a nested array through an explicit access policy. The inner array length comes from a compile-time function, and `size_of<Values>()` waits for target layout. Both queries must preserve the generated accessor's exact dimensions and permissions. The runtime checks both original values, both replacements, the storage size, and the untouched nonzero neighbors.

The matching permission controls are `tests/omega/fail/layouts/placed_primitive_denied_write` (policy forbids the write) and `tests/omega/fail/layouts/placed_primitive_lookalike` (an ordinary value is not an accessor). This is a regression for the compiler repair needed by Cathedral's placed page-table access; it does not claim Cathedral boot or nested LayoutStorage access support.
