a Console provider call, and a subsequent remainder. Empty stdin selects 37;
a second invocation selects 81. Native and Terminal must emit `3781`, with empty
stderr and exit 0. Recovery may shorten an unhomeable range through existing
validated copies, rematerialization or spill storage; it must never assign an
incompatible register or drop the surviving source value. The watershed sample
provides the larger witnessed composition and varied inputs.
