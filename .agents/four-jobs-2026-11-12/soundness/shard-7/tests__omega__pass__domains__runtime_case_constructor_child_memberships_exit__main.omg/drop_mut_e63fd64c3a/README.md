# Completed issued case children

Run `omega run --both main.omg` from this directory, or use
`cargo run -p omega -- run --both tests/omega/pass/domains/runtime_case_constructor_child_memberships_exit/main.omg`
from the repository root.

The common child copies an issued value before a later constructor child
replaces its source. The payload completes an independent issuer call. Both
members must retain their exact occurrence's membership and bytes through the
case's ordinary owned call argument, whether bound first or constructed inline.
An omitted zero-valid structural sibling must not drop those facts. An empty
case still requires its common member's issuance, without demanding inactive
payload membership. The native and Terminal executions exit 0.
