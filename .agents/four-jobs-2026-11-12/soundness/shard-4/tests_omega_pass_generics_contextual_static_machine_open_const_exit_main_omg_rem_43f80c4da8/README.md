A named callback's type application is determined by an array whose extent
belongs to the caller's const telescope. The source wrapper must admit that
symbolic application without manufacturing a closed executable instance.
The concrete call later closes Count=2 and must produce native and Terminal 0.

Run: `omega run --both main.omg`.

Pins caller-scoped const substitution through callback admission and executable
closure. Neither an unused binder nor an unsatisfied provider bound may be
erased when the selected provider's telescope is applied.
