# Internal constructor arms retain their source frontier

One match arm builds a pair by consuming `first` and `second` through calls.
The sibling builds its first field from a nested selection of those same
incoming homes. All three paths execute with their authored 11/11/22 result.

The outer dispatch must restore its incoming source names before emitting a
sibling. Completed child captures retain their exact homes, while the next
constructor owns their actual transfer. Unselected owners keep their checked
cleanup duties.

The reject twin is
[`sibling_constructor_same_arm_reuses_owned_source`](../../../fail/drops/sibling_constructor_same_arm_reuses_owned_source/main.omg):
it changes only the first arm's second operand from `second` to `first`.
The compiler must reject consuming `first` twice on that execution path.
