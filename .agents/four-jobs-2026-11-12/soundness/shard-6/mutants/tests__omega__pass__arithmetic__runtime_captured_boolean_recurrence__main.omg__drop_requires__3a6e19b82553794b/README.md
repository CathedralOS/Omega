# Captured Boolean arithmetic conditions

A saved Boolean retains consequences about the values it observed. Selecting
its true or false arm may use those consequences, but cannot reread replaced
storage or assert an individual conjunct from a false conjunction.

The decimal recurrence comes from Cathedral's UEFI serial reporting. This
fixture runs recursive and helper calls, copied local conditions, copied record
fields, the false polarity of a comparison, field replacement, and a condition
whose original numeric source has since changed. Native and Terminal execution
must both return zero. It does not change arithmetic policy: the runtime
Trapping operations supply values only on their normal continuations.

The `captured_boolean_replaced_scalar`, `captured_boolean_replaced_condition`,
`captured_boolean_exposed_condition`, and `captured_boolean_wrong_polarity`
rejection fixtures pin numeric replacement, Boolean replacement, opaque
exclusive exposure, and the unsound extraction of a conjunct from its denial.
