A call result owns a record with a mutable byte-view field. A separate ordinary machine receives that record and transfers it to an internal state before lending the same field to a shared call. The backing remains in the suspended caller; this does not ask a state jump to preserve a source-local backing home. The mutable count changes from 2 to 3 and the original independent literal length guarantee remains. The boolean result observes both the actual length and byte 30; Trap distinguishes a wrong result. Authored native and Terminal exits are 0; execution is required before acceptance.
