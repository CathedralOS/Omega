# Fused computed borrow namespace

Cathedral gallery `damage::prepare::compare` calls a scalar predicate on borrowed
local records inside a terminal nested-machine cycle. The emitted fused body
must retain the complete type, storage and domain requirements of each computed
producer in its original declaration namespace. Its dispatch head is not the
source owner of every computation.

The frozen positive refuses on optimized producer
`d43c13258401ad9bdff6c1503ff18f73d6787ff737fc527474d0356b4f258ccf`
with `computed producer has no structural type namespace`. The runtime oracle
requires the predicate to select the writing branch and complete the cycle.
The reject twin changes only the record multiplicity to linear; borrowing it
does not retire either owned record.

This is a rung for the named Cathedral UI customer, not a completed capability
or nine-place fact row. Windows gallery execution and the broader compiler
capability remain separate acceptance.
