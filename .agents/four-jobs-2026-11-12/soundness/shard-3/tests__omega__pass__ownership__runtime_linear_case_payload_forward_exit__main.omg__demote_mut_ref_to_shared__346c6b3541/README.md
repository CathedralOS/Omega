# Linear payload custody through an unexamined sum

Each known constructor passes through a helper that returns the sum without
examining its discriminator. The receiving helper consumes only the selected
payload, exactly once. Native and Terminal must both exit 0.

A nested sum also passes as a projected argument. Its payload claims cross
below that argument path, while the containing owner's residual debt remains
with its caller.

Run `omega run --both tests/omega/pass/ownership/runtime_linear_case_payload_forward_exit/main.omg`.
