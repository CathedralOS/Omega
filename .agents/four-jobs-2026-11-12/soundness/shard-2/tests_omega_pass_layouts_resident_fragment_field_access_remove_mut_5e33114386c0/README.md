# Resident field composition

A bool field shares one physical byte with an inaccessible bool neighbour. Changing true to false must leave the neighbour true, preserve seven initialized padding bytes and preserve the unused allocation tail.

This is an embedding entry, not a hosted native ProgramEntry. Terminal execution has been exercised with actual admitted provider storage. Native scalar access currently refuses this packed codec: its whole-container operation cannot project fragments or preserve neighboring bits. A partial native write must also prove supply for its physical read-modify-write.
