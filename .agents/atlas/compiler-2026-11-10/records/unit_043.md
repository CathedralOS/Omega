## selection.rs (4732 lines) - read in full

### Purpose
Declaration selection that lexical lookup cannot settle, run in a fixed order by `resolution::drive` (header 1-10): operator homes before symbol assignment; after symbols exist: authored-selection ledger, nominal machine-parameter requirements, closed conformance rows, domain establishment routes, evidence forwardings, service reaches. ## selection_authored.rs (1737 lines) - read in full

### Purpose
The authored-selection ledger: for each authored source token that names a declaration (call target, operator, member, struct literal type/field/case, path segment, domain membership, static operand, conformance bound), mint one occurrence in `program.authored_declaration_selections()` and attach the occurrence id to every compiler-derived copy of the expression (header 1-9).

### Shape
- `CandidateTarget{Resolved(SymbolHandle), LateBound(LateBinding)}` (36); `Candidate` (42); `CandidateGroup` (50); `UnattachedCandidate` (766); `AuthoredStatementCallCandidate` (351); `AuthoredStatementCallSite` (338).
- Entry points: `finalize_authored_expression_selections` (172, pub(crate)); `normalize_case_membership_facts` (276, pub(super)); `finalize_normalized_static_operands` (672, pub(super)); `finalize_conformance_reference_selections` (733, pub(crate)); `finalize_constant_expression_selections` (1540, pub(crate)); `original_call_target` (110, pub(crate)).
- Internals: `reconcile_copy_targets` (61), `expression_candidates` (1197), `finalize_expression_groups` (1555), `collect_authored_statement_call_candidates` (359), `finalize_authored_statement_call_selections` (423), `finalize_statement_static_argument_selections` (888), `call_selection_index` (486), `existing_call_occurrence` (528), `contract_clause_expression_handles` (1068), `collect_expression_subtree` (1087), `package_qualifier_member_count` (1175).

### Inputs and outputs
Reads the symbol-resolved program, `PendingAuthoredExpression` and `PendingAuthoredProofMembership` sidecars from the lowerer; mutates the ledger (`record_resolved_/record_late_bound_authored_declaration_selection[_in_partition]`), attaches occurrences to expressions (`attach_authored_selection_occurrences`, 1693), writes `call.target_symbol` when invalid (1699-1705), `call.authored_call_binding = Some(ResolvedAuthoredCallBinding{selected, original})` (1711), `authored_call_selection` on statements/transition targets (637, 653), `authored_static_argument_selections` (980), `membership.authored_domain_selection` (262), and replaces `ProofFact::Membership` by `ProofFact::Expression` for case memberships (328-332).

### How it decides
- Grouping key for copies of one token: `(source_span, exposure, kind, compiler_partition)` (1596-1601). Identity = source SPAN plus kind plus partition.
