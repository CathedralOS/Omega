### 1a. activation_storage (11-780)
1. Purpose (read). Interpreter side of activation claims: a bounded byte reservation made per call frame. Establish checks `committed <= bound`, mints a result value in the "established" or "rejected" case, and (if established) allocates zeroed backing bytes, a ledger claim, and a byte-sequence descriptor. Release, split and merge change the ledger and the published descriptors.
2. Shape (read). `RuntimeActivationLedger` (33) wraps `extents::ActivationClaimLedger` plus an accounting lease. `RuntimeActivationStorage` (122) has `ledgers: RuntimeRows<Frame,..>` where `Frame=(usize, MachineId)` (121), `grants` (frame, claim id, operation id, claim type) keyed by owner place, `owners`, `claim_descriptors`, `split_children`. Entry points on `TerminalExecution`: `execute_establish_activation_claim` 177, `is_live_activation_descriptor` 319, `execute_release_activation_claim` 341, `complete_activation_storage` 475, `execute_split_activation_claim` 486, `execute_merge_activation_claim` 577, `prepare_activation_division` 671, `publish_activation_division` 730.
3. Inputs/outputs (read). Reads operation kind, scalar values (`committed`), `live_claims`, `live_affine_frontier`, `call_stack`, byte descriptors; writes `structural_cases`, `structural_values`, `structural_byte_storage`, `live_claims`, `live_affine_frontier`, and the five activation tables.
4. How it decides (read). Established = `committed <= bound` (212). One grant per (frame, operation id) (204-211). Frame identity is `(call_stack.len(), current_machine)` (203, 335, 364, 476, 527, 641). Release refuses unless the grant frame equals the current frame, no live reference loan, the live claim set has exactly one claim equal to `claim` with empty path (373-376), and no retained byte loan exists in the current or any caller frame (415-451). Merge succeeds only when `lower_home == upper_home` (637) and `split_children` has a recorded pair for that home (642-652).
5. Cases by shape (read). Establish requires `result.claims` to be exactly one binding whose path ends in `Field` (275-280). Release requires the binding to be `MutableOwner` with `ByteOwnerHome::Storage` (356-362). Division descriptors are kept only for bindings whose last segment is `Field` and that sit on the published case (696, 748-756).
6. Same job elsewhere. `RuntimeActivationLedger::reserve_claim`/`retire_claims` (48-67) repeat the "grow one cell on a lease, else reserve from account" logic of `reserve_row` and `retire_removed_rows` in `runtime_rows` (4754-4768, 4824-4828) (both read).
7. Unused/one-caller (grepped). `is_live_activation_descriptor`, `complete_activation_storage`, `retire_reentered_results`, `owns_allocated`, `reserve_host_at_cursor`, `PrimitiveStorageHome::captured_frame` together: 18 occurrences in 7 files (Grep count on the combined alternation, includes definitions). Not separately counted.
8. Stated limits. None in this module.
9. Fail-open. (a) `split` swallows any ledger `split_claim` error with `.ok()` (102-103) and returns `Ok(None)`; the caller publishes `rejected_case` (568-572). Wrong program getting through: none, it routes to the rejected case, but the error kind is discarded. Open (no comment). (b) `merge` swallows any ledger error with `.ok()` (113); caller publishes `rejected_case` (666-667). Same. (c) Different homes at merge go to rejected case (637-639). All three lead to the rejected branch, not acceptance.

### 1b. primitive_storage::aggregate_projection (805-1040)
1. Purpose (read). Builds and reads/writes a `Projection` endpoint: a scalar window over an aggregate made of bit fragments of several backing scalar cells.
2. Shape. `mask` 810, `projection_bits` 817, `aggregate_projection_storage` 834, `read_storage_projection` 927, `PrimitiveStorageWrites::pending_storage_value` 948, `stage_projection` 992.
