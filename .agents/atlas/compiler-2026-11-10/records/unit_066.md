## File-level purpose

Header comment (1-5): "Attached Unit closure assembly (`lower_unit_closure`, `lower_unit_effect_closure`): transitive call catalogs, boundary and provider admission, signature and parameter allocation, ordinary machine emission, and scalar/structural completions." The file is one `pub(crate) use crate::unit::*` (7) plus one giant `pub(crate) mod inner` (9) holding about 30 nested submodules. It takes the checked trees (`CheckedTrees`, plans in `checked.facts.flow.terminal_unit_effects`) and produces the Lowered Psi / Terminal Psi declarations for a program: boundary machines, structural types, structural domains, services, provider conformances, target families, native/target layouts, scalar applications and conditions, machine signatures, and the emitted ordinary machines. It is a catalogue of lowering stages, not one algorithm; each submodule is one stage. (The top-level driver functions named in the header, `lower_unit_closure` / `lower_unit_effect_closure`, are not defined in lines 1-12700; see later section.)
