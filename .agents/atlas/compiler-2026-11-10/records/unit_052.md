## File 1: `P05/src/checks_current_scalar_values.rs` (6740 lines, read in full)

### Purpose
Builds, for one point in one state's statement list, a "current roster" of what is known about integer values, collection (slice / fixed-array) lengths, scalar record fields, saved Booleans and call guarantees. It replays the statement prefix of a state (initial entry facts, `requires`, then each statement in admitted execution order) and tracks captured values as `ScopedArithmeticValue`s, retiring entries when a write may have reached them. Downstream proof code (contracts, calls, ranking/termination) asks this struct for goals and values to feed the scoped arithmetic prover in the `validation` crate (header comment 1-36).

### Shape
- `pub(crate) struct CurrentScalarValues<'program>` (4501-4526): `program: &dyn CheckingInput`, `machine`, `state`, `statement_index`, `initial: Vec<Binding>`, `current: Vec<Binding>`, `lengths`/`initial_lengths: Vec<Length>`, `fields: Vec<ScalarField>`, `result_fields`, `conditions: Vec<ConditionBinding>`, `hypotheses: Vec<ScopedArithmeticHypothesis>`, `anchors: Vec<(CanonicalPlace, Snapshot)>`, `completed_calls: CompletedCallGuarantees` (lent by the caller), `scalar_observations: OnceCell`.
- `Binding` (4422-4438): symbol, name, `value: Option<ScopedArithmeticValue>`, `alternatives` (match-arm values, max 8, 5746), `immutable_coordinate`, `unwritable`.
- `LengthSubject` enum (4440-4460): `Storage(sym) | Result(sym) | Field{owner,path} | ResultField{owner,path}`; `Length` (4463-4470) with `stable` flag.
- `ScalarField`/`CapturedScalarField` (3545-3558), `ScalarProjection {Field, Case, Element{source, selector}}` (3332), `CallArgumentProjection` (4532), `ScopedOccurrence` (6366), `EntryValue` (4477).

### Inputs and outputs
Reads: typed-tree expression/statement/type tables via `program: &dyn CheckingInput`, contracts via `program.state_contracts` / `machine_contracts` / `proof_facts` (4794-4809), the storage graph via `program.storage_graph()` (5255), `validation::CallFrameResolver` (frames), and many `validation::*` helpers (e.g. `scoped_arithmetic_implication`, `scoped_arithmetic_values_relation`, `scoped_completed_call_guarantees`, `captured_numeric_observations`). Produces `ScopedArithmeticExpression` goals / `ScopedArithmeticValue`s, `CheckedEntryIndexBound` rows (3820), and mutates its own rosters; nothing is written to the program.

### How it decides
- Replay order and effect retirement: `replay_prefix` iterates `order.indices()[..position]` (4818); each write calls `retire_unpreserved` (5251), which keeps an entry only if `immutable_coordinate`, `unwritable`, already empty, or `place_preserved_since(graph, at, place, anchor)` says so (5276-5284). With no graph position (`at == None`, or no `storage_graph()`) the closure returns `false` -> entry retires (5257-5271). Lengths with `stable` are never retired (5315).
- Identity keyed on `SymbolHandle`/`ExpressionHandle`/`CanonicalPlace` for places; call-site memo keyed on `(machine, state, CompletedSite)` and re-derived if `actuals`, `machine_values` or `result` differ (284-296). `CompletedSite::Statement` uses the **address** of the call row (`std::ptr::from_ref(call) as usize`, 256).
- `admitted` (6500) decides whether an expression is inside the "integer vocabulary": Integer/Boolean, casts, integer-embedding calls, member/indexed with a length/field/window read, names with a value binding, binary ops from a fixed operator list (6543-6560). Depth capped at 64 throughout (e.g. 6514, 1166, 1408).
- `capture_at_depth` (5474): case ladder: named binding -> integer literal (i64 only, 5495) -> call with `normal_return_integer_bounds` -> member/index reads -> preserving cast -> Add/Subtract/Multiply in Exact or Trapping domain only (5632-5636) -> match join -> `admitted`+`scoped`.
- `matched_length` (1303): arms agree if equal, or fold to the same exact integer, or `proves_values_relation(Equal)`; otherwise `None`.
- `window_bounds` (1690): range ordering `0<=start<=end<=source` and `0<=authored_end` must be proved (1727-1742) unless `range_operator_establishes_endpoint_extent`.
- Field selection by identity, with one name fallback: `selects_field` uses `member_symbol` if valid else compares `symbols.name(field) == member.member.as_str()` (1986-1995) -- a source-spelling compare.
- `static_argument_value` (574) has spelling-based branches: `name.as_str().parse::<i128>()` for an unresolved `Named` type (608) and `static_const_argument_spelling` then `parse::<i128>()` (630-640).
- `entry_selector_value` (3444) rejects selectors that name non-parameter, non-bound, non-const symbols (3463-3482).
- Conditions: `capture_condition` (5358) handles `x == true/false`, `a && b` (when holds) / `a || b` (when not holds), `!x`, then falls to `admitted`+`scoped`.

## File 3: `P05/src/checks_multiplicity_borrowed_windows.rs` (2003 lines, read in full)

### Purpose
Implements the "borrowed-storage invariant window" check: a consuming move out of storage reachable through `&mut` leaves a hole; until a later store of the exact type reseats it, any read/borrow/move/store touching that place or an enclosing owner is rejected, and every exit must find the window closed (header 1-30). Also checks that calls/boundary operators are not made while a window is open, and handles agreement of holes across `match` arms.
