## 2. S/selection_interrupts.rs (2080 lines) -- READ IN FULL

**Purpose.** Emits the selected-instruction stream for x86_64 static interrupts. Header (1-4): "We select static interrupt installation, helper calls, guard checks, stack/table layouts, and static interrupt invocations". Installing an interrupt table produces a long run of emitted compare/load/refuse instructions that validate an IDT-like gate table, a GDT, a task-state structure, stacks and arrival rosters at run time, then publish them; invoking a token (`Context`, `FinishCompletion`, acknowledgement) checks a root word and updates it.

**Shape.** Four `pub(crate) mod`s, all written against the `Builder` from `crate::selection::construction::scalar_graph::structural` (imports at 7-26; module paths are re-exports, so the call sites in `selection_structural.rs` use `interrupt_installation::emit` at 5387 and `static_interrupts::emit` at 5437):
- `interrupt_installation` (6-478): `emit(function, source, row, builder)` (45-279), `control_home` (281-322, allocates a `LocalStorageSlotId::Boundary{operation}` of `guards::CONTROL_BYTES`=128 bytes, align 16), `publish` (324-477), nested `address::prepare` (28-39, wraps `calling_conventions::interrupt_gate_address`).
- `interrupt_installation_calls` (480-611): `struct Invocation` (488) implementing `InvocationArgumentSource` (492-518, with empty ownership/work lists at 501-506), `emit(function, source, row, role, call, builder)` (520-610) for the two helper calls `InstallationCallRole::Validate` (returns a Boolean register) and `Work` (no-normal invoke).
- `interrupt_installation_guards` (613-1791): nested `checks::Checks` (631-881: `constant`, `binary`, `add`, `compare`, `equal`, `require`, `equal_constant`, `at_most`, `aligned`, `address`, `load`, `scratch`, `save`, `reset`, `increment`, `iterate`), `layout::Layout::prepare` (882-935; `Layout` is `crate::InstalledInterruptOperandLayout`, defined in `lib.rs:53`, not read), `pairs::validate` (936-1103), `stacks::validate_arrivals` (1106) and `validate_stacks` (1160), `table::validate_table` (1282) and `validate_code_selector` (1377), `with_validated` (1470-1715), `view_words` (1717), `bounded_view` (1728), `root_interval` (1744); consts `CONTROL_BYTES=128`, `CONTROL_ALIGNMENT=16`, `DESCRIPTOR_OFFSET=48`, `GATE_INDEX=64`, `ARRIVAL_INDEX=72`, `STACK_INDEX=80`, `MATCH_COUNT=88`, `TIMER_ROOT=96`, `STACK_TOP=104`, `PAIR_BASE=112`, `PAIR_END=120` (1437-1445, 939-940); `struct GuardEntry` (1447), `struct ValidatedInstallation` (1454).
- `static_interrupts` (1793-2080): `emit(source, row, builder)` (1810-2004) for `InstructionKind::StaticInterrupt` ops; helpers `load` (2007), `store` (2037), `require_equal` (2056).

**Inputs and outputs.** Reads `LegalizedScalarInstructionKind::InstallStaticInterrupt{arguments, indices, calls}` (51-56, exactly six structural arguments: table, gdt, task, stacks view, arrivals view, context; `arguments[0..=5]` used throughout; `Layout::prepare` takes `&[StructuralArgument; 6]` at 915), `builder.interrupt_helpers` (`installation_scope`, `installation_entries`, `require`), `builder.installed_stack_requirements` (sorted, binary searched 133-137), `builder.installed_interrupts` (`cohort.psi()`), `builder.environment.target()`. **How it decides.** Almost all judgments are `SelectedInstructionError::custody_because("...")` rejections with fixed message strings, keyed on identity/equality of operation ids, placement indices and gate offsets:
- `emit` 67 `scope.arguments() != arguments`; 78 `entries.len() != scope.fatal_entries().len() + 1`; 139 `requirement.psi != cohort.psi()`; 154-162 duplicate application/placement/gate rejection; 163-189 ack entry vs fatal entry match found by `application`, `machine`, `gate_byte_offset` and exactly one match required (173-182); 190 `requirement.entry_plan != expected_plan`.

## 3. S/selection_scalar_graph.rs (8055 lines) -- CHECKPOINT A: lines 1-2000 read in full

## Five things a maintainer most needs to know about this unit

1. The four files are one pipeline stage (instruction selection, `selection.rs:693` -> `build_with_environment` `selection_scalar_graph.rs:7067` -> `select_function` 7094). The dispatcher is a two-level chain: file 4's `operation` (`selection_structural.rs:5374`) is tried after several inline arms in file 3's loop (7277-7347); file 3's exhaustive match (7358-7540) is the final consumer and lists every `LegalizedScalarInstructionKind`, so a new kind forces a compile error there but must be added by hand to the right dispatcher level.
2. File 1 is a library of "is this shape well-formed" predicates keyed on `PlaceId`/`OperationId` identity, each finding its row by linear scan of the function and requiring exactly one match; most return `Option` and the callers turn `None` into `SelectedInstructionError::custody()` (opaque). Three hand-maintained lists of "instruction kinds that read a place" exist (`parameter_home_required` 547-649, `requires_descriptor` 2503-2541, `view_access` 2303-2386) and are not shared.
3. `selection_interrupts.rs` is x86-64-only (`static_interrupts::emit` rejects other architectures, 1825) and bakes in architectural constants (gate attribute 0x8e, IST 1..=7, task state 104 bytes, descriptor snapshot 10 bytes, GDT access/flags masks); the 104/10 constants are duplicated in `selection_structural.rs`. The installation emitter produces a long chain of guard blocks via `operation_control` (file 3, 5390-5764).
4. `select_function` skips a literal `Constant` that feeds a compare directly followed by a conditional branch (7282-7287) and relies on `folded_literal`'s "constant has no other use" scan (file 1, 2988-2999) to make that safe; the compare is emitted later as `CompareI64Zero`/`CompareI64Immediate` (file 3, 1339-1398) or by `control::build` (2750-2878).
5. Per-function state is a handful of `Vec`s with linear scans (`Transport.pointers`, `.fragments`, `.local_slots`, `Builder.definitions`) plus `BTreeSet`/`BTreeMap` in `Builder.required_values` (file 3, 7649) and `storage_origin_input` (file 1, 4739); `ReleaseReference | EstablishTrivialAffineLocal` emit no code (file 4, 5522) and `OwnedResult` roots are admitted without producer match in `leaf_copy::reseat` (file 4, 1044).
