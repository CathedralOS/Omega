## 1. R: `checks_ranges.rs` (the index and subslice-range bounds check)

### 1.1 Purpose
Proves, for every indexed access `a[i]` and subslice `a[x..y]` in a machine body, that the index or both range endpoints lie inside the collection's length, using facts known at that statement. It builds a per-state store of facts (`RangeFacts`, in F), seeds it from five sources (state `requires`, facts carried on edges into the state, incoming guards, loop invariants, and the statement transfer), replays each statement, and at each `[]`/`[..]` asks the bounds judgment. It returns either a list of expression handles proven in-range (plus constant coordinates and constant-recipe obligations) or a list of diagnostics (R:10964-11161).

Header comment: R:1-34. The submodules are inline `mod` blocks inside one 11k-line file.

### 1.4 How it decides (what each judgment is keyed on)
- **Fact store keys are rendered expression labels.** `RangeFacts` rows are `(String, String)` etc. keyed by `program.expression_table.display_name(expr)`. `display_name(` appears 85 times in R and 9 in F (Grep count mode over `checks_ranges*.rs`). F's header calls them "legacy expression labels" (F:541-543). A second parallel table (`expression_dependencies`, F:2634) records typed reads (`CanonicalPlace`) behind each label so writes can tell which labels survive. Identity is therefore a label plus an optional typed read set, not a place only.
- **Index proven?** `check_known_length_index` R:6592-6716 accepts if any of: constant interval 0 <= i < length (R:6617-6625), folded integer value (R:6626, 6701), or the OR of: `facts.index_is_proven(collection_label, index_label)`, carrier maximum < length (R:6644), `index_upper_bound_is_proven` (label keyed), via ordering, declared range, ensured call result high, standing bounds, hoist temp initializer (R:6642-6671); and independently a lower bound (unsigned type, non-negative label fact, ordering, declared range, ensured low, standing low) R:6672-6682. Unknown length: `unknown_length_index_is_proven` R:9999 using `index_is_proven`, `index_value_is_proven` vs a `minimum_length`/`exact_length` floor, ensured high, label upper bound vs length floor, ordering chain.
- **Hoist temps by spelling:** `hoist_temp_initializer` R:6512 keys on `index_label.starts_with("__hoist_")` and then finds a `LocalData` whose `name == index_label` (R:6517-6530).
- **Collection geometry dispatch** (R:6205-6286): known length (`expression_indexable_length` or fixed array type length) -> slice/bounded byte type with unknown length -> fixed array with constant recipe extent (`fixed_array_type_recipe`) -> symbolic const-parameter extent -> else `Unsupported` (R:6285).
- **Selected operator custody** (`selected::obligation` R:5920-6049): re-joins the checked operator use at this exact `(machine, state, statement_index, expression)` (R:5931-5940), requires spelling/status/candidate roster to agree, replays the domain selection on freshly derived candidates (`replay_selection` R:6099-6129), and if the collection has builtin array/slice geometry validates the selected operator's `requires` against a fixed list of clause shapes (`clauses::validate` R:5738, `clause` R:5796). Judged on symbols and handles, not names, except `CollectionMeasure::from_authored_spelling(members[1].as_str()) == Length` at R:5897 and R:5907 (`len` spelling).
- **Incoming guard survival** (`guard_survives` R:889-907): guard survives if it names no member path that overlaps a path written in states walked so far (`validation::frame_paths_overlap`, string paths) and no opaque call frame was crossed (`written_any`). Paths are strings from `display_name` filtered by `place_field(data_binding, path)` (R:944, R:1004-1007). Parameters are matched across states by name: `parameter_bound_identically` R:1243-1281 (`target.name == source_parameter.name` at R:1262, plus place identity at R:1273 and a "no same-named local" check at R:1279); `seed_incoming_guard_facts` also pairs parameter roots by name at R:1096.
- **Loop invariants**: natural-loop detection from edges (`natural_loop` R:1765, back sources = edges into `head` from states not reachable without passing `head`, R:2882-2890); counter candidates are direct attached fields written as `self.f = self.f - c` or `+ c` with positive literal `c` (`classify_counter_write` R:3138); direction must be uniform (`loop_modifications_direction` R:3267); entry init must be a constant on every entry edge (`entry_constant_init_range` R:2351); update order must be preserved (`updates_preserve_order` R:1365). Output is `UpperBound(max_init+1)` for decreasing, `NonNegative` if `min_init >= 0` for increasing, plus `UpperBound(bound)` at head from back-edge guards (R:2985-3002), plus `IndexWithin(collection)` (R:3004-3029, 3031-3056).
- **State argument facts** (`calls::collect_state_argument_facts_for_call` R:3545-3859): merges what every incoming call/transition edge proves about each parameter; meets: exact length/integer survive only if all edges agree (`MergedFact` R:4289-4305), min length takes the min, upper bound the max, any unbounded edge poisons (`MergedBound` R:4223-4246), proofs and receiver lengths survive only if every edge carries them (`MergedIndexProofs::merge` R:4331-4338; `merge_contribution` R:4690-4736).
- **Guard seeding** (`seed_binary_guard_facts` R:9631-9816): a fixed match on `BinaryOperator` (Less, Greater, LessOrEqual, GreaterOrEqual, And, Equal, NotEqual; every other operator is listed and does nothing, R:9803-9814). It first calls `peel_boolean_alias_guard` (R:9338): a guard with no builtin decomposed meaning is skipped entirely (returns true to stop, R:9352-9354); a name-headed guard re-seeds from the boolean local's recorded comparison.
- **Type judgments**: unsigned detection by primitive pattern (`expression_is_unsigned_integer` R:10517), `primitive_of_type_reference` resolves `TypeReferenceNode::Named { name }` through `PrimitiveType::from_name(name.as_str())` (R:10600, source spelling of the type name).

## 2. F: `checks_ranges_facts.rs` (the `RangeFacts` store)

### 2.1 Purpose
Holds the mutable per-state fact store used during one state's replay: lengths of fields and locals, known integer values, boolean-guard locals, and a family of label-keyed relations (index in collection, exclusive upper bound, non-negative, ordering, range bound, minimum length, exact length, window parent, const-binder floors). ### 2.4 How it decides
- **Which facts survive a write.** `preserved_expression_labels` F:3531-3603: a label is preserved only when (a) the whole write list is non-`None`, (b) every write's root is a valid non-`Field` symbol (F:3552-3556), (c) the row's reads are non-overlapping with every write (`canonical_places_may_overlap`, F:3572; descriptor reads use `write_covers_place` F:3567-3570), (d) the label is not in `label_collisions`. This is keyed on typed places with the display label as the table key. Label collision (F:3456-3529): two rows with the same label but different machine/state/read sets make the label unusable.
- **Fallback for rows without typed reads: strings.** `write_affects_bound` F:4098-4109: a bound label that is not identifier-shaped (`split('.')` parts of alphanumerics/`_`) is treated as always affected; otherwise `frame_paths_overlap(name, path)` on strings, with `place_field(data_binding, path)` to convert `main.i` to `i`. Used as `string_fallback` in F:3785 and F:3923.
- **Read-set completeness.** `collect_reads` F:2192-2337: every `ExpressionNode` variant is listed. `SavedSubject` is incomplete (false, F:2207), literals complete, `Call` requires a matching checked call occurrence (`find_call`), nominal route, static application carrying no caller storage, then adds operand access places (F:2222-2267), `Atomic` loads must contribute at least one read (F:2329-2332). Depth bound `EXPRESSION_WALK_DEPTH_BOUND` (128). An incomplete read set stores `reads: None`, which "is an incomplete read set, not a storage-free computation" (F:2639).
- **Which indexing/arithmetic nodes are readable.** `has_builtin_index_meaning` F:1802-1871 and `collect_selected_index_reads` F:1611 decide whether an index is builtin or an authored operator call; operator reads come only from an exact `CheckedOperatorUseFact` at the statement (F:1650-1687). A constant-shaped authored arithmetic application is refused even with custody (F:1963-1975, 1984-1989).
- **Member field identity for temporaries** `temporary_member_symbol_at` F:1519-1543, `temporary_receiver_leaf` F:1560-1598: `match` receivers require all arms to have the same result type symbol (leaf symbols, not handles). Case-qualified hops stay unproven (F:1530).
- **Roster lookup** is symbol first then name text (F:4821-4833).
- **Ordering and length chaining** use string label equality (`known_lower == lower` etc., F:4478-4482, F:4500-4512).

## 4. Five things a maintainer most needs to know about this unit

1. The whole fact store is keyed by rendered expression labels (`display_name`: 85 uses in R, 9 in F), with a parallel typed-read table (`ExpressionDependencies`, F:2634) that decides which labels survive a write. A label whose rows disagree on machine, state or reads is treated as collided and dropped (F:3456-3529). Spelling is the key; typed identity is only the survival check. Name-text fallbacks exist in `roster_lookup` (F:4821-4833), parameter pairing across states (R:1096, R:1262), `starts_with("__hoist_")` (R:6517) and `PrimitiveType::from_name` (R:10600).
2. There are two replays of every statement, but one transfer: `transfer_statement_facts` (R:7259) drives both the checking pass and the state-argument collection, with sinks for the differences (R:7207). The state-argument pass is a fixed point of up to 64 passes that publishes nothing if it does not settle (R:4349, R:4459). The comment claiming a whole-pass comparator test (R:3524) refers to a function that does not exist in the tree.
3. Facts enter a state from five places in this order: `requires`, argument facts, incoming guards, loop invariants, then statements (R:11102-11134). Incoming guards walk back along single-predecessor edges with a write-survival gate and then do a separate meet at joins (R:384-498); `IncomingGuardIndex` is also consumed by borrow overlap, contracts and multiplicity checks outside this file (grep list in 1.7).
4. Index verdicts that are not proven are not always diagnostics. `Unsupported` (R:6271, R:6285) is recorded as "not proven" in `IndexVerdicts` with no diagnostic; `has_builtin_collection_geometry` defaults to true for missing types (R:6074, R:6091), which decides which of two checks owns an indexed occurrence (`ranges_seam_owns`, one outside caller at `checks_operators.rs:1854`).
5. Several inputs are parser-desugar shapes and exact tree shapes: atomic update models (F:1403-1430), `subject == true` shells (R:3183-3205, R:1180), the `__hoist_N` local name (R:6512), and fixed clause shapes for operator `requires` (R:5840-5867). A change to those producers silently turns cases into refusals (or, for `hoist`, into an unproven index).
