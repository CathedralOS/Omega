## Five things a maintainer most needs to know about this unit

1. It is one 13.8k-line file made of nested inline `mod` blocks that mirror what used to be separate files (comments still cite `admission.rs`, `emission/state.rs`, etc., 1227-1262, 10065). Edits must go through paths such as `super::super::super::super::super::`; `emit_state` (6804-8250) and `successor_edge` (8546-10037) are each about 1,450-1,500 lines in a single function.
2. The graph is lowered in a fixed pass order, and later passes patch earlier output in place: `custody_frontiers::prepare` (splits states) -> `admit` (live, entry aliases, claim aliases, exclusive handoffs) -> `emit_state` per live state -> `captured_loans.finish` -> `loaned_local_homes::finish` -> `loan_chains.finish` -> `continuation_specialization::complete` -> `affine_cleanup::complete` -> crash routes -> `ranking::retain` (10791-11241). Storage disposal for lent locals is not decided when the edge is emitted; it is inserted afterwards into terminator `cleanup_actions` by the three `finish` passes, in an order computed from operation ids and parameter positions.
3. Three separate loan/lifetime mechanisms coexist for borrowed state parameters: `captured_loans` (descriptor carriers, groups), `loan_chains` + `retained_homes` (exclusive local-backed chains and retained homes), and `loaned_local_homes` (entry-lent locals), plus `entry_aliases` and `exclusive_handoffs` (parameter aliasing and access promotion). They share inputs (`loan_subject`, `transferred_loan_backing`) but each has its own union-find, region walk and rejection strings; this matches the AGENTS.md stop-rule situation (several carriers for one mechanism).
4. Crash-like terminators (`Crash`, `InvokeNoNormal`, `ExternalCompletion`) are skipped by every cleanup-insertion pass (2378, 4359, 5765, 5972) and exempt from window closure (3231, 361-368). Whether that is sound rests on crash routes being handled elsewhere (not stated in this file).
5. Several judgments return "nothing to do" instead of failing when a checked-table row is missing or an enum shape is not recognized: `capture_dispatch_copies` (3564-3571), `custody_frontiers::arrive` `_ => (None,None)` (1528), the unseeded early return in `LoanChains::plan` (4963), the ordinary-path loan fallback in `successor_edge` (9333-9432), and the `continue`s in `retire_observed_references` (12629-12700).
