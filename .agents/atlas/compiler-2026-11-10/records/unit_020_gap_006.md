**How it decides (keys).** All decisions key on machine-instruction identity and register/unit identity, not on spelling. No `display_name`, string compare or `format!` anywhere in the file (read).
- Consumer/producer pairing: `MachineSemanticKind` pair lookup via `condition_materialization_for(producer, consumer)` (187-191) and `terminator_pair_for` (832-836), both generated by the `declared_pair_lookup!` macro (467, 1109; macro defined elsewhere, not read), then `rule.matches_producer(compare_instruction.kind)` (192, 837).
- Flag units: `flag_universe` is built as the union of `implicit_defs` of the three compare constraint rows (136-149, 756-769).
