## File 1: checks_termination.rs (8421 lines)

### Purpose
Decides, once per program, whether each machine (a recursive state machine) really terminates, and records that decision in a `CheckedRankArrivalPlan`. It picks a "ranking" (a number that must strictly shrink around every call/transition cycle: a countdown `Nat::Descending`, a `Nat::BoundedDistance` pair, `Nat::IncreasingTo(limit)`, `Slice::Length`, or a user-declared `measure`), proves the edges decrease, and stores the proof facts and a diagnostic string per machine body. Header comment: `admit_machine_rankings` runs once; later stages "only project accepted observations" (1-17). File is one huge file of nested inline modules (`mod x { ... }`), no tests.

### Inputs and outputs

### How it decides (keys)
- Which machines need judgment: keyed on `machine.termination_plan.implementation_witness.is_some()` AND (cycle in own state graph, or `rank_range.is_some()`, or topology says `requires_arrival_witness`) or being in a joint-ranked component (8021-8038).
- `local_terminates` starts true only when `supply_mode == CheckedBody`, no state cycle and no required arrival witness (8039-8044); a second path sets it true when a component's `source_outcomes` has `Proven` (8045-8057).
- Ranking view selection keyed on the `view_path` STRING of the witness: `witness.view_path.split("::")` (2737-2741), then `path_matches(order, &["Nat","Increasing"])` etc. (2659, 2665, 2711), `RankingViewId::canonical(&order.join("::"))` (2689, 2751), `find_declared_measure(program, order)` (2690, 2762). So view choice is by authored spelling, then by declaration identity.
- Authenticity of the builtin views: `catalog_declaration_is_authentic` (3079-3125) compares `normalized_hermetic_symbol_identity(symbol)` to `format!("toolchain::{}", row.path())` (3091) and checks source origin is Toolchain and relative path equals `row.source` (3097-3105); operators/machines are matched to the catalog row by name strings (3109-3121).
- Default order inference for plain `terminates by x` (2804-2820, `decreasing_value_kind` 2911): unsigned integer primitive -> `Nat`, `Slice`/`FixedArray` -> `Slice`, `length_member` -> `Nat`; else ambiguous.
- Diagnostic text for ambiguity keyed on type display strings: `is_signed_integer_type(name)` matches `"i8"|"i16"|"i32"|"i64"|"isize"` (2867); `declared_measures_for_type` compares `display_name(parameter.type_reference) == type_name` (2889-2892) -- diagnostic only (suggestions), "never selected implicitly" (2800-2802).
- Syntactic fallback tier `nat` (4108-4583): a countdown edge is proven if the argument is syntactically `param - 1` and a guard/`floor` shows positivity. Parameter matching in this tier is by symbol OR by NAME STRING: `parameter.symbol == decreases_path.symbol || parameter.name.as_str() == decrease_name` (4488-4491), and the callee's argument slot is found by `parameter.name == name` (`target_argument_index` 4438-4447). Struct-member countdown matches member name string (`field.name.as_str() == member_name` 4152; `member.member.as_str() == member_name` 4297).
- Joint (private helper) ranks: judged edge by edge by `compare` (1716-1847) using `proves_values_relation`; result `Option<bool>`; edge is rejected on `None`, weak edges collected, and the weak-edge graph must be acyclic (1301-1306).
- Arrival correspondences: `state_edges::select` (5619) chooses coordinate assignment via `validation::select_rank_arrival_correspondence`, proves each edge with `prove_ranking_range_transition`, requires `membership_and_pinning` and, if the edge is inside a cyclic SCC, `strictly_decreases` (5789-5798).
- Source-natural: keyed on `is_indexed_logical_machine` (7111); the rank is the machine's value/const binder (`machine_type_parameters`, 7583) or a realized specialization parameter matched by `generated_from == original` and normalized type identity (7733-7739).

### Purpose
