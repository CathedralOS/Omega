## Five things a maintainer most needs to know about this unit
1. calls.rs 29479-44215 is the tail of one 44,000-line file whose `write_frames` module (6550-39721) is a tree of ~60 `pub(crate) mod`s that all answer variants of "what storage does this reference/call touch" - `stored_calls` (27400-33695), `stored_origins` (33696-37389), `state_write_walk`, `caller_aliases`, etc. Most functions return `Option`/`Result<_, &'static str>` and refuse by returning `None`/`Err`; the refusal strings are the only diagnostic (e.g. 29561-29588, 42..: ~90 strings in argument_correspondence).
2. `stored_calls::invocation_reference_effects` (33180-33447) is a priority-ordered dispatch; five early returns produce `SlotRelationTransfer::complete(Vec::new())` (no effects): asm/IntegerEmbed (33194), `call_preserves_reference_slots` (33266), static call intrinsics (33286), empty destination inventory (33311, 33432), preserved-descriptor interrupt (33379). The first two and the intrinsic one carry no comment.
3. Place identity is tracked in two parallel representations: `PlaceSegment` vectors (`local_segments`) and `String` paths (`local_path`, `place_suffix`), stored side by side in `StoredWriteOrigin` (36898-36906); `frozen_bindings` (34068-34745) mostly decides by field NAME strings and `name_path_members`, while `projections` decides by segments.
4. Call-ordinal numbering (`occurrences`, 43396-44205) is the identity for call sites (`InvocationOutputIdentity{state, statement_index, call_ordinal, parameter}` built at 33487-33492); only calls that can dispatch to a machine (or are byte predicates) consume ordinals (43681, 43767), and statically-unreachable and And/Or-short-circuited subexpressions are skipped (43567, 43623). The effect walker in `expression_effects` skips the same cases separately (31632, 31757).
5. completed_storage_and_conservation.rs: `completed_storage` (5-4674) is a read-only analysis over the flow checker's snapshot graph with explicit work budgets (query 124-138; membership 65_536/128 at 3699/3614; `finite_projection_paths` 4096; `loan_homes` operands*3+1) and fails closed to `Unavailable`; `content_conservation`/`content_projections` (4676-6993) are name-keyed (field names, domain names, algebra names, `"project"`, `"Content"`) after a compiler-ownership gate (`compiler_owned_symbol` 6871) and carrier identity by string compare.
