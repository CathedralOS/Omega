## Five things a maintainer most needs to know about this unit

1. `selected_form_encoding.rs` (this range) is a per-family encode-then-revalidate design: every encoder builds bytes and then calls its own validator, and the generic path accepts only bytes equal to `encode_unchecked`'s canonical output (23990-23995). The one giant `match` in `encode_unchecked` (13835-14139) holds the bytes for most ordinary kinds; kinds it refuses (installed-interrupt, accessor/float, layout-dependent, dedicated forms) are handled by separate modules, several of which live before line 12011 and are not covered by this unit.
2. Exit-contract (`exit_contract.rs`) builds and replays the contract with two near-identical walks (`compute_inner` 235-689 and `check_ordinary_exit_roster` 838-1158) and repeats the policy-promotion match and relaxed-branch test in both. Production custody accepts only `BaselineNearLayoutV1` and `X86RelaxConditionalBranchesToRel8V1` (1322-1330) even though the enum has a post-allocation-optimization variant (used in tests 3006-3027).
3. `validate_non_return` (2094-2607) decides per kind by matching the decoded memory effect; its `(_, NoneV1, _)` arm (2584-2597) accepts any kind outside a hard-coded exclusion list when memory is `NoneV1`, and `expected_control` defaults to `FallThroughV1` for unlisted kinds (2142). New instruction kinds that touch memory must be added to that exclusion list by hand.
4. Foreign-call admission is centralised in `normalized_foreign_call_plan::admit` (2 outside callers: x86 17090, AArch64 13188), but the x86 `table_call` and `system_call` forms do their own partial checks (19590-19611, 19737-19756) and the system-call form accepts only `NativeTarget::linux_x64()`.
5. Target/geometry decisions often key on `NativeTarget` equality and string target names: `layout` matches realizations by `target_name()` string (lib.rs:209-213, boundary_values.rs:136-143); hosted forms accept only linux_x64 and macos_x64; wrapper encoder accepts only `uefi_x64` with one canonical request value (semantic_unit_wrapper_encoding.rs:408-413).
