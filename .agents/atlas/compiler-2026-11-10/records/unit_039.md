   Strings: escapes `\" \\ \n \r \t \0 \xHH` accepted (311-312); `\u` -> profile error (313-318); other -> "unsupported escape sequence" (319-324).

- **Five things a maintainer most needs to know about this unit.**
  1. The evaluation pipeline in lib.rs is a two-phase hand-off: `evaluate_pre_resolution` (lib.rs:201) does syntax-level work and returns a `PreCheckEvaluation` that must later be consumed against the typed program; its pending state is persisted via `compiler_storage::Record` (797-832) and a restored value refuses to run until `rejoin_source_authority` has re-validated source custody (619, 694, 712).
  2. Admission of a machine for compile-time execution (machine_execution.rs:3922-4008) is the single floor for build-time execution: it composes closure checks (authored `requires`, linearity, termination), effect reach (services, suspend, block) and package selection authority. Many "authority" decisions pass whenever the program or the requester is toolchain-owned (3219) or no authority object is supplied (2507, 3842, 4259).
  3. Identity is often by spelling in this unit: name-string compares for enum cases (product.rs 726-761, 3301-3306), for the `Access`/`Accessor`/`::plan` templates and generated accessor names (layouts.rs 2583-2612, 2184-2219, 3891), for `entry_state` (machine_execution.rs 737, 1833), and a program-wide spelling search for unresolved selections (machine_execution.rs 2992-3045).
