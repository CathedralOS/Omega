## What this area does

These nine crates are the data the Psi half of the compiler passes from stage to stage, plus the checks that travel with that data. Source text becomes tokens, then syntax trees (names are still text), then symbol-resolved trees (names carry symbol handles), then typed trees (types, applications of generics, trait scopes, operators). At the far end sits Terminal Psi: a target-neutral program of machines, blocks and operations, with a byte codec that only accepts canonical bytes, and a large library of judgments over that program (where a reference may point, which claims are live, what a call may change). Most of the code is tables and records; the decisions are concentrated in the typed-trees queries, the Terminal codec's receiving validator and the Terminal semantics crate.

**tokens** (776 lines). In: lexer pushes `(kind, span)` or decoded literal bytes. Out: `TokenStream` that owns or borrows source text, and the closed keyword and punctuation vocabularies (`tokens/lib.rs:209`, `tokens/token_kind.rs:18-291`).

**syntax-trees** and **syntax-trees/derive** (11,068 + 85 lines). In: parser output. Out: paged tables of items, statements, expressions and type references whose names are `Identifier` text; copy machinery between forests (`ST/copies.rs:1027`); a JSON snapshot (`ST/inspection.rs:2668`); structural equality through a derive macro (`syntax-trees/derive/src/lib.rs:22`).

**symbol-resolved-trees** (8,885 lines). In: syntax trees after name binding. ## How it decides

Keyed on **identity** (handles, ids):
- Symbol-resolved lookups by exact `SymbolHandle` index and generation (`SRT/declarations_and_machines.rs:580-586`); typed-trees index lookups through `SymbolRows` sorted by `(arena_index, generation)` (`DTI:460-526`).
- Terminal validation and semantics key on `PlaceId`, `StructuralTypeId`, `ValueId`, `OperationId`, `MachineId` (`codec/foundation_validation.rs`, typical lookups are linear scans, 27 uses of the two place-type helpers; `sem/descriptor_replay.rs:5738-5759` slot membership by type shape).
- Type-world reasoning binds `SymbolKind::TypeParameter` sides (`TT/type_system.rs:866-873`).
- Proof-only classification is keyed on `symbol.arena_index()` only, generation ignored (`TT/evidence_and_inspection.rs:192-201, 468`).

Keyed on **place** (root plus projected path):
- Descriptor origins and liveness on `DescriptorLocation{root, path}` (`sem/descriptors.rs:549`, `:628-713`); reference-origin coverage on place, access and path prefix (`sem/references.rs:1767-1845`); path overlap (`sem/structural.rs:2713-2766`); activation claims on root plus path prefix (`sem/storage.rs:170`); membership selection per projected path (`TP/types_and_values.rs:360-396`).

Keyed on **value**:
- Canonical bytes: decode accepts only when re-encoding gives the same bytes (`codec/semantic_module.rs:4115-4118`; artifact container `codec/canonical_artifact.rs:177-182`).
- Elision of proof-bearing scalar operations when the goal reduces to `Truth` under known literals (`sem/scalars.rs:845-957`).
- Closed integer evaluation (`TT/type_system.rs:180`, `TT/values.rs:80`, `TT/values.rs:4154`).
- Proposition and conservation equations compared structurally (`sem/content_transformations.rs:1947-1957`; interned premise handles `sem/descriptors.rs:4102-4106`).

Keyed on **position** (ordinal, arena order, case order):
- Rebase splits stores at a recorded frontier, `index < frontier` (`SRT/control_flow_and_calls.rs:747-798`, `SRT/lib.rs:382-463`, `SRT/values.rs:2775-2803`).
- Access lifecycle outcomes read as `[ready, rejected] = cases` by case order and field counts (`sem/access.rs:98, 158, 277`); activation claim shape `[established, rejected]` (`sem/storage.rs:71`).
- The zero value of a sum is its first case (`sem/structural.rs:5481, 5730, 5782`; `sem/storage.rs:3651, 3660`).
- State matching by ordinal in a machine's state list (`TT/callable_applications.rs:1589`); "entry state" is state position 0 (`DTI:1745, 1760`).
- Newly created type references given an owner by arena index range `>= start` (`TT/callable_applications.rs:4685-4691`).
- Wire tags: every enum is a hand-numbered tag byte; unknown tag is an error (`codec/block_wire.rs:1354`, `codec/module_wire.rs` throughout).
