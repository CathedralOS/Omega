## What this area does

This area is the shared ground floor of the Psi half of the compiler plus the two programs that run Psi. The foundation crates hold the storage containers every table lives in (arenas and handles), the names and symbol table, source files and spans, exact numbers and float meaning, the vocabulary of propositions and scalar terms that proofs are written in, layout and access plans for memory, the address-range authority model, filesystem authority, diagnostics, and accounting for compile-time evaluation. The checked interpreter runs a checked (or typed) source tree directly, for build-time evaluation and differential runs. The terminal interpreter runs admitted Terminal Psi artifacts. One file of the terminal-installation validator (scalar conditions) also sits in this area.

- **terminal-installation (one file, `SA`)**: in: a Terminal Psi artifact, a target, admitted target/provider/layout selections. Out: which retained scalar conditions apply, their evaluated values, and pass/fail per range or predicate (SA:45-152, 1732-1899, 2610-2675).
- **access-plans**: in: a layout report, per-field access decisions, a resource profile, an extent loan. Out: validated access plans, resource compatibility, placement carriers and sealed primitive access requests (AP/placements.rs:171-346, AP/plan_policy.rs:20-200, AP/resources.rs:545-677).
- **arena**: in: values. Out: dense generation-checked handles and spans, paged and concurrent variants, interners, revision-tagged derived indexes (F/arena/src/arena.rs:19-144, 414-424; paged.rs:196, 859, 1365; owned_index.rs:15-18).
- **build-time-values**: one value enum exchanged across the compile-time boundary, with cell and text-byte counts (F/build-time-values/src/lib.rs:28-71).
- **compiler-storage (+ derive)**: in: any `Record` value. Out: bounded binary bytes and back, with shared-`Arc` identity and generation remapping; no version or digest of its own (F/compiler-storage/src/lib.rs:37-56, 162, 338-408; derive/src/lib.rs:29-141).
- **diagnostics**: the `Diagnostic` record and bounded text renderers (F/diagnostics/src/lib.rs:94, 249, 311).
- **evaluation-accounting**: in: charges for work, log bytes, filesystem attempts, storage. Out: accept or refuse against invocation and session ceilings, and a usage record (invocation.rs:149-408; lib.rs:160, 431-514, 643-756).
- **extents**: linear carriers for address ranges with split, merge, attenuate, loan, mapping, external loans, ordering events, activation claims (extent.rs:69-320; mapping.rs:35-301; loans_and_claims.rs:398, 686, 1251).
- **filesystem-authority**: canonical metadata index, grant roots, handle identities, host stat layouts, observation codec, a 50-row host operation table, and a staging sponsor (filesystem.rs:185-281, 598-757, 799-1049; lib.rs:108-183; filesystem_sponsor.rs:320).
- **flow-effects**: data-only effect summaries published by the checker: capability flow, invocation inference, operational plan, service reach (F/flow-effects/src/lib.rs:41-567).
- **language-core**: source vocabulary tables: atomic orderings, the inline-assembly catalog, operator spellings, carry policy, static-interrupt and layout-query names (atomic.rs; inline_assembly.rs:1435-1850; lib.rs:51-379; source_semantics.rs).
- **language-semantics**: declaration-selection ledger and Build operation vocabulary, provider choice, canonical constant encoding, content conservation, numeric intrinsic catalog, service surface, a parser for type-identity strings (declaration_selection.rs; const_value.rs; content.rs; numeric_intrinsics.rs; service_surface.rs; type_identity.rs).
- **layout-plans**: layout reports and fingerprints, sum geometry, placement constraints, writing and reading fields in byte buffers, symbolic materialization plans (layout_reports.rs; lib.rs:60-172, 175-466; materialization.rs; symbolic_materialization.rs:31-46).
- **mutation-matrix**: a test helper that substitutes one field at a time (F/mutation-matrix/src/lib.rs:28-65).
- **numerics**: big integers, rationals, exact floats and rounding; a 65-row float operation catalog; arithmetic domains, integer interval recipes, policy obligations, predicate evaluation; literal carriers (bignum.rs; float_semantics.rs:1262-1333; lib.rs:44-1083; literals.rs).
- **optimization**: the 9-member optimization selection list and its codec, plus a byte cursor and SHA-256 domain digest helper (F/optimization/src/lib.rs:42-338).
- **semantic-vocabulary**: typed ids, id tables, FNV-1a, propositions, scalar terms, integer types, proof-application reachability, content terms, structural places (identity.rs; lib.rs; proposition.rs; scalar_terms.rs; proof_applications.rs; storage.rs).
- **source / source-audit**: source files, spans, the selection-aware source map and catalogue, captured source trees and routing; source-audit is a test helper that scans crate sources for forbidden substrings (source/src/lib.rs:744-1337; capture.rs:29-494; source-audit/src/lib.rs:27-100).
- **symbols**: the symbol table, builtin rosters, name storage, retained declarations, and the top-level lookup rules (table.rs:1867-3458; builtin.rs; symbol.rs; retained_declaration.rs).
- **checked-interpreter**: in: `CheckedTrees` or typed trees, an entry, stdin, options, optional filesystem grants and sponsor. Out: `InterpretOutcome` or a `BuildTimeValue` with usage (CI/interpreter.rs:765, 905, 1001). It also implements the Build prelude facets and a virtual and a real filesystem provider (CI/build_machine.rs; CI/filesystem.rs; CI/filesystem_real.rs).
- **terminal-interpreter**: in: an admitted Terminal Psi program, runtime supplies (host imports, checked or component providers, target selections, layouts), entry arguments and structural inputs, a work meter. Out: a resumable `TerminalExecution` that yields status, effects, a result or a crash (TI/embedding.rs:2232, 2388, 2642; TI/engine_execution.rs:1770-1859, 2545-2940). File groups:
  - `embedding.rs`: the host-facing program, instance, import adapters, component bindings, and post-return observation.
  - `engine_*`: the run loop, capability preflight, scalar operations (`engine_execution.rs`); calls and boundary calls (`engine_calls.rs`); claims and the affine frontier (`engine_custody.rs`); structural operations (`engine_structural.rs`); terminators and returns (`engine_terminators.rs`).
  - `boundary_*`: staging, validating and committing what crosses to a host (`boundary_effects.rs`, `boundary_storage_inputs.rs`), entry inputs (`boundary_inputs.rs`), value, result and error vocabulary (`boundary_values.rs`).
  - `storage_*`: primitive scalar homes, activation claims, accounted row tables (`storage_primitives.rs`); provider storage and value images (`storage_providers.rs`); records, scalar arrays, staging and retirement (`storage_records_and_arrays.rs`); references (`storage_references.rs`); byte sequences and element views (`storage_bytes_and_views.rs`).

## How it decides

Keyed on identity (handles, ids, pointer identity):
- Arena lookups by (index, generation) (arena.rs:1310-1340; paged.rs:679, 1486-1512).
- Scalar condition selection by proof-declaration and application ids (SA:90-101).
- Extent merge and loans by address space, rights, provenance, era, lineage (extent.rs:336-394); external loan and mapping receipts by field-by-field or whole-struct equality (loans_and_claims.rs:759-785, 837-872; mapping.rs:241-266).
- Accounting ownership by `Arc::ptr_eq` (invocation.rs:199, 451). Virtual clock bindings by the address of the `CheckedTrees` reference (CI/evaluation.rs:753, 769, 822). Root Build value by cell pointer identity (CI/build_machine.rs:105-109, 1573-1577, 1747-1751).
- Symbol and builtin identity by root slot position (builtin.rs:425-544; table.rs:3157-3242).

Keyed on place or position:
- Record derive variant tags are declaration positions (derive/src/lib.rs:118). `ProductTarget::code` and the float catalog rows and `FLOAT_OPERATIONS` wire byte are positions in a list (declaration_selection.rs:1603-1621, inferred by reader; float_semantics.rs:1500-1517; numeric_intrinsics.rs:432-442, inferred by reader).
- Declaration-selection ledger: occurrence id is the row index; lookups by source span + exposure + kind (declaration_selection.rs:2282, 2313, 2457).
- Access-field slots are ordinals in a `BTreeMap` of identities (access_fields.rs:276-293).

Keyed on value:
- Range and predicate discharge (SA:2610-2675); budgets (invocation.rs:215-217); resource supply by region and width (resources.rs:679-761); float format by whole-record equality with `BINARY32`/`BINARY64` (float_semantics.rs:233, 311, 455, 557, 665); integer typing by sign and width (proposition.rs:454-552).
- Host environment: `open_flags` bits and `FilesystemMetadataLayout::host()` are chosen by `cfg!` of the compiler's own host (filesystem-authority lib.rs:44-69; filesystem.rs:671-741).
