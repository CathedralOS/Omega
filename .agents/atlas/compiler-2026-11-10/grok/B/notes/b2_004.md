## What this file does instead of constant folding

1. **`countdown_induction`** (`12-337`, **read**): From validated cycle custody, derive loop regions and unsigned countdown summaries; record initial rank value as `ValueId` on the preheader jump (`59-105`, `199-245`).

2. **`countdown_invariant_constants`** (`339-882`, **read**): Locate exactly two existing `O::IntegerConstant` nodes (roles `PositiveGuardZero`, `BackedgeDecrementOne`) matching certificate operations and literals 0 and 1 (`395-406`, `773-795`); optionally validate nodes moved to a preheader suffix (`714-763`).

3. **`countdown_invariant_constant_placement`** (`884-1606`, **read**): For each invariant constant, find the sole consumer (`IntegerLessThan` or `IntegerArithmetic` subtract with `Exact` policy) and a preheader insertion point before the header jump (`920-966`, `1008-1043`, `1546-1605`).

4. **Cross-cutting** (`268-272`, `617-620`, `1447-1450`, **read**): Independent replay reconstructs the same snapshot; `accept` compares candidate to reconstructed (`SnapshotMismatch` on inequality).
