## Scope summary

This file represents revision-bound integer value-range facts (`ValueRangeFact`), extracts closed conjunctive integer intervals from canonical propositions (`extract_integer_intervals`), and maps proof-bearing shift and division operations to `CanonicalScalarGoal` (`proof_range_goal`) (`read`, file header `range.rs:1-7`).

There is no sparse conditional constant propagation pass, no literal-fold rewrite table, and no evaluation of arbitrary arithmetic expressions into a single folded scalar in this file (`read`, lines 1–413). Constant and range work here is: (1) absorbing proposition literals into interval bounds, (2) ±1 adjustments for strict inequalities, (3) type extremal bounds for open ends, (4) merging interval endpoints by comparison, and (5) naming proof goals for shift/division (not folding their results).
