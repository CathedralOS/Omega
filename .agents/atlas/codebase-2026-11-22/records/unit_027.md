## Five things a maintainer most needs to know
1. `construction.rs` builds the seed with no admission authority: empty services, domains, frontier facts, accepted obligation facts and `verified_contract` (`construction.rs:58-77`, `:241-250`). Everything else is attached later by code outside this unit.

4. Obligation checking in `unit_validation.rs` is mostly "a fact exists for (machine, owner, obligation)"; only the `WholeRepresentation` element-view branch compares the stored proposition bytes to a recomputed goal in the range I read (`:1931-1943`).
5. Ownership frontiers are checked only when `ownership_frontier_facts` is non-empty (`:1208`); edge exit frontiers are compared by exact struct equality to a recomputed one (`:675`).
