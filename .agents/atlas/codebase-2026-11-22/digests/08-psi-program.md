## 1. What this area does

This area defines the Psi program record and everything that puts it into bytes, reads it back, and binds it to one run. Source stage 07 builds a `terminal_psi::Psi` in memory (`P/psi.rs:8`, 11 fields). `terminal-codec` seals it with its canonical `PSITERM\0` bytes and identity (`ClosedTerminalModule::new`, `A/codec/src/closed_module.rs:22`) and wraps it in the `PSIART\0\0` envelope with optimization, debug and publication sections (`CanonicalTerminalArtifact::to_bytes`, `A/codec/src/canonical_artifact.rs:195`). Bytes from outside come back through `decode_module` (`W/semantic_module.rs:4260`), which runs a fixed sequence of validators and then re-encodes and compares (`:4268-4303`). The receiving host then records its producer-trust decision (`authorize_terminal_artifact`, `A/authorization/authorization.rs:133`), and the execution-input crates check the target, layouts, providers, entry memory and scalar observations against that one artifact before the interpreter, native stages 00-02 or Build use it. The area is about 84,600 lines in 22 crates (crate map: 21 crate rows plus the root). About 13,800 lines are `FV`, the decode-time structural check. Much of the rest is wire codecs, many with inline tests.

## 8. Stated limits

**Trust and authority.**
- "Closure does not show that a checker accepted the program or that its producer can be trusted." (`A/codec/src/closed_module.rs:1`); the wire crate "does not define or hand out the sealed Terminal Psi module" and host authorization "remains separate from decoding" (`W/lib.rs:10`, `:29-31`).
- "Absence of producer trust still permits inspection" (`A/authorization/authorization.rs:129-131`).
- Evidence seals "grant no truth, execution authority or producer trust" and do not replay the kernel (`W/obligation_evidence.rs:12-16`, `:585`); identity formations: "does not re-decide the encoded judgment", "Inspection of untrusted bytes runs no kernel" (`W/identity_formations.rs:5-6`, `:18`).
- The identity visitor "validates framing, not package authority" (`ID/type_identity.rs:1812`); source descriptions may name a toolchain declaration before its revision is joined (`:1886`); schema regions "describe a declaration's binder, never a live value's lifetime" (`:588`).
- "neither a familiar name nor successful parsing grants host access" (`P/interfaces/service_schemas.rs:90-91`); schema descriptions grant no call or storage permission (`P/types/reflection/schema.rs:1-3`); static reach records "are not executable rows" (`P/execution/static_reach.rs:1-3`); reading a header grants no permission (`P/execution/contracts.rs:15-17`); theorem rows "grant no identity witness" (`P/proofs/theorems.rs:9-10`); a scalar predicate definition is "not evidence that its body holds" (`P/proofs/evidence/declarations.rs:5-6`); static callable constants "grant no execution or source authority" (`ID/const_value.rs:131-132`); extents issue no storage authority (`P/access/extents/src/lib.rs:1-2`); access mode comparison establishes no custody (`P/access/capabilities.rs:66-68`); encoding invocation results "does not prove the analysis correct" (`DE/invocations.rs:3-5`).
- Invocation evidence is never consulted by ordinary identity or portable publication (`P/identities/table.rs:121-122`).

**Formats and versions.**
- "Marker 290 retires the external sealed byte-read intrinsic ... Earlier artifacts are refused." (`W/semantic_module.rs:4203-4204`); the spec says marker 291 (section 9).
- Authored order of `requires` clauses is identity (`W/semantic_module.rs:337-339`); "Canonical ordering must not depend on whether code exists." **Numeric caps.**

**Supported shapes.**
