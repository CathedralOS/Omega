Words used below. **Terminal Psi** is the internal last portable form of a program before machine code. A **boundary** is a call that leaves the program's own code (a foreign import, a system call, a compiler built-in, a component); a **provider** is what supplies it, and a **settlement** is the admitted record of how one boundary is realized. **Identity text** is a string looked up through an identity table (`identities.text(index)`) and compared with `==`; records use it for requirement and provider identities. A **canonical** catalog or model is the one a target crate builds itself; a **supplied** one is checked against it. **Fail-open** means an unknown, `None` or missing row leads to accepting or keeping something. Classes: **stated** (a comment at the site says why), **traced** (the reader followed callers), **open** (neither).

## 1. What this area does

This area is the native compiler's driver, the target-description crates it and the numbered stages read, and the verification crates that admit providers and audit emitted objects. The driver takes an authorized Psi program plus the receiving host's providers and permissions, runs admission, lowers the entry and each private callable through the stage crates, and returns a finished image or the provisions the Psi interpreter needs. The target crates describe each deployment target as data: profiles, register models, constraint catalogs, calling plans, layout geometry and per-instruction effects. The verification crates decide whether selected providers, interrupt installations, component descriptions, behavior exclusions and authority claims match the published Psi exactly. Area total: 288 files, 98,804 lines (`units.tsv`).
