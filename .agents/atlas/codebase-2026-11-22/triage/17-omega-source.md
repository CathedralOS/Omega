This applies in [ordinary checking](../../../../source/subsystems/compiler/source_to_psi/pipeline/typed_trees_to_checked_trees/obligations.omg) and [fact evaluation](../../../../source/subsystems/compiler/source_to_psi/pipeline/typed_trees_to_checked_trees/fact_values.omg). | 169. Widening an infeasible zone | The [state-arrival path](../../../../source/subsystems/compiler/source_to_psi/pipeline/typed_trees_to_checked_trees/checker.omg) widens only after `zone_join` reports a change. The [join](../../../../source/subsystems/compiler/source_to_psi/pipeline/typed_trees_to_checked_trees/zone.omg) ignores an infeasible incoming contribution. When the previous arrival is infeasible, it copies the first reachable contribution into the merged zone. Returning early from widening in that case preserves all reachable states in that contribution. |
| 169. Constraint coordinates and active rows | The two production callers of `zone_open` both pass 64. [Place creation](../../../../source/subsystems/compiler/source_to_psi/pipeline/typed_trees_to_checked_trees/places.omg) initially assigns only subject zero and issues each further subject below 64. [Arrival projection](../../../../source/subsystems/compiler/source_to_psi/pipeline/typed_trees_to_checked_trees/checker.omg) creates a 64-row contribution. [Constraint closure](../../../../source/subsystems/compiler/source_to_psi/pipeline/typed_trees_to_checked_trees/zone.omg) reads the supplied coordinates and writes `first, second`, each below the active count. The product trace covers all issued subjects. A direct caller constructing a smaller zone would have to supply coordinates within that zone. |
| 170. Width of a reference recast | [Typing](../../../../source/subsystems/compiler/source_to_psi/pipeline/symbol_resolved_trees_to_typed_trees/expressions.omg) checks matching access and requires identical referents or equal, positive scalar sizes. [The checker](../../../../source/subsystems/compiler/source_to_psi/pipeline/typed_trees_to_checked_trees/recasts.omg) then checks Boolean bit patterns and mutation rights. [Scalar lowering](../../../../source/subsystems/compiler/source_to_psi/pipeline/checked_trees_to_scalar_operations/scalar.omg) requires successful typing and checking. Differently sized scalar referents therefore cannot reach scalar lowering through this recast. |

## Bundled SHA-256

[Digest line 188](../digests/17-omega-source.md#L188) is repaired. The old digest wrote a partial hash for a declared length of 8,256 bytes in the 8,192-byte staging buffer. The package now refuses oversized input before hashing and clears all 32 output bytes on refusal. Its round-constant lookup requires a proven index below 64. The [native and Psi fixture](../../../../source-rust/application/tests/fixtures/library/run/sha256_digest/main.omg) checks known digests at 3 and 8,192 bytes, rejects lengths 8,193 and 8,256, and reuses the same state after refusal.
