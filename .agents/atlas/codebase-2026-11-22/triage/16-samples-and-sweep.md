The CLI handoff requires both exit reports and a matching command status for an executed program. The expected output check reads forwarded native stdout after the CLI compares the two execution streams. A crash or missing exit report fails the sample. Sweep stage names group diagnostic text for reporting. Its guard rechecks previous nonblocked outcomes. Watching an unreachable fleet host keeps reporting its unsettled state until it finishes or the operator stops watching.
