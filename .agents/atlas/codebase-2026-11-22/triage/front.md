## Front-half handoffs

The [boundary survey](../boundaries/front_half.md#handoffs-where-nothing-independent-checks-the-value) identifies seven handoffs with limited independent validation. Those are leads. For each, test whether a reachable producer or a supported artifact reader can supply a bad value, and whether the owning consumer relies on that value.

| Handoff | Candidate case |
| --- | --- |
| 00 → 01 | Change a token span or kind and check which producer or consumer owns detection. |
| 01 → 02 | Distinguish a stale syntax handle read from an invalid but supported optional handle. |
| 02 → 03 | The binder-position regression above covers the shared lookup. Reach rows and selection identities need separate cases. |
| 03 → 04 | Apply specialization twice to a state that needs specialization and check whether the ordinary route can present it twice. |
| 04 → 05 | Change a typed state reference while keeping value inputs valid. Trace the first stage whose contract requires a refusal. |
| 05 → 06 | Change an owed row and a suspension frontier independently. Compare each checker judgment with the original. |
| 06 → 07 | Change a provider or selection identity while preserving counts. Check publication admission and companion validation independently. |
