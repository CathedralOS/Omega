# Atlas packet unit_019: native stages 11 to 14 (encoding, layout, function placement, objects)

Packet complete. Every correctness claim in `records/unit_019.md` has a disposition below. No claim shows a
wrong result in the current tree. One claim stays open as a hardening lead: stage 14 has no single check that
every unresolved image address was given a relocation. All six address kinds are handled today, so no program
is affected. Four source comments were wrong, and this packet's PR corrects them. No compiler code changed.

`frame_application.rs` and `text_placement.rs` in stage 13, and `body_object.rs`, `lib.rs` and `names.rs` in
stage 14 (Windows ARM64, unwind plans, #5206, #5208, #5274, #5280, #5300). The cited lines are current lines.
`units/unit_019.tsv` lists 46 whole files. `second_pass_ranges.tsv` assigns no gap packet range to unit 019,
so nothing was skipped. The checkout is shallow, so merged PRs were found by search, not by `git log`.
