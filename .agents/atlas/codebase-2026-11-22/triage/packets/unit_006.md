## Unresolved claims

1. **Stage 01 revalidates published evidence seals: duplicate check, still open.** Record Part E, `native_execution.rs` item 6 (lines 814–815); [digest 09 §3](../../digests/09-native-stages-00-03.md); [Psi and native handoff](../../boundaries/psi_and_native.md).
   - **Code.** `P1/src/native_execution.rs` `PreparedNativeExecution::from_scoped_providers` runs `EvidenceSealValidator::validate_all` on every published seal. Bytes received through `psi/artifact/codec/src/canonical_artifact.rs` `CanonicalTerminalArtifact::from_bytes` have already passed the same validator.
   - **The other route.** The in-memory source route publishes with `CanonicalTerminalArtifact::with_publication`, which checks only `evidence.module`. On that route the stage 01 call is the only seal check.
   - **Evidence.** No wrong result. This is repeated work on the saved-bytes route and a self-check on the source route; AGENTS.md says that default compilation does not re-verify its own stage output.
   - **Proposed fix.** Decide which owner validates seals. Removing the stage 01 call alone would leave the in-memory route unchecked, so keep it until that decision.
2. **Discarded component-description error: refusal preserved, diagnostic still open.** Record Part C, `inputs/published_application.rs` (lines 670–676).
   - **Code.** `DRV/inputs/published_application.rs` `review_source_providers` turns a `describe_portable_component` failure into `None` with `.ok()`.
   - **Effect.** A consumer that later selects that package is still refused in `compiler.rs`, with "the completed Product for `…` has no separately published provider description for this target". That message names a missing description and drops the `DescribeError` that caused it.
   - **Evidence.** No reproducer was built. It is not established which valid library programs reach a `DescribeError`.
   - **Proposed fix.** Retain `Result<Vec<u8>, DescribeError>` (or its diagnostic) in `ReviewedPackage` and `IndependentComponentDescription`, and report the reason when a consumer selects the package.
