## Summary

All 43 inventory rows are rules of the language, so every row is classified here.

- Enforced: 23 (R1-R6, R9, R12-R15, R17, R20-R24, R26-R28, R32, R34, R43)

The stage 05 README is out of date. Its "References" section describes only call-duration loans of `@T` formals. The code now also serves reference locals, stored references, returned views, successor (state-to-state) loans and byte views. All of these are judged by one loan judgment in `S06/src/places/loans.rs`, and its tests cover most of the borrow rules (R1-R6, R9, R12-R15, R21).

Two of the "not found" rows are permissions, not safety checks. The old code let loans in different sum cases (R18), and array elements whose indices were proved different (R19), coexist. The current overlap relation treats both as overlapping, so it refuses programs the old code accepted. That is sound but stricter.

The most worrying gap is content conservation (R37, R38, R40). I found no check that a content-bearing result descends from a consumed owned claim, and no source of `Proposition::ContentConservation` in stage 05. The prover refuses that proposition as a goal. I could not tell whether such programs are refused upstream or accepted unchecked.

Two other "not found" rows need an owner's look. One is the fit of stored integers in narrowed layout fields (R31). The other is the per-value carry-policy check at a suspension (R25): a comment in `S06/src/operational.rs:347-348` says it is "checked row by row", but I found no code that does it.
