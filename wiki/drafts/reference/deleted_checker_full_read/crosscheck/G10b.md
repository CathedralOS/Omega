# Cross-check G10b

Path abbreviations used in every table: `S01`, `S03`, `S05`, `S06` are the stage directories under `source-rust/subsystems/compiler/source-to-psi/pipeline/` (`01_tokens-to-syntax-trees`, `03_symbol-resolved-trees-to-typed-trees`, `05_prepared-typed-trees-to-lowered-program/src`, `06_lowered-program-to-checked-program`). `PSEM` is `source-rust/subsystems/compiler/psi/semantics/src`.

## Summary

Of the 78 inventory rows: 40 enforced, 22 refused wholesale, 3 not found, 8 unclear. I skipped 5 rows as the old code's own bookkeeping or as a limitation the language never had: R26, R27, R39, R47, R60.

The rules for call arguments are enforced in stage 05, and stage 06 proves the contracts. Stage 05 checks argument count, argument type, reference access, literal fit and record-literal shape, and refuses an argument that breaks them. Stage 06 then proves every callee `requires` as a `CallRequirement`. That is stronger than the old check, which only asked whether the caller's facts refuted the clause.

The old write-frames module (about 34,000 lines) is replaced by one mechanism. `PSEM/storage/borrowed_storage/write_frames.rs` infers which parameter fields each body writes and refuses a published frame that differs from the body. Stage 05 turns that frame into exact `Overwritten` rows, and stage 06 resolves reads over one `overlap` function. Where the old code had five disagreeing overlap matchers and six type walks, the new code has one of each.

Large families are refused rather than checked:
- `dyn` dispatch, which the spec retired and the parser refuses (R14-R16);
- receiver calls (R8, R23, R24);
- assembly (R9);
- type arguments to generic machines (R20, R21);
- recast or domain-changing views (R53);
- all content-conservation contracts and `Content::project` machines (R68-R78).

For content conservation, no stage-05 reader exists at all. A `satisfies Content<..>::project` clause is refused as "a trait with parameters", and the stage-06 prover has no rule for `ContentConservation` goals.

The three "not found" rules are: write preservation through an accessor (R7), writes through a view reaching the whole collection (R59), and the `BorrowBytes` and access-view result contracts (R61). Each is more likely covered by a general mechanism or retired than silently unenforced. R59 is the one I would check next.

## Unclear and not looked up

Unclear:
- **R12** (a recursive proof machine declares `terminates by` over a bare parameter). The current reader has no separate "proof machine" category that I found. A cycle needs a ranking only when it promises termination (`S05/components.rs:153`). Non-tail recursion is refused (`169`), and so is an erased binding or witness on a cycle (`181`). So proof recursion seems refused in practice, but I could not confirm that.
- **R29** (a unit call completes a state only as the exact statement root). There are transition refusals at `S05/read/transitions.rs:39` and `492`, but I did not trace the completion rule.
- **R31** (names are declared; `A::b` resolves). A call with no bound target is refused (`S05/read/calls.rs:653`), and unknown types are rejected in `source-to-psi/representations/typed-trees/type_records/data_applications.rs:253`. I did not find stage 02's general undeclared-name diagnostic.
- **R36** (a native callback names one `machine` binder). Private callback placement is refused (`S05/read/calls.rs:877`), and generic callback arguments have checks at `2154`. I did not find the binder-count rule.
- **R51** (a frozen binding is not exposed while a write may replace it). Loan conflict and freeze judgments are in `S06/src/places/loans.rs`, but I found no rule specific to frozen bindings.
- **R52** (divergent aliases). Reference captures must name one existing binding (`S05/read/statements.rs:408`), which may make divergent aliases impossible. Not confirmed.
- **R54** (an independent descriptor load at each reference crossing). Stage 05 inserts an `ExpressionKind::Referent` node at each crossing (`S05/read/calls.rs:3630-3640`). I did not confirm that this gives a load per crossing everywhere.
- **R65** (a view's extent is one consistent count). There are extent-correspondence checks in `S06/src/places/byte_views.rs:274`, `1374` and `1383-1387`. They may be the rule; not confirmed.

Skipped as old-code bookkeeping or an old limitation, not a language rule:
- R26: a nested call as a value argument is now served; calls pass their outcome on in evaluation order.
- R27: value-position shapes.
- R39: an acyclic named-transition subgraph for alias tracking.
- R47: finite substitution growth for cycle summaries, replaced by "call cycles as loops" in `S05/components.rs`.
- R60: destination slot accounting.

Not looked up: none.
