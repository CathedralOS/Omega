# Group G05: old checking stage: ownership counting, operator contracts, index ranges and termination

Slices 035-044, 61,719 lines, all in `05_typed-trees-to-checked-trees/src/`. File abbreviations used in citations:
`cm` = checks_multiplicity.rs, `bw` = checks_multiplicity_borrowed_windows.rs, `co` = checks_multiplicity_claim_outcomes.rs, `cd` = checks_multiplicity_cleanup_dispositions.rs, `lv` = checks_multiplicity_linear_validation.rs, `pe` = checks_multiplicity_permission_events.rs, `op` = checks_operators.rs, `cr` = checks_ranges.rs, `crf` = checks_ranges_facts.rs, `ct` = checks_termination.rs, `pr` = checks_termination_progress.rs, `ex` = execution.rs.

## What this code was

These twelve files were four checks of the old source checker plus one plan builder. The ownership check (26,469 lines, slices 035-038) recorded a ledger of "permission events" (Establish, Transfer, Consume, Restore, AffineDrop) per state, then replayed it to refuse use after move, unconsumed linear values and bad cleanup (cm:2343-2384, lv:4203-4446). The operator check reported ambiguous operator choices, refused float-format mismatches and tried to prove each operator `requires` at each use (op:1-5). The range check carried a per-state store of facts keyed by the rendered text of expressions and decided every `c[i]` and `c[a..b]` (cr:10980-11177, crf:4971-5054). The termination check decided `terminates by` rankings for state cycles and recursive call groups, then checked that every call a terminating machine makes also terminates, possibly under "progress premises" (ct:7900, pr:4516-4597). `execution.rs` ran after checking and built the plans the lowering consumed, yet it also decided whether a run of `when` guards is exhaustive (ex:2427-2596). None of the 61,719 lines calls the proof kernel. The files contain 15 tests, and none of them compiles an Omega program or pins a language rule (co:140-3356, cd:163-536, pr:1911-2018).

## Mechanisms

- **Event ledger and replay.** A producer walks each state once in a fixed schedule and emits permission events; a validator replays them over a roster of tracked places (cm:5397-5509, lv:2910-3627, lv:4265-4446). Serves all ownership rules. No budget.
- **Custody joins.** Two policies exist. Expression arms AND `live` and mint a new claim identity when arms differ (cm:8448-8497). A separate may-presence join keeps cleanup for what any route retained (cm:7146-7175). `RemainingCustody::join` unions possible exclusions and intersects definite ones (cd:752-833).
- **Claim collection over a completed value** gathers `(path, claim, condition)` from transfers, constructed children, call results and a backward store trace, then checks coverage and disjointness (cm:6030-6611).
- **Borrowed-storage holes.** A linear list of open holes, a planner that requires all match arms to agree, and route rebasing of at most 16 hops (bw:214-850, bw:1182-1559, bw:1721-1762).
- **Claim outcome maps.** Three nested fixed points derive per-state result-to-source maps, call-result joins and identity rewrites, bounded by `state_count + 1`, `events + 1` and `2 * (maps + joins) + 2` rounds; running out is a refusal (co:3581-3659, co:1946-2044, co:3487-3501).
- **Content snapshot traversal** follows stored values and predecessors with 65,536 visits and depth 128 (cm:428-554).
- **Receipt-tree validation** for instruction effects, terminated by decreasing arena indices (cm:5132-5303).
- **Invocation context selection** finds the one capture row of an invocation and intersects operand contexts (op:1260-1613).
- **Float semantic terms** build a term per float predicate under a 1,024-step budget and decide closed cases by catalog evaluation (op:377-1152).
- **Forward range-fact transfer** replays each state's statements over a fresh fact store seeded from `requires`, incoming guards, loop invariants and edge arguments (cr:11095-11151, cr:7213-7524).
- **State-argument fixed point** over a machine family, 64 passes, optimistic start (cr:4353-4462).
- **Loop analysis**: natural loops, interval propagation with widening, search over authored bound chains (cr:1365-1524, cr:1738-1786, cr:2150-2216).
- **Typed read sets behind text labels**: for each recorded expression the set of storage places it reads, used to decide which string-keyed facts survive a write; depth 128 (crf:2141-2337, crf:3531-3603). **Alias fan-out** copies facts onto every expression in the program that will name the same storage (crf:618-829, crf:975-1151).
- **Ranking provers**: Tarjan components, a lazy search for one rank per component member, rank inference for private helpers by backtracking, arrival-correspondence selection under two premise regimes (ct:365-422, ct:238-316, ct:722-1380, ct:5648-5878). No budgets.
- **Termination summaries**: a fixed point per call component, a three-value lineage lattice for state parameters, and backward origin tracing limited to 16 steps (pr:248-575, pr:686-1111, pr:2020-4356).

## The three properties, tested

**1. Acceptance was the code's own yes or no.** Holds without exception. Every one of the ten reports searched for kernel names and found none in 61,719 lines. No part of this group used the proof kernel. The nearest things are: `kernel_discharge` on a float catalog row, of which only `.result` is kept (op:699-701); a published receipt tree for instruction effects that is re-validated by hand-written matching (cm:4996-5303); a tag test `is_independent_receipt()` (pr:1905); and `instruction_effect_evidence` (cm:4840). ## Patterns not seen before

1. **A stage checks its own output by running itself again.** Seven instances: ledger replay (lv:4220 with pe:796), expected cleanup events rebuilt and compared (lv:391-409), join-binding production and replay (cm:8161-8333), `derive_receipts` twice (co:2081), instruction receipts (cm:4996-5130), operator selection replay (cr:6105-6135), cleanup eligibility computed twice (ex:980-1035). A wrong shared helper passes both sides.
2. **Obligations dropped on a hypothesis.** A fixed point's candidate map clears a live obligation in two places (co:3525-3531, pe:2044-2080). Soundness then rests on re-walk scheduling.
3. **Running out of rounds is a verdict.** Four "did not converge" errors, one silent "publish nothing" (cr:4461), and at least five loops or searches with no bound at all (pr:461-574, pr:993-1009, ct:238-316, ct:1240-1380).
4. **A third outcome that is neither accept nor refuse.** `Diagnostic::incomplete` at six sites (cm:7827-7838), `BoundsCheckResult::Unsupported` (cr:6277, cr:6291), and four planners that return `None` (ex:625-802, ex:2427-2808). What the consumer does is outside every slice.
5. **Skips outnumber refusals where work is discovered.** About 30 `continue`s against three diagnostics for temporaries (cm:9894-10309); ten in `derive_receipts` (co:1669-1860); about 24 for early deaths (lv:2251-2330, lv:3709-3800).
6. **The same question answered separately by several analyses.** "May this write touch this place" is written at least 16 times across six files (cr:927-950, cr:2460-2681, cr:3281-3326; crf:3800-3972; pr:2749-4043; ct:6291-6317, ct:6640-6670; co:1592-1643; cd:1491-1533). The meaning of a run of guarded transitions is written six times (cr:296-350, cr:7471-7522, ct:5046-5116, pe:1937-2001, ex:2427-2596, cm:5479-5490). The state graph is built four times (cr:295-351, cr:1683-1735, ct:504-507, pr:803-1010).
7. **Later code reverse-engineers earlier rewriting.** Five instances: `__hoist_` (cr:6523), `__transition_subject` followed as an alias (cr:7540-7546) and by prefix (ct:5175), atomic operands by the shape of a desugared expression (crf:1416-1430), generated names without symbols (crf:1357-1362).
8. **A handle layer added beside a text layer, not in place of it.** 3,150 lines of typed read sets exist only to police string labels (crf:540-3700); float terms beside label provers (op:377-1152 against op:2286-2356); place plus label carried together (cr:4170-4183).
9. **Acceptance decided in a plan builder.** Guard exhaustiveness and terminator shape live in `execution.rs`, after checking (ex:2427-2808); `publish_owned_transfer_paths` never refuses (cm:4525-4612).
10. **Declared contracts of bodyless things are premises.** Boundary `ensures` (cr:8286-8336), exclusive-call restore (lv:1929-2002), published guarantees (pr:1626-1681), `IntegerEmbed` (pr:1619-1625), instruction effects (cm:4887-4906).
11. **Refusals without a source position.** Bare `&'static str` reasons in the content modules (cm:100, cm:1169), about 36 in `returned_claims` (cm:5862-6654), join reasons (co:553-663).
12. **Checker speed and memory shape the rules.** Parallel per-state walks with serial fallback and a memo across rounds (pe:341-765); a comment records 2.7 GB for 2,135 states (pe:284-300); plan order once depended on thread races (ex:381-387).

## What a rebuilt compiler must still do

- Refuse a linear value that is live at any ordinary exit, and require the same treatment on every exit (R1, R2).
- Refuse any use of a moved value or of a place overlapping it, and let a covering store re-establish it (R3, R4, R29).
- Treat zero-filled storage as owing nothing and establish values only by explicit writes (R5, R28).
- Refuse overwriting a live linear value, and drop what an overwritten affine value still owned (R6, R7).
- Refuse partial moves out of types with a cleanup hook and out of temporary results that would strand a linear claim (R8, R9).
- Give every leftover owned region an authorized disposal, in the specified reverse order (R10, R11).
- Allow a move out of `&mut` storage only with an exact-type refill before exit, and forbid overlapping uses, suspension and boundary calls while the hole is open, including across match arms (R12, R13, R14).
- Let crash exits abandon claims and record what was live (R15).
- Account for every declared linear claim of a returned, passed or stored value exactly once (R16).
- Keep a caller's claim identity when a callee hands its input back, and agree on sources across a callee's returns (R17, R18, R19).
- Join ownership at arm merges and through match-selected moves (R20, R21).
- Track which sum case is active for ownership and cleanup, and forget it on writes (R22).
- End obligations at non-returning calls and transitions (R23).
- Distinguish moving a reference from moving its referent, and scope temporaries to the statement (R24, R25).
- Restore validity of storage lent to an exclusive call, and end stored loans on overwrite (R26, R27).
- Let an instruction-effect contract consume a linear claim under the stated conditions (R30).
- Support content conservation and boundary custody of backing addresses (R31, R32).
- Refuse ambiguous or inadmissible operator choices and float-format changes without conversion (R34, R35, R36).
- Prove every operator `requires` at every use, in every position including statement calls and named calls to index operators, from facts captured at that invocation (R37, R38, R39, R40, R41, R42).
- Prove every index and subslice window in bounds, with non-negativity separate, for known, unknown, const-parameter and deferred extents (R43, R44, R45, R46, R47).
- Derive bounds from guards, `requires`, callee `ensures`, declared types, arithmetic under its domain, loop counters and requirement chains, and carry them across state edges (R49-R54, R56-R60, R63).
- Retire a fact when anything it depends on may be written, and respect evaluation order (R48, R55, R61).
- Treat provably unreachable branches as discharging obligations (R62).
- Require and prove a strictly decreasing rank for every state cycle and recursive call group, with view inference and view rules (R64-R74).
- Require every callee of a terminating machine to terminate, carrying conditional premises back to the caller's contract (R75-R79).
- Decide exhaustiveness of guarded transitions once, as a check with a diagnostic (R80, R81).
- Remove fact-only citations from execution (R82).
