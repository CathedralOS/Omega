# Group G06a: old checking stage: execution planners, first half

Slices read in full: 045, 046 (`execution_scalar_computations.rs`, cited `esc`), 047 (`execution_terminal_unit.rs`, `ETU`), 048 (`execution_terminal_unit_calls.rs`, `calls`), 049 (`execution_terminal_unit_cleanup.rs`, `cleanup`), 050 (`execution_terminal_unit_control.rs`, `control`). All six files live in stage `05_typed-trees-to-checked-trees/src/`.

## What this code was

These six files are not checkers in the usual sense. They are execution planners that ran inside the old checking stage, after the source checks, and turned each checked machine body plus the facts the checks had produced (`CheckFacts`: flow calls, borrow facts, permission events, proof facts, contract plans) into executable plans for the next stage: scalar computation graphs and structural value graphs (045, 046), per-call argument plans (048), cleanup action lists (049), call-occurrence accounting and boundary/single-state machine plans (050), and the root that routes, prunes and merges them all (047). Nearly every function returns `Option`, and `None` means "this builder cannot plan this expression or body" (esc:1-11, ETU:41-47, control.rs:5233-5242). A body with no plan gets a "plan gap" with reason `Unsupported`, and that gap is reported only if lowering later demands the body (ETU:2966-2974, control.rs:593, 5441). The header of ETU says these conditions "describe implementation coverage, not additional language rules" (ETU:4-7), yet all six reports find ownership, borrow, cleanup and call rules re-decided here. Facts from other passes are found again by coordinate (`(state, statement index, call ordinal)`, role, expression handle) and the code refuses unless exactly one row matches. The group contains about 42,000 lines and four tests (cleanup.rs:3557-3625, control.rs:3062-3120).

## Mechanisms

- **Computation DAG with templates** (esc:4241-4264, 4547-4559). `Apply { expression, operands }` holds a pure template over `Parameter { position }` holes; effects (calls, reads) are separate nodes. Memoised in linear lists by `(expression, carrier)` (esc:4277-4287, 9933-9967). Serves evaluation order and short-circuit semantics.
- **Structural value graph by ordered ladder** (`structural_value` esc:8982-9418, `build_expression` esc:9969-10427). The arm order decides which producer wins (046 surprise 11).
- **Three-valued Boolean fold** of a DAG (esc:4849-4934), explicitly "not permission to erase" calls (esc:4832-4840).
- **Callee-availability closure** (ETU:2177-2286): worklist over reverse call edges; terminates because each body drops once.
- **Windowed speculative parallel planning** (ETU:7139-7256): rayon forks at most `threads * 4` ahead, accepted only if a change log admits them; motivated by 3.5 GB extra memory (ETU:7157-7173).
- **Transfer summary algebra** (ETU:5430-5507): possible, definite and after-production moves; branch join intersects definite paths by prefix. Serves cleanup at returns and transitions.
- **Open-window ledger** (ETU:1249-1850) for values moved out of borrowed storage.
- **Place-to-path walk** (calls.rs:911-1092) inserting `Referent` steps per stored-reference layer.
- **First-admitting-row tables** (calls.rs:3837-4144).
- **Exhaustive event accounting**: count matched events and require equality with events found (calls.rs:4889-4934, 6275, 7406-7410, 7710). The only refusal-by-default mechanism in the group.
- **Disposition to actions with case partition** (cleanup.rs:210-610), via `validation::reconstruct_case_selected_cleanup_partition` with budget `usize::MAX` (cleanup.rs:546, 2848).
- **Call occurrence ledger** (control.rs:1324-1423), recursive scalar walk with cycle detection and minimum-ordinal propagation (control.rs:2405-2675), structural worklist (3504-3774), outer-call discovery with a growing-vector fixpoint (4281-4328).
- **Construction trace** (control.rs:5251-5444; calls.rs:1953-1956): last-written phase string explains a `None`.
- **Budgets and caps**: 64 reference crossings (esc:7707), 9 descriptor peels (esc:7156-7166), 16 rebase hops (ETU:1212-1240), 4096 contract-lowering steps (control.rs:74), type-reference count (calls.rs:671), `usize::MAX` (cleanup.rs:546), array length 3..=26 (calls.rs:48-51).

## The three properties, tested

**1. Acceptance was the code's own yes or no.** For: no slice calls the proof kernel; 045, 046, 047, 049 and 050 grepped for `proof_admission|ProofNode|verify_obligation|certificate` and found none, and 048 states it (calls.rs:1-14). `ProofFacts` is read as tables (esc:10441-10480); proof-term arguments are accepted on type identity alone (calls.rs:330-338); `resident_range_decision` is copied without reading (ETU:313-319); contract agreement is equality of stored fingerprints (ETU:3700-3701, control.rs:442-443); the one "cannot prove" diagnostic is a syntactic tuple match (cleanup.rs:1663-1711); nodes are marked `formation_decided: true` on a comment's word (esc:5208, 5339, 5811). "Certificate" in calls.rs:7028-7029 is a row in `facts.borrow.reborrow_disposition_events`. Against: these files say a different owner judges (index bounds re-proved by the Terminal verifier, calls.rs:630-631; contracts by "ordinary checking", esc:3658-3661, calls.rs:3589-3591). Verdict: holds. No place in this group used the kernel. Additionally, the verdict depended on planner completeness (cleanup.rs surprise 16, ETU surprise 3).

**2. Identity by text.** For, about 15 sites: generic carriers matched by base name even when symbols differ (esc:8354-8388, **checked in source**: the `||` lets equal names win over unequal valid symbols); sealed accessor by operation name (esc:521); intrinsics by builtin name (esc:963-972, calls.rs:1985-1992, 2057-2064, control.rs:2131-2133); carrier name to primitive (esc:981, calls.rs:2071, 2087, control.rs:2147, 4588); member resolved by name then compared (ETU:3193-3200); `&mut` path member compared to parameter name (calls.rs:4417); callback binder by name (calls.rs:8148, 8161, control.rs:665); `case_name` presence instead of `case_symbol` (esc:7336). `CheckedMemberIdentity::of_member(identity, name)` (esc:3373, ETU:554, calls.rs:1051, cleanup.rs:817) may compare names; 049 could not tell. Against: everything else uses handles: `SymbolHandle`, `ExpressionHandle`, `(arena_index, generation)` keys, `TypeIdentityId`, `normalized_type_identity`, `CanonicalPlace` compared structurally (ETU:712-729), binding ordinals. Authors warn against name identity (cleanup.rs:765-769, 2733-2735, 3480-3481). Verdict: mostly does not hold here. The real substitutes are source coordinates (`(state, statement, role)`, esc:9617; `(statement, ordinal)`, control.rs:4065) and memory addresses (`std::ptr::eq`: ETU:3591, 6034, 6099; cleanup.rs:4498-4503; control.rs: 14 sites plus a slice address at 3323).

**3. Verdict: holds, but the axis is mostly source kind, callee kind and body catalog, not syntactic placement.

## Patterns not seen before

- **Language rules re-decided in lowering planners.** All six slices. ETU re-decides linear overwrite, double move-out, unrepaired holes and claim carry (047 surprise 3); calls re-derives mutable authority (048 surprise 5); cleanup checks hook `requires` (049); control decides call-once semantics. Their refusals are `Unsupported` gaps, silent unless demanded (ETU:2972-2974), so the same property had two judges with different failure modes.
- **The same fact held in several tables and re-joined by coordinate with "exactly one" checks.** All six. 050 finds half its file (control.rs:1306-4544, about 3,200 lines) exists because one call lives in up to three tables. 049 counts five tables for one value (surprise 2).
- **Rebuild and compare.** The planner reruns itself and requires equality: ETU:3705-3858, 6674-6693; cleanup.rs:4316-4368; control.rs:5773-5787. Four sites in three slices.
- **Two implementations of one judgment that disagree.** At least seven: esc arm loops (045), carrier compare (045), two checked-body predicates and multiplicity functions (047), sequence vs graph cleanup (049), call-reached-twice walkers and nested result type (050).
- **Refusal reason is the last string written.** Four slices: 047 (`ok()?` loses reasons, ETU:7276-7286), 048 (calls.rs:1953-1956), 049 (cleanup.rs:4383), 050 (control.rs:5330-5372). 045 throws away its 17 reason strings with `.ok()?` (esc:4295).
- **Silent discards**: `let _ =` (esc:5483-5485, 10627, 10634), `unwrap_or_default` (ETU:500-502; calls.rs:6397, 7229, 7777, 8070; cleanup.rs:5002; control.rs:4671), `continue` on failure (esc:5402-5576, 11 cases).
- **Identity by memory address**: about 20 `std::ptr::eq` sites in 047, 049, 050.
- **Hardware and OS features inside the planner**: descriptor tables, register intrinsics, activation storage, interrupts (045, 048, 050).
- **Debug `eprintln!` in the checker** behind trace flags (calls.rs:5744-5758, 6898-6925; cleanup.rs:1255-1269, 2627-2641, 4565-4571; control.rs:6408-6417).
- **Order decides meaning without a stated rule**: ladders (esc:9283-9300, 9974-9980), first-admitting rows (calls.rs:3837-3841), target resolution order (calls.rs:2578-2647).
- **Fixed caps with silent results**: 16 hops, 64 crossings, 9 peels, 4096 steps, 3..=26.
- **Dense-table violations**: `BTreeMap` keyed by `(u32, u32)` and `Vec::contains` visited sets in 045, 046, 047, 049, 050.
- **Almost no tests**: 4 tests in 42,000 lines; none pins a language rule.

## What a rebuilt compiler must still do

- Lower atomic accesses only on atomic storage at built-in coordinates, with the operation's operand count and result type (atomic rows).
- Admit boundary and bodyless calls with their declaring trait, closed generic application, contract commitment, service reach and representable requirements (boundary rows).
- Check argument count, `const` and mutable scalar formals, result shape, and Unit statement calls for every call (call rows).
- Carry caller-to-callee contract evidence on every call, including selector and statically dispatched requirement calls (contract agreement, dynamic call rows).
- Evaluate each authored call exactly once, in source order, with short-circuit skipping of unevaluated right operands (call-once, short-circuit rows).
- Decide which storage may be passed as which parameter type, with which access, from one rule over values rather than per source (storage-presentation, access lattice, reference-crossing rows).
- Prove index and range bounds, fixed ranges and runtime selectors before access (index, range rows).
- Account for linear claims one for one at call entry, transfer and state entry (claim rows).
- Forbid moving out of borrowed storage twice and require repair before the body ends; forbid a linear value overwriting a live one (window, overwrite rows).
- Check record and case literals: declared fields once, omitted fields zeroable, carriers equal including generic arguments (literal, carrier rows).
- Copy only `Copy` types; adapt quotients only to their carrier when unrestricted (copy, quotient rows).
- Check `match` coverage for scalar and structural subjects, and case membership against the value's type (match, membership rows).
- Type integer operands, Bool-to-integer casts, comparisons and qualification casts (integer, cast, comparison rows).
- Observe `terminates by` ranks at run time with the declared measure (rank row).
- Run cleanup for every dying value: partition by case, call `dropped by` hooks of the right shape, discharge the hook's `requires` from the caller's facts, retire descriptors, order actions, and handle replaced values and temporaries (cleanup rows).
- Check machine body shape: result kinds, state contracts, successor argument positions, declaration ABI storage (body-shape rows).
