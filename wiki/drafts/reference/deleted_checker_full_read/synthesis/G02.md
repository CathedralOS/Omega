## What this code was

Two subsystems sat in this group. The `build-time-evaluation` crate (slices 007-012) computed constants, const-generic arguments, fixed-array lengths, range endpoints, `size_of`/`align_of`, layout and access policy plans, and build-configuration requests before the program was checked. It did most of this by wrapping an expression in a synthetic one-state "probe" machine, re-running name resolution, typing and often the whole tree checker on a clone of the program, evaluating the probe, and writing the result back into the tree as text (ce.rs:2158-2233, cge.rs:6078-6182, CI:1321-1332, me.rs:520-652). Machine calls at build time were admitted by `me.rs` (termination, no linear values, `requires` discharged at concrete arguments, package authority, services) and then run as Terminal Psi in the Terminal interpreter under a 100,000-unit work budget (me.rs:5046-5339, EA:274). Stage 04, "typed trees to typed trees" (slices 012-016), was an elaborator: it specialized generic machines to a fixed point, inferred static arguments, filled lifetimes, rewrote operator, policy-operator, assembly and reflection constructs into ordinary calls and machines, and handed a frozen program to the stage-05 checker (mono.rs:3746-3910, prep.rs:1945-2062). Slice 016 also held the stage-05 README, the authors' own inventory of what the deleted checker enforced. Neither subsystem called the proof kernel. At deletion several features here could no longer run: layout and access policy plans and domain-fact machines were refused for every program because the tree interpreter that ran them had been removed (ER:14-43, lib.rs:9-12, layouts.rs:1632-1639).

## Mechanisms

- **Probe and recheck** (ce.rs:2158-2233, cge.rs:5757-6001, CI:4232-4400, me.rs:520-652, layouts.rs:3592-3668, syntax_probes.rs:139-438). Append a private machine `@const-...` that returns the expression, re-run normalization, resolution and typing (often the full checker) on a clone, evaluate, then compare the constants and calls the probe selected against the authored ones by source span. Serves every constant feature. No budget; whole-program clones per item (CI:3365, me.rs:534, 1520).
- **Replay** (CI:2077-2485). After the final typed program exists, evaluate the authored initializer and the materialized literal again and require both equal the stored value. About 35% of slice 009 by line count.
- **Two evaluators.** The canonical-value interpreter (cge.rs:4343-5742) with explicit stack, lazy `match`, short-circuit `&&`/`||`, policies, floats and exact rationals; and an `i64`/`bool` fact interpreter for domain facts (ce.rs:1127-1330), three-valued with a visiting stack.
- **Rational-bounds lattice** (cge.rs:2842-3443). Exact rational intervals per sign cell plus an arithmetic progression and a bounded exact point set; splits an interval at the progression points nearest zero to prove a divisor nonzero. Budgets 256 points, 4,096 products, 256 lattice points, 4,096 landing summaries; exceeding them loses precision and refuses.
- **Build-time admission walk** (me.rs:201-382, 3668-3691). Depth-first over call edges with a stack; recursion asks termination inference. Five separate traversals of the same graph (me.rs:251-382, 3668-3691, 3847-3864, 3883-3945, 4307-4330). Checked-closure cache keyed by pointer address plus two counts (me.rs:3984-3988).
- **Terminal execution** (me.rs:5046-5339, EA:574-689). Produce a Terminal Psi artifact, bind arguments, bind float imports, run under `WorkMeter` (100,000 units), read back and relabel the value, charge result size. Array lengths already used this route (ce.rs:2804-2842).
- **Round-based fixpoints with rollback** (ce.rs:120-200, 4852-4933); readiness scheduling of constants (CI:3931-4518); dependency layering (ce.rs:1834-1898); demand-driven length evaluation with an active stack (ce.rs:2597-2817). None has a round limit.
- **Layout geometry** (layouts.rs:4461-4749, 6727-6928). Sorted destination intervals for overlap, exact source tiling, constant stride; natural size/alignment by recursion with a visiting stack; minimal bit width from the primitive range intersected with intervals read from `requires` clauses (layouts.rs:6667-6705).
- **Specialization fixed point** (mono.rs:3746-3910 inside prep.rs:1990-2037, 2090-2101). Each round runs about twenty sub-passes, collects a `CallSelection` per call site, clones a machine per complete tuple (bcr.rs:692-1660) and redirects calls. Four nested unbounded loops.
- **Proposal-based static argument inference** (sel.rs:35-327, 745-897, 1095-1275). One-directional structural match of required against actual types, no occurs check, first proposal wins a slot, later ones set a conflict flag.
- **Lifetime inference by structural matching** (conf.rs:823-1103, CR:36-114). One pass, by lifetime name, first binding wins.
- **Checking-work selection** (product.rs:1860-2116). Per target, a growing fixpoint over reachable machines and provider candidates; every unreached machine is excluded from checking.
- **Hand-built SSA for assembly** (aao.rs:268-410, 1230-1339). Must-defined bitset over labels, then each register write becomes a versioned local `<reg>$version$<n>`; the block becomes a helper machine with contracts copied from `requires`/`ensures` facts.
- **Inertness analysis** (prep.rs:520-768, 882-1143). Decides whether a value-index argument can be evaluated twice, from call write frames.
- **Budgets in the stage-05 prose**: range-state fixed point 64 rounds (README05:200-205); logical conversion 4,096 units, depth 64 (README05:721-727).

## The three properties, tested

**1. Acceptance was the code's own yes or no.** For: all ten reports grep-confirmed no call to `proof_admission`, `ProofNode`, `verify_obligation` or a certificate (007 Surprises; 008 Surprises; 009 Surprises 1; 010 Surprises 16; 011 Rules preamble; 012; 013 Coverage; 014 Surprises 1; 015 Surprises; 016 Property-1 paragraph). "Proof" in this group means the code's own lattice (cge.rs:2801-2840), its own `i64` evaluation that overwrites a membership fact with `true` (ce.rs:1748-1751), or a re-run of the tree checker. "Receipt", "custody", "verified" and "commitment" name records the same code wrote (EA:7 vs EA:159-183; conf.rs:1754-1761). The stage-05 README says the checker kept no certificates (README05:50, 650-651, 689-690). Against: none found. The places that came nearest to independent evidence were all the old tree checker run on generated programs: precondition discharge by snapshot (ce.rs:4317-4363, CI:227-256, me.rs:640-649, 802-826), constant qualification (ce.rs:3101-3121), array lengths (ce.rs:2770-2775), `check_mathematical_declarations` (prep.rs:2051, 2110), and two places that emit `Requires` facts for the checker instead of deciding (sel.rs:1948-1960; aao.rs:1009-1137). Probes themselves rejoined the program unchecked (`rejoin_unjudged`, CI:1949-2029), and call-free scalar leaves were never checked (CI:4232-4240). Verdict: holds for all ten slices; the proof kernel is used nowhere in this group.

**2. Identity by text.** For, with counts by form:

- Specialization keys as `normalized_type_identity_text` strings (mono.rs:3318-3355, sel.rs:1005-1020, bcr.rs:654-667).
- Source spans as identity across clones: every probe slice (ce.rs:3083, cge.rs:2380-2474, CI:177-185, 3509-3533, layouts.rs:3410-3417, syntax_probes.rs:180-209, DP:1307-1415, prep.rs:469-497).

## Patterns not seen before

- **Clone, re-derive, compare against itself.** Six slices (007-012) evaluate in a cloned program and then check that the clone selected the same constants and calls as the authored source, compared by source span. This produces most refusals in the group: about 80 of 130 messages in CI (009 Rules), about forty in cge.rs (cge.rs:47-2117), 54 in CC/DP (014 Surprises 9). Replay recomputes and compares (CI:2077-2485); access plans are computed on a probe and again on the typed program and compared by `identity()` (layouts.rs:3811-3816); evaluated lengths are computed by three passes (ce.rs:2194-2233, 3003-3057, 2770-2775).
- **A checker nested inside an evaluator.** Full `prepare_typed_trees` + `lower_typed_trees` per array length, per constant qualification group, per build-time call with `requires`, and per argument establishment (ce.rs:2770-2775, 3050-3057, 4397-4463; me.rs:534-652, 1520-1603). The discharge can run twice for one call (ce.rs:4397-4398, 4463).
- **Values smuggled through the type table.** Six slices store const values as symbol-less named types and parse them back (see property 2). Two lookups fail when nobody has yet written that decimal text (mono.rs:4494-4499, sel.rs:86-98).
- **Unbounded fixed points.** At least twelve loops end only on "no progress": ce.rs:147-196, 217-270, 349-403, 4876-4930; CI:3952, 2288, 3353; syntax_probes.rs:251; CC:3345-3457, 4046-4077; mono.rs:3751, 1522; prep.rs:1990, 2034, 2090; product.rs:2041-2114. The only numeric limits are 100,000 work units, the rational-lattice budgets, and the prose's 64 rounds and 4,096 units.
- **Silent refusals by `continue` or `Ok(None)`.** Every slice has them; the reports list roughly 300 sites (for example CC:1301-1383, 2614-2619; DP:341-345; mono.rs:1199-1215; product.rs:1419-1422). Many say "cannot tell" who reports the skipped case.
- **Rules decided in rewrites.** Unreachable transitions deleted by a small evaluator (bcr.rs:3932-4070); membership facts replaced by `true` (ce.rs:1748-1751); constrained types stripped (ce.rs:3138-3143, syntax_probes.rs:473-497); `ensures` facts selectively copied to assembly helpers (aao.rs:60-119); termination witnesses moved by text (aao.rs:770-819); which machines get checked at all (product.rs:2102-2112).
- **Two answers to one question.** Two entry-state definitions (ce.rs:2904-2916 vs 1412; me.rs:737-752 vs 1512); two integer evaluators (ce.rs vs cge.rs); three agreement tests with three outcomes (CC:1583, CC:3621, CR:1112); two `const_identity_type_reference` (mono.rs:2586, 4486); two `copy_expression` (bcr.rs:143, 1696); three pipelines with different checks (prep.rs:1945-2135).
- **Shared expression nodes rewritten in place for all contexts.** ce.rs:4904-4906 (one fold), CC:3025-3077 (refusal when contexts disagree), prep.rs:954-977 (struct literal refusal). A body shared by two contexts cannot call two instances (014 Surprises 2).
- **Parts already on the lowered form.** Array lengths and build-time calls ran on Terminal Psi (ce.rs:2834-2842, me.rs:5072-5097, EA:584-589); unchecked input was refused (EA:691-702).
- **Large unreachable surface at deletion.** Layout, access and lifecycle validation (010 Surprises 1), domain-fact machines (ER:14-22), data-context policies (layouts.rs:6197-6205).
- **Panics standing for invariants and diagnostics without spans** (cge.rs:4884, 5173; CI:4303, 4351; layouts.rs:5955; bcr.rs:4203; mono.rs:2567 vs diagnostic at 1408; ce.rs:1732-1740; bcr.rs:2880; CC `Diagnostic::error` alone).
- **Order coupling by position.** Evidence placeholders matched to requirements by depth-first closure order (bcr.rs:4211-4212, conf.rs:2015-2026, aao.rs:2012-2022); specialized states by ordinal (bcr.rs:2849-2858, cge.rs:1210-1214); "Ready" case is the first variant (layouts.rs:673-687).

## What a rebuilt compiler must still do

- Evaluate constants, const-generic arguments, array lengths and range endpoints at build time in dependency order and refuse cycles (rows: cycles, destination type, array length, zero-argument length).
- Evaluate integer arithmetic exactly under each type's arithmetic policy and width, refusing overflow, division by zero and bad shifts (rows: arithmetic policy, 64-bit storage).
- Give anonymous numbers exact rational meaning and refuse inexact landings and fractional intermediates (rows: anonymous landing, constant `match`).
- Admit only builtin operator meaning in constant and build-time contexts (row: builtin meaning).
- Restrict casts in constants to total conversions (row: constant cast).
- Let const arguments name only constants visible in their lexical scope and respect constant privacy across packages (rows: lexical scope, private constant).
- Run a machine at build time only when its closure terminates, carries no linear values, uses only permitted services, has its `requires` proved for the concrete arguments, and stays within the work budget (rows: `requires` at concrete arguments, termination, linear, services, work budget).
- Return only closed, freely copyable build-time values (row: ConstEvaluable).
- Enforce package dependency authority for build-time and reflection selections (rows: package authority, reflection authority).
- Prove a constant satisfies its constrained destination type and every domain on its type before treating it as a member (rows: qualification, domain membership, zero-gate).
- Refuse `size_of`/`align_of` of proof-only or unresolved types and restrict `align_of(value)` to addressable places (rows: size_of, align_of).
- Model NaN without payload and exact float representability in constants (row: NaN).
- Keep the compiler-owned `Build` value out of every storage placement (row: `Build`).
- Validate fixed layout plans, access views, lifecycle views and reflected schemas, including capacities (rows: FixedLayout, Access, View, schema reflection).
- Specialize generic machines, conformances, domains, cleanups, providers and families completely, refusing incomplete or inconsistent static tuples and over-long argument lists (rows: static argument arity, proposals agree, incomplete tuple, cleanup/domain/dyn, finite family, target family).
- Infer and check lifetime arguments of calls and conformances consistently (rows: lifetime conflict, explicit lifetimes).
- Route a requirement call through a named implementation only when it implements the declaring trait application (row: named implementation).
- Keep a runtime-bound const parameter out of static positions (row: runtime Value parameter).
- Refuse false `requires` type predicates on generic machines (row: type predicate).
- Desugar suffixed policy operators with the carrier and contract restrictions (row: policy operators).
- Check inline assembly register definedness, control and target agreement (row: assembly).
- Bind user operators, match-by-equality and range indexing with their stated restrictions (row: body-bearing operator).
- Resolve record-pattern rows, match subject types and runtime index descriptors (rows: record pattern, match subject, descriptor).
- Admit `build.omg` requests against their declarations: provider uniqueness, composition modes, test groups, native bindings, assumed-binding authority, wire facts (row: build requests).
- Eventually run layout policies, access policies and domain-fact machines on the lowered form instead of refusing them (row: three refused jobs).
- Carry the stage-05 rules the prose documents: range fixed point, termination ranking, borrow and loan judgments, elision, crash routes, call guarantees (row: prose rules).
