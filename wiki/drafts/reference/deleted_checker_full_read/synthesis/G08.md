## What this code was

Slices 066-074 are the back half of stage 05 (typed trees to checked trees). This code turned the checker's intermediate results into the `CheckFacts`, `ProofFacts` and `FactPlan` tables that later stages read. `pf:10993-11527` (069) is the top-level driver: it builds borrow, value, proof and semantic facts, then loops flow construction, permission events, cleanup-loan retention and entry-requirement inference until nothing changes. Around that driver the files publish contract identities, crash contracts, evidence lanes, cleanup prerequisites, index-compatibility facts and provider tables. Most of these files only copy or reshape decisions made in `validation`, `flow` or `checks`. Some of them refuse programs themselves: proof-output calls (067), named `ensures` evidence (066), automatic cleanup (068), index compatibility (069), crash refinement (069, 070), and the declaration-selection ledger and Build protocol (071). `values.rs` and `values_scalar.rs` (072-074) translate source expressions into the closed `CheckedScalarExpression`/`CheckedBooleanExpression` language. They never emit a diagnostic, and their `None` decides whether a later stage can express a value at all. Slice 075 is not checker code: it holds the stage-07 optimizer (branch folding, constant folding, copy propagation, value numbering, dead-scalar removal), the stage-08 publisher, and an audit of float result policies that production does not run. No part of the group calls the proof kernel to verify anything.

## Mechanisms

- **The checking fixed point** (pf:11089-11159, 069). Each pass reseeds the declaration plan, rebuilds flow facts, then repeats if permissions asked for a retry, if cleanup-loan retention added a loan (pf:725-824), or if entry-requirement inference added a row (pf:871-1024). There is no pass counter. I checked pf:11136-11158: `continue`/`break` only. Flow reuse compares six whole cloned tables with `==` (pf:11571-11610).
- **Definite assignment of evidence** (pub:2441-2703, 066). A breadth-first search over (state, assignment map, known label set) with a `seen` set over the whole triple. It has no budget and serves named `ensures` evidence and outcome guarantees.
- **Callee body summaries.** Possible result cases (pub:2917-2991), private crash summaries (CC:729-789, which stops after n+1 sweeps without checking convergence), and float "returns its argument" (CC:4676-4757).
- **Cleanup hook sequencing** (pf:1148-1981). Groups dispositions per death edge, orders hooks by declaration geometry, carries a live fact state, and kills facts on writes. The predicate budget is 4096.
- **Unit-propagation prover** (BP:2030-2172). Closes truth over `!`, `&&`, `||`, Boolean `==` and the symmetry of integer `==`. It has no arithmetic. `boolean_predicates::proves` is the only "prover" in the group, used for crash refinement (pf:10846).
- **Entry path conditions in DNF** (BP:660-843). Clause sets with subsumption. The clause product is unbounded.
- **Crash-route refinement** (CC:2727-3835). Substitutes arguments into guards, folds literals and intervals, and widens unknowns. The guard identity is a source-syntax tree carrying text.
- **Backward entry provenance** (CEV:1742-2402). Recursive with depth 64 and no memo table. It uses a syntactic write scan with a path-disjointness algebra (CEV:716-1315).
- **Interval sources and constant folding** (val:24-1139). Hand-written meet and join, element enumeration capped at 4096 visits, and a three-valued folder over checked forms that admits only 64-bit leaves.
- **Contract reader with a shared budget** (vs:3284-3457, 6947-6969). One budget of 4096 steps and depth 64. The literal `4096` is written at 5 constructors in vs and at 3 sites in pf. Peel loops are capped at 8 steps.
- **Plan walk** (vs:5485-5567). One pass over every statement records scalar rows tagged with 17 placement roles.
- **Selection-ledger cascades** (sh:359-465, 1653-1698, 2217-2336). Seven-source fallbacks run in parallel per expression in chunks of 256 rows.
- **Machine call SCC waves** (sh:3629-3798). Iterative Tarjan, then waves run in parallel.
- **IEEE set evaluation** (CC:4345-4638). Every possible value is carried; Cartesian products are unbounded.
- **Optimizer retention inventory and machine-pruning fixpoint** (cfr:171-617). Dominator value numbering is quadratic (passes:425-575). The saturation-eligibility recognizer has a 4096-lookup budget (rpv:22-274).

## The three properties, tested

**1. Acceptance was the code's own yes or no.** Every report finds no call to `proof_admission`, `ProofNode`, `verify_obligation` or a certificate check (066 Surprises, 067:98, 068 Surprises, 069 Surprises, 070:281, 071:19, 072:134, 073 Surprises 2, 074:146, 075:70). Against the property: 068 and 069 sometimes delegate to `checks::contracts` provers (pf:1396-1426), and the BP prover is a real if small decision procedure. Those are still the checker's own code. Against: these parts identify things by handles:

- 068 cleanup `CanonicalPlace` and index normalization (pf:668-671, 5067).

Handles rule in places, cleanup, index equality, Boolean predicates and scalar plans. BP and CC sit side by side, and `SummaryCrashPredicate` carries both a text identity and a checked scalar (CC:3019-3046).

**3. One rule written per placement or construct.** Repetition estimates: 066 15-20%, 067 15-20%, 068 10%, 069 10%, 070 5% by placement plus 15-20% by construct, 071 25%, 072 15%, 073 35-40%, 074 25-30%, 075 12-21%. The clearest per-placement cases:

## Patterns not seen before

- **Re-derive and compare inside one compile.** At least 9 places rebuild what an earlier step produced and refuse on a difference:
  - 12 "drifted before checked binding" checks (pub:3575-4534);
  - the proof-output signature compared with `validation`'s choice (pub:5507-5530);
  - the resource-envelope second gate (pf:2954-3017);
  - the nominal-use envelope comparison (pf:7328-7339);
  - the `refresh_realized_contract_envelopes` assertion (pf:11534-11556);
  - the boundary application rebuild (sh:4293-4526);
  - the CEV third derivation (CEV:619-635);
  - the storage-place re-resolve (vs:11141-11276);
  - the rpv audit (075).
- **Whole files that never refuse.** BP, CEV, `values.rs` and both halves of `values_scalar.rs`, about 33,000 lines, contain no diagnostic. A `None` means both "another builder owns this" and "malformed" (073 Surprises 1; 074:20; 072:172).
- **Refusals stored as data.** Instead of a diagnostic, the code stores `Unavailable { reason }` descriptions (pf:4631-4671), provider `Err(String)` rows (pf:8880-9319), `CheckedReferenceSourceContract::Unavailable(String)` (val:2211-2253), and a custody flag (pf:10387). That is 4 mechanisms.
- **Rules decided by callee implementation, not contract.** Result-case summaries (pub:2917), the float identity-return check (CC:4698), private crash summaries (CC:473), and identity mathematical definitions (vs:1896-1931).
- **Contract clauses the author never wrote are inferred.** Conditional cleanup entry requirements (pf:862-1496), crash summaries (CC), blocking/suspension/invocation interfaces (pf:7763-7891), and capability flows (pf:261-370).
- **Several unbounded fixed points.** The driver loop (069), capability verbs (068), cause sets (CC:125-150), definite assignment (066), machine pruning and constant folding (075). One bounded loop does not check convergence (CC:750).
- **Bare budgets.** `4096` appears at 3 sites in pf, 4 in BP/CC, 6 in val and 5 in vs. Depth 64 appears about 15 times, and 8-step caps 5 times. Results fall off a cliff at those sizes (val:492, 615).
- **The entry state is found by position.** `machine_states(..).first()` is used in 067 (5 places), CC (5), vs (6), while BP uses `activation_target_state_index` (070 Surprises 6).
- **Coordinates fixed by position.** Hard-coded `call_ordinal == 0` (pub:4056, 5455, 5744, 7767, 8390), the package at statement +1 (pub:5733), the adapter as the next operation (rpv:424), qualification rows by argument position (passes:337), and `late_binding_ordinal` counting (sh:1453).
- **"Builtin" has four or more definitions,** and a missing record counts as builtin (071, 073, 074).
- **Several Boolean lowerers for one predicate algebra.** `BooleanLowering`, the `crash_entry::Reader`, `structural::lower`, `ContractPredicates::boolean` and the shared `lower_boolean_expression` (073, 074), plus six variant walks in BP/CC (070). They differ in which forms they accept (floats, `match`, byte equality).
- **Rules decided in lowering planners.** Borrow admission falls out of whether `reference_sources` can build a lowering plan (val:1717-2270). Cleanup asks `execution::terminal_unit` for clause rosters (pf:1363).
- **Text round trips.** A place becomes text and is parsed back (CEV:404-596). BigInt and decimal strings are parsed back (pf:6967, vs:7291). Float spellings are compared by parsing (val:2757, CC:3192).
- **The dense-id rule is broken.** `HashMap`/`HashSet` keyed by handle or index appear at pf:9798-10264, sh:2114, 3523 and val:2303. A pointer identity appears at pub:1911.
- **Comments and code disagree** in at least 8 places: pub:9167; pf:372, 573; vs:8166-8201; CEV:1262; 07/README; 08/README.

## What a rebuilt compiler must still do

- Discharge a callee's `requires` at each call and make its `ensures` available after; internal state transfers carry neither (rows: call imports, owes `ensures`).
- Prove a machine's `ensures` on every ordinary exit (row: owes `ensures`).
- Inherit trait-requirement contracts into conforming machines through parent traits, by exact conformance application (rows: trait contract, call signature).
- Check named witness evidence: binding to witness propositions, forwarding from `requires` to `ensures`, projections `term.member`, and proposition equality (rows: named binding, forwarding, projection).
- Require every named `ensures` evidence output to be definitely assigned exactly once on every ordinary exit (row: definite assignment).
- Check outcome-specific guarantees per result case, including terminal-call discharge, and `when`-arm outcome selectors on saved call results (rows: outcome guarantees, terminal call, selectors).
- Check proof-output calls and static named-witness requirement dispatch (rows: proof-output, dispatch rung).
- Evaluate a `when` dispatch subject once (row: evaluate once).
- Make a qualified type argument owe its domain on the actual argument, and lend shared-reference formals correctly (rows: qualified type argument, shared formal).
- Derive case facts from `ensures result in Case` and `requires x in Case`, and decompose only builtin `&&` (row: case facts).
- Seed entry facts from parameter domains, field domains, float bounds and carry permissions, and seed uninitialized locals to their first case and zero (rows: entry facts, zero init, parameter constraints).
- Retire every fact when storage it reads is written, per field path (row: fact retirement).
- Keep loans live until automatic cleanup runs, and prove each cleanup hook's `requires` at every death edge, in declaration order, under the hooks' writes (rows: cleanup loans, cleanup requires).
- Publish or refuse cleanup prerequisites in generic code according to the ratified design; the old code inferred them as conditional entry requirements (row: generic cleanup).
- Publish a machine's contract identity and crash interface, and require nominal uses to match them (rows: contract identity, crash buckets).
- Treat trapping operations as `Trap` crash sites, compute family crash envelopes, and infer or require crash contracts of private machines (rows: trap, family, private summary).
- Refine callee crash routes at each call by arguments, path condition and caller `requires`, and refuse static callable arguments that exceed the required crash ceiling (rows: crash refinement, static callable, operator crash).
- Check index compatibility of indexed domain instances at every write, argument and return, and the establishment of bodyless families (rows: index compatibility, bodyless family).
- Check that integer writes fit the stored type (row: integer write).
- Require unconditional termination for `embed` and fact-position call projections (row: embed).
- Publish blocking, suspension and synchronous-invocation interfaces (row: interfaces).
- Keep provider associations, qualification origins and authorized establishment routes exact (rows: providers, qualification).
- Resolve every authored selection to the declaration actually used, and refuse unresolved ones (row: selection ledger).
- Enforce the Build binding protocol (row: Build protocol).
- Grant builtin laws to an operator only when its selection is builtin, and never assume it from a missing record (row: builtin operator).
- Check float-meaning projections against sealed toolchain declarations, IEEE comparison meaning, NaN and signed zero (rows: float meaning, float comparison).
- Type integer literals by context with width checks, and type comparisons, arithmetic, casts and recasts (rows: literal landing, integer comparison, casts).
- Support byte-carrier equality and byte-as-`bool` reads (rows: byte equality, byte as bool).
- Restrict contract expressions: `result` scope, `requires` vs `ensures` storage access, no trapping arithmetic, predicate expansion (rows: contract language, predicate expansion).
- Check index reads and borrow access rules (rows: index read, borrow).
- Handle erased formals and proof-term actuals (row: erased formals).
- Supply payload-membership predicates only under a selected case (row: payload membership).
- Keep every proof-named id intact through optimization (row: optimizer).
