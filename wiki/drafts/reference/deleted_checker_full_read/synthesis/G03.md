# Group G03: old checking stage: driver, borrow facts, general checks, borrow checks, content conservation

File names used below (all under `05_typed-trees-to-checked-trees/src/`): `borrow.rs` (slices 017-018), `checking.rs` (019), `checks.rs` (020-021), `checks_borrows.rs` (022-023), `calls.rs` = `checks_borrows_calls.rs` and `overlap.rs` = `checks_borrows_overlap.rs` (024), `cbr.rs` = `checks_borrows_resources.rs` (025), `checks_content.rs` (026). All ten reports were read in full. Claims I checked in the old source are marked "(checked)".

## What this code was

This group is the core of the old source checker's stage 05, "typed trees to checked trees", about 66,000 lines. `checking.rs` is the driver: `check_program` (checking.rs:1021-1421) calls about thirty checks in a fixed order, stops at the first one that returns diagnostics, and publishes `CheckedTrees` with a large facts record. `borrow.rs` builds borrow facts: loans, who supplied them, last uses, and which loans a return carries; it refuses only when its own inputs are missing (018 Surprise 1). `checks.rs` holds the general checks run by `check_checked_facts_recording` (checks.rs:12216-12418): case selection for payload access, atomic fence ordering, runtime type indices, integer fit for encoded fields, suspension carry, crash-route coverage, cleanup admission, and an evaluation-order model of ownership. `checks_borrows*.rs` is the borrow judgment: per-statement conflict checks, call-argument conflicts, a spatial overlap test backed by an integer-ordering prover, returned-view escape and elision, and an interprocedural "every caller must prove it" mechanism. `cbr.rs` joins the borrow and flow ledgers into resource rows that lowering reads to suspend and restore parent borrows. `checks_content.rs` checks conservation of content-bearing domains (a value's qualified backing may only be handed back if an owned claim to it was consumed). Only one unit test exists in the whole group, and it tests an index, not a language rule (checks_content.rs:4951-5029).

## Mechanisms

- **Running roster per state, no join** (borrow.rs:8687-8907). Borrow facts are built statement by statement over a straight line; each state starts from its parameters only (018 Mechanisms). Facts are keyed to statement index and owner place, not to values (022 Surprises).
- **Last-use fixpoint** (borrow.rs:2287-2459): monotone, no iteration cap, quadratic in loans per round, one-statement granularity.
- **Pointer following** (`rebase_borrow_places_following`, borrow.rs:7191-7355): replaces a place by the loan target behind it; only an `active` stack bounds it; it stops at storage whose type equals the referee type (borrow.rs:7071-7104).
- **Replay schedules**: reference-slot contexts (borrow.rs:1477-1666); statement occurrence lists with a branch-and-join driver that runs each join once (checks.rs:8149-8248, 8722-8997), consumed by checks_borrows.rs:3595-3643, 5947-6153 and calls.rs:1251-1432.
- **Value-producer walks**: descriptor-load resolver, storage-address resolver, lineage with intersection at joins, completed-value producer walk (checks_borrows.rs:7163-10208); the 14-arm supplier search (cbr.rs:3638-4083); backing resolution (cbr.rs:5262-5412). All use ancestor lists for cycle refusal, no budgets.
- **Spatial judgment** (overlap.rs:2924-3015): root and segment overlap/containment; index selectors normalized to literal, symbol plus offset, sum of two symbols, call result or projection (overlap.rs:1077-1146); ordering asked of `validation::prove_integer_ordering`, which composes one premise pair through a middle bound (overlap.rs:1161-1164). Premises come from `requires`, incoming guards, domains, transparent propositions, callee guarantees and recorded values (overlap.rs:1828-2024).
- **Interprocedural discharge** (checks_borrows.rs:2544-2749) and the **stored-integer walk** (checks.rs:4649-5240, no memo, no budget, cost grows with call paths).
- **Fixpoints**: persistent-static facts over the state graph (checks_borrows.rs:827-905), debt transfers (cbr.rs:6269-6352), partition-wrapper composition (checks_content.rs:6886-7119), integer order closure (checks.rs:11543-11567): none has a cap. Bounded ones: `compare` depth 128, region inference depth 16, float reaching store depth 16 (checks.rs:2749, 2602, 1164); `Consequences` 4096 steps and depth 64 (checks.rs:9672); terminal-demand transport 65,536 units (checks_content.rs:80); content lineage 65,536 visits and depth 128 (checks_content.rs:1297, 1674).
- **Lattices**: carry policy, born strict for claims and intersected (checks.rs:5380-5454, 7254-7323); path-condition algebra `SelectionConditions` for coverage (checks_content.rs:617-626, 7037-7049).
- **Parallelism**: per machine with arena handle shifting (borrow.rs:9574-9643), per state (checks_borrows.rs:11805-11874, calls.rs:1511-1608), `rayon::join` in the driver (checking.rs:1151-1281).
- **Whole-result reuse** keyed by full structural equality of typed programs (checking.rs:808-938).

## The three properties, tested

**1. Acceptance was the code's own yes or no.** For: all ten reports searched for `proof_admission`, `ProofNode`, `verify_obligation` and certificates and found none (017 line 158, 018 Surprise 2, 019, 020, 021 Surprise 1, 022, 023 Surprise 1, 024 Surprise 10, 025, 026). The stage's verdict is "no diagnostics collected" (checks.rs:12409-12417) or "every Result was Ok" (checking.rs:1021-1421). Where the code wanted a second opinion it asked itself again: replay of rosters (borrow.rs:345-372, 877-904), rebuild of operator crash sites (checks.rs:10479-10515), "drifted from independent topological replay" (cbr.rs:2805-2840), saved requirements re-discharged by the same code (checks_borrows.rs:2772-2907). Indexed theorems are marked as proved normal returns before any check runs (checks.rs:12234-12247, checked); 019 shows the theorem terms were copied from preparation as data (checking.rs:1292-1398). Against: nothing in the reports. Delegated provers that might or might not reach a kernel, each named by the reports: `proof::checker::check_proof_plan_with_decisions` (checking.rs:422), `judge_contract_entailment` (checking.rs:1100-1106), `validation::prove_integer_ordering` (overlap.rs:560-567), `CurrentScalarValues::proves_values_relation` (checks.rs:2985-3007), `contracts::call_values::proves_entry_predicate` (checks.rs:5165-5177), `operators::context_proves_float_semantic_term` (checks.rs:10682-10715), `termination::entry_covers_progress_premises` (checks.rs:9171-9192), `validation::completed_value_*` (checks_content.rs:782, 966, 987, 1201), and `StateGuarantees` premises (checks_borrows.rs:1937, overlap.rs:1955-2015). All return `bool` or decisions, not evidence. Verdict: holds for all ten slices.

**2. Identity by text.** For, at decision points: last use is decided by name OR symbol (borrow.rs:2281-2283, 2356-2367), and slice 018 shows that the names fed in for call results, returns and descriptor loads are the state's own name (borrow.rs:5636-5637, 7643-7644), which corrects 017's reading that the slice was structural; lifetime region operands are strings (checks.rs:2514-2661); an index value is parsed from a type name's spelling (checks.rs:2131-2139, 3522-3527); a data type is found by last `::` segment (checks.rs:5670-5673); carry claims are matched by rendered label or label prefix, and a call argument's key is its display text (checks.rs:7292, 7362-7376, 7852; also 5420); crash predicates are name-encoded, with an explicit provenance defence (checks.rs:9234, 9483-9498); the generated `__transition_subject#` prefix decides loan end (checks.rs:11121; checks_borrows.rs:4486); a static-path invalidation compares rendered path strings (checks_borrows.rs:1464-1532); first local by name (checks_borrows.rs:1339-1344, 1653-1656); pattern-bound names (checks_borrows.rs:4543-4555); `prepare`/`prepare_tests` (calls.rs:1635-1644); dependent-data field names (overlap.rs:3335-3357, checked); projection-plan carrier by type-identity text, parameter root by name OR symbol, case and field by name with a dotted split, Debug-rendered sort order (checks_content.rs:3724-3731, 3833-3835, 5286-5317, 4367-4409). Against: 019, 023 and 025 found no decision made by text, and every report says handles dominate. Positional identity is the stronger pattern: calls by (statement, ordinal) or (statement, authored expression) in 019, 021, 023, 024, 025, 026; entry state as "first state" (checking.rs:1366-1369, checks_borrows.rs:835-848, 10864-10868); state exit as statement index equal to statement count (checks_borrows.rs:6869). Verdict: holds in 7 of 10 slices at roughly 25 decision points; not the main mode.

**3. One rule per placement or construct.** For: bare boundary trait across six hand-listed placements (checking.rs:500-566); content custody written for root and for nested field, and for result and out-parameter (checks_content.rs:5077-5197 vs 6193-6337; 1803-2050 vs 2235-2526); assignment writes and call writes judged by different code with the same message (checks_borrows.rs:6155-6324 vs 6366-6519). Against: most repetition is per expression kind, segment kind, loan kind or value origin, not per placement; one spatial judgment serves all places (overlap.rs:19; 024 Surprise 11); 018 unifies placements by fabricating a `let` for each (borrow.rs:5634-5646, 7563-7575, 7641-7653, 7980-7992). Estimated repetition shares: 15%, 20%, 20%, 14%, 15-20%, 11-13%, 12-15%, 12-25%, 30%, 20% for 017-026. Verdict: weak for placement; strong for construct and origin (the 13-strategy supplier search in cbr.rs:3743-4052 is the largest single case, about 1,400 lines).

## Patterns not seen before

1. **Internal-consistency failures shown as user errors.** Messages that say a table "lost", "drifted" or "has no exact" something: nine reference-slot messages (borrow.rs:1502-1665), every refusal in 018, five Build messages (calls.rs:1654-1694), most of cbr.rs (025 Surprise 6), placement primitives (checks_content.rs:2573-2611). Five of ten slices.
2. **Refusal reasons hidden.** About 130 reason strings in 023 against eight user diagnostics (023 Surprise 9); terminal-demand reasons and stored-call-input reasons discarded (checks_content.rs:180, 206; cbr.rs:5827-5835); the unavailable reason replaced by a fixed string (borrow.rs:7494-7496).
3. **No source spans.** Diagnostics name "statement N" (018, 021, 023); cbr.rs attaches a span once (cbr.rs:5998-6019).
4. **Debug prints on the verdict path.** `eprintln!` under trace flags in 017, 021, 022, 023, 024, 025 (13 sites, about 170 lines in cbr.rs).

## What a rebuilt compiler must still do

- Refuse any access to storage that interferes with a live loan, with shared reads allowed together, using one judgment for borrow, read, move, assignment, call write and call argument (R1, R3).
- Refuse conflicting holds formed in one evaluation, such as two `&mut` arguments to overlapping storage (R2).
- Allow reborrows only at equal or weaker access and suspend the parent until every reborrow ends (R4, R15).
- Check returned views against the declared lifetime relation and elision, and refuse views of locals, owned inputs and temporaries (R5, R6, R7).
- Require borrows stored in persistent machine fields to be static (R8).
- End loans at last use, including inside a statement and on one taken edge, while copies and suppliers keep them alive (R12, R13, R14).
- Refuse a state jump that carries a loan of storage ending at the jump (R9).
- Prove a helper's overwrite of a field it still points into is safe for every caller, and recheck at an external entry (R10).
- Keep owned inputs unborrowed when an implicit transformation completes (R11).
- Cover each function's output lifetime inputs exactly by its declared dependencies (R16).
- Give string-literal storage shared access only (R17).
- Treat loans in different sum cases as non-conflicting and separate array elements by proved index facts (R18, R19).
- Keep dependent sibling fields pinned when one field of a `requires`-related pair is borrowed, by declaration identity rather than spelling (R20).
- Fix the evaluation order of receivers, arguments, match parts and short-circuit operands (R24).
- Refuse values crossing a suspension unless their carry policy allows it and their backings are retained, and require `suspend`/`block` acknowledgement in direct positions (R25, R26).
- Prove the selected case before payload access and a single fence ordering (R27, R28).
- Preserve runtime type indices and erased proof identities at every binding (R29, R30).
- Prove integers fit encoded fields across calls and recursion (R31).
- Cover every crash site and propagated crash route with a published route, and keep `crash` exits and constants clean (R32, R33).
- Admit only infallible, terminating, service-free cleanup machines (R34).
- Refuse boundary traits as value types and portable references to target-specific machines (R35, R36).
- Enforce content conservation: one owned source or one exact loan per result, equations for partitions, provenance for published memberships, and lineage to the moved-in claim (R37-R40).
- Recheck indexed theorems against their authored contracts (R42).
