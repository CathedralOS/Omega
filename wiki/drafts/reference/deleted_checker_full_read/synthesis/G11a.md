# Group G11a: validation contract prover, first half (arithmetic engine, call requirements, citations, induction, law conformance, rank descent)

All citations are to `contract_entailment.rs` in `omega-rust/psi/compilation/validation/src/`, written `ce:line`. The group is lines 1-46180 of that one file (slices 098-103, 46,180 lines).

## What this code was

This was the part of the old checker that answered "is this fact proved here?". It held two provers. The first is `Engine` (ce:6249-6278), an integer arithmetic prover over polynomials whose variables are strings. The second is `StructuralJudge`, which walks the statements leading to a site path by path and carries symbolic values (`StructuralTerm`) and hypotheses; its body is outside the group, but the walk that drives it is at ce:45465-46123. About forty inline modules each put one question to one or both provers: does a call meet its callee's `requires`, which facts does a lemma call deliver, is an index in bounds, does a struct literal meet its `data` invariant, does a provider's contract cover the trait requirement it fills, does a `terminates by` rank descend. Every answer left as a `bool`, an `Option` or a three- or four-valued enum. No module built or checked a proof object. Most refusals carried no text: slice 098 has no diagnostic, and slices 101 and 102 have one each. The group has nine unit tests, eight on an empty program (ce:1252-2705) and one truth table (ce:35837-35867).

## Mechanisms

- **Polynomial engine** (098). `Polynomial` is a map from monomials of string atoms to big integers (ce:6026-6031). Equalities become substitutions, applied for at most 8 rounds (ce:1853-1896, 6281). Bounds `a - b >= c` feed a difference-bound matrix (ce:1787-1832). `prove_at_least` tries, in order: a conditional case split, constants, the matrix, a stored bound, a proportional bound, intervals, a greedy pairing for 3 to 128 atoms, a Horner interval, then one combination with each stored bound (ce:3519-3863). It has no multi-step linear combination. Contradiction search is pairwise (ce:6860-6892).
- **Opaque terms.** Quotient, remainder, shift, bitwise, wrapped or saturated value, conditional, call result and measure application each get a minted atom and an interval (ce:2715-2761, 3024-3201). Known-bits analysis runs to depth 64 (ce:3211-3291). Calls and measure applications get congruence closure (ce:4043-4095). A value's dependency closure can be saved and replayed in another engine (ce:1366-1499), which serves ranks carried between states.
- **Conditional case split.** The prover clones the engine per `match` arm and charges a shared counter of `1 << 20`; exhaustion answers false and is final (ce:3970-4031, 6352).
- **Path-set forward walk** (103). The walk follows a state's statements, keeps one judge and one name-keyed environment per path, splits per outcome, merges outcomes that added nothing, and prunes contradictory paths (ce:45465-46123). It enters concrete callee bodies (ce:44658-44862) and skips repeated arrivals through a memo (ce:44489-44594).
- **Visitor on the walk.** A question names a site `(state, statement index, in transition target)` and is told when the walk reaches it. Fourteen visitors use it: nine in 099 (ce:8679-13978), numeric observation and operand fit in 100 (ce:19996-20979, 23133-23675), strict decrease and call-result length in 101 (ce:23771-23881, 28702-28751), rank progress in 102 (ce:31024-31355).
- **Cascade of hypothesis sources.** A question tries the state under its own contract, then the whole invocation if the state graph is acyclic, then the facts at the machine's private callers (ce:8494-8594). Each question tries a different subset.
- **Two-pass batched bound proofs** (ce:10598-10732) and **batched memos** for variants (ce:12208-12355), numeric observations (ce:20082-20372), operand fits (ce:23133-23324) and shared proof walks (ce:38558-38609). None has a budget.
- **Citation as fact injection.** A lemma's `ensures` is substituted at the arguments and added to the judge in statement order (ce:9563-9634, 9846-9987).
- **Per-arm induction.** One engine per transition arm holds `requires`, negated earlier guards and the arm's guard; a tail self-call adds the `ensures` as hypothesis after the measure check (ce:16648-17140).
- **Contract comparison.** Positional atoms make two contracts share variables (ce:15776-16083). A canonical source key with a 4,096-visit budget compares expressions (ce:17502-17697). One-way term matching with a generality check serves laws (ce:19004-19025, 19331-19442). A union-find over law endpoints with a stack search serves conservation (ce:14389-14565).
- **Rank proof.** A fixed point discovers where each entry coordinate sits in each state (ce:25414-25534), a backtracking search picks one destination per demand (ce:25688-25776), and one engine per edge substitutes arguments for entry atoms and proves membership, pinning and the difference (ce:33672-34289; ce:25993-26522 for calls).

## Patterns not seen before

1. **Proof power depends on who asks.** The same fact is provable or not by route: which hypothesis sources a question tries (four questions use private callers, four do not; ce:8585-8592 against 13107, 13481-13495), which translator runs for a `match` (ce:322-487 against 7461-7482), engine mode (ce:3801-3808), a shared budget (ce:6352), query order under thread-keyed guards (ce:28632-28700, 38516-38556), the layout plan (ce:22342-22391), and whether an unrelated type annotation exists (ce:43050-43056).
2. **One rule at different strengths.** "Provider covers contract" is arithmetic implication for trait requirements, syntactic matching for operators and term matching for laws (ce:16075-16083, 18539-18551, 19828-19925). Ex falso accepts in the arithmetic side (ce:24154, 26453-26455, 34228-34236, 38155-38157, 44467) and refuses in one structural function (ce:34840-34842).
3. **Declared contracts stand in for proved ones.** Law conformance reads declared `ensures` ("compiling means proven", ce:19669-19670); citations rest on the callee being checked "in this same validation batch" (ce:9838-9842); call results take the callee's `ensures` and range as hypotheses (ce:173-182, 37532-37641). Nothing in the group links these to a record of what was proved.
4. **Results computed and thrown away.** Twelve sites: ce:5503, 5539, 9408, 18378-18400, 19603-19609, 23758-23768, 30532, 30545, 30580, 30611, 33944, 34033.
5. **Silent refusals.** 098 has no diagnostic; 101 and 102 have one user-facing message each; 099's inherited-requirement reasons and 102's forty rank reasons are visible only under trace (ce:7739-7893, 31385-31540).
6. **"Zero paths" and "never visited" have no fixed meaning.** Six visitors treat an empty entry list six ways (ce:8787-8794, 10899-10909, 11573-11576, 12388-12390, 13801-13803, 12861), and the walk marks an unvisited end-of-state visitor valid (ce:45965-45990).
7. **Unbounded searches beside bounded ones.** No cap: the arrival fixed point, the selection search, `resolve_deferred`, the law graph, the formation walk, the remainder fixed point (ce:25438-25533, 25688-25776, 10627-10732, 14389-14565, 41956-42579, 5294-5310). 8. **Two records of one thing cross-checked.** ce:26942-26951 (witness against custody), ce:7739-7870 (inherited clause against call occurrence), ce:9615-9619 (incremental against full citation intake).
9. **The old checker already called the new one**, and fell back when it declined (ce:15415-15431).
10. **Deferred decisions.** A target-dependent `addr` fit returns true and records an obligation (ce:5067-5079, 22444-22463, 42173-42181); a range recipe counts as a positive proof (ce:23385-23393).

## What a rebuilt compiler must still do

- Prove that every integer operation, cast and literal stays inside its carrier, with exact, wrapping, saturating and trapping policies (R1, R5-R7, R10, R12).
- Prove divisors nonzero, exclude signed `MIN / -1`, and bound shift counts (R2-R4).
- Check `addr` values against the address bound, including bounds known only per target (R9).
- Check float and integer conversions for exactness (R8) and proof `Int`-to-`Nat` casts for non-negativity (R13, R14, R93).
- Reason about quotient, remainder, shift, bitwise and wrapped values, not only linear arithmetic (R1, R6).
- Prove each callee `requires` at each call on every path, and report a certainly false one (R19-R23, R27, R33).
- Discharge static-only `requires` of generic signatures and `requires` inherited from trait requirements at the exact application (R24, R28, R29, R36).

- Refuse cyclic `requires` and use callee `ensures` only when they do not depend on the caller (R25, R34).

- Allow a recursive machine to assume its own `ensures` only under a proved descent (R44-R47).
- Prove `ensures` on every exit, including results bounded only by returns and guards (R46, R48, R65, R18).
