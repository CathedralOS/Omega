## What this code is for
This is the back half of the "value custody" checker: the part of the old source checker that decided who owns, borrows, moves and cleans up values, and what a type's contents allow. Its modules are small query/check helpers. They cover: recognising a single-arm record match whose subject can be aliased (`logical_matches`); finding which domain-membership facts cover a place (`membership_evidence`); working out which pieces of a partly moved affine (use-once) value still need cleanup (`partial_affine_residuals`); checking that the planner's fixed-layout ("plan-laid") records agree with the data declarations (`plan_laid`); checking `as ... in Domain` casts (`qualification_casts`); deciding whether a reference argument carries the access (shared, mutable, write-only) its parameter needs (`reference_access`); and one walker that answers many "what do this type's contents allow" questions (`storage_contents`). The remaining modules compute type identity and shape (`structural_identity`, `type_shapes`, `reference_shells`, `scalar_representation_range`), liveness of a symbol in a statement (`source_liveness`), runtime-sized inline arrays (`static_inline_storage`), and memo tables (`type_properties`). Most functions return `Option`/`bool` for the checker's own use; only five modules produce user-visible diagnostics (plan_laid, qualification_casts, reference_access, reference_local_establishment, static_inline_storage). No function in the slice calls a proof kernel or certificate API (grep for `proof_admission|ProofNode|verify_obligation|certificate|kernel` over the slice returns nothing); the closest are interval/entailment helpers in other modules that this code calls (`integer_domain_membership`, F:8017; `domain_predicates_hold_at_occurrence`, F:8056).

## Mechanisms
- **Requirement-parameterised contents walker** (`storage_contents`, F:9992-10720). `resolve` (F:10226) turns a `TypeReferenceHandle` into a `ContentType` tree (Scalar, Atomic, Array with optional length, Slice, Shared, Data{symbol,application,args}, View, ConstValue, RuntimeIndex, ImplementationSelection, UnclassifiedOperand, Provider); `check_contents` (F:10563) then walks data fields and variant payloads. The 13 `ContentsRequirement` values switch behaviour inside `matches!` lists (e.g. F:10243-10247, 10357-10425, 10441-10508, 10581-10598, 10641-10672, 10685-10695). Cycle guard: `active` list of (symbol, structural size); a type already active with equal-or-larger size fails (F:10661-10663); `complete` memoises successes. Opaque data uses the selected representation carrier (F:10627-10636, 10700-10703). Serves ownership, copyability, cleanup, FFI/seam marshalling and stable observation.
- **Partial-affine residual reconstruction** (F:6456-7249). Walks a type-plan map (`BTreeMap<TypeIdentityId,...>`) with moved paths and "boundary" paths, in two passes: first with `emit=false` to count residual regions, abort if `count > max_residuals`, `try_reserve_exact(count)`, then `emit=true`. Handles Record, FixedArray (only literal length, untouched indices counted as one region each, F:6795-6809), Sum/Mixed (cases classified Inactive/Selected/Runtime by a caller callback; runtime cases push conditions, F:6926-6932). `established_cases > 0 && reachable_cases != 1` refuses (F:6974). Optionally retains a node partition (Scope/Leaf/Cases) with a node budget `max_partition_nodes` (F:6474). Active-type stack rejects recursive types (F:6673). `validate_type` (F:6545) checks the type has well-formed cleanup (unique valid field identities, no linear claim, etc.) with active/complete sets, and is called with fresh empty sets each time (F:6721, 6798).
- **Static inline extent search** (F:9592-9785). Depth-first through type references, generic argument bindings (a stack of `Binding{parameter,argument,outer}`) and const-expression children, finding a Parameter/Local/Field symbol used as an array length. Budget: `remaining: 4096` steps decremented per node (F:9598, 9615, 9720, 9765); visited list of (reference, bindings) pairs. Stops at types with independent storage (`access_view_plans`, F:9696-9701).
- **Place-segment cover** (F:6225-6270): a candidate segment list covers a subject when each segment is equal or a `FixedRange` containing a `FixedIndex`, contained range, or (for a runtime `Index`) constant index in range or the whole `0..usize::MAX` range. Sorted rows with binary search by place identity then domain key, plus a linear scan fallback restricted to "flexible" rows (F:6195-6217).
- **Plan-laid cross-check** (F:7348-7855). Re-derives offsets/bit fragments/strides from the report entries and compares to the stored plan; stride for repeated fields is derived from sorted element offsets and must be constant and nonzero (F:7758-7775).
- **Type peeling loops with count bound** (`peel_carrier_shells` F:8797, `carrier_beneath_borrows` F:8822, `structural_identity_type` F:10729, `structural_storage_type` F:10777, `has_slice_base` F:11149): each loops at most `type_reference_count()+1` times (or keeps a visited list) to avoid cycles.
- **Logical saved-subject projection** (F:6074-6100): walks Member/Indexed/Borrow receivers up to 64 steps to a SavedSubject, then finds the latest binding permitting the alias.
- **Memo tables** (`type_properties`, F:10968-11091): per-type-reference and per-data-definition `OnceLock` slots in vectors sorted by (arena index, generation), found by binary search; when the memo set is absent or the handle is not found the value is computed uncached.
- **Closure of expression handles** (F:6012-6066): worklist over an expression tree plus match-pattern dependencies, then checks each saved subject's capture owner/subject/anchor are all inside the set.

## Surprises
- `structural_storage_type` (F:10803-10821): inside the "reference to reference" branch a loop advances `selected` through nested references until it reaches a non-reference, but the function then returns `stored` (F:10821), not `selected`. The loop's only effect is to return an invalid handle if peeling fails or the count bound is exceeded. Comment and intent are not given; this looks like dead computation or a lost return value.
- `borrow_source_access_refusal` (F:8486-8490): when the requested access is `Shared` and the borrow is not permitted, the refusal reported is `WriteOnlyMayNotRead`, whose text is "may read, but the source supplies only write-only authority". `ExclusiveBorrowSourceRequired{root, access}` carries `root` but the diagnostic text (F:8327-8334) uses only `access`.
- `scalar_representation_range`: only `i32`/`u32` get an automatic range (F:9317); other fixed integers need a domain to produce a range, and empty domain intersections are encoded as `(1, 0)` (F:9329-9331), a sentinel rather than an error.
- The unrestricted `ArithmeticDomain(_) => true` and "any declared domain with valid semantic id" acceptance inside the contents walker (F:10450, 10452-10465) means contents capability does not depend on the domain's predicate for most requirements.
- `MembershipEvidence` stores `_semantic: &FactPlan` but never uses it after `prepare` (F:6118, 6174).
- The public `reconstruct` demands zero runtime conditions (F:7117), so any runtime-selected case makes the whole reconstruction fail; `max_residuals` is passed as `max_partition_nodes` (F:7217).
- `qualification_casts::predicates_hold_on_private_arrivals` finds which state owns an expression by scanning every machine, state and statement, collecting expression trees each time (F:8038-8052): a whole-program scan per cast that failed the first judgment.
- `plan_laid::validate_plans` checks `argument.abi_version != 4` (F:7521), a hard-coded schema ABI version in a checker, and caps fields at 32 (F:7527, 7536).
