## What this code is for

This file decides whether a machine that says it terminates really does. It runs once per compile, after effect analysis and caller write frames exist (`admit_machine_rankings`, :7900), and writes one `CheckedRankBodyJudgment` row per machine with a `local_terminates` flag, an `entry_rank_formed` flag and a diagnostic string (:8247-8256). A machine with no state-graph cycle and no recursive call needs nothing; a machine with a cycle or a recursive call component needs a `terminates by <subjects> [-> View]` ranking that the code can show strictly decreases around every cycle. The file resolves which well-founded order the clause names (`order`, :2499-3134), prepares the values the rank reads at machine entry (`rank_inputs`, :3137-3878), and then tries several separate provers for "the rank goes down" (`ranking`, :3879-7080; `joint_natural`, :526-2498; `source_natural`, :7081-7881). For a group of mutually recursive machines it searches for one consistent choice of rank per member (`component_selection`, :110-317), including inferring a rank for private members that wrote none. After a proof succeeds it stores the chosen coordinates, edges and measure applications in `CheckedRankArrivalPlan` so later stages can emit a runtime rank without re-proving (:5387-5611, :1855-1998, :4599-4825). A sibling file `checks_termination_progress.rs` is mounted as `mod progress` (:3135-3136) and is not in this slice.

## Mechanisms

- **Strongly connected components** (:365-422). Iterative Tarjan over a `Vec<Vec<usize>>` adjacency list; used for machine state cycles, the weak-edge graph of a call component (:1301) and source-natural internal cycles (:7563). No budget. `component_is_cyclic` (:428-435) and `reaches_self` DFS (:454-470) accompany it.
- **Lazy component search** (:238-316). Members are visited in component order. For each member, `ranking::machine_decrease_outcome_with` enumerates local candidates and calls the `accept` closure for each; `accept` pushes the candidate, asks `topology.judge` on the prefix, and recurses to the next member if the prefix is acceptable. First complete acceptance wins. No budget or depth cap; depth equals component size.
- **Private rank inference for call components** (`joint_natural`, :722-1068, :1240-1380). For members that wrote no ranking, the code builds candidate rank inputs from every non-erased, non-const scalar parameter and scalar field of the entry state (and declared-measure roots), optionally paired with a bound (another coordinate, a closed literal from a peer, or a peer's authored bound "transported" through the helper's own call arguments, :1078-1164). A backtracking search then picks one candidate per member, pruning on edges whose two ends are both assigned, and finally requires every edge non-increasing and the non-strict edges acyclic. No budget; cost is the product of candidate counts.
- **Three natural orders reduced to one comparison** (:1771-1846). Descending compares values; BoundedDistance compares `upper - value`; IncreasingTo compares `ceiling - value` and allows strictness only when `value < bound` is proven.
- **Guard-fact accumulation** (:5046-5116) and **comparison normalisation** (:4942-4990): strips `!`, `== true`, `== false`, complements the operator when the fact is known false, and carries the negation of an earlier `when` into later consecutive transitions.
- **Arrival correspondence selection** (:5648-5878). `validation::select_rank_arrival_correspondence` drives a callback that returns Refuted / Pending / Complete for each partial assignment of entry coordinates to destination coordinates per state; the callback proves each state-to-state edge with `validation::prove_ranking_range_transition`. Two premise regimes are tried in order, `EntryInvariant` then `RankInvariant` (:6086-6111); an entry state with no incoming edge is proved under `InitialEntry` (:5786-5795).
- **Prefix preservation walk** (:6291-6386) with a node-kind whitelist (:6411-6480): decides which earlier expressions may be used as hypotheses and refuses the edge if any earlier statement may write a protected path.
- **Entry coordinate capture** (:3219-3322, :3845-3877): one pass over parameters for each of two observations (value, length), plus scalar fields and length fields discovered by `CurrentScalarValues`.
- **Source-natural coordinate lookup** (:7582-7661): recursion through specialization templates with a depth cap of 16 (:7587).
- **Parallel selection** (:8029-8041): components are judged in parallel with rayon on `validation::checking_thread_pool()`; results are collected in order.

## Identity by text

- View selection is by string path. `witness.view_path.split("::")` (:2737-2741); `path_matches(order, &["Nat","Increasing"])`, `["Nat","IncreasingTo"]`, `["Nat","BoundedDistance"]` (:2659, :2665, :2711, :3127-3133); `RankingViewId::canonical(&order.join("::"))` (:2689, :2751); `find_declared_measure(program, order)` (:2690, :2762); `declared_scalar_view(..., &order.join("::"))` (:2769). The name decides which well-founded order is used.
- Catalog authenticity compares `format!("toolchain::{}", row.path())` with the hermetic identity string, compares a relative file path with `row.source`, and finds candidate declarations by `machine.name.as_str() == path`, `attached_data` owner string `== row.namespace`, and operator path members by string (:3086-3123).
- The resolved view is written back as text: `canonical_order_path` returns `"Nat::Descending"`, `"Nat::BoundedDistance"`, `"Slice::Length"`, `"Nat::IncreasingTo"` (:6954-6964) and `build_checked_termination_plan` stores it in `witness.view_path` (:8354-8359).
- Structural recognizers locate the rank by parameter name: `target_argument_index` finds the target state's parameter by `parameter.name.as_str() == name` (:4438-4447); `countdown_edge_parts` matches the source parameter by symbol **or** by last name member (:4483-4491); `expression_is_parameter` accepts symbol equality **or** `member.as_str() == parameter.name.as_str()` (:5238-5242); member fields are matched by `field.name.as_str() == member_name` (:4152) and `member.member.as_str() == member_name` (:4297, :5254). The comment at :4406-4408 states it: "the decreasing argument is located by the matching parameter name in the *target* state".
- A generated local is recognised by name prefix: `local.name.as_str().starts_with("__transition_subject#")` (:5175); the comment (:5155-5162) says typed trees "do not always retain its `DispatchSubject` role, so the unspellable generated name identifies it, as in checks.rs".
- A machine's entry state is found by name: `machine.name.rsplit("::").next()` compared with `candidate.name` (:5193-5204), falling back to the first state.
- `static_value` turns a static argument's spelling into a number: `CanonicalConstValue::from_atom(&spelling)` then `BigInt::from_decimal_str(&spelling)` (:7864-7879).

## Surprises

- **Several independent provers for one rule, tried in sequence.** `machine_decrease_outcome_with` (:6804-6912) tries: the range prover; the relational prover; the current-values root-cycle prover; then, for proof machines only, the syntactic `n - 1` recognizers (:6853-6876); then a swapped-subject retry for the diagnostic. Component selection adds `source_natural` and `joint_natural` in front (:134, :189). A program is accepted if any one says yes.
- **The syntactic tier survives only for proof machines and leaves no witness.** `structural_order` requires `is_proof_machine` (:6853-6854) and returns `Proven(None)` (:6874), so nothing is retained about which edges decreased. This tier is where parameters are matched by name.
- **The checker infers rankings the author did not write.** Private helpers in a recursive call component get a rank chosen by search over all their scalar parameters and fields, and can borrow a peer's authored bound through their call arguments (:966-1062, :1078-1164). This is a capability beyond checking a stated measure.
- **Possible gap: helper-only recursion in a logical component** (see "Accepts or skips", :7313-7315). Stated with uncertainty: no check for it is visible in this slice.
- **Unreachable success path.** In `source_natural`, a transition back to the machine's own entry state sets `next = current.clone()` (:7411-7412) and then requires `next < current` (:7448), which cannot hold; `internal_cycle` (:7214) would also have refused such a machine earlier. The `reentry` flag and `argument_position: (!reentry)...` (:7465-7467) therefore never contribute to an accepted component.
- **Dead arms in the structural tier.** `cycle_edge_strictly_decreases` and `state_has_provable_self_loop` admit `BoundedDistance` and `IncreasingTo(_)` (:7029-7035, :7066-7072), but `edge_decrease_proven` returns false for any non-`Single` measure (:4420-4422) and `IncreasingTo` always produces a `Distance` measure (:6792-6795). The comment at :4408-4410 says distances "have no recognizer here".
- **Comment and code disagree.** The comment on `state_rank` calls it "The measure `edge_decrease_proven` reads" (:4318-4323); `edge_decrease_proven` does not call it. Its only caller is `current_values::scalar_rank` (:3967).
- **Redundant test.** `if let Some(range) = witness.rank_range` returns in both arms (:6804-6817), then `if witness.rank_range.is_none()` (:6820) is always true.
- **`.any` where the sibling uses `.all`.** `slice::state_has_proven_self_loop` accepts if any guarded self-loop decreases (:6608-6623); `nat::state_has_proven_self_loop` requires all (:4389-4400). The slice version is safe only because its caller runs it when the component has exactly one self-edge (:6988-6990).
- **Authenticity check is partial.** The sealed-toolchain check runs for explicit `-> Nat::Descending` / `-> Slice::Length` (:2751-2759) but not for the inferred default, `Nat::BoundedDistance` or `Nat::IncreasingTo` (:2665-2678, :2702-2704, :2711-2712).
- **Explicit `-> Nat::BoundedDistance` on one subject gives a generic refusal.** `from_path` returns `None` for any canonical view other than the two it lists (:2755-2759), which becomes `Unsupported` and then "cannot prove the `terminates by` ranking".
- **Two diagnostics list different builtin views.** :2694-2695 lists four including `Nat::IncreasingTo(limit)`; :8417 lists three without it.
- **Source-natural failures lose their specific text at component level.** The detailed message is stored per member as `Rejected(message)` (:153-157) while the component decision is the fixed string "a source natural call edge lacks independent strict descent" (:150).
- **Hard-coded carrier.** A bounded-distance joint rank is retained as `PrimitiveType::U64` regardless of the cursor's type (:1340-1341); the lower primitive is kept separately (:1350-1351).
- **`joint_natural` handles only single-state machines** (:730-732); any multi-state member makes the whole prover inapplicable.
- **Unused parameters.** `Subject::input_type(&self, _application)` ignores its argument (:2163-2168). `admit_machine_rankings_with_topology` takes `demanded`, and its only caller in this slice passes `None` (:7905, :8023).
- **Misleading name.** `non_self_parameter_index` (:5218-5227) just returns the position of the parameter by symbol; nothing about "non-self".
- **Diagnostic-only guesses.** For the ambiguity message any subtraction is reported as type `u64` (:3038-3042), and `is_signed_integer_type` has no 128-bit entry (:2868).
- **Compile-time recursion check compares member lists by exact order** (`retained == members.as_slice()`, :7971) for runtime components but element-wise by `(machine, body)` for source-natural components (:7982-7985).
- **The checker runs components in parallel** (:8029-8041) inside a stage whose output is otherwise built sequentially.
