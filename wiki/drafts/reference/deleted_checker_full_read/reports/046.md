## What this code is for

This slice is the second half of the stage-05 "scalar computations" builder. It does not report errors to the user: there is not one diagnostic string in the 5,339 lines. It builds plans. For every statement of every state of every machine, the driver `build_checked_value_computation_plans` (esc:10545-11137) creates a `Builder` and asks it to turn the statement's expressions into two graphs: scalar computations (`CheckedScalarComputationPlans`) and structural values (`CheckedStructuralValuePlans`), plus completion plans. The builder decides which producer an expression has: an existing place, a copy of a place, a projection, a reference, a slice view, a subslice, a call result, a record, a case, an array, a match dispatch, a quotient adaptation, and so on (`structural_value`, esc:8982-9418; `build_expression`, esc:9969-10427). Every decision function returns `Option`; `None` means "this builder publishes no plan for this expression". Whether a missing plan later becomes a compile error is decided outside this slice. The modules in the slice are `reference_captures` (esc:5825-6045), `slice_view` (esc:6046-6512), `structural_fields` (esc:6513-7169), `structural_values` (esc:7170-9440), `builder` (esc:9443-10543), the driver (esc:10545-11137) and `record_rank_observations` (esc:11144-11163). The code reads facts other stages produced (`BorrowFacts`, `FlowFacts`, `ProofFacts`, operator facts, exact-integer-cast facts) and repeatedly says in comments that "ordinary checking" elsewhere proves bounds, case, copy permission and contracts.

## Mechanisms

- **Occurrence memo.** `expression` (esc:9933-9967) memoises a scalar computation by `(expression handle, primitive carrier)` in a `Vec` scanned linearly. If the built node already carries a different authored root, it wraps it in an identity `Apply` so the new occurrence keeps its own identity. No budget.
- **Call deduplication.** `insert` (esc:9761-9805) scans the nodes added since the statement began and returns an existing `Call` node with the same flow call and callee signature and primitive type.
- **Structural value graph by recursive descent.** `structural_value` (esc:8982-9418) is an ordered if/else ladder that recurses into operands (elements, fields, cast operands, match arms, projection roots). The order of arms decides which producer wins. No explicit depth budget.
- **Single-source agreement.** `captured_reference_place` (esc:5839-5988) folds several borrow record tables into one place via the closure `retain_capture`; any disagreement aborts.
- **Reference peeling with caps.** `readable_place` crosses at most 64 references (esc:7707); `descriptor_fields` peels at most 9 (esc:7156-7166); `scalar_observation_type` uses a visited list instead (esc:6555-6566).
- **Place projection.** `projected_place_path` (esc:8517-8536) maps a canonical place to a path, substituting recorded selector computations for runtime indexes. `retain_projection_selector_evaluations` (esc:8538-8600) records one selector roster per owner expression and reuses it if identical.
- **Short-circuit folding.** For `&&`/`||`, constant folding of the left operand plus the flow roster test, else a `Select` node (esc:10337-10375).
- **Evidence roster shape check.** `has_declared_evidence_inputs` sorts lane positions and requires them to be 0..count (esc:10462-10482).
- **Statement driver.** One pass over machines, states and statements; no fixpoint (esc:10565-11132). Plans are sealed at the end (esc:11133-11135).

## Surprises

1. **This part of the "checker" emits no diagnostics.** In 5,339 lines there is no error text, no error type and no `Result` with a message. Every refusal is `None`, and the driver discards many of them (esc:9625-9634, 10627, 10634, 10796, 11109). `retain_structural_argument` returns `None` both for "refused" and for "an existing place needs no retention" (esc:8888-8900, 8910-8921), so its callers cannot tell the two apart.
2. **`structural_carriers_match` ignores generic arguments and can match by name** (esc:8354-8388). A call returning `G<A>` matches an expected `G<B>` here.
3. **`unwrap_or(expected)` in `subslice_view`** makes the source type equal to the target when the lookup fails, which turns the following comparisons into self-comparisons (esc:6382-6400).
