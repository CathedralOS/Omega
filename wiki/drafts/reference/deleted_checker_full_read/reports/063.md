## What this code is for

These five files are helper layers of the old checker's "flow" stage. None of them reports a user-facing error; each answers a question that other flow and check modules ask, and the answer decides whether those modules accept.

- `flow_operand_values.rs` takes a completed call operand (a `FlowOperandFact` row recorded when the operand finished evaluating) and a field path, and finds which earlier recorded value supplied that field: through copies, match selections, constructor literals, primitive reads through a reference, and stores. It also maps a captured value to the storage places it denotes and answers whether a callee's promised domain membership on a call result still holds at a later observation.
- `flow_ownership.rs` walks one state's statements once and emits "move events" (`FlowStorageTransferFact`): which storage place each expression moves out of, under which statement, call, transition guard or transition target. It decides, per expression kind and per parameter type, whether a use is a move or only an observation.
- `flow_place.rs` holds place utilities: pinning runtime index selectors to fixed indices, case-tag evidence (which variant of a sum is live at a place), and projecting a field path through constructor literals.
- `flow_reference_places.rs` resolves which caller storage a reference-typed local, parameter or expression currently points at, by reading initializers, call result routes from callee bodies and earlier assignments, and checks that earlier operands of the same statement could not have changed that answer.
- `flow_retained_borrows.rs` computes "handbacks": when a normally returning call consumes a value that carries an exclusive borrow, which borrowed places return to the caller, which declared domain memberships they bring back, and whether another still-live holder blocks the return.

## Mechanisms

- **Captured-value projection** (flow_operand_values.rs:740-976, 1159-1193). Given an operand row and a field path, recursion returns every recorded value that could have supplied that field. It follows `Copied` rows to their source, forks on `Selected` rows (one result per match arm, each tagged with a `CapturedValueChoice`), descends constructor literals through `literal_value_projections`, crosses one primitive read through a reference, and walks backwards through stores (`reaching_store_values`, 1039-1128). No depth or cycle guard is visible in this function. Serves contract and domain checks on call arguments.
- **Reference-place collection with a cycle guard** (flow_operand_values.rs:107-306). Depth-first over the same value graph with an `ancestors` stack; a revisited handle declines (136).
- **Promise index** (flow_operand_values.rs:333-458). Per invocation, a `BTreeMap` from operand handle (index, generation) to prepared `CallEnsures` membership promises with their storage dependencies, so thousands of field queries do not rescan all facts. The comment says it is "an invocation-local evidence index, not a proof cache" (310-317).
- **Move-event discovery** (flow_ownership.rs:779-1031, 1825-2002). One recursive expression walk carrying an expected type and an event source; each visited expression is classified as observation or move. The sink records the evaluation lane (statement, transition guard, transition target) and the enclosing match arm. Calls to machine states are driven separately from the borrow stage's call list (1985-1998). No budget.
- **Operator ownership policy** (flow_ownership.rs:1254-1346). Lines an operator's declared parameters up against receiver and arguments in three shapes (declared `self`, method form with leading parameter, static path).
- **Case-evidence batch** (flow_place.rs:291-409, 547-1211). Collects all tag observations from live fact contexts, normalizes their index segments, sorts them by place identity, and answers queries by binary search (`partition_point`, 965-983) plus a scan of indexed rows under the same root. Proves a case by direct evidence, by a sibling's selection, or by exhaustion of all other variants (1172-1211).
- **Boolean predicate decomposition** (flow_place.rs:466-542) with an expression-depth guard (467-474).
- **Index pinning** (flow_place.rs:26-88, 417-448): interval point, scalar fact, or constant integer value.
- **Constructor-literal projection worklist** (flow_place.rs:1945-2204). A stack of (expression, type, remaining path, destination path); three modes (`Access`, `SelectedValue`, `ConstructedValues`); produces authored expressions or `OmittedZero` sources.
- **Reference storage resolution** (flow_reference_places.rs:146-532). Recursive, depth budget 16 (202, 217, 229-231); a runtime index expands to every fixed slot through `finite_projection_paths` and every slot must resolve.
- **Meet/append on `RetainedSources`** (flow_retained_borrows.rs:406-436). `meet` intersects holders and handbacks across alternatives while unioning their supplies as conjunctive duties; `append` unions across independent sources. Applied recursively over retention profiles with an `active` stack against cycles (564-690).
- **Alias closure through stored bindings** (flow_retained_borrows.rs:261-370) with an `active` list of (place, type, path) queries.
- **Loan supplier graph walks** (flow_retained_borrows.rs:1076-1179). Iterative depth-first search with explicit enter/exit entries; a cycle or an unknown supplier span fails.

- The `Err(&'static str)` values at flow_ownership.rs:246-286 are messages; nothing in this slice branches on their text.

## Accepts or skips without proof

flow_operand_values.rs
- 71-78: an unrecorded operand "belongs" to any owner as long as its handle is invalid. Proof consumers call `recorded_in` (58-65), which refuses it; ordinary projection accepts it.
- 188-190: an inactive literal path returns success with no place. The comment (90-97) says the ordinary live-case check elsewhere still guards payload access; that check is not in this file.
- 649-651: `control.copied_values.get(copy)` and `control.operands.get(copied.source)` run with no validity check, and `span_or_empty` (651, 655, 659, 699) turns a stale span into an empty one. The sibling function at 224-226 does check validity. Cannot tell whether a stale handle can reach here.
- 971-973 and 1026-1028: when no reaching store is found, the current value is kept as its own origin. The comment (1036-1037) states this as intended; the consumer still has to prove facts on that value.

flow_ownership.rs
- 43-51, 66-69: if the call site or the target's parameters cannot be found, the call produces no move events at all. Cannot tell whether another stage reports the unresolved call.
- 52-64: a call that is a non-canonical copy of a saved dispatch call is skipped; the canonical copy is expected to carry the events.
- 76-99: a proof-only target or requirement citation exempts affine non-linear arguments from moving, decided by classification.
- 109: `zip` silently drops surplus arguments or parameters.
- 261: other permission-event sources return `Ok(None)`.
- 869-910: a place expression that needs transfer but has no ownership place records nothing and returns.

## Surprises

1. **Two designs sit side by side.** `flow_operand_values.rs` and `flow_retained_borrows.rs` already attach evidence to completed values identified by arena handles: a value is `Copied`, `Selected` or `Constructed` from other values, and its comments repeatedly forbid consulting initializers (flow_operand_values.rs:544-548; flow_retained_borrows.rs:256-260). That is close to "a fact belongs to a value, and a place only says which value it holds". `flow_reference_places.rs` and parts of `flow_place.rs` work the older way: they scan the statement list for the local's `let`, read `local.initial_value`, and look for later assignments (flow_reference_places.rs:57-70, 362-410, 432-496, 812-831; flow_place.rs:1242-1276). So property 2 (identity by text) has little support in this slice, and property 3 is strong in the source-replay files and weaker in the value-graph files.

2. **Comments say "no initializer replay" beside code that replays initializers.** flow_reference_places.rs:22-23 says neither consumer "replays a declaration initializer", yet `storage_places_for_canonical_place` in the same module resolves a local through `local.initial_value` three ways (380-387, 433-439, 480-481). flow_place.rs:1859 says "never replay a local initializer to discover its former tag", yet `dispatch_copy_carries_case` (1219-1277) finds a local's initializer to carry a tag between the copy and its source. The comments may be scoped to callee bodies and to literal projection, but a reader cannot tell that from the text.

3. **Unresolved operator: opposite defaults for the same call written two ways.** As an expression, an operator call that cannot be resolved makes every operand move (flow_ownership.rs:1319-1321, 1261-1266). As a statement, it records nothing (1208-1210).

4. **The borrow-call cursor can stall.** flow_ownership.rs:1985-1998 advances through the borrow stage's call list only while the call's statement equals the statement being visited. One call on a statement that `admitted_execution_statements` does not yield, or a list not in that order, stops all later calls from getting move events, with no diagnostic.

5. **`reference_route_source` can return an older route.** In the backward scan (flow_reference_places.rs:816-831), `place_at(...)?` and `return None` sit inside the `find_map` closure, so an assignment whose target cannot be resolved is treated as "not this local" and the scan continues to an earlier initializer. The doc comment (786-787) says the function returns `None` "when the route cannot be replayed". The same function, and the rebound scans at 63-67 and 372-378, ask `place_at` for the assignment target at the query's statement index, not the assignment's own.

6. **A move event with no expression and no type.** For an assignment whose value is an owned operator result, the code records a move on the target place with `Default::default()` for both the expression and the value type (flow_ownership.rs:1850-1861). The lookup at 269-270 filters by expression, so these rows cannot be matched by it.

7. **Authentication by recomputation.** `replay_memberships` (flow_retained_borrows.rs:156-233) checks a recorded handback membership by running `handbacks` and `memberships` again from stored facts. This supports property 1: the check on the checker's output is the same code run twice.

8. **`value_provable_domain` short-circuits evidence** (flow_retained_borrows.rs:113): a declared field domain is counted as supplied by every input without looking at any input's evidence.

9. **An ambiguous exclusive referent silently yields no duty.** flow_retained_borrows.rs:502-514 records a handback only when exactly one referent place is known and otherwise returns success with nothing, while the neighbouring cases return `None` for unknowns.

10. **Fact-table identity by pointer.** `CapturedOperand` decides ownership with `std::ptr::eq` on the facts table (flow_operand_values.rs:63, 74), so a clone of the same table is a different owner.

11. **Debug printing in the decision path.** `has_value` and `has_value_for_call_projection` print `CHECKSITE ...` lines to stderr under `trace_flags::check_sites()` (flow_place.rs:923-934, 1060-1065, 1083-1088, 1156-1168); three counters at 1091-1114 exist only for that trace.

12. **Repeated preparation.** `has_value` normalizes the same subject twice (flow_place.rs:915, 920). Each `place_case_*` wrapper rebuilds the whole evidence batch for one query (1496-1503, 1528-1535, 1551-1558). `stable_subject` may build `CurrentScalarValues` on each call (1587-1590). `selected_operator` scans every resolved operator use per indexed expression (flow_ownership.rs:605-613). `is_private_result_place` scans all data definitions per segment (flow_ownership.rs:1503-1508, 1534-1543).

13. **Inconsistent validity checks on the same table.** flow_operand_values.rs:224-226 checks `copied_values.is_valid(copy)` before `get`; 649-650, 755 and 1175 do not.

14. **A range segment stands in for an index in case paths.** `for_each_inactive_element_case` writes a `FixedRange` where an element index would be (flow_place.rs:892-895) and relies on "every reader" accepting it (887-891); `zero_case_below` rejects a `FixedRange` selector (1393-1403, test at 1657-1664). The two conventions meet only through `observed_segment_admits` (1334-1343).

15. **`unreachable!()` guarded by two separate predicates.** flow_ownership.rs:819-821 assumes both `intrinsic_enum_equality` and `selected_meaning_borrows_operands` return false for non-binary expressions; each checks that on its own (1750-1752, 1047-1052).

16. **Ordered maps keyed by handle parts.** flow_operand_values.rs:336 and 421 use `BTreeMap<(u32, u32), ...>` keyed by arena index and generation.
