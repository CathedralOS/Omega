## What this code is for

This is the first half of the module that runs the old checker's "checks over checked facts": passes that read the typed source trees plus fact tables built earlier (`CheckFacts`: flow, borrow, semantic facts, operators, mutation) and push diagnostics (1-37). The slice holds eight inline submodules. `atomic_fences` proves which `FenceOrdering` case an `Atomic::fence` call receives (47-216). `case_access` proves that every payload access reads a place whose case tag is known to be selected (217-764). `collection_extents` answers "how many elements does this captured collection have" from live loans (765-931). `float_implications` answers whether known facts prove an IEEE float comparison that a call requires (936-1582). `runtime_indices` is the largest (1583-4364): it checks that a value whose type is applied to value indices (`Const`/`Value` type parameters, "runtime indices" with descriptor fields) keeps the same index when it is bound, stored, returned, cast, constructed or passed, including the erased-proof-binding variant. `stored_integer_calls` proves that every integer written into an encoded (`IntegerAt`) field through a call fits its physical storage, walking callee bodies with an invocation stack (4365-5259). `zero_value_qualifications` records domain membership for zero-constructed values (5260-5304). The start of `carry` computes a per-machine carry (suspension) policy and a "is this place used after the call in the same statement" query (5310-5968). The slice has no tests.

## Mechanisms

- **Memoised recursive proof with cycle refusal (payload access).** `recorded_access_is_selected` keeps a sorted vector of `(access handle, AccessProof)` and binary-searches it (500-507, 607-627). A slot is marked `Checking` during recursion, so a cyclic provenance chain returns an error rather than discharging itself (615, 619). No depth budget; termination comes from the marking.
- **Reachability search over completed-storage predecessors.** `reaches` (371-478) asks whether a value's contents came from a given owner at a given projection. For an owned, non-copied, non-reference value with an address projection it steps to the backing operand and prepends the path (402-451); otherwise it asks `validation::completed_storage::predecessors_in_control` and requires every predecessor to reach the target (453-474). Cycle guard is an `active` stack searched linearly (386-390). Serves case evidence for moved/stored enum values.
- **Extent agreement.** `collection_extents` computes one length per referent and returns `None` on the first disagreement (812-814, 918-926). Serves indexing and call admission of fixed arrays and windows.
- **Float bound implication.** A required comparison is normalised to a `FloatPredicate` (interval-style, with `non_nan`), and facts are tested with `observed.implies(predicate)` (1130, 1143, 1541). The reaching-definition walk goes backward over `admitted_execution_order` to the last store that prefixes the place, requires index selectors to be unchanged between the store and the call (`place_selectors_agree`, 1374-1393), recurses through match-selected alternatives (all must prove, 1269-1294) and through literal projections (1300-1371). Budget: depth 16, exceeded means "not proved" (1164, 1266). Bails out as "not proved" at any statement that may write the place (1239-1247).
- **Applied-type comparison (`compare`).** Structural recursion over two type references carrying per-side context (`Application`: formation statement, substitutions, captured argument expressions, call site, parameter position; 1827-1834). Looks through domain constraints and generic-instance wrappers (2753-2793). Depth budget 128, exceeded means unequal (2749). Value indices are resolved three ways in order: static identity (`static_index`, 1940-2008), scalar value at the formation statement (`index`, 2025-2140, which uses `CurrentScalarValues`), then for `Value` parameters a captured call-argument match (2897-2922).
- **Region operand inference readback.** For a call that authors no lifetime rows, `region_operand` finds where the callee's binder name occurs in each parameter type (`region_binder_paths`, 2643-2686), follows the same path in the argument's actual type (`region_node_at`, 2692-2715), and resolves that region recursively. Budgets: recursion depth 16 and path length 16; exceeding the depth, or two arguments supplying different regions, yields `Region::Inferred`, which compares equal to anything (2602-2604, 2629, 2854).
- **Callee result substitution for indices.** `call_returned_value` takes the callee's published result equation or the entry state's single returned value and substitutes type-parameter and parameter actuals to get a scalar term (2150-2226). Only one level deep (entry state only).
- **Proof-alias unwinding.** Erased-proof checks follow immutable earlier locals back to their initializers by rebuilding `Scope` at the earlier statement (3213-3224 and its five users), with depth budget 128 (3236, 3380, 3455, 3545, 3686, 3710) and a per-walk membership scratch that resets on drop (1715-1742).
- **Inventory scratch with reset-on-drop.** `StateLocalDeclarations`, `AliasMembership`, `CastTargets`, `CastTargetChecks` use sorted vectors plus `Cell<bool>` marks cleared in `Drop` (1647-1821).
- **Interprocedural write walk with an invocation stack.** `stored_integer_calls::Admission` walks every state of a machine, and for each call that may write a fit-requiring destination pushes an `Invocation` and walks the callee body (4649-4657). Write addresses are mapped back to caller storage through each frame (`destinations`, 4911-4990). A fitting predicate is carried outward frame by frame: proved at the frame's entry, or rewritten into the caller's terms and guarded by `not(path condition) or predicate` (5155-5200). Recursion is detected by target symbol on the stack; frames in the cycle are marked `cyclic` (4639-4648). There is no depth budget and no memo of visited callee bodies; the only shortcut is `established` (5138-5150). `proof_only_classification(program)` is recomputed on every `visit` (4573).
- **Policy lattice intersection.** Carry policy starts `PERMISSIVE` and is intersected with each contribution (5380, 5513, 5521); claims on the same place and evidence are relaxed together, then all claims are intersected (5431-5454).

## Identity by text

- **Region (lifetime) operands are strings.** `application_lifetimes` returns `(String, String)` pairs (2514-2524); `region_binder_paths` finds a binder by `argument.as_str() == name` (2661); `region_operand` takes the binder name from `lifetime_arguments.get(ordinal)` (2601) and passes `name.as_str()` (2613).
- **An index value read from the spelling of a type name.** `index` parses a `Named` type reference's `name` as `i128` (2131-2133) and otherwise as `CanonicalConstValue::from_atom(name)` (2134-2139) when the symbol is invalid. `stable_static_proof_argument` accepts a static argument if its spelling parses as `i128` or as a canonical const atom (3522-3527). A const's value is decoded by building `CanonicalConstValue::new("", encoding, "")` with empty strings (2113).
- **Data type found by name suffix.** `add_unnamed_named_type` picks the first data definition whose name equals the given name or whose last `::` segment equals the name's last `::` segment (5670-5673). It is fed the cast target's type name (5631-5635) and a struct literal's `type_name` (5651). `PrimitiveType::from_name(name)` decides that a name is primitive (5667).
- **Carry claims grouped by rendered place label.** `established_claim_carry_policy` keys claims on `semantic.place_label(program, place)`, a `String` (5420, 5430-5433).
- **Fallback name for "used after call".** `observe_place` treats a name path whose first member's text equals `fallback_name` as a use of the place, alongside the handle-based test (5958-5965).
- **`LocalWriteSource.path` is a `String`**, set to empty in the fallback (4907); `same_source` does not compare it (5252-5258).
- Text used only for messages: state name fallback `"<unknown>"` (540), `canonical_place_label_from_parts` (552), `display_name` (562, 3790), `display_type_reference` (3206), machine name (4190, 4455).

The comment at 2952-2955 says descriptor fields are matched by "the retained field handle rather than treating an identically spelled ordinary field as an index", and 2147-2148 says "a callee's own binder never falls back to a same-named caller symbol".

## Accepts or skips without proof

- **Region operands that inference did not pin are accepted.** `(Some(_), Some(_)) => true` when either side is `Region::Inferred` (2854). `Inferred` results from depth > 16 (2602-2604), from arguments disagreeing (2629), or from no argument naming the binder (2636). The comment says such a binder "is left to the borrow checker and carries no obligation to this comparison" (2573-2575). The borrow checker is outside this slice; cannot tell whether it catches every such case.
- **Lifetime and type arguments marked "not relevant" are not compared** (2842-2845, 2871-2874, via `application_lifetime_is_relevant` / `application_argument_is_relevant`). Cannot tell what decides relevance.
- **Unreachable static context skips the index comparison**: `static_type_context_is_unreachable(expression)` returns early (4177-4179). Cannot tell how unreachability is established.
- **Invalid symbols count as constant/stable.** `is_const_symbol` returns true for `!symbol.is_valid()` (1902, 1951); `stable_index_symbol` returns true for an invalid symbol (3338-3340). A literal has no symbol, which is the likely intent; any other symbol-less reference is also accepted here. Cannot tell if another check catches that.
- **A call expression counts as constant** if its static arguments look constant; its runtime arguments are not examined (1926-1935).
- **Whole pass skipped** when the program declares no `Const`/`Value` data type parameter (4202-4212), and the stored-integer pass when no layout has a non-total integer field (4410-4419). These are scope tests, not proofs.
- **States, calls and call sites that cannot be looked up are skipped with `continue`** in `runtime_indices::check` (4215-4220, 4305-4316) and non-fence calls in `atomic_fences::check` (68-70). The stored-integer pass, by contrast, turns the same failed lookups into errors (4764, 4852).

In `call_substitutions`, a static-argument count mismatch silently skips the substitutions (2343), which leaves indices unknown (leading toward refusal rather than acceptance).
- **`expected_erased_identity` tolerates a static parameter/argument count mismatch when the argument list is empty** (3850-3852).
- **Assignment to a target with no recoverable applied type is not checked** (4280-4282); a store whose target is not a descriptor field does nothing in `check_descriptor_store` (3089-3091).
- **A received struct literal whose data definition cannot be resolved, and an array literal received into a non-array type, fall through** to the completed-value check (4072, 4047-4062, 4164-4169), which only runs when the required type has value indices.
- **Erased binding accepted on stored evidence.** `constructor_evidence` and `checked_evidence` accept by comparing type identities recorded in `prepared_mathematics()` (3130-3183). The comment says "The source producer checked this exact closed term against its complete W application" (3095-3097). - **A call-returned descriptor's case prefix is taken from the call.** For a `Return` formation the code only confirms the call lists this formation among its normal-return referents, then skips the namespace's case prefix (701-725, 747). Cannot see here what proves the callee selected those cases.

- **Previously recorded stored-integer decisions are trusted.** `admit_write` starts from `Constant(true)` when an identical `Assignment`-site row already exists in `facts.stored_integer_writes` (5138-5150). That row was written by an earlier pass outside this slice.
- **Stored-integer early `Ok`s**: call writes nothing (4549-4551), no exclusive access and no write-capable declared parameter (4567-4569), callee is a proof-only machine (4570-4578, also 4439), call cannot reach a fit-requiring destination (4583-4585), same-machine state call (4856, covered because `visit_body` walks all states), unresolved operator use (4672-4677), non-reference parameter with no actual origins (4970-4972). `runtime_write_parameter` excludes erased parameters and types that `frames.proof_value_is_caller_isolated` (4996-5002); these rely on the frame resolver's classification.

The comment says "the complete zero-value judgment checks carrier validity, home-case fields and domain obligations" and "Receiving bindings only transport this evidence" (5264-5269); the only test in this function is `!type_requires_establishment`. ## Surprises

- **No proof-kernel call anywhere in the range.** There is no `proof_admission`, `ProofNode`, `verify_obligation` or certificate use in lines 1-5968. Every rule ends in a `bool`, an `Option`, or `Result<_, &'static str>` computed in this file or returned by `crate::flow`, `validation`, `CurrentScalarValues` or `contracts::call_values`. The stored-integer pass comes closest to carrying an explicit obligation (a `CheckedBooleanExpression` predicate), but it too is discharged by `call_values::proves_entry_predicate` returning `bool` (5165-5177).
- **Checks that also produce facts.** `stored_integer_calls::check` takes `&mut CheckFacts` and inserts `CheckedStoredIntegerWrite` decisions (4460); `zero_value_qualifications::record` appends qualifications (5289-5300); `carry::activation` builds `MachineActivationCarryFact` (5405-5411). The fence pass computes the selected `FenceOrdering` and throws it away (71); `ordering` is `pub(crate)` (95), so a later consumer recomputes the same judgment rather than reading a recorded result.
- **The header comment does not list several passes in this file.** `atomic_fences`, `runtime_indices`, `stored_integer_calls`, `zero_value_qualifications`, `float_implications` and `collection_extents` are not in the ten-step list (15-31). The driver is beyond this slice, so the actual order could not be confirmed here.
- **Budgets disagree on which way they fail.** Region inference past depth 16 returns `Inferred`, which accepts (2602-2604, 2854); every other budget in the slice refuses.
- **`same_source` ignores two fields.** It compares root, segments, representation, recasts and `collection_coarse`, but not `is_image_storage` or `path` (5252-5258), so the recursive-footprint check treats image storage and ordinary storage with the same root and segments as the same place.
- **Cast target carry policy is looked up by name although a type handle is at hand.** `visit_expression` holds `cast.target_type` but calls `named_type_reference(...)` and then searches data definitions by name suffix (5629-5636, 5662-5681). Two data types in different packages with the same final name segment resolve to whichever comes first. The same accumulator has a handle-based `add_type` (5499-5518).
- **Every borrow expression forces `STRICT` activation carry**, regardless of what is borrowed (5642-5645).
- **The two traversals in `carry` differ.** `activation` visits an assignment's target and value (5536-5539) and both `atomic.value` and `atomic.result` (5605-5608); `intra_statement` visits only `assignment.value` (5800-5802) and only `atomic.value` (5894). So `place_is_used_after_call` does not see a use of the place inside an assignment target (for example an index expression there) or inside an atomic's result. Cannot tell whether that is intended.
- **`intra_statement` models match-arm reachability itself**: it stops visiting arms once a wildcard or both boolean patterns have been seen (5862-5890), a small exhaustiveness rule living inside a liveness query. It identifies the target call by pointer equality `std::ptr::eq` (5811, 5915) and, for a named transition, by equality of the argument span (5844).
- **Every expression statement in a state with a return type is compared with the return type** (4268-4273). If a state can contain an expression statement that is not its result, that statement would be judged against the return type's indices. Cannot tell from this slice whether such statements exist.
- **The return type's indices are evaluated at statement 0** (`Application::bare(state.return_type, 0)` at 4271 and 4295), as are names that are not local declarations (2447-2451) and constants (2434). So an index symbol in a return type means "its value on arrival".
- **`runtime_indices` handles two different things under one name.** The same pass covers runtime descriptor equality and erased mathematical-evidence bindings (`is_source_evidence_carrier`, `prepared_mathematics`, "W application" at 3097). The erased path can accept a binding without running the index comparison at all (3127-3129, 3151-3153, 3181-3183), and when it fails it appends a second diagnostic on top of the ordinary ones (3187-3209).
- **`check_binding` only reports the erased reason if the ordinary check also failed** (3187). If none of the three erased routes hold but the ordinary comparison passes, the erased binding is accepted through the ordinary route.
- **`expression_is_const` and `static_index` treat `ZeroValue` and string literals as constants usable in index position** (1914-1918).
- **`StateLocalDeclarations` erases duplicates.** If two local declarations share a symbol, both rows lose their declaration (1674-1681), so later lookups behave as if the local did not exist (formation 0, no alias initializer).
- **`CastTargetChecks::needs_check` uses `expect`** on a binary search over an inventory built by iterating the expression arena (1795-1799); this relies on the arena iterating in sorted `(index, generation)` order, which the code does not sort for.
- **The stored-integer walk has no memo and no budget.** Each call occurrence re-walks the callee's whole body, including all of its states (4657, 4756-4863), so the work grows with the number of call paths rather than the number of machines.
- **Any operator that can write to a fit-requiring field is refused outright** (4744-4748): the rule is "operators have no performed-write inventory", not a fit proof.
- **The fence rule depends on `exact_toolchain_atomic_fence_contract`** (92): one operator of the bundled library gets a dedicated checker pass. How that function recognises the operator is outside this slice.
- **In `comparison_holds_for_place`, a fact in any one context suffices** (`contexts.iter().any`, 1096). This is sound only if all supplied contexts hold together at the call; the function does not check that.
