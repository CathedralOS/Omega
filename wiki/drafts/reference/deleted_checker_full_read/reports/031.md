## What this code is for

This slice is the second half of the old checker's exit-contract file. It decides, for each normal exit of a machine, whether each `ensures` fact holds, and reports "cannot prove ensures contract" when none of its routes succeeds. The top-level driver is `check_exit_ensures` (10135-10412); everything above it in the slice is the `scalars` module (5190-10035), a collection of special-purpose provers for scalar postconditions that mention `result`. Those provers each recognize one shape of returned expression (a parameter name, a call, a const-generic call, a constructor field, a match, a guarded transition, `(a / d) * d`) paired with one shape of postcondition atom (`result == p`, `result <= literal`, `result.field.len == n`, an arithmetic relation). The slice also holds `BoundaryRefutations` (5225-5362), which reports an error when a domain obligation admitted at a package boundary is positively refuted at an exit. Two functions do not answer yes or no but hand back deferred obligations (`ConstantRecipeObligation`, `IntegerRangeObligation`) that a later stage must settle (5381-5475, 7901-8025). No proof-kernel call appears anywhere in the slice; every route returns a Rust `bool` or `Option<bool>` computed here or by a sibling module.

## Mechanisms

- **Per-atom boolean evaluation** (9534-9564). `evaluate_for_atoms` walks the `ensures` expression; at every node it first asks an observer whether that node is already known true or false, and only then decomposes it. The observer here chains: static type predicate, case observation, four "proves" functions that can only answer true, then `current_predicate` which can answer true or false. Leaves are valued by `contract_value` (9826-9866). The comparison-admission callback is the constant `&|_, _| true` (9538). Serves scalar `ensures`.
- **Three-valued interval comparison** (`interval_comparison`, 8053-8089). Given two closed integer ranges and one of six comparison operators, returns proved, refuted or unknown; empty ranges are unknown. Serves result bounds.
- **Linear forms with cancellation** (6942-7130, 7310-7380, 7510-7568). A form is a constant plus `i64` coefficients over atoms (an immutable parameter, or a `root.field` pair); all arithmetic is checked and overflow means "no proof". Forms are built from integer literals, names, members, `+`, `-`, and `*` by a constant. Locals are expanded through their single immutable initializer with a cycle guard (`expanding`, 7458) and depth limit `EXPANSION_LIMIT = 8` (6940, 7178, 7318). Calls are expanded by substituting argument forms into the callee's single returned expression (7266-7308). The minimum of a form is read from parameter and field bounds (7104-7129). Serves the truncating-division window.
- **Guard refinement with a step budget** (6784-6905, 6652-6782). Starting from the carrier range (or a literal), each guard conjunct of the form `returned <op> literal` narrows the range. Boolean and integer locals in the guard are replaced by their recorded initializer expressions. Budget: 4096 steps (6631), decremented per visit (6659, 6711, 6793).
- **Conditional congruence** (5504-5646). Proves a goal conjunct by finding a `requires` conjunct with the same tree shape; `result` matches an immutable returned parameter; positions holding closed constant recipes produce equality obligations instead of answers. Depth limit 64 (5545). Nothing is published unless every conjunct matched (5427, comment 5371-5372).
- **Closed-term identity** (5653-5701). Structural equality plus field-by-field comparison of static call metadata, depth limit 64.
- **Walk over match arms and constructor fields** (`collection_lengths_through`, 8901-8984). Recurses into every arm of a returned `match`, recording the integer each value pattern fixes for the subject and the ordered pattern prefix; at a leaf, only matches whose pattern prefix is "inert" before the leaf are applied (8946-8957). One arm without an answer fails the whole walk (8932-8938). No explicit budget.
- **Roster rebinding** (`bind_current_scalar`, 9003-9128). Rewrites a lowered scalar expression so that each parameter, structural field, storage read or local becomes an index into a list of canonical places, deduplicated by `intern_place` (9246-9263). Serves the arithmetic solver.
- **Write-frame preservation scan** (`preserved_contract_subject`, 9130-9243). For every statement before the exit, collects storage writes from the statement and from its value and may-write frames, and refuses on overlap with the subject place.
- **Predicate lowering and transport** (6357-6520). Lowers the predicate with budget 4096 (6363), binds each parameter and the result to a place, attaches captured observations, and asks the transport and truth helpers.
- **Deferred obligations.** `result_range_condition` (7901-8025) turns `returned <op> endpoint` into "`returned - endpoint` lies in `[min, max]`" computed from the carrier span (7999-8007); it refuses unless the difference `is_target_dependent()` (7996). `!=` is not supported (8006).
- **"Exactly one" selection** is the standard lookup idiom: take the first match and return `None` if a second exists (6019-6025, 6673-6676, 6690-6697, 8412, 8492-8495, 8877-8880, 9104-9107, 9992-9994, 10006-10009).
- **Bounded type peeling**: `exact_integer_carrier` loops at most 128 times (8096); `result_receiver_segments` refuses at 128 members (8816).

## Identity by text

Most identity in this slice is by `SymbolHandle`, `ExpressionHandle` or `CanonicalPlace`, not by string. The string cases:

- `exact_integer_carrier` accepts a `Named` type as a built-in only if `name.as_str() == atom.symbol_name()` (8115-8120).
- `field_of_data` selects a record field by symbol, but when `member.member_symbol` is not valid it falls back to `field.name.as_str() == member.member.as_str()` (8886-8890).
- `is_result_reference`, called at 5550, 5872, 5874, 6569, 6571, 8038, 9683, 9685, 9830, decides whether an expression is `result` by `signature_reserves_result` over the entry parameters' name strings (`checks_contracts.rs:11636-11650`, outside the slice).
- Diagnostics render names: 5356-5357, 10217, 10397-10399. Trace output uses `self.machine.name` (8021). These do not decide anything.
- A local string `stage` tracks which step refused (7905-7993); it is only printed under a trace flag (8018-8023).

Identity by position rather than by text or handle, recomputed from source order:

- Scalar roster positions: a `Parameter { position }` is the n-th non-erased primitive parameter (9012-9020, 9029); a `Local { position }` is the n-th immutable primitive local before the exit (9065-9074). `selected_scalar_expression` rebuilds the roster from source and requires it to equal the recorded symbols (10012-10022).
- Call arguments are matched by `binding_ordinal`, `argument_ordinal`, `call_ordinal` and `statement_ordinal` (6165-6186); the binding ordinal is a count of immutable primitive locals before the statement (6151-6161).
- Scalar position of a callee parameter is a count of primitive parameters before it (6224-6231).
- A call occurrence is identified by the authored expression handle (6018) and confirmed by pointer equality on the call node (6039).
- `LinearAtom::Field` equality is `(root symbol, field symbol)`, deliberately ignoring the expression handle (6974-6993, comment 6959-6963).

## Accepts or skips without proof

- **Unreachable exit skipped.** If `static_type_context_is_unreachable` holds for the returned expression, no `ensures` is checked on that exit (10149-10153). Cannot tell from this slice what establishes unreachability.
- **Boundary-admitted `ensures` skipped.** An `ensures` whose contract fact has `qualification_authorization` and is owned by this state is not proved here (10170-10183). `BoundaryRefutations::check` (5257-5361) is the visible counter-check, and it only reports a positive refutation: an unknown predicate passes (5350; comment 5215-5218 "unknown predicates grant neither a veto nor evidence of consistency"). Its caller is outside the slice.
- **Entailment-covered `ensures` skipped.** If the expression is in `entailment.expressions`, `continue` (10184-10192). Trusts the entailment module.
- **Evidence-assigned proposition skipped.** A proposition-application `ensures` whose machine contract fact carries an `evidence_term` is not checked here (10193-10209). Cannot tell where the evidence term is checked.
- **Domain membership without a predicate.** With an authorized route, membership of `result` in a domain is accepted when `!domain.predicate_presence.is_present()`; and `domain_definition(...).is_none_or(...)` means a missing domain definition is also accepted (10334-10344). No other check visible in the slice.
- **Cyclic header route ignores the missing-origin guard.** The expression is `(missing_origins.is_empty() && (...)) || cyclic_headers.proves(...)` (10271-10346). Cannot tell whether `cyclic_headers.proves` checks origins itself.
- **Available content plan ignores the missing-origin guard** and any proof in this function (10261-10267): `available_content.contains(&source.plan)` is enough.
- **Deferral instead of refusal.** When no route proves the fact, `proves_with_recipe_conditions` (10349-10362) or `proves_with_range_conditions` (10363-10376) may return obligations; the function records them and `continue`s without a diagnostic. The obligations are checked by whoever consumes `recipe_obligations` and `integer_range_obligations`, outside the slice.
- **`BoundaryRefutations::check` silent returns**: machine has no obligations (5265-5271), no state flow site (5272-5276), no entry state (5277-5279), domain definition missing (`continue`, 5306-5308), subject place not resolvable (5334-5335). Each means "not refuted".
- **Comparison admission always true**: `&|_, _| true` at 9403, 9538, 9892. Whatever the callback was meant to filter is not filtered here; operator built-in checks at 9516-9525 and 9914-9920 are the visible guards.
- **Hard-coded carrier.** In `contract_value`, a `Member` expression is lowered as `PrimitiveType::U64` and, if that yields an integer literal, the literal is the value (9834-9848). The declared type of the member is not consulted here.
- **Field name fallback** (8886-8890): when the member has no resolved symbol, the field is chosen by name text.
- **`_ => {}` in `refine_guarded_return`** (6903): unrecognized guard conjuncts are ignored. This only narrows less, so it loses proofs rather than accepting.
- **`preserved_contract_subject` skips other states** when the exit is on the entry state (9174-9175). Re-entry is refused only when the subject has field segments (9133-9169); for a whole-parameter subject it is not examined. Cannot tell whether that case is covered elsewhere.
- **`has_builtin_operators` ends in `_ => true`** for node kinds other than binary, unary and borrow (`facts.rs:255-268`, outside the slice); every use in this slice inherits that.
- **Reconstruction route skips the stability check.** `truncating_reconstruction_proves` is called at 7713, before `return_expression_is_stable` at 7811, and never checks built-in operator meaning for the `*` and `/` it reads from the returned expression or its initializers. See Surprises.

## Surprises

- **The reconstruction prover replays initializers and callee bodies, which three comments in the same module say is never done.** `local_initializer` (7469-7507) follows a returned name to its initializer, `local_form` (7450-7467) does the same for operands, and `call_reconstruction` reads the callee's returned expression from its body with `state_returned_value` (7306) rather than from its contract. The comments at 5792-5793 ("No source arithmetic, callee body ... is replayed"), 6527-6528 ("no initializer or stale mutable read is replayed") and 8132-8133 ("It does not replay local initializers or calls") say the opposite.
- **Possible stale read in the reconstruction prover (not confirmed by running anything).** `truncating_reconstruction_proves` runs at 7713 before the stability check at 7811. A field atom `p.f` is accepted when `p` is any non-const parameter, including a mutable one (7404 tests only `is_const`, whereas a bare parameter name is refused when mutable at 7353), and when no statement in the state is a direct assignment `p.f = ...` (`field_is_assigned`, 7415-7448). That scan does not see a whole-record assignment `p = ...`, a write through a call, or a write through a longer path. `local_initializer` refuses only assignments to the local itself (7488-7501). So for `let r = (p.f / d) * d; <something that changes p.f other than a direct field assignment>; return r` with `ensures result <= p.f`, the two `p.f` atoms cancel (7563) although they are read at different times. The bounds used come from `stored_integer_bounds`, which is the declared type-level interval (`arithmetic_domains.rs:17150-17166`), so it would not notice the write either. Whether another check refuses such a program first, I cannot tell from this slice.
- **No built-in-operator check on that path.** `proves_bounds` checks operators of the `ensures` expression (7584-7590), not of the returned expression; the reconstruction path reads `*` and `/` from the returned expression by `BinaryOperator` alone (7222, 7246). Parameter leaves must be exact integer carriers (7356) but field leaves have no carrier check (7387-7413).
- **Operator-precedence asymmetry in the driver.** `cyclic_headers.proves` and the "available content plan" disjunct are outside the `missing_origins.is_empty()` guard, while every other route is inside it (10260-10347). The layout suggests the grouping at 10346 was intended, but nothing says so.
- **`contract_value` lowers any `Member` leaf as `U64`** (9844) with statement index 0 on the entry state. Any member expression that lowers to an integer literal gets that literal as its value regardless of the member's own type.
- **Evidence for property 1.** A search of the slice for `proof_admission`, `ProofNode`, `verify_obligation`, `certificate` and `kernel` finds nothing. All verdicts are `bool` or `Option<bool>`. The nearest thing to checkable evidence is the two obligation types pushed at 10360 and 10374, which defer a numeric condition rather than certify a proof.
- **Evidence against property 2 in this slice.** Apart from the three string comparisons listed above, identity is by handles. The fragile part is instead identity by recomputed ordinal position in a "roster" of primitive parameters and immutable primitive locals; four separate pieces of code recount that roster from source (6151-6161, 6663-6672, 9065-9074, 10012-10019).
- **Strong evidence for property 3.** The slice is a catalogue of return-expression shapes. A return that is a parameter, a call, a static call, a constructor, a match, a guarded transition, or a multiply-of-divide each has its own prover, and a shape not on the list (for example a field of a field: "Longer member paths stay unproven", 8031; or a `match` whose arms are calls) gets no proof.
- **Capability not expected:** a small symbolic linear-arithmetic engine with atom cancellation exists solely to prove the rounding-down idiom `(a / d) * d` (6908-7580, about 670 lines), including inlining through calls to depth 8.
- **Capability not expected:** slice extents are tracked through `match` arms with the matched integer substituted for the subject, including the ordered prefix of earlier patterns so that side effects of earlier failed patterns are accounted for (8901-8959, comment 8140-8146).
- **Debug trace in checker code:** `eprintln!("STRUCT return-range refused ...")` under `trace_flags::struct_trace()` (8018-8023), with a `stage` string maintained through the closure only for that message.
- **`closed_terms_identical` zips argument lists without comparing their lengths** (5682-5688); it relies on the earlier `expressions_structurally_equal` call (5663) for that.
- **`normal_return_call_target` contains a no-op map**: `.map(|state| ((), state)).flat_map(|(_, state)| ...)` (6008-6009).
- **`result_range_condition` never handles `!=`** (8006) and returns `None` unless the difference is target-dependent (7996), so a target-independent comparison that the other routes missed is refused here rather than evaluated.
- **Only one unit test** covers this half of the file; none of the bounds, reconstruction, length or driver logic has a test in the slice.
