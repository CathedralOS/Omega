## What this code is for
One file with two modules. `literals` (lines 5-3084) handles numeric, string and array literals: it lands unsuffixed ("anonymous") integer and float literals into the type of the place that receives them, rewrites them in the typed tree, and refuses suffix/destination disagreements, fractional intermediates landing in integers, and anonymous `%`, `/`, bitwise forms with no typed operand. It also decides which constant array/record expressions are "closed" (all leaves known) so later stages can read them, and lands a quoted byte string into a `[u8; N]`. `struct_literals` (3086-6123) checks every struct or case literal (`Data { f: v }`, `Data::Case { .. }`) at construction: duplicate/unknown fields, quotient and opaque-boundary types, case-bearing data, omitted fields that need establishment, the `requires` predicates of the data (default domain) and of the case, per-field type/reference/domain/range/stored-integer checks, and array-literal element checks. Proof of the `requires` predicates is requested from `contract_entailment::construction_predicate_judgments`; what that cannot prove is either turned into a retained range obligation, held as a "pending predicate" for a later pass, or reported. The file also walks every statement of every machine (in parallel per machine, 5493-5658) to find literals. It is validation plus a small amount of tree rewriting (float landing 350-566, byte-literal landing 3026-3081).

## Mechanisms
- **Landing of anonymous literals by destination type**: `land_float_literal_destinations` (350-566) first collects `(expression, declared type)` pairs from every placement, then rewrites each expression in place (557-565). `land_float_value_for_type` (632-728) descends through match arms, struct/case literal fields, borrows (`Reference`), constrained types, fixed arrays and named f32/f64. `land_float_tree` (730-764) evaluates an exact rational tree (`anonymous_exact_float_tree` 766-805 using `numerics::bignum::ExactFloat`), rounds with `FloatSemantics::round_exact`, and overwrites the node with a landed `Float`. No budget; recursion is by tree depth. Division by exact zero returns None (794-797). Serves unsuffixed float literals.
- **Anonymous integer/numeric evaluation**: wrappers 2589-2803 over `typed_trees::closed_numeric::evaluate_anonymous_value` (not in slice). Exact rational (`BigRational`) evaluation with `fractional_origin` tracking; used for landing, comparison folding (2611-2657), match-arm selection by subject value (2680-2703).
- **Float comparison folding**: `fold_anonymous_float_comparison` (807-855) replaces a comparison of two anonymous exact values by a `Boolean` node.
- **Closed constant array / record projection**: work-list walks with an `active` stack to refuse cycles (1183-1194, 1299-1307, 1981-1993, 2029-2032) and a loop bounded by `type_reference_count()` (979, 1022, 1754). Compute leaves of a constant array under its declared type (1071-1142, 1170-1289, 1291-1382) and select a projected scalar from a constant record or array (1779-1873). Serves constant arrays/records readable at compile time.
- **Interval/truth abstract interpretation for zero-value admission**: `Bounds` {i64 interval, length, capacity, float interval} (3107-3151), `bounds_eval` (3215-3400) evaluates a case's `requires` on an all-zero value; Truth is three-valued (3153-3157), `tri` maps back to interval 0..1 (3497-3509). `case_predicates_admit_zero` (3174-3213) is true only if every fact folds to `True`. Serves "can this variant be zero-filled" (public, used elsewhere).
- **Two-pass scalar analysis**: `validate_scalar_receiving` (4008-4053) first analyses a value with an empty environment; if that is clean it returns, else it re-analyses with `observations.environment(expression)` (occurrence value environments computed lazily once via `OnceLock`, 5107-5120). Match values are joined by interval union and environment join (4087-4094).
- **Construction predicate obligations**: `construction_conditions` (3877-3985) turns a conjunction of `field <op> bound` predicates into `IntegerRangeObligation`s of `snapshot(field) - observation(bound)` within a carrier-span range, so a later pass can discharge them. Only handles `<=,<,>=,>,==`, where one side is a single-name field parameter and the other a constant recipe of the same primitive; otherwise None (falls to pending predicate).
- **Pending predicate retention and later discharge**: `ConstructionObservations` (5029-5180) holds `Mutex<Vec<..>>` of range obligations and pending predicates; `discharge_pending_predicates` (5208-5255) re-judges them. Serves construction-time `requires` that depend on facts proven later.
- **Parallelism**: `validate_struct_literal_fields` runs per machine on rayon (5498-5603).
