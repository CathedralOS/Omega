## What this code is for
This slice has two halves. The first (37840 to 40902) finishes the "write frames" machinery: for a call, it works out which caller places the callee may write, by following reference origins (which stored local holds a borrow of which place), type capabilities (can this type carry a write), and transparent call results (a reference returned from a callee that came from an argument). The second half (40903 to 45408) is the call validator and its helpers. `validate_call_node` (40969) sends each call to a gate (conformance, receiver declared, `asm#` statement, self entry ban, receiverless, receiver call). `validate_call_arguments` (41344) checks each argument against its parameter (literal landing, reference access, pending views, type match, bounds, data conflict, scalar shape, domain weakening). The `topology` module (41661) resolves call targets and decides whether a state can complete normally. `receiver_topology` (42344) resolves which state a `receiver.target(...)` call means. `argument_correspondence` (42815) proves that the executable formals of a call through a trait requirement correspond to the applied public formals, and that static (header) bindings match their source. `occurrences` (44589) numbers the calls in a statement by one traversal and finds a call from `(statement_index, call_ordinal)`.

## Mechanisms
- **Origin canonicalization fixpoint** (`canonical_write_origins` 38385-38420, `overlapping_origins` 38422-38487). Computes the set of places a write to a path may reach, through stored references held in locals. A worklist pops an origin, finds every stored leaf whose `local_path` prefixes or is prefixed by it, composes the leaf's origin with the suffix, and pushes new origins deduplicated by `(path, precision)`. Each stored leaf (its index in the list) may be crossed once per chain; a second crossing returns `None` (38411). No numeric budget. Serves aliasing/loan tracking for writes through stored references.
- **Window coarsening** (`summary_windows::coarsen_path` 38606-38649). Rewrites a place path so adjacent range windows merge: two `FixedRange`s compose (start+inner_start, start+inner_end) when the inner range fits, otherwise the pair becomes `OpaqueRange`; runtime selectors are erased; changed paths are marked `CollectionCoarse`. Serves slices of arrays in call summaries.
- **Write frame resolution cascade** (`known_call_written_paths_for_parts` 40377-40627). A fixed-order lookup that picks a callee by symbol, then by name, then summarizes it (`summarize_resolved_call` 40630: push the callee on `active_states`, run `summarize_complete_state_written_paths` under an invocation, instantiate each relative path against the receiver and argument origins) or trusts its declared signature. Recursion (`active_states` contains callee) returns `None` (40582). Target-family interfaces join the paths of all members (40539-40567). Serves "what does this call write".
- **Type walks with cache** (`type_reference_is_reference_free`, `type_may_carry_write_in` 39438-39620). Recursive walks over `TypeReferenceNode` with a visiting list for cycles and a cache keyed by `(handle, bindings)`. Unknown or ambiguous definitions answer "may carry/opaque" (conservative).
- **Generic binding unification** (`bind_formal_type` 39865-39970; `transition_signature_type_bindings` 39817-39863). One-way structural matching of a formal type against an actual declared type, building `(parameter, type)` bindings; all type parameters must end up bound.
- **Reachability / acyclicity DFS** (`transition_state_reaches` 38873, `named_transition_subgraph_is_acyclic` 38908, `compute_normal_completion_possible` 41689). Worklist or DFS over state graphs with `visited` vectors (linear `contains`). No budget.
- **Normal completion analysis** (41689-41817). Walks states by finite execution order; a state "departs" if its last statement tail-calls a body target, calls an external completion target, or transitions only to such targets. Result is memoized per initial state in frozen-program memos. Serves checking whether a machine/state can fall through.
- **Carrier correspondence** (`CarrierCorrespondence::new` 42851-42980). Builds a chain of static-application frames from a closed conformance application down the realization lineage, requiring each frame to have exactly one invocation or one exact capture; then compares applied type identities of executable and public carriers. Serves generic trait-requirement calls through realization machines.
- **Call-site traversal** (`CallSiteTraversal` 44609-44744, `find_call_site_in_expression` 44756, `find_call_site_in_statement` 44945). A pre-order walk of a statement that numbers each call; in "find" mode returns the site at a requested ordinal, in "collect" mode records all. Tracks `conditional` (inside a match arm, the right side of `&&`/`||`, or a transition operand) so `call_is_unconditional` (45250) can tell. Skips code in statically unreachable contexts and the right side of a short circuit that is statically decided (44816-44825).

## Accepts or skips without proof
- `bind_formal_type` returns `true` when a `Generic` formal meets a non-`Generic` actual (39920), when the generic bases differ (39923), when a `FixedArray` or `Slice` formal meets a different actual shape (39951, 39965), and `_ => true` (39968). - `value_call_result_is_admitted` returns `true` for `CallArgument` and `IndexOperand` positions without looking at the call (40133-40138). The argument type check at 41409 may catch a wrong return type; cannot tell for reference-returning calls.

- `known_call_written_paths_for_parts`: callees with non-checked bodies are trusted by their declared signature (40569-40581); intrinsic and accessor calls are given empty write frames by predicate (40428-40441); a GDT `Load` is given an empty frame (40419); a callee that failed summarization falls back to its declared signature when it has no owned data or generic parameters and the reach plans show no services (40597-40626). ## Surprises
- Dual identity for places. `FramePlaceOrigin` carries both a string `path` and a symbolic `source` (root symbol plus segments). Containment and overlap decisions in `overlapping_origins` and `place_suffix` use the string, and `compose_origin` and `expand_write_path` create origins whose `source` is `Default::default()` (38496, 38524). The symbolic form is discarded on that path. The stored leaves also keep both `local_path` and `local_segments` (38076-38077).
- Calls are identified by position: `invocation_output_parameter` (45364-45397) takes `InvocationOutputIdentity` containing `state_symbol`, `statement_index`, `call_ordinal` and re-walks the statement with `find_call_site_in_state` to find the call. The ordinal is the pre-order position in the traversal, which visits a call before its receiver and arguments (44874-44896) and skips statically unreachable or short-circuited code. Any change to the walk renumbers calls; `argument_evaluation_order` (45136) is a separate computation.
- `transition_state_reaches` (38873-38897) returns `false` for the whole search as soon as one reached state has no equation (38891), rather than skipping it, so a missing equation hides any state still on the worklist.
- `bind_formal_type` is lenient on shape mismatch while `selected_call_arguments` is extremely strict (about 45 distinct refusal reasons); the two sit at opposite strictness within one file.
- `single_exclusive_reference_storage` (40352-40374) rebuilds `TopLevelSymbols` and an empty `FrameInference` on every call.
- `validate_value_call_arguments` reports "internal: value call ... reached another program's or machine's refutation judge" (41627) as an ordinary error diagnostic.
- `CallSite::target_symbol` for statement calls picks an operator only when there is exactly one candidate and it is a boundary operator (45206-45211).
- Acceptance in this slice is the code's own yes/no or another module's yes/no.
