## What this code is for

These two files define the data the old source checker handed to later stages: the "checked trees" fact tables. `facts.rs` holds `CheckFacts` (facts.rs:23-79), one struct with about 55 fields, each a table of things the checker had decided: proven indexes, decided call `requires`, borrow facts, flow facts, qualification (domain membership) facts, carry and suspension facts, service reach, termination, and so on. `caof.rs` holds four families: three kinds of deferred obligation that can only be decided once a target is selected (constant predicates, constant "recipes", integer overflow ranges), and the per-machine contract plan (contract identity hash, crash routes, resource "envelopes", closed scalar contracts).

Most of the slice is record definitions, lookups by symbol, and well-formedness checks on the tables. The parts that decide something about a program are: discharging the three deferred obligations (caof.rs:173-217, 462-532, 765-828), the crash-plan constructors that refuse malformed site rosters (caof.rs:1727-1840), the contract-identity hash (caof.rs:1029-1107), the content-claim frontier walk (facts.rs:971-1069), and the membership queries over content transformations (facts.rs:1073-1174). Nothing in the slice calls a proof kernel. Where the tables say something is "proven" they store only the site (an expression handle or a state/statement coordinate), not the reason.

## Mechanisms

- **Deferred constant predicate.** `retain` walks an expression with a worklist and a visited list (caof.rs:58-111). `capture_predicate` copies it into an arena in post-order using an explicit Enter/Capture stack, sharing repeated sub-expressions and refusing cycles (caof.rs:220-309). Each leaf keeps the pair (expression handle, owning symbol), so a `const` initializer is observed in its own owner's scope (caof.rs:29-33, 250-254). `discharge_all` is all-or-nothing: it marks every obligation discharged for a target only if none failed (caof.rs:208-216). No budget. Serves target-dependent constants (layout queries) in conditions.
- **Deferred integer interval program.** `IntegerRangeRecipe` is a postfix list of steps (`Bounds`, `Observation`, `Add`, `Subtract`, `Multiply`, `Interval`, `Intersect`, `Union`) plus a `target_dependent` flag (caof.rs:555-558). `compose` concatenates both operands and appends the step; if neither side depends on the target it evaluates immediately and stores one `Bounds` step; if that evaluation fails it keeps the unevaluated steps so the failure reappears at discharge (caof.rs:614-631, test at 863-884). Target-dependent recipes are never simplified and grow by one step per composition (test asserts length 5 at caof.rs:894). `union` returns early when both sides are equal (caof.rs:608-610). Serves exact-arithmetic overflow checks and address-width fit.
- **Constant recipe discharge.** Resets every flag, checks each obligation, sets all flags only if none failed (caof.rs:462-532).
- **Scalar predicate adapter.** `source_node` maps one source expression to a predicate node: static boolean value, integer or boolean literal, a caller-observed boolean, borrow forwarded to its target, logical not, a comparison or and/or, else a leaf (facts.rs:300-339). Evaluation itself lives in `numerics::scalar_predicates::evaluate_nodes`, outside this slice.
- **Contract identity hashing.** `ContractHasher` feeds every byte to two sinks: a 64-bit FNV-1a "report fingerprint" and a 32-byte `DomainDigestEncoder` "commitment" (caof.rs:1203-1252). Domain strings: `omega.declared-contract-structure.v2`, `omega.declared-termination.v1`, `omega.checked-machine-public-contract.v3`, `omega.crash-data-identity-type.v1`, `omega.declared-crash-fact.v2`. Clauses, service names and invocation names are sorted and deduplicated before hashing (caof.rs:1059-1071, 1154-1168). Type identities are hashed by their text, not their table id, so two tables that mint ids in different orders agree (caof.rs:1148-1152; tests at 1262-1377).
- **Crash predicate expression tree.** Four iterative walks over one enum: `contains_structural_identity` (caof.rs:1968-2005), `substitute` parameters by argument expressions (2025-2209), `boolean_value` constant folding over literal/not/and/or with no short-circuit (2211-2278), `write_canonical` byte encoding (2280-2414). `structural_identity` orders its two operands with the derived `Ord` so `a == b` and `b == a` are one predicate (2015-2017, 2095-2097).
- **Content-claim frontier.** `descendant_frontier` replays claim transformations in arena order up to a given body conservation, restricted to one machine, one state, statements up to a given one, and one evaluation phase; each transformation replaces its parent claims with its outputs and carries forward the set of original entry claims each output descends from (facts.rs:971-1069). Linear scans throughout; no budget. Serves content conservation (ownership of content across partition and reshuffle).
- **Row merge with handle shifting.** `append_walk_rows` merges tables produced by independent per-state walks, shifting handles, spans and plan indexes (facts.rs:749-967).
- **Qualification linking.** `link_value_formations` merges formation rows and "vacuous use" rows, drops rows a content transformation already publishes, sorts by site, deduplicates, groups, and attaches each group to the structural value node with the same coordinate by binary search (facts.rs:1829-1916).
- **Sorted machine index with fallback.** Two tables keep a sorted `(arena index, generation)` index and fall back to a linear scan when the index is stale: `MachineContractPlans` (caof.rs:3604-3673, `indexed` flag) and `CheckedDeclarationDescriptions` (facts.rs:1379-1433, compares arena revision and length).
- **Suspension crossing id.** FNV-1a over identity strings, statement and call ordinals, carry policy, and per live value its normalized type text, storage kind and policy; result forced nonzero with `.max(1)` (facts.rs:2851-2873, 2954-2956).

## Accepts or skips without proof

- **"Proven" lists carry no reason.** `proven_scalar_indexes`, `proven_byte_writes`, `proven_assignment_indexes`, `decided_call_requires` are lists of sites; presence means proven (facts.rs:39-44, 134-207). A consumer cannot recheck them from this data. Cannot tell from this slice what filled them.
- **`call_requires_decided` has no call ordinal.** The key is (state, statement, target) (facts.rs:101-105, 140-151). One row covers every call to that target in the statement. Cannot tell whether another check separates two such calls.
- **Every comparison is admitted when discharging.** `discharge_all` and `closed_boolean_value` pass `&|_, _| true` as the comparison admitter (caof.rs:189; facts.rs:237). Whatever that hook was meant to restrict is not restricted on these paths.
- **`has_builtin_operators` ends in `_ => true`** and does not descend into calls, members, indexes or casts (facts.rs:255-267). A user-defined operator inside a call argument is not seen here. `evaluate` would probably treat the call as an unresolved leaf and return `None`, but that is in `numerics`, outside the slice.
- **`retain` returning `None` is ambiguous.** It means "invalid expression", "unsupported shape", "non-builtin operator", or "no target-dependent leaf, nothing to defer" (caof.rs:66-68, 87-89, 109, 112-114). The caller cannot tell these apart. Cannot tell whether the caller refuses or continues.
- **`substitute` keeps an unbound parameter.** A `Parameter(i)` with no argument, or a `None` argument, stays in the result (caof.rs:2035-2040). No error.
- **`uses_structural_proof_gated_arithmetic` ends in `_ => false`** for scalar and boolean forms it does not list (caof.rs:1694, 1715), and returns false for any guard with no scalar expression (caof.rs:1721-1722). Guards built by `from_declared_fact`, `from_operand` and `from_expression` have none (caof.rs:2436-2454). Cannot tell whether another check covers those.
- **Requirement-call branch does not compare the recorded contract hash.** In `executable_contract_identity`, the direct branch compares the site's recorded fingerprint and commitment with the plan (caof.rs:2847-2851). The requirement branch checks coordinates and symbols only and returns the concrete target's identity (2855-2879).
- **Zero commitments by constructor.** `CrashContractCapsule::new` and `CheckedCrashCallSite::new` fill the commitment with 32 zero bytes (caof.rs:2753, 2894). The resource validators refuse zero commitments (caof.rs:3102, 3198, 3301), but these two types are not validated there.
- **Resource envelopes prove nothing about resources.** `CheckedEntryResourceEnvelope::from_checked_contract` builds three anchors from (machine, entry, contract identity) alone (caof.rs:3133-3172). Each anchor names a `CheckedResourceDerivationObligation` and a hash; no stack size, work bound or state footprint is stored. `validate` recomputes the hashes. `CheckedCallbackResourceReceipt::validate` rebuilds the envelope from the receipt's own fields and compares (facts.rs:2260-2268), so it can only fail if the receipt was corrupted.
- **"Refinement" is two pairs of hashes.** `CheckedMachineContractRefinement` stores the published and selected contract identities (facts.rs:2190-2195); `try_with_uses` checks they repeat the envelope identities (2356-2377). Whether the selected contract actually refines the published one is not decided here. Cannot tell where it was.
- **Out-of-range type lookups fall back to row 0.** `ContentClassFacts::classes` and `ReferenceCustodyFacts::custody` index by `reference.arena_index()` with no generation check, and on a miss return the first row, then the default (facts.rs:2992-2998, 3164-3170). `ResolvedTypeFacts` in the same file checks the handle and returns invalid on a miss (facts.rs:3225-3241).
- **`StateLocalFacts` indexes by arena index only**, no generation; an unknown state yields an empty slice (facts.rs:3426-3444).
- **Deferral states.** `SuspensionValueBorrowFrontier::TemplateDependent` and `Unresolved` (facts.rs:2827-2839), `SuspensionCrossingLoanBacking::Unresolved` (2801-2803), `MachineActivationCarryFact.analysis_complete` (2724), `ContentClaimTransformationSource::Unknown` which `descendant_frontier` silently skips (facts.rs:1020), `deferred_layout_applications` (facts.rs:26).

## Surprises

1. **No proof kernel anywhere, but heavy "proof" vocabulary.** The slice has no `proof_admission`, `ProofNode`, `verify_obligation` or certificate. Words such as "receipt", "replay", "commitment", "checked" and "exact" refer to hashes of identities that are recomputed and compared (caof.rs:3105-3115, 3225-3237, 3322-3333; facts.rs:2260-2291). `CheckFacts.proof` and `proof_applications` are tables and type aliases (facts.rs:25, 54, 1456-1463).

2. **Resource envelopes contain no resources.** A reader would expect stack or work bounds. The three axes hold only a tag naming an obligation "to derive" and an FNV-1a hash of (machine, entry, contract identity, tag) (caof.rs:3014-3063, 3349-3365). About 430 lines (caof.rs:3005-3438) plus the receipt (facts.rs:2197-2292) validate these hashes against each other.

3. **A machine's contract identity is a hash of clause text.** `requires`/`ensures` clauses enter as rendered strings (caof.rs:952-961, 1175). Every later "same contract" test (call sites, envelopes, nominal uses, refinement) compares this hash. Two contracts with the same text under different name resolution would hash the same; the same condition written two ways would differ. The 64-bit FNV fingerprint is checked beside the 32-byte commitment everywhere, which adds no strength.

4. **Crash predicate canonical bytes can collide.** `Name(["a", "b"])` and `Name(["a.b"])` both encode as `a.b.` then NUL (caof.rs:2353-2360). `ContentConservation(bytes)` is written with no length or terminator (2405-2408), so its end is not marked when it is a left operand. `Opaque(String)` makes display text the identity (2396-2400). Guard equality, bucket sorting and deduplication all use these bytes (2501-2528).

5. **`CrashPredicateIdentity` equality ignores `scalar_expression`.** Equality, order and hash use only `canonical_bytes` (caof.rs:2501-2528). Two guards with equal bytes, one with a scalar expression and one without, are equal; `sort` then `dedup` keeps whichever came first (caof.rs:1408-1409), so the scalar form can be dropped and `uses_structural_proof_gated_arithmetic` then answers false for that guard.

6. **`boolean_value` does not short-circuit.** `false && x` and `true || x` return `None` when `x` is not a literal (caof.rs:2222-2243).

7. **The requirement-call branch of `executable_contract_identity` never reads the site's recorded hash** (caof.rs:2855-2879; compare 2846-2852). See "Accepts or skips".

8. **Row-0 fallback in two type-indexed tables.** `ContentClassFacts::classes` and `ReferenceCustodyFacts::custody` return the first row for an out-of-range type reference (facts.rs:2992-2998, 3164-3170). If row 0 is a real type, an unknown type inherits its ownership class ("plain owned", "borrow free", loan referents). Neither checks the handle generation.

9. **Dead conditions in `descendant_frontier`.** `parents.is_empty()` at facts.rs:1031 cannot be true, because line 1025 has already `continue`d when no parent is in the frontier. `"replacement parent is absent"` at 1046 cannot fire, because line 1033-1035 required every parent to be in the frontier.

10. **`try_with_uses` compares `application_index` and then overwrites it.** The conflict test is whole-record `!=` (facts.rs:2387), which includes `application_index` (2296); the function then reassigns that field for every retained row (2397-2400). Two otherwise identical uses that arrive with different incoming indexes are reported as "conflicting admitted identities".

11. **`authored_requires` can panic.** It slices `self.requires[..self.authored_requires_len]` (caof.rs:3534-3536) and `with_authored_requires_len` accepts any value (3501-3504).

12. **A predicate of literals only is not an obligation.** `retain` returns `None` when no leaf is target-dependent (caof.rs:112-114), the same value it returns for an unsupported shape. A constant-false literal predicate is therefore not caught here; cannot tell where it was.

13. **Capabilities a reader might not expect.** The checker deferred some checks until a target was chosen and stored exactly what remained to be evaluated: predicate trees with per-leaf owners (caof.rs:16-33), interval programs with target observations (555-558), and an address-width model with its own commitment (641-645). It distinguished a crash interface that is inferred from one published as a ceiling (caof.rs:1906-1910), tracked crash routes as buckets of alternative guards per cause, and carried a "permission frontier lower bound" per crash site (2641). It modelled content conservation with claim lineages across transformations (facts.rs:617-630, 971-1069), quotient types (facts.rs:2093-2108), installed interrupt registrations (2153-2168), and per-value carry policy across suspension (CPU, host thread, address stability; facts.rs:2944-2952).

14. **`has_builtin_operators` is quadratic.** It scans all of `operators.uses` at every node of the expression (facts.rs:249-253).

15. **Tag order in `crash_frontier_claim_sort_key`.** `InstructionExitDisposition` gets tag 5 and `InstructionDisposition` tag 4, listed in the opposite order (caof.rs:2992-2999). Sort order only.

16. **`ContractHasher::new` builds the digest with an empty domain and then writes the domain as ordinary bytes** (caof.rs:1209-1216). The domain separation therefore relies on the byte prefix, not on the encoder's own domain parameter.

17. **How the three properties fare here.** Property 1 (own yes or no): supported; every decision in the table above is a local compare or a call into `program`, and the outputs are flags, lists and hashes. Property 2 (identity by text): supported for contracts, crash predicates, termination premises, service names, targets and cross-package identities; not supported for sites, places, domains and claims, which use handles and place segments. Property 3 (one rule per placement): only weakly visible, because this slice is the storage layer; the shapes of the tables (four index-proof lists, three write sites, three qualification records, four crash-site kinds) show that the code filling them was split by placement.
