## What this code is for

The slice holds four sub-modules of the old contract-entailment checker. Three
are small. `proof_edges` (23685-24003) decides whether a recursive proof call
passes a strictly smaller `Nat` to its measure parameter. `proof_integer`
(24004-24346) decides which expressions are mathematical integers and checks
that proof-only `Int`-to-`Nat` casts and divisions are well formed.
`quotient_congruence` (24347-24566) decides whether two values cast into a
quotient type are equal because the quotient's relation is in the machine's
`requires`.

The rest, about 6,400 lines, is the first part of `ranking_range`, the
termination checker for machines declared `terminates by <measure>` with an
optional rank range. It works out which entry-state parameter (or field of a
parameter, or slice length) each later state's parameters still hold
(`arrival_correspondence`, `arrival_selection`), then proves for a call or
transition between ranked machines that the rank does not increase and stays
in range (`calls::prove_ranking_range_call`). Supporting modules name storage
places as "coordinates" (`coordinate`, `fields`, `lengths`), decide which
expressions the arithmetic engine may interpret (`meanings`), prove a callee's
arithmetic `requires` at a call site (`requirements`), and treat immutable
locals as saved values (`saved_arguments`). Every decision is made by a
polynomial arithmetic `Engine` or a `StructuralJudge` defined outside the
slice; the slice builds their inputs and reads back a yes or no.

## Mechanisms

- **Structural prefix visitor.** Two visitors implement
  `StructuralPrefixVisitor` and are driven by code outside the slice that
  replays the state's statements up to a site. `StrictDecrease` (23771-23881)
  builds one equation and asks the judge. `NormalReturnLength` (28702-28751)
  asks the judge for every normal outcome of a call and keeps a length only
  if all outcomes agree. Each has an `unresolved` hook that turns the answer
  to "not proven" (23795, 28715). Serves `terminates by` over `Nat` and
  collection lengths.
- **Polynomial engine use.** `Engine::strict` is built from symbol bindings,
  then the slice binds member expressions to named atoms
  (`bind_strict_projection`), installs comparisons as hypotheses
  (`install_hypotheses`), calls `refresh_opaque_intervals`, and asks
  `prove_at_least(polynomial, constant)`. The engine itself is outside the
  slice. Before a trial step the code clones the engine and commits the clone
  only on success (27743-27757, 27795-27801, 27935-27947, 28222-28225).
- **Arrival correspondence fixpoint** (`discover`, 25414-25534). For each
  state it keeps rows "entry coordinate E is now at destination coordinate D,
  transported by these argument expressions". It seeds the entry state with
  the identity, then repeats over all internal arrival sites, adding rows and
  transports, until one pass changes nothing. There is no iteration cap. The
  only growth guard is the recurrent-arrival refusal (25503-25520).
- **Completed coordinates** (24889-25293). A recursive walk over an argument
  expression that returns the entry coordinates it carries, each with a
  relative path inside the value, a `CapturedCoordinate` or
  `ComputedDependency` tag, and the locals it passed through. It handles
  names, members, struct and array literals, borrows, casts, binary
  expressions and built-in subslices itself and defers everything else to
  `completed_value_observations` (outside the slice). Depth limits: 64 in
  `completed_source_coordinates` (25219) and the expression table's own
  `expression_at_depth`.
- **Backtracking selection** (`select_rank_arrival_correspondence`,
  25688-25776). For each demanded entry coordinate it lists candidate
  destinations (from discovered rows and from type-compatible projections of
  received arguments, 25717-25725), then does a depth-first search over one
  choice per demand, calling the caller's closure after each choice
  (`Pending`, `Complete`, `Refuted`). No budget; worst case is the product of
  the candidate counts.
- **Receiving projection search** (`receiving_projection_paths`,
  25337-25412). Recursively walks every field and variant payload of a
  parameter's declared type to find places whose type matches a demanded
  path, with an owner stack to stop on recursive types.
- **Coordinate, CoordinateSet, CoordinateFamily** (27171-27608). One generic
  record for "a field reached from a parameter", used for integer fields and
  for slice lengths, with a trait for the parts that differ (resolve, demand,
  arrived actual, comparisons). `FieldFamily` (27615-27660) and `LengthFamily`
  (29336-29395) implement it.
- **Symbolic length evaluation** (`evaluate_length`, 28900-29056). Returns a
  polynomial for the length of an expression: parameter atom, field
  coordinate, checked subslice, declared extent, const-parameter extent,
  saved local, string or array literal size, call result. Call results go
  through a per-program memo keyed by `(machine, state, expression)` with an
  "active" set keyed additionally by thread id to stop re-entry
  (28626-28700).
- **Carrier admission** (`admitted_carrier`, 29406-29684). Returns
  `Some(Some(type))`, `Some(None)` (admitted, no integer carrier) or `None`
  (refused) per expression kind. Refused kinds include unary operators other
  than logical not, recasts, casts whose target is not a fixed integer, range
  indexing without built-in subslice meaning, and anything not listed
  (29682).
- **Atom substitution** (`substitute_atoms`, 29198-29220, and
  `inductive_judgment::apply_argument_map` outside the slice). Replaces named
  atoms in a polynomial by polynomials; used to move a callee's obligation
  into the caller's variables.
- **Depth and size limits seen.** 64 (25219), 128 (27822, 27990, 28424,
  29293, 29730), 16 (29066), 4096 nodes (30745).

## Accepts or skips without proof

- **Contradictory hypotheses count as proof.** `requires_unsatisfiable`
  accepts a non-negative cast (24154), a non-zero value (24170), a subslice
  bound (29000), a callee requirement (30473), and makes a ranked call
  `Strict` (26453-26455); it also skips endpoint landing and rank formation
  (26259, 26281). The hypotheses include the rank-range invariant assumed for
  non-entry states (26246-26253, 30386-30398) and declared type bounds. I
  cannot see in this slice where the invariant is established.
- **Declared types are trusted as facts.** `field_comparisons` installs the
  field type's primitive bounds and `enforced_integer_type_bounds` as
  hypotheses (28075-28114); `prove` does the same for caller parameters
  (30284-30305); every slice length is assumed non-negative (29389-29393,
  30277-30283).
- **`saturating_sub` is chosen by name and signature only** (23974-23991).
  Nothing in the slice looks at its body. The judge may unfold it; I cannot
  tell.
- **A carrier named `Nat` is accepted in `proof_edges` without the toolchain
  origin test** that `proof_nat_type` applies (23898 against 24040-24044).
- **`proof_nat_type` accepts a symbol with no recorded origin** when the
  symbol table has no source metadata at all (24043).
- **A user range operator is trusted for extent.** When
  `range_operator_establishes_endpoint_extent` is true and the end is
  exclusive, `evaluate_length` returns `end - start` with no bound proofs
  (28974-28977). Another module makes that decision.
- **Callee parameters are assumed unsigned** in
  `transparent_call_result_length`: every non-slice parameter becomes an atom
  with `unsigned: true` whatever its type, and the callee's `requires` are not
  installed (29126-29138). The callee's own body check may cover this; I
  cannot tell.
- **`LengthFamily::demanded` always returns true** (29356-29361), while
  `FieldFamily::demanded` tests membership (27629-27631).
- **`forms_in_carrier` returns true** for every measure that is not computed
  (26806-26808).
- **Untransported roles pass on a path suffix.** In
  `ranking_range_arrival_preserves_roles`, a source coordinate that no
  argument transports is accepted if all argument inventories are complete
  and the destination's path ends with the same segments (24649-24653). The
  parameter is not compared.
- **Failed lookups that continue.** `discover` skips an argument whose
  coordinates cannot be computed (25469-25479); a later demand with no
  candidate refuses (25726-25728). `collect_destination_fields` and
  `collect_destination_lengths` skip members they cannot resolve and ignore
  all other node kinds (26678, 26782). Struct and array literal children that
  fail become an empty, incomplete inventory (25005-25007, 25024-25025).
  Callee parameters that are not demanded or not integers are not bound
  (26296-26304).
- **Ignored results.** `saved_arguments::install` and
  `refresh_under_hypotheses` discard the results of `lengths::install`,
  `install_nonpolynomial_terms`, `bind_strict_arguments`,
  `rebind_saved_expression` and `bind_strict_projection` (30532, 30545,
  30580, 30611, 30620, 30628, 30816). `lengths::install` fails exactly when a
  projection binding conflicts (28877-28881); what the engine holds after a
  discarded conflict I cannot tell.
- **Hypotheses without an admitted carrier are dropped** (30159-30166), and a
  failed `telescoped_bindings` falls back to the caller's own bindings
  (30190-30195). Both only weaken the premises.
- **`install_nonpolynomial_terms` does not descend** into members, indexed
  expressions, casts, unary expressions, matches or borrows (`_ => {}`,
  29822). A modulo with no typed carrier is accepted with nothing installed
  (29817-29819).
- **`admitted_carrier` for a `match`** checks only arm values, not the
  subject or patterns (29666-29681); for a call it requires only that a
  selected contract exists (29520-29529); `unselected_or_builtin_arithmetic`
  is true when an expression has no selection occurrences at all
  (29694-29706).
- **`state_aliases::collect` default arm** records nothing for a node kind it
  does not name and succeeds if its children succeed (30978-30990). A name
  whose symbol differs from its head symbol falls there.
- Fail-closed defaults, for balance: `unwrap_or(false)` at 29998 and 30121;
  `_ => None` at 25942, 26839, 28282, 29053, 29682; `unresolved` hooks at

## Surprises

1. **Strict decrease on `Nat` rests on five names.** The proof that a
   recursive proof call descends is the equation
   `saturating_sub(Succ{prev: a}, m) == Zero`, with the data, variants, field
   and relation all found by name (23838-23867, 23898, 23975).
   `selected_decrease_relation` checks the relation's name, arity and types
   and never its definition, and it does not require the carrier to be the
   toolchain's `Nat`.
2. **A per-program cache and a thread-keyed re-entry guard inside the
   checker.** `normal_return_length` reads and writes
   `memos.completed_collection_lengths` under a mutex and records the active
   query with `std::thread::current().id()` (28632-28700). Only successes are
   cached, so a failing query is recomputed each time. A re-entrant query on
   the same thread returns `None`, so the answer for a site can depend on
   which query reached it first.
3. **One diagnostic in the whole slice.** Every rule except the `Int`-to-`Nat`
   cast returns `bool` or `Option`; refusal text is produced elsewhere.
   `proof_interval_strict_decrease_judged` collects the recogniser's
   diagnostics in a local vector, tests only that it is empty, and drops them
   (23758-23768).
4. **`lengths::bindings` signals a conflict by returning an empty vector**
   (28828-28830), which also throws away the valid base bindings. Its caller
   in `prove_ranking_range_call` merges the result into bindings it already
   holds (26096-26106), so there a conflict is silently ignored.
5. **`stable_references` does not look at a call's receiver.** For a call it
   pushes only `call.arguments` (30750-30756); every other node uses the
   general child walk. A receiver that is an exclusive reference or a written
   local would not make the initialiser unstable. This looks like an
   oversight.
6. **Modulo and divide are treated differently** when the expression has no
   typed carrier: divide refuses, modulo passes with nothing bound
   (29817-29819).
7. **Two walkers over the same premise expressions disagree on strictness.**
   `collect_read_coordinates` refuses unknown node kinds (25942);
   `state_aliases::collect` accepts them (30978-30990). `required_symbols`
   then calls `Vec::dedup`, which removes only adjacent duplicates (30849).
8. **A subslice argument carries only its collection's coordinates.** For
   `s[a..b]` in an arrival argument, `completed_coordinates` returns the
   coordinates of `s` marked `ComputedDependency` and does not record `a` or
   `b` (25072-25087).
9. **Unary minus is not admitted.** `admitted_carrier` accepts only logical
   not among unary operators (29550-29553), so `-x` is refused unless the
   whole expression is an anonymous integer constant (29414).
10. **Redundant branch.** In the cast arm, the early return at 29545-29547 is
    implied by line 29548, because `integer_literal` already makes
    `integer_source` true (29540).
11. **Evidence-like records exist but nothing checks them here.**
    `RankCoordinateTransport`, `RankLocalCapture` and `RankValueDerivation`
    (re-exported from `checked_trees::CheckedRankValueDerivation`, 24664)
    record how each coordinate reached a state, and
    `RankStateBindings::from_checked` reads a
    `checked_trees::CheckedRankArrivalPlan` back (25558-25584).
    `requirements::prove` takes such a plan as `admitted` and assumes the
    rank invariant from it (30108, 30182-30188, 30386-30398). So this checker
    publishes a derivation for later stages and trusts one from an earlier
    step, but no proof-kernel call (`proof_admission`, `ProofNode`,
    `verify_obligation`, certificates) appears anywhere in the slice.
12. **Termination of `discover` depends on a flag computed elsewhere.** The
    loop has no cap (25438-25533); only arrivals marked `recurrent` are
    guarded against ever-longer paths (25503).
13. **Two independent records of the same termination plan are
    cross-checked** (`termination_plan.implementation_witness` against
    `ranking_expression_custody_for`, 26943-26951), which suggests neither was
    trusted alone.
14. **Increasing-to measures get a clamp.** A call is `NonIncreasing` when the
    next rank `limit - subject` is at most 0, whatever the current rank
    (26520), and `Strict` additionally needs the current rank at least 1
    (26517). The other five measure kinds have no such rule.
