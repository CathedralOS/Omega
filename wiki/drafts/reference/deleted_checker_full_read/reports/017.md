## What this code is for

This is the first 4,792 lines of the old checker's borrow fact builder. It does not itself report most borrow errors; it records `checked_trees::BorrowFacts` (writable roots, loans, borrowing calls, argument accesses, last uses) that `checks::borrows` and the flow builders later judge (`borrow.rs:1-18`). The slice contains six sub-modules. `accesses` (`borrow.rs:36-1239`) walks a call's argument expressions and records, in evaluation order, which storage place each one reads or borrows and when that hold ends. `calls` (`borrow.rs:1240-1907`) finds every machine call and transition target in a statement, gives it an ordinal and an access roster, and (`reference_custody`) replays a per-statement schedule to record which reference loans each call takes in, replaces and publishes. `children` (`borrow.rs:1908-1978`) is a shared expression traversal. `last_uses` (`borrow.rs:1979-2478`) computes, per loan, the last statement that uses it. `lifetime_contract` (`borrow.rs:2479-3087`) re-derives, from recorded flow facts, the declared "result borrows from input" edge of a call and refuses when recorded and re-derived data disagree. The read part of `loans` (`borrow.rs:3088-4792`) decomposes initializers into reference leaves, relates loan owner paths to place paths, compares a state body's returned references with its declared view-return contract, forms loans for call results, and captures which stored loans an assignment replaces.

## Mechanisms

- **Ordered access roster with end positions** (`borrow.rs:65-286`, `931-1212`). The collector appends one `BorrowArgumentAccessFact` per accessed place in evaluation order. Each row has `end_before_access`: an index into the same roster before which the hold ends (`None` = held through the invocation; `0` = ended by the dispatch's copy). `finish_completed_value` closes all open rows from a start index when a value of borrow-free type completes. No budget. Serves simultaneous-argument conflict checks.
- **Replay as authentication** (`borrow.rs:307-386`, `815-906`). To tie a stored roster to a source call, the code re-runs the same collector into scratch arenas and requires row-by-row equality. On equality it either upgrades end positions (`completed_dispatch`) or returns the call site (`replay`). Any difference means "do nothing"/`None`.
- **Recast geometry** (`borrow.rs:532-636`). Peels the expression, recognises a recast whose source is an indexed element, and returns a place plus a separate representation address.
- **Reference-custody schedule replay** (`borrow.rs:1477-1666`). `CallFrameResolver::stored_reference_call_contexts` supplies an ordered list of contexts (`Entry`, `Join{alternatives}`, `Invocation{entry, expression, effects}`, `StatementCompletion{entry}`). The loop keeps `contexts: Vec<Option<Vec<StateLoanTracker>>>` indexed by position. A join is the de-duplicated union of its alternatives, or `None` if any alternative is `None`. An invocation records its input loans, its slot effects, removes definitely replaced trackers, forms result loans and appends them. `None` means "roster unknown" and propagates. Linear, no budget.
- **Last-use fixpoint** (`borrow.rs:2287-2459`). Three direct passes (call accesses; statement uses; parameter-field loans) then a `loop` that repeats until nothing changes: suppliers inherit dependents' last use; carriers inherit overlapping aliases' last use. `extend_last_use` only moves forward in `StatementExecutionOrder`, so the loop is monotone; there is no iteration cap. Cost is trackers × trackers per round and calls × accesses × trackers in the first pass. Granularity is one statement.
- **Lifetime-contract rejoin** (`borrow.rs:2487-2657`) and **one-to-one cover check** (`borrow.rs:2930-2988`, `used` bit vector). The recorded edge is matched back to the declaration by parameter index, source kind, normalized type identity and canonical path equality (`same_path`, `borrow.rs:2866-2877`).
- **Type-directed initializer decomposition with substitutions** (`borrow.rs:3179-3421`). Recurses over the receiving type and the initializer in parallel, carrying a list of `(type parameter symbol, concrete type)` pairs searched from the back.
- **Owner-path algebra** (`borrow.rs:3428-3694`, `2186-2203`). `BorrowOwnerSegment` (`Field`, `Case`, `FixedIndex`, `DynamicIndex`) versus `facts::PlaceSegment` (`Field`, `Case`, `FixedIndex`, `FixedRange`, `OpaqueRange`, `Index{expression}`), with several relations: may-overlap, prefix match, definite cover, exact leaf.
- **Declared frontier versus body relation** (`borrow.rs:4103-4243`). Uses `CallFrameResolver::reference_result_transports_for_arguments` to get the callee body's returned leaves, expands value transports into per-reference leaves, and classifies each into `ImmutableImage`, `UnresolvedDescriptor`, `DescriptorCandidate` or (uncovered fields) `LifetimeDependency`. Three outcomes: `None` unavailable, `Err(parameter)` contradiction, `Ok`.
- **Result-loan peeling loop** (`borrow.rs:4340-4581`). Loops through `Borrow` wrappers collecting access limits, recurses through `Indexed`/`Member` filtering loans by owner-path head, and ends at a literal or a call. A per-call cache of carried argument loans is a `Vec<(usize, Vec<..>)>` searched by position (`borrow.rs:4619-4652`).

## Surprises

- **Two rules disagree about ranges.** `owner_path_overlaps_place_segments` (`borrow.rs:2191-2202`) accepts a dynamic owner index only against `FixedIndex` or `Index`; `owner_path_matches` (`borrow.rs:3605-3615`) also accepts `FixedRange` and `OpaqueRange`. A fixed owner index against a `FixedRange` place gets `None` from `owner_segment_matches_place_segment` (`3594`) and so is "no overlap" in the last-use pass and "no match" in `owner_path_matches`, while `place_path_covers_owner` handles that pair explicitly (`3645-3648`). `FixedRange` places are produced by recast footprints (`borrow.rs:581-584`). So a recast-range access to a collection does not extend the last use of a loan stored in an element of it (`2327-2333`). This looks like a gap; I cannot tell from the slice whether another pass compensates.
- **A contradiction is turned into an empty list.** `completed_sources` maps `Some(Err(_))` to `Vec::new()` (`borrow.rs:3926`), while the doc comment of the enum says an unavailable alternative "must not" be masked (`3843-3847`).
- **The mismatch detector says "no mismatch" on most lookup failures** (`borrow.rs:3970-4014`), although its own comment warns against silently treating unrecognised sources as permission (`3944-3947`).
- **The code authenticates its facts by re-running itself.** Both `completed_dispatch` and `replay` trust a stored roster only if a fresh run of the same collector reproduces it (`borrow.rs:345-372`, `877-904`). `completed_output_retention` requires whole-struct equality of the `BorrowCallFact` (`borrow.rs:3006-3009`). This is extensive self-consistency checking between the checker's own tables, with no external evidence.
- **Internal schedule errors are user diagnostics.** The nine "normal reference-slot …" messages (`borrow.rs:1502-1665`) describe a malformed schedule from `CallFrameResolver`, not a fault in the user's program, yet are returned as `Diagnostic::error`.
- **A trace print is on the checking path**: `eprintln!("STRUCT output-lifetime-contract-refused …")` under `validation::trace_flags::struct_trace()` (`borrow.rs:2594-2598`).
- **Last use is per statement and partly by name.** A loan's expiry is the index of a statement; the name test and the symbol test are OR-ed (`borrow.rs:2281-2283`, `2357-2358`). Assembly statements never count as a use (`2081`, `2144`).
- **`attenuate` lowers only Mutable loans** (`borrow.rs:4593-4600`); a WriteOnly loan re-borrowed as Read keeps WriteOnly. In `argument_loans` a carried loan of any kind is set to the declared field kind when that is Read or WriteOnly (`4693-4701`), so a Read loan can become WriteOnly, which sits oddly with the comment at `476-481` about never taking the kind from the destination.
- **`has_receiver` is decided by arithmetic**: for a selected operator, it is true when the operator's parameter count equals the argument count plus one (`borrow.rs:1420-1429`); otherwise by whether the receiver symbol is not a `ConformanceParameter` (`1416-1419`, `1869-1871`).
- **`store_destination_places` asks for the target's type "at statement index = number of statements"** (`borrow.rs:3472-3480`), i.e. the declared type at the end of the state, not at the store.
- **The only image storage is a string literal** (`borrow.rs:505-512`).
