## What this code is for
This slice is the "other changes" diff of PR #2823: everything outside the big checker crates. It is mostly the plumbing that used to feed the old checker's output (`CheckedTrees`) into Build admission, product selection, provider/target settlement and Terminal publication, plus its caches and its tests. Cargo.lock/Cargo.toml drop the crates `checked-trees`, `facts`, `validation`, `representation-planning/selections`, `lowered-psi*`, `typed-trees-to-checked-trees` (d:1-503). The `build-settings` crate loses the Pure-Build result cache, the Build-slice projection/settlement/check, selected-constant folding, target layout queries, and `via` producer evaluation (d:570-2581). The `compiler` crate loses the checked-slice disk cache, retained-check reuse between compilations, the old route governance (`govern`), source-checking projection, target preparation, provider settlement, calling-program capture and product-code production (d:2804-5703). Replacements are mostly stubs that refuse with "no product route yet" (d:1446-1449, 2329-2345, 4415-4418, 4658-4660, 4804-4806, 4826-4830, 5699-5701), plus a few new pieces: `AcceptedTerminalSource::judge` (d:3618-3666), `SourcePreparationRequest` (d:3899-3906, 4203-4259) and a new `entry_shapes.rs` (d:3187-3300). Several tests that grep source text for architecture, and tests that read the deleted `tests/omega/` corpus, are deleted too.

## Mechanisms
- Pure Build reuse (d:570-871, 2137-2200). Computes whether a completed Build can be reused. A session-wide append-only `Vec<Arc<CompletedPureBuild>>` behind a mutex; length is the "publication generation" (d:715). `retain_completed` compares candidates added since the last pass outside the lock (loop d:763-785); lookup clones the Vec under the lock and compares outside it (d:737-749). No budget; linear scan. Serves Build evaluation. Deleted.
- Build slice settlement (d:1145-1275). Projects the Build slice, evaluates pending constants, projects again, derives provider plans, selects them, folds deferred constants, projects a third time. `BuildPlanDemand` decides whether provider planning runs at all for a rejoined slice (d:1139-1143, 1179-1185). Serves Build-time constant folding and provider choice. Deleted.
- Selected constant evaluation (d:1650-1793). Per resolved expression-selection use, finds the selected plan and binds it to a provider body or a primitive float operator, then folds pending constants in place. Deleted.
- Checked-slice store (d:2832-2971). On-disk content-addressed cache; atomic publish by write-to-temp then rename; eviction by modification time to a 4 GiB budget (d:2858, 2912-2943). Env var `OMEGA_CHECKED_SLICE_CACHE`. Deleted.
- Retained check reuse across compilations (d:4266-4370, 3892-3897). Session keeps `RetainedCompilationChecks`; `retain_judgment` replaces an entry with `same_judgment` else pushes (d:4357-4369). Deleted.
- Route judgment combinator (d:3406-3425). Refusal-dominates-rejection-dominates-acceptance merge over several separately judged parts (`judge` per machine of the closure). Deleted.
- Provider selection pipeline (d:4849-5021): prepare calling program, plan boundary calls, settle providers, select program entry, bind physical adapter, prepare selected execution. Deleted.
- Terminal product roots (d:5527-5584, 5632-5698): union of entry roots, calling-policy machine roots (expanded to all family members), constant-recipe provider machines, sorted by `(arena_index, generation)` and deduped; boundary roots from provider selections, float catalog, assumed bindings, recipe requirements. Deleted.
- NEW `bound_program_entry_shapes` (d:3207-3300): resolves each root binding's slot to a callable shape with retained declarations.
