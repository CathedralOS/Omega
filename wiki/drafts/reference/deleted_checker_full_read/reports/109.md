## What this code is for

The slice holds four support layers of the old "structural" contract checker and the function that drives contract checking for one machine. `structural_prefix` (CE:85418-87405) walks a state's statements up to one statement ("the prefix site") and hands a visitor the judge (`StructuralJudge`) holding the facts that are true there; its sub-module `private_arrivals` decides when a private nested machine with no written `requires` may take its entry facts from all of its call sites. `type_consequences` (CE:87406-88148) uses those walks to compute, per expression, which type-parameter equations hold, which `match` cases are possible, and whether an `is` test is known true or false. `structural_terms` (CE:88158-91725) turns a source expression into a `StructuralTerm`, the judge's own value language; it also reads kernel terms from prepared "mathematical" applications back into that language. `transparent_applications` (CE:91726-92096) unfolds a transparent proposition into conjuncts and proves or assumes them. The last part (CE:92170-92917) is `validate_machine_contract_entailment`: for each `ensures` expression of a machine it tries a cascade of judges (verbatim match with a `requires`, content conservation, structural case arms with induction, quotient equality, result bounds, inductive transition entailment, polynomial arithmetic, collection predicates), records the fact in `proven.entry` or `proven.normal_returns`, or pushes a diagnostic. Every verdict in the slice is a Rust enum or `bool` computed by this code; nothing in the slice builds or checks a kernel proof.

## Mechanisms

- **Loop-entry selection over the private call graph** (`cycles::entries`, CE:85434-85487). An iterative depth-first walk over member machines that can reach the callee. A node reached again while still on the stack is selected as a cycle entry. Independent entries are pre-selected and not walked into. No budget; linear in edges. Serves caller-derived entry facts for private nested machines.
- **Whole-program private-use index** (`ProgramPrivateArrivalIndex::build`, CE:85873-86004), memoised once per frozen program (CE:86007-86015). It records which machines are nested under which root, every call site into them, which state symbols have a unique owning machine, and which symbols are "unclosed" (used other than by direct call). The closedness test is a counter: each direct call adds one, each callable use subtracts one (CE:86425-86429, 86460-86466).
- **Closed arrivals** (`compute_closed_arrivals`, CE:86045-86283), memoised per `(root, callee)` behind a mutex (CE:86024-86043). Computes expected call-site arrivals, backward reachability from the callee, open entries, strongly connected components that carry `requires` (asks `graph_components::strongly_connected_components`, CE:86206-86227), entry boundaries, and caller frontiers.
- **Progressive caller frontiers** (CE:86285-86340). Starting at the callee's direct callers, repeatedly replaces each non-anchor machine with its callers until the set equals the anchors or repeats. Stops early when a caller's ownership is not unique or it has no callers. No numeric budget.
- **Prefix walks with visitors** (`StructuralPrefixVisitor`, CE:87006-87066; `visit_arm`, `SiteArm::deliver`). The walk itself is outside the slice (`recognize_structural_case_arms*`); here the visitor protocol and the premise assembly live. `AdmittedArm` (CE:87254-87300) keeps one judge per statement loop and admits only new citations, to avoid quadratic re-admission (comment CE:87235-87253).
- **Type-equation pruning** (`predicate_type_contexts`, CE:87688-87830). Candidates are the product of a machine's type-formal references and every closed type that appears in a static type predicate anywhere in the program. Each candidate survives only if the judge proves it on every reaching entry. Results for the same expression are joined by intersection (CE:87541-87554).
- **Expression to term translation** (`structural_term`, CE:91264-91623). Recursive match on the expression kind with an optional substitution callback. Two contexts: `scope` (machine, state, expected type) and `frame` (owner symbol, parameter list). Anything unhandled is `None` or an `Opaque` display string.
- **Kernel term read-back** (`mathematical::read_term`, CE:88624-88855). Converts a `proof_admission::Term` from prepared mathematics into a `StructuralTerm` by recursion with de Bruijn captures; depth limit 128 (CE:88633).
- **Transparent unfolding** (`unfold_definition`, CE:91792-91866). Follows `= other(..)` definitions with a `visiting` list as cycle guard; splits `&&`; drops literal `true`.
- **Zero-value construction** (`zero_term`, CE:89471-89542) with an `active` symbol list as recursion guard.
- **Scalar representation normalisation** (CE:90513-90604). Collapses recast round trips and folds literals through their bit patterns up to 64 bits.
- **Constant application unfolding** (`unfold_constant_applications`, CE:90766-90846); asks `StructuralJudge::closed_application_value`.
- **Scope guessing** (`expression_scope`, CE:88499-88521, depth limit 32; `scoped_machine_state`, CE:88474-88497). Finds the first name inside an expression and walks that symbol's parents to a machine and state.
- **Entailment cascade** (`validate_machine_contract_entailment`, CE:92193-92836). Order per `ensures` expression: indexed mathematical contract; verbatim `requires`; content conservation; structural (case-observation paths, quotient equality, normal-return paths, per-arm induction); then for the remainder result bounds and inductive transition entailment (machines with a body) or the polynomial arithmetic `Engine` and collection predicates (body-less machines).

## Surprises

- **Property 1 holds throughout.** Every acceptance is `StructuralJudgment::Proven`, `Judgment::Proven` or a `bool`, pushed into `proven.entry` / `proven.normal_returns` (CE:92603, 92629, 92641-92643, 92651, 92678-92680, 92752, 92777, 92793, 92804, 92823). The one contact with the proof kernel runs the other way: `read_term` translates kernel terms into the judge's terms (CE:88530, 88659-88852). Nothing in the slice calls `verify_obligation`, builds a `ProofNode` or produces a certificate.
- **A closed-world interprocedural analysis exists.** A private nested machine with no written `requires` gets entry facts from all of its call sites, with a call-graph index, cycle-entry selection, strongly connected components and caller frontiers (CE:85418-86854). The brief's three properties do not predict this capability.
- **Only the last caller frontier is tried.** `progressive_caller_frontiers` builds a list of frontiers, but `observe_private_arrivals` loops over `.iter().rev().take(1)` (CE:86633). The batch variant never tries a frontier (CE:86677-86782), so the single and batch paths can answer differently for the same machine.
- **Closedness is a counter, not a site match.** A callable use is paired with any earlier direct call of the same symbol (CE:86460-86466). The pairing depends on the traversal visiting the call before its callable use.
- **Refusal reasons never reach the user.** The reason strings of `closed_arrivals` and `source_operation_term` print only under trace flags (CE:86609-86613, 88838-88846); the caller sees `Some(false)` or `None`.
- **A type equation is a string-named variable.** `static_type_equation_term` formats two type identity texts and flags into a variable name, and `open_closed_type_atom` parses it back (CE:91235-91262).
- **Names decide meaning in `structural_term`.** Outside a frame, a one-segment name is `Variable(<spelling>)` regardless of its symbol; inside a frame the same name is `Variable(parameter.name)` for a parameter and `BoundValue(symbol)` otherwise (CE:91321-91347). Two bindings with the same spelling yield equal terms. Cannot tell whether the language forbids such shadowing.
- **The enclosing machine can be guessed from a name inside the expression.** When no scope is passed, `binary_term_in_scope` and `indexed_term_in_scope` take the first name in the expression and walk its parents (CE:88306-88314, 90005-90010). An expression with no name has no scope.
- **Vacuous `Proven` on empty arm lists** (CE:92379, 92452, 92482); see "Accepts or skips".
- **Silent drops in the driver.** Content-conservation facts in checked-body machines (CE:92624-92632) and arithmetic unknowns outside the engine's language (CE:92826-92832) leave the function with neither a `proven` entry nor a diagnostic.
- **Flag read before it is final.** `judge_structural` reads `all_facts_are_expressions` to decide whether to use the induction hypothesis (CE:92520). The flag is lowered for zero-value and proof-only mentions only afterwards (CE:92730-92737), so that adjustment affects only `inductive_transition_entailment`.
- **Comment and code differ on opaque terms.** The doc says "display-only term proves nothing" (CE:91088-91090); the filter rejects `Opaque` only at the top level (CE:91100).
- **Two definitions of "equality means identity".** `has_identity_equality_meaning` admits any non-float scalar and `Int`/`UInt` (CE:89919-89930); `builtin_identity_operand_references` admits only fixed integers, `bool` and addresses of the same type (CE:89964-89976).
- **The zero value of a sum type is its first declared variant** (CE:89562-89568), so declaration order has meaning.
- **`FactCallTargets.any` is written and not read at the only call site**, which uses `.all_declared` (CE:92601, 92838-92841, 92885).
- **Two trace mechanisms.** `OMEGA_ENTAILMENT_TRACE` is read with `std::env::var` inside the per-fact loop (CE:92782); the rest uses `crate::trace_flags` (CE:92170-92181). Trace `eprintln!` calls sit in checking code at CE:86611, 86694, 86841, 87512, 88545, 88560, 88647, 88756, 88840, 91406, 91417, 92399, 92591, 92783.
- **Internal labels in user-facing text and comments.** The diagnostic at CE:92662-92665 says "chapter 10 engine veto"; comments cite "N3 rung 2" (CE:92510) and "the L7 protocol" (CE:92309).
- **File layout.** The file's top-level `use` lines and entry function come after all nested modules (CE:92140-92168, 92193), and re-exports are interleaved with modules (CE:88149-88157, 92098-92138, 92919-92926).
