## What this code is for

This is the first half of the old borrow checker's judgment file (module `checks::borrows`, included from `checks.rs:40`). It does not build loans; it reads loan, call, operand and ownership rows that earlier passes stored in `CheckFacts` and decides whether each is allowed. The slice holds twelve inline sub-modules: `elision` (which input a returned view borrows), `escape` (a returned view must not borrow a local, an owned input or a temporary), `persistent` (a borrow stored in a machine's persistent field must be provably static), `aggregates` (reference leaves formed together in one value must not conflict), `captured_descriptors` and `incoming_backing` (a helper overwriting a field whose old pointer it still holds must be safe for every caller, proved transitively through the call graph), `completed_custody` (owned inputs must be unborrowed when an implicit transformation completes), `moves` (no move under a live loan), `retained_outputs` (is a stored result's retained borrow recorded as a loan), `reads` (no read or reborrow under a conflicting loan, plus when a loan ends inside a statement), `selected_retirement` (a loan may die early on one taken transition edge), and `staged_values` (copied arguments keep their reference leaves alive while a call stages its other operands). Nearly every module ends in the same out-of-slice judgment, `overlap::captured_place_compatibility` or `overlap::canonical_place_non_interfering`, or `simultaneous::simultaneous_hold_conflict`. Results are `Vec<Diagnostic>`, `bool` or `Result<(), &'static str>`; nothing in the slice produces or consumes proof-kernel evidence. There are no tests in the slice.

## Mechanisms

- **State-graph fixpoint for static persistent paths** (827-905). For each state it computes which persistent field paths are known at entry to hold only static borrows. It seeds the first state, runs `analyze_persistent_state` to get exit facts, rebases them across each named transition edge (930-985), and merges into the target by intersection. It loops until nothing changes; there is no iteration budget, and termination rests on the sets only shrinking after first assignment. Serves borrows stored in machine attached data.
- **Index renaming across a transition** (930-1031). A path segment indexed by an immutable parameter or local survives an edge only if the same symbol, or a chain of immutable local copies of it, is passed to an immutable target parameter; the segment is then renamed to the target parameter's symbol. Cycles in the copy chain give `None`.
- **Path overlap on a small segment algebra** (1366-1408). Field vs field, case vs case and fixed index vs fixed index are disjoint only when different; anything involving a symbolic index may overlap.
- **Static-source recursion** (1670-1789). Structural recursion over expression kinds and callee states, with a `resolving`/`visiting` list so a cycle answers "not static".
- **Declaration frontier deferral** (258-452). Classifies each signature as complete, template-dependent or incomplete; template-dependent ones are put on a `deferred` list and their call sites are checked instead.
- **Pairwise leaf judgment** (2043-2174, 5434-5469). Quadratic comparison of all leaves formed at one statement, or all held leaves of one call statement; no budget. Premises (stated orderings from contracts) are collected lazily once per statement (2064-2075).
- **Caller index** (2471-2542). A table `Vec<Vec<IncomingCallerRoster>>` indexed by the target symbol's arena index, plus a similar table of "external" machines (roots, providers, conformance realizations, callback-selected machines).
- **Transitive discharge through callers** (2544-2749). A worklist of `Requirement {state, backing, storage}` with per-item ancestry. Each requirement is checked against every invocation of its state; a pair is either proved locally, or turned into a new requirement on the caller. A same-state different-requirement ancestor is an error (the relation changes round a recursive cycle). Afterwards a second fixpoint (2728-2739) marks a parent established when a child is, and any observed requirement left unestablished is an error. No budget; bounded by distinct requirements.
- **Occurrence replay** (3595-3643, 4256-4353, 4367-4472, 5261-5270). Uses `ownership_occurrences::statement_steps_at_evaluation` to get the ordered steps of one statement (Observe, Complete, Move) with a branch "route"; positions in that list decide what is live, and `routes_compatible` decides whether two steps can lie on one path.
- **Operand completion walk** (4696-4748). A visited-list graph walk over constructed children and selected alternatives of the statement's operands, to decide whether a whole-root read is a transferred view value.
- **Held-leaf collection** (5190-5341). Recursion over an operand's alternatives and children to list every reference leaf, with a fallback "mutable leaf with unknown place" whenever data is missing.

## Surprises

- **No proof kernel anywhere.** The only contact with the prover is a `call_guarantees::StateGuarantees` handle passed through to `overlap::append_statement_premises` (1937, 2050, 2066-2073) to gather stated ordering premises. Every verdict is this code's own comparison.
- **A saved obligation that is replayed, despite the header.** The header says results are "not certificates to serialize and replay" (9-10), but `incoming_backing::publish` stores `BorrowIncomingCompatibilityRequirement` rows in the checked facts (2799-2850) and `check_external_roots` re-validates and re-discharges them later per Build request on the finished `CheckedTrees` (2772-2797, 2852-2907). The replay is by the same code, not by a kernel.
- **An interprocedural, whole-program check.** `discharge` proves a callee's safety from every caller's actual arguments and climbs the call graph (2544-2749). A callee's acceptance therefore depends on who calls it, and any machine that is a root, provider, conformance realization or callback target fails the requirement outright (2574-2582) even if it also has ordinary callers.
- **Path-sensitive loan death.** `selected_retirement::before_target` (4956-5071) ends a loan on one taken transition edge under eight conditions and relies on lowering to "place that same checked release" (4903). `final_holds_in_statement` (4367-4472) ends loans at a position inside a statement. Both are finer than per-statement liveness.
- **Dead arm.** In `check_formed_leaves` the `Err(reason)` arm at 2099-2105 cannot run: any `Err` window was already reported and skipped at 2078-2088.
- **Debug print in the checker.** 771-775 writes `STRUCT stored-output machine=... state=...` to stderr when `validation::trace_flags::struct_trace()` is on, from inside the closure that decides `requires_relation`.
- **`unreachable!` whose message describes a different guard.** 1429-1435 says range and dynamic owner paths "are rejected before persistent propagation", but `owner_path_place_segments` (1534-1551) returns `None` for a dynamic index and the caller skips that leaf (1420-1422); nothing is rejected there.
- **Unestablished entry assumption.** 835-848 treats every borrow-carrying attached field as static on entry to the first state, by position, with no check in this slice. No comment explains it.
- **Three name helpers of unequal strictness.** `exact_name_symbol` takes the first local with a matching name when the symbol is invalid (1339-1344); `immutable_local_index_symbol` demands a unique immutable local (1659-1660); `immutable_state_index_symbol` checks uniqueness of matches on one symbol, which is always unique (1316-1320).
- **Statement index set to the state's statement count.** In the `Borrow` arm of `is_state_independent_borrow_source` the type of the borrow target is looked up at `state.statement_nodes.count()` (1690), not at the statement being checked.
- **Two ways to list a transition's exits in one module.** `state_transition_edges` uses `transition.targets()` (914); `state_returns_only_static_borrows` uses only `[transition.target, transition.continuation]` (1764). If `targets()` yields more than those two, the static-return check misses exits. Cannot tell from this slice.
- **Binary expressions as borrow sources.** 1696-1699 accepts a binary expression as a static borrow source; the slice does not say which operator yields a borrow.
- **String-path overlap for invalidation.** Static facts about typed segment paths are converted to text to be compared with a callee's may-write strings (1464-1532). A `Case` segment or an unnamed field truncates the rendered path (1492, 1520), which widens the overlap test, so this errs toward invalidating.
- **Facts are keyed to statements and owner places, not values.** Loans are found by `statement_index`, `owner_symbol`, `storage_owner` and `owner_path` (1946, 2193-2197, 3634, 4127-4131), and several authors' notes exist to say that a matching root or type is not enough (3980-3983, 3551-3552). Linear scans by statement index recur (3584, 3725, 3730, 4587).
- **One conflict per statement.** `staged_values::conflicts::check` returns after its first diagnostic (5431, 5467); `check_view_return_escape` reports once per root (529, 595).
- **Unknown completion treated as position 0.** `HeldLeaf::mutable` and `append` use `route.unwrap_or(0)` (5180, 5270), so a leaf with no unique completion is held from the start of the statement.
