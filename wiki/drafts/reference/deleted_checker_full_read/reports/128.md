## What this code is for
This module decides where a reference that a state or called machine returns comes from. A machine that returns a reference (or a record holding references) must say which input parameter, or which fresh storage formed during the call, the reference points into. The code works out a set of "origin" records for each returned reference leaf (`CheckedReturnedReferencePlan`) and checks they agree with the borrow facts (`returned_loans`, `incoming_references`) recorded earlier by other passes. It does this through calls: the origin of a result of a called machine is expressed in terms of that machine's own parameters, and is then rewritten in terms of the caller's actual arguments (`invocation_return_sources`, `argument_return_sources`, `invocation_argument_sources_with_inputs`). Mutual recursion between states is handled by a worklist fixed point (`relations::complete`) that also demands every recursive return have a non-recursive value that completes it ("productive"). It also contains the stored-carrier walk (`stored_carrier_sources`) that finds what a structural value contains and the reception check (`record_call_reception`) that a local record receiving a call result holds the loans that call formed. Almost every failure is `None`; the readable reasons are `&'static str` values that are only printed when a trace flag is set (`crate::trace_flags::check_sites()`), so this code produces no user-facing diagnostic itself. It consumes `CheckFacts` (flow/borrow/values tables) and typed trees through `crate::CheckingInput`.

## Mechanisms
- **Structural value walk** (`select`, rrc:67-349): recursive descent with an `active` stack for cycle detection; outputs a list of `StoredCarrierSource` (Place/Image/Borrow/Call). No numeric budget except cycle refusal. Serves reference-carrying records, slices, byte literals, fixed arrays, and cases.
- **AND/OR coverage graph** (`ReturnCoverage`, rrc:827-1027): nodes are `Call(state)`, `All`, `Any`; built from flow operand facts by `Builder` with memo tables (`values`, `prefixes`, a `None` marker for in-progress items acting as cycle refusal, rrc:940, 957). `established(returning)` evaluates nodes in index order (children pushed before parents). Serves "does this return value actually get built on every path" for recursive machines.
- **Memoized call roster** (`CompletionCalls`, rrc:592-684): lazily filled maps keyed by `(arena_index, generation)` in `BTreeMap`; ambiguity (two calls at one site) recorded as `None` rather than picking one.
- **Depth-limited descriptor and argument recursions** (`completed_descriptor_sources`, `argument_return_sources`): `active`/`visiting` stacks plus `MAX_REFERENCE_ORIGIN_DEPTH` and `MAX_REFERENCE_ORIGIN_LEAVES` caps (values defined outside the slice). Serves references stored in structures and passed through calls.
- **Worklist fixed point over return equations** (`relations::complete`, rrc:3723-3973): rows per state, sorted by `(arena_index, generation)`; each round re-evaluates pending states with the current approximations (`approximation` returns an empty list for unknown states and records the dependency); sources, dependencies, completions only grow (monotone check refuses otherwise); callers are re-queued when a row changes; new dependency edges trigger a strongly connected component pass (`machine_calls::graph_components::strongly_connected_components`) and cyclic components must stay inside precomputed `candidates`; productivity is a least fixed point of the coverage graphs. No explicit iteration cap; termination rests on monotone growth plus the leaf cap. Serves recursive and mutually recursive machines returning references.
- **Origin composition** (`checked_input_origin`, `invocation_argument_sources_with_inputs`, `invocation_return_sources`): substitutes callee-parameter-relative origins by caller argument origins, composing `presentation` paths (`RepresentationView`, `Referent`, `Element`) and an extent (`Projected` vs `WithinRegion`, where WithinRegion wins on merge).

## Surprises
- The `Case` arm of `select` returns None when the requested case equals the live case (rrc:330-332: `selected == requested || !...any(...)` returns None). Reading it literally, selecting a payload of the live `Case` value is refused and selecting a non-live one is accepted with no source, the reverse of what the record-pattern arm does (rrc:265-269 for the same non-live situation also accepts with no source). No comment explains the asymmetry.
- AGENTS.md's dense-ID rule (flat tables, no `BTreeMap` for dense ids) is not followed here: `CompletionCalls` uses `BTreeMap<(u32,u32), ...>` (rrc:573-578, 592-596) and `Builder` memo maps (rrc:908-909). These key on handle arena index and generation.
- The fixed point loop (`relations::complete`) has no iteration limit; termination relies on sources only growing and the caps `MAX_REFERENCE_ORIGIN_LEAVES` on single evaluations. A row's `sources` can still grow by `row.sources.push` across rounds without a total cap (rrc:3801-3806).
- `recursive` states are only compared to `candidates` computed from the facts' returned loans (rrc:3991-4059); the equation values come from `captures.returned`. The two computations must agree, and disagreement refuses ("recursive source is outside its captured frontier").
- The name `language_core::ReferenceAccess` (rrc:133-134) and `language_semantics::ReferenceAccess` (rrc:18, 1241) are both used for what appears to be the same enum in different crates.
- The module is deeply nested (`captured_returns` encloses `completion_calls`, `completions`, `descriptor_sources`, `family_returns`, `incoming_origins`, `input_views`, `invocation_inputs`, `invocation_returns`, `loaded_origins`, `presence`, `relations`) and reaches up with `super::super::` throughout (for example rrc:1226, 1537, 1778, 2013).
- `completed_descriptor_sources` constructs and then discards possible leaf state: `let _actual` (rrc:1752) is unused, and `let selected = operand;` (rrc:2847) merely aliases.
- Most refusals are `Option::None` with the reason sent only to stderr when a trace flag is on; the reason strings in `Result<_, &'static str>` are converted away at `.ok()` (rrc:2411, 3062). A caller sees no reason.
- `StoredCarrierSource::Image` carries no source place; images are treated as always supplied by something outside the call (rrc:3354-3355: Borrow is `true`, Image is `false` for "present"). Image storage is therefore never considered a present reference leaf.
- `select`'s `ViewSubslice` arm pushes one `Image` per image supplier, so a view over several image suppliers yields duplicate `Image { value }` entries (rrc:110-113); harmless if the consumer dedupes, but no dedupe is in this file.
- `fields.nth(1)` (rrc:165) means the "region" field of a native-layout data type is the second declared field, independent of its name beyond the identity compare.
