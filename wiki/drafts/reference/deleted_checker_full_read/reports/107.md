## What this code is for

This slice is four sub-modules of the "structural judge", the old checker's own reasoner that answers Proven / Refuted / Unknown about contract facts by rewriting terms (`StructuralTerm`).

1. `returned_fields` (ce:69678-70059) works out, for a callee with a body, which scalar fields of the returned data value always equal an expression over the callee's inputs, so a caller can use `result.field == f(args)` without the callee declaring it.
2. `runtime_induction` (ce:70060-70160) records which recursive calls may use the induction hypothesis, taken from the termination checker's rank plan.
3. `selected_contracts` (ce:70161-72977) is the call-contract machinery: it decides whether a callee's `requires` facts hold at a call (`selected_requirement_judgment`), translates contract expressions into terms under the call's argument bindings (`bound_contract_term`), and turns the callee's `ensures` facts into equations, data identities and conditional guarantees for the caller (`capture_guarantees`).
4. `storage_effects` (ce:72978-77437) tracks what the judge knows about values held in storage (parameters, locals, fields, array slots, things behind references): it keeps "entry" and "current" observations per storage coordinate, ties each one to a version of the storage graph, drops them when writes happen, and moves them across call entry and return.

The slice also holds a hash-indexed container for those observations (`StoredValues`, ce:75692-76024) and a size-limited debug trace printer (`call_consumer_trace`, ce:76212-76478). Nothing in the slice emits a user diagnostic directly; refusals are `None`, `StructuralJudgment::Unknown`, or a `&'static str` reason handed back to a caller outside the slice.

## Mechanisms

- **Returned-field template with memo and cycle tracking** (ce:69700-69937). Computes, per callee, a list of (field path, input-only term). It builds a fresh judge from the callee's `requires` (ce:69828-69833), runs `recognize_structural_case_arms` over all normal returns, projects every leaf to each scalar field and keeps a field only if all leaves agree. A stack of owners (`returned_field_owners`) stops recursion. A shared `ReturnedFieldTrace` records the shallowest stack index a cycle touched and every callee visited; the template is cached in `memos.returned_field_projections` under the callee symbol only when no cycle reached below this frame (ce:69803-69827), and a cached template is reused only when none of its visited callees is on the current stack (ce:69765-69796). Serves: call results of data type.
- **Contract term binding** (`bound_contract_term`, ce:71084-71570). Recursive translation of a contract expression into a `StructuralTerm` under (symbol → term) bindings, type bindings and an optional result term; depth limit 64. It consults the judge while translating (case membership, `and`/`or` short-circuit), so the same expression can translate differently in different judge states. Serves: `requires`/`ensures` instantiation at calls.
- **Guarantee capture with path conditions** (`capture_guarantees`, ce:72637-72976; `capture_match_guarantees`, ce:70737-70858). Walks an `ensures` expression; unconditional results go to `equations` / `data_identities`, results that hold only under a condition go to `ConditionalGuarantees { conditions, equations }`. To analyse a branch it clones the whole judge and assumes the branch condition in the clone (ce:70718, 70771, 70793, 72830). A caller can pass `ConditionalGuaranteeUse::Discarded` to skip that work (ce:71701-71709, 72008). Depth limit 64.
- **Target-family intersection** (ce:70401-70470). Guarantees for an interface are the set intersection over members, comparing equations in either orientation.
- **Constant-boolean body walk** (`recorded_body_boolean`, ce:72013-72191). Worklist over states and callees with a visited list; reads each state's statements in `finite_execution_order`, tracks immutable Bool locals whose initializer is a literal, call or member read, follows named transition targets and tail calls, and requires all exits to agree. Depth limit 32; `followed_exit` follows at most 32 local aliases (ce:71599).
- **Selected-application carrier memo** (ce:71788-71927). Verdict cached in `memos.selected_application_carriers` under (calling machine, target, result type, argument count).
- **Normal-form rewrite by callee equations** (ce:71755-71786). Collects application sub-terms, derives their guarantee equations, and replaces the whole value by the other side of an equation if that side does not contain the value.
- **Runtime induction table** (ce:70071-70158). A flat list of (state, call expression, callee entry) filtered from the rank plan; lookup is a linear `contains`.
- **Versioned storage observations** (ce:73928-74616, 76183-76193). Each observation has a coordinate (root + segments, where a dynamic index segment is the term of the index value), an `entry` term, a `current` term, anchors (`Incoming`, `Store(expr)`, `After(snapshot)`, `CallReturn`) and the state it was anchored in. Validity at a `StorageVersion` (state + snapshot handle) is decided by asking the storage graph (`completed_storage::at_snapshot`, `sources_at_snapshot`, `contents_preserved_from`). `CallReturn` anchors are rewritten to `After(new snapshot)` on the next version advance (ce:74243-74258). Without a graph, a write counter and wholesale retirement stand in (ce:76866-76874).
- **Address-chain check** (ce:74682-74770). Walks an operand's backing chain, at most `graph.operands.len()` steps, comparing path segments and normalized type identities and checking reference bindings are preserved.
- **Call entry/exit storage transfer** (ce:76607-76757, 73012-73135). On entry, observations under each argument's source coordinate are re-rooted at the callee parameter; on return, callee observations are re-rooted back with a `CallReturn` anchor.
- **`StoredValues` index** (ce:75692-75888). Vec of `Arc<CapturedStorageValue>` plus a `HashMap<u64, u32>` from a mixed hash of the coordinate to the last position with that hash, and a `previous_with_key` chain. `position` returns the oldest equal coordinate; removal rebuilds the index.
- **Bounded trace** (ce:76212-76357). At most 16 observations per process (global atomic counter, ce:76230), 32 rows per section, 4,096 characters per record.

## Accepts or skips without proof

- **Unproven `requires` falls back to a constant result.** When a `requires` fact is not Proven, `prepare_declared_entry` returns `recorded_body_boolean(owner)` as `EntryEvidence::UnconditionalBoolean` (ce:70386-70395), and the caller then gets `result == literal` (ce:70421-70426). That walk counts an exit that returns a parameter field listed in the callee's `requires` as `true` (ce:71628-71672, 72152-72157), a value that is true only when the `requires` holds. I cannot see in this slice whether the call site's own requirement check refuses such a call first.
- **Projection-premise exits ignore writes.** `projection_premise_exit` compares the exit's term with the `requires` fact's term by shape only (ce:71643-71671); it does not check that the parameter is immutable or that the field was not written earlier in the body. Cannot tell whether another check covers it.
- **Declared type trusted for domain membership.** `admitted_value_has_membership` proves `x in D` from `declared_type_domain_rows` of a parameter's or call result's declared type (ce:72259-72295, 72343-72387). The membership is taken from the type declaration; nothing here re-checks the value.
- **Declared type trusted for data predicates.** `retain_entry_scalar_fields` calls `intake_admitted_value_predicates(reference, subject)` for an entry parameter once all its fields are observed (ce:73520-73545), so the type's `requires` invariants are assumed for inputs.
- **Two observations of one coordinate are equated by assumption.** `assume_completed_value_equation(previous, value)` at ce:73680-73689 (entry snapshots; guarded by "no write yet") and ce:75077-75107 (post-call; guarded by the current value being valid at the version).
- **No storage graph means "still valid".** `current_value_valid` returns `true` without a graph (ce:74431-74433); `graph_place_observation_invalidated` returns `false` without a graph or version, or with an invalid snapshot (ce:74326-74335); `storage_value_transfer_is_current` accepts when there is no version and no graph (ce:76764-76767); `current_storage_value_at` treats every stored value as valid outside graph mode (ce:77285-77288). The non-graph path relies on `retire_unversioned_storage` having run on every write (ce:76866-76874).
- **Unresolved place read as "incoming".** `read_anchor` maps `None` from `at_snapshot` to `StorageAnchor::Incoming` (ce:74413-74415) and `current_value_valid` maps `None` to `Incoming` (ce:74497-74500, 74594-74596). The comment at ce:74350-74353 says that for `sources_at_snapshot` a `None` means "the graph cannot resolve this place" and must invalidate. These are two different query functions; I cannot tell whether `at_snapshot`'s `None` means the same thing.
- **`Unavailable` reaching source accepted** if any `After` anchor is preserved (ce:74600-74603).
- **Empty write set skips effects**: `written.is_some_and(is_empty)` returns before the write sequence is bumped (ce:76857-76860).
- **Name is always an ordinary storage path** (ce:76997); no check on what the name refers to. Later steps (`canonical_place_from_expression`, parameter lookup) narrow it in most callers.
- **Any non-parameter symbol becomes a `BoundValue`** in contract terms (ce:71194-71202) with no check on its kind beyond "not a parameter or type parameter". Cannot tell what limits it.
- **Cast with unknown source type**: the denotation-preservation test runs only when the source type lookup succeeds (ce:71460-71466); with `None` the code proceeds to `conversion_term(program, cast, source, value)` (ce:71477). Cannot tell whether `conversion_term` refuses.

## Surprises

1. **A failed precondition can still yield a result fact.** `EntryEvidence::UnconditionalBoolean` is chosen exactly when a `requires` fact was not Proven (ce:70386-70395), yet the walk that produces it counts "returns a parameter field named in `requires`" as `true` (ce:72152-72157). The name says unconditional; that exit is conditional on the precondition that just failed. The same walk does not look at writes or mutability for that field (ce:71628-71672).
2. **The constant-boolean walk is a second, syntactic body analysis** living in the contract module (ce:72013-72191). It ignores guards and reachability and demands every exit agree, follows tail calls into other machines and family members, and returns `None` on a `Terminal` target. It gives the caller `result == true/false` for callees with no `ensures` at all (ce:71960-71966, 70574-70585).
3. **Translation depends on the judge's current knowledge.** `bound_contract_term` asks `judge_case` and `judge_observed_predicate` while translating (ce:71498, 71522), and returns `None` for an undecided case test (ce:71504). The same contract expression therefore becomes a different term, or no term, depending on what the judge knows at that moment.
4. **Judgments can depend on caches.** The trace code is told not to run queries "whose cache could change the observed judgment" (ce:76481-76482). The slice writes two process-wide memo tables, `returned_field_projections` (ce:69820-69826) and `selected_application_carriers` (ce:71817-71821), and bumps a per-judge `capture_sequence` to mint fresh opaque values (ce:73601, 74935).
5. **Two storage regimes with opposite defaults.** With a storage graph, validity is asked per read. Without one, everything stored is valid until a write wipes it (ce:74431-74433, 77285-77288, 76866-76874). The two paths share call sites, so the same query can be precise or wholesale depending on whether `storage_version` is set.
6. **`None` means "incoming" in one query and "unresolved, invalidate" in another** (ce:74413-74415 and 74594-74596 against ce:74350-74361). See "Accepts or skips".
7. **`retire_unversioned_storage` names its loop variable `earlier` but iterates every state of the machine** (ce:76952-76962), then repeats the current state's parameters and locals (ce:76973-76980), which the first loop already covered when the state belongs to that machine.
8. **Depth budget reset** at ce:72904 and ce:72916 (literal `0` where every other call passes `depth + 1`).
9. **Float index selectors all share one hash key** by design; a test pins it (ce:75949-75952). Lookups stay correct but degrade to a chain walk for float-indexed coordinates.
10. **Duplicate coordinates are allowed in `StoredValues`** and `value_at` / `value_at_mut` always address the oldest (ce:75716-75727, tests ce:75965-75987), while `values_at` yields all. Writers that update through `value_at_mut` never touch a later duplicate.
11. **A sizeable part of the slice is debug tracing**: `call_consumer_trace` and its callers are about 390 lines (ce:76212-76605), with five tests of exact trace strings and a process-global counter (ce:76230), plus 17 `struct_trace()` blocks elsewhere in the slice.
12. **Capabilities not obviously expected in a contract-entailment file**: induction-hypothesis bookkeeping for recursive calls (ce:70060-70160); inferring field equations a callee never declared (ce:69700-69937); a hook for content-conservation guarantees on call results (ce:70586-70600); re-reading scalars through reference recasts with bit-level representation normalisation (ce:73212-73221, 75453-75464).
13. **Property 3 shows up differently here.** The per-case copies are split by where a value came from (by-value argument, reference argument, call result, completed operand, return, entry parameter) and by expression kind, not by local/field/parameter placement. Storage places themselves are handled uniformly as root + segments.
14. **Whole-judge clones are the branching mechanism** (ce:70718, 70771, 70793, 72830, 76704). `leave_storage_scope` clones the caller's judge, applies the write effects to the clone, then copies five fields back (ce:76750-76755).
