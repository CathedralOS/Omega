## What this code is for

`flow_transfers.rs` is the module `flow::transfers` of the old checker (the crate's source was flattened to one file per module path, lib.rs:17-21). It runs once per `let` or assignment statement and decides which facts known about the written value are copied onto the place that was written (flow_transfers.rs:1-19). Because the old checker keyed every fact by a storage place (a root symbol or expression plus a path of field, case and index segments), a statement that moves a value has to re-create each fact under the destination's path; this file is that re-creation. It has seven lanes: facts at the source place itself (`context_transport`), domain memberships and float predicates at or below a moved owner (`owned_qualifications`), value facts below a copied place (`projected`), facts for each field of a constructor (`constructed`), byte-class facts for string concatenation, subslices and single-byte stores (`byte_sequences`), the exact scalar value or integer range written (`scalar_values`), and memberships granted by the destination's declared type (`declared_domains`), plus `replacement`, which keeps old memberships when one element of a collection is overwritten. `scalar_values` contains a small symbolic interpreter that walks a called machine's state graph to learn the value a call returns. The file issues no diagnostics: a rule that fails means a fact is not published, and some later consumer then fails to find it.

`lib.rs` is the crate root: module list, re-exports and three comments describing the stage. `immutable_checking_input.rs` is one test that searches source text for forbidden strings to keep the checker from mutating the typed program. `products.rs` holds three things reached after checking: thin `package_review` wrappers that re-derive facts, `product_pruning` (delete machines unreachable from chosen roots and compute a SHA-256 identity of the selection), and `quotient_eligibility` (refuse a quotient operation whose representative or theorem machines may crash).

## Mechanisms

- **Symbolic walk of a callee's state graph** (`normal_returns`, flow_transfers.rs:2025-2513). It computes the value a call returns on normal return, generic over a `CapturedValue` domain with two implementations: exact `ScalarValue` (2892-2973) and `IntegerRange` (2975-3095). It walks statements in order, keeping immutable bindings by ordinal and mutable scalars by symbol (`CallValues`, 3891-3895), follows transitions and nested returned calls, and joins arms. Limits: primitive scalars only; no receiver, machine arguments, static machine parameters, evidence arguments or owned data; a state already on the `visiting` stack returns `None` (2106-2108), so any loop withholds the capture (comment 2033-2034: "A cycle requiring induction ... withholds the whole capture"). There is no memo table and no step budget; an unknown guard explores both arms (2156-2186), so a state reached along several paths is re-walked each time. Serves value and range facts for `let x = f(...)` and `x = f(...)`.
- **Two-domain join** (2057-2066, 2943-2945, 3038-3043): exact values join only when equal; ranges join to their hull. "No normal value" (a crash arm) is the join identity.
- **Cast-chain classification** (`conversions`, 3134-3350): peels non-recast, domain-free casts around a call or operand, then classifies each against the running carrier as same-carrier or total widening; anything partial yields no conversion list. Range conversion checks containment in the target carrier (3091-3094).
- **Prefix rebasing of place paths**: a fact at `source ++ suffix` is re-created at `destination ++ suffix`. Written in `constructed` (657-663), `owned_qualifications` (1359-1365), `projected` (1735-1741) and `declared_domains` (1092-1095).
- **Byte-class algebra** (43-539): uses `ByteSequencePredicate::{ALL, implies, holds_for, is_subslice_preserving}` from `validation::field_domains`. "Per-byte class" is encoded as `is_subslice_preserving()` (341). Concatenation and subslice proofs recurse over the expression (114-166).
- **Grouping published facts into contexts** (4444-4517): hashes (place bucket hash, is-case-tag, domain identity) with `std::collections::hash_map::DefaultHasher`, groups equal positions with `PlaceBucketIndex::group_equal_positions`, and appends one context per group to the active contexts and constraints.
- **Structural place validation against declared types** (4641-4772): walks a place's segments through declared data types, variants and fixed arrays.
- **Reachability closure for product pruning** (products.rs:1138-1182): a worklist over `HashMap<SymbolHandle, Vec<SymbolHandle>>` edges collected from about ten fact tables and a typed-reference visitor (439-518). No budget needed; terminates on the finite machine set.
- **Selection identity** (products.rs:1236-1254): domain-separated SHA-256 (`omega.psi.checked-tree-product-selection.v1\0`) over counts and the arena index and generation of each root, retained and pruned symbol.
- **Machine-keyed table rewrite** (products.rs:639-921): one `retain` per fact family.

## Identity by text

- flow_transfers.rs has no comparison against a string literal, no rendered label and no joined path. Places are a root handle plus typed segments; domains are a `SymbolHandle` plus `SemanticDomainId`; types compare by `normalized_type_identity` (4816-4820). This file is evidence against property 2.
- The only name read in flow_transfers.rs: `program.semantic_domains.name(semantic_domain).is_some()` (4619) tests that a name exists; the name is not compared.
- What stands in for text in flow_transfers.rs is identity by authored coordinate: `PlaceRoot::Expression(source)` (1236, 3531), fact-to-statement matching by expression handle equality (915, 925, 2499, 2655, 3723, 3866), and (state symbol, statement ordinal, role, argument ordinal) keys (2487-2512, 2649-2651, 3721-3739). Two textually identical expressions are different identities; one value reached through two expressions has two identities.
- immutable_checking_input.rs decides everything by text: `include_str!` and `read_to_string` followed by `contains` on literals such as `"&mut program"`, `"mod preparation;"`, `"thread_local!"`, `"RefCell"`, `"GenericContracts"`, `"structural_fingerprint"`, `"ProgramKey"` (11-128); it selects four stage-04 files by file name (84-90) and excludes itself by file name (79).
- products.rs: the quotient diagnostic renders `program.symbols.display_path(operation.public_machine, "::")` (1275), for display only. The pruning-root diagnostic prints a symbol's arena index, not its name (1129-1130). The comment at 33-38 says the late-bound member query exists to avoid matching "every same-spelled member in the program".
- products.rs selection identity hashes symbol arena indexes and generations (1243-1249), not names.

## Accepts or skips without proof

- **Membership from a declaration** (flow_transfers.rs:1030-1062, 1076-1104): a write to a place whose declared type names a domain records membership, with evidence `checked_validation_evidence(state_symbol)` (1044), without examining the written value. Only domains that require provenance are excluded (1032, 1088). Whether another module checked the value against the domain predicate before this runs: cannot tell from this slice.
- **Candidate memberships re-issued** (1162-1193): kept when live before the write, on the premise that the written value is in the declared domain; same dependency as above.
- **Membership transport ignores destination stability** (865-892): value payloads need `stable_value_target` and agreeing carriers (828-857); memberships, carry permission and carry origin need neither, so they are published on a destination that may still contain a runtime index. Cannot tell whether a consumer rejects such places.
- **Constructed-field copy** (700-741): copies `AssignedValue` without the literal test that `projected` applies (1646) and without `completed_value_carriers_agree` for facts at the child's own place. `projected::append_copied_field_predicates` (742-744) does apply both below the child. Cannot tell whether this matters.
- **Assigned value from any call** (4365-4382): every stable destination written from a call expression gets `AssignedValue{value: call}`. The comment at 1201-1202 says "Call facts remain provisional until the call/custody checker validates their exact producing invocation"; that checker is outside this slice.
- **Exact-result bypass** (1236-1247): when the source place is the written expression's own result, the builtin-coordinates test is skipped.
- **Null semantic-domain identity counts as a match** (536): `!semantic_domain.is_valid() || semantic_domain == domain.semantic_id`. `append_derived_predicates` itself publishes memberships with `SemanticDomainId::NULL` and an empty domain span (103-108). Other lanes treat a null identity as disqualifying (1294-1298, 1953).
- **Derived byte memberships for every domain in the program** (83-111): the destination's declared type is not consulted; the value becomes a member of every unrouted, index-free, non-alias domain whose predicate it proves.
- **Endpoint-only class test** (321-322): for a stored byte known only as a range, the class is tested on `[minimum, maximum]` alone. This is sound only if each per-byte class is an interval of byte values; the class definitions are outside this slice.
- **Element type not tested** (242-265): the one-element store rule checks that the target is an indexed node and the carrier path is fixed, not that the element is a byte. Cannot tell whether the caller guarantees it.
- **Range fallback to the declared carrier** (2674-2676, 2686, 3045-3051): an argument with no snapshot is given the full range of the formal's primitive type. This trusts the declared type; it is an over-approximation, not a narrowing.
- **Unit call inside a callee** (3839-3842): values are kept across it if `call_storage_writes(...).observation_places` is empty; trusts that module's footprint.
- **Correspondence silently omitted** (4540-4595): any failed exactness test returns without recording, after the fact itself was already published (937-948).
- **Early returns that drop everything** (4110-4112, 4135-4145): a non-current destination or unselected source case publishes no facts at all, including declared-domain membership. This skips towards refusal.

## Surprises

- **The file states no rule a user would recognize.** flow_transfers.rs has no `Diagnostic` and no proof-kernel call in 4,833 lines. Its whole output is fact rows tagged with a `QualificationEvidence` origin label. Acceptance here is the code choosing to append a row (supports property 1).
- **Sibling comments contradict `declared_domains`.** Three modules say declarations create no facts (543-547, 1199-1200, 1837-1838), while `declared_domains::establish` creates membership facts from the declared type alone and labels them "checked validation" (1030-1062, 1044). The statement in 1200 is true of its own module only.
- **Receiver calls are prepared and then refused.** `capture_call` computes and validates the receiver place (2544-2557) and passes its root to `exact_call_occurrence` (2558-2570), then returns `None` for any receiver (2587-2589). `CallValues.fields` is created empty at all three construction sites (2343, 2449, 2696) and never filled, so both `structural_field` readers (3109-3120, 3909-3921) always return `None`, contrary to the comment at 3888-3889. Receiver-call capture is dead code in this slice.
- **A failed cast classification reads as "no call".** `selected_call` returns `None` both when the source is not a call and when a cast around the call is partial or the callee is not primitive (3330-3332). `capture_statement` treats `None` as "no call selected" and continues to later routes (3426-3483). The comment at 3139-3141 says a partial conversion "fails the capture". Whether a later route can produce a value for a cast-wrapped call: cannot tell.
- **`selected_call` resolves the callee differently.** It uses `program.state_by_symbol(call.target_symbol)` (3330); every other site uses `validation::call_target_entry_symbol(program, validation::call_target_symbol(program, call))` (2424-2427, 2571-2574, 2749-2752).
- **Correspondence is never recorded for a `let`.** `correspondence_root_type_reference` accepts a local only if `ordinal < formation_statement_index` (4767), and the destination of a `let` is declared at the formation statement itself. So `retain_qualification_correspondence` can succeed only for assignments to earlier locals or parameters. This is either intended or an off-by-one; the slice does not say.
- **Lanes read different snapshots.** `context_transport` and `projected` read `active_contexts` (4117, 4306, 4333); `owned_qualifications`, `constructed`, `byte_sequences`, `replacement`, `declared_domains` and the scalar capture read `assignment_source_contexts` (4157, 4189, 4208, 4289, 4347, 4357, 4419). The slice does not state why they differ.
- **No budget on the callee walk.** The only guard is the `visiting` stack (2106-2112). Unknown guards fork without memoization, so the walk can be exponential in the number of undecided guards; it runs once per call-valued `let`/assignment, and twice when the exact capture fails and `capture_bounds` repeats it (4159-4173).
- **A variable named `before` holds the next statement.** `state_statements(...).get(statement_index + 1)?` (1798-1799) is passed to `sole_local_referent_origin`; a reference bound by the last statement of a state therefore gets no referent evidence.
- **`contextual_expression_place` discards its machine argument** (4794), and an orphaned comment block describing `selected_operand` sits above a different function (3207-3213).
- **An assignment's call arguments use the role `UnitCallArgument`** (2641-2645), a name that elsewhere means the argument of a Unit call statement (3869-3872).
- **products.rs: the roots constructor sorts** (977) although its comment says duplicates are "rejected rather than canonicalized so the selection identity never differs from the coordinator's input" (969-971).
- **products.rs: selection identity is built from handles** (1243-1249) while the comments promise an "independently reproducible" record (228-231) and say of the neighbouring review seams that "handles and private coordinates never enter review identity" (12-13). It is reproducible only if symbol arena numbering is.
- **products.rs: four arenas are rebuilt, the comment names two.** The comment lists `flow.control.states` and `service_reaches.machines` as the roster arenas no handle points into (266-269); the code also rebuilds `qualifications.content.body_transformations` (718-728) and `operators.provider_requirements` (786-800), renumbering their handles, and frees rows in `provider_instance_publication.requirements` (752-770). Whether handles elsewhere point into them: cannot tell.
- **products.rs: pruning edits a flag on rows it keeps.** `is_generic_template &= retained_template(origin)` (780-785) clears the template flag on operator uses whose origin machine was pruned or has no machine. The slice does not say what a cleared flag makes later stages do.
- **products.rs: `retain_live_family_members` looks unreachable in effect.** Every family member is added to `retained` before the closure (1157-1163), so the later filter (1216-1233) can only remove a member that is not a declared machine.
- **products.rs: vestigial code** `.into_iter().map(|state| ((), state))` followed by `for (_, state)` (1361-1367).
- **The architecture guard is a text search.** `immutable_checking_input.rs` enforces "checking does not mutate typed trees" by substring; it reads sibling crates' source files from disk at test time (64-120) and a rename or different spacing would pass it.
- **Against property 2, with a twist.** flow_transfers.rs never identifies anything by text, but it identifies values by where they were written: a fact's subject is an authored expression node or a storage path, and most of the file is the bookkeeping needed to say that the same value now sits at another path.
