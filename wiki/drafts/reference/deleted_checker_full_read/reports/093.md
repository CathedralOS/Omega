## What this code is for
This slice computes "write frames": for a call, an expression or a statement, the set of caller storage places that the operation may write. A write frame is a `Vec<String>` of place paths such as `self.items[*]` or `a.b`, wrapped in `NormalizedWriteFrame::complete(paths)`, or `NormalizedWriteFrame::opaque()` when the code cannot tell (calls.rs:16270, 16587, 16630). Other checks (borrow, fact invalidation, ownership) consume these frames. The slice contains (a) the end of the `CallFrames` facade that forwards to many sibling modules (15136-16940), (b) the write-path collection for calls and expressions (16942-17318), (c) a small constant-propagation helper `FrameInference`/`ParameterValues`/`BoolTruth` (17320-17956), (d) a "caller isolated type" analysis that decides whether a type can carry a caller reference (18054-18611), (e) alias and origin tracing for references passed through parameters, locals and call results (18613-19660, 21683-22329), (f) instantiation of a callee's relative written path into the caller's paths, including aggregate arguments (19661-20473), and (g) place-path and source-place data types, recast (reference view) coordinate translation, and the text rendering of places (20475-21681). Almost every function returns `Option`, and `None` means "refuse / unknown". There are no user-facing diagnostics in this slice; refusals are `None`, `opaque`, or `&'static str` reasons.

## Mechanisms
- **Frame composition with explicit unknown.** `may_write_frame` (16147), `expression_write_frame_uncached` (16590), `statement_expression_roots_write_frame` (16705), `operation_write_frame` (16505), `signature_invocation_write_frame` (16347). Each walks expression children first (`collect_expression_call_written_paths` 16969-17013, post-order) then adds the node's own writes (`collect_operation_written_paths` 17016). Any child returning `None` makes the whole frame `opaque`. Results are closed through "origins" (`prefix.close_paths`, `close_observed_paths`) that map callee/local alias names to caller roots. Caches: memo tables keyed by (machine symbol, address of statement node), (machine, expression handle), and a `Mutex` map for calls (16152-16158, 16274-16276). No explicit work budget is in this slice.
- **Three-valued constant propagation** (`ParameterValues`, `BoolTruth`, 17596-17942). Tracks only literal bool and fixed-integer actuals for parameters that are private scalars (`private_boolean` 17621-17634, `binding_is_exclusively_exposed`, `binding_has_write_effects`), and locals as statements finish (`finish_statement` 17757-17827). Serves index specialization in write paths and choosing branches. Comment 17846-17852 says an earlier version was cubic on long `&&` chains and `meaning_checked` avoids re-checking subtrees.
- **Type isolation analysis** (18265-18611): structural recursion over type references and data definitions, with a `visiting` stack for recursion, a bindings vector for generic substitution, `TypeIdentityMemo` per query, and a verdict cache keyed `(handle, proof_value, bindings)` stored in `IsolationVerdicts` fetched by `structural_fingerprint()` (18075). Serves deciding whether a by-value argument/local can carry a caller write.
- **Parameter-relative origin resolution** (19104-19659): recursive descent on expressions; for calls, resolves the callee (including requirement applications with several provider alternatives, 19415-19443), asks the callee's transparent result origins under `with_invocation` constant values (19537-19554), then substitutes the caller's actuals for the callee parameter roots (19572-19620). Union with de-dup (`push_unique_parameter_relative`).
- **Aggregate reference-leaf worklist** (`reference_leaves` 19965-20366): an explicit `pending` stack of (expression, expected type, remaining suffix, local suffix text, local segments, coarse flag, generic scope). Walks match arms, struct literals (fields plus variant payload), fixed arrays, and call results; produces reference leaves, case selections and moves. Serves writes through struct/array literal arguments and returned aggregates.
- **Recast chain translation** (`storage_coordinate` 20630-20751): iterates recasts in reverse, at each step recovering the predecessor carrier/path and translating the leaf (`recast_scalar_source_leaf`), accumulating `preserves_scalar_value`, `preserves_primitive_bits`, `replaces_place`. Serves writes through reinterpret views (`Access::view_mut`, byte views).
- **Source-place algebra** (`FrameSourcePlace` 20882-21177): `recast`, `append_segments`, `projected`, `append_source`, `append_relative` (with `erase_runtime_selector`), `substitute_source`. Serves rebasing a callee's symbolic place onto caller places.
- **Finite substitution check** 16007-16027 (details in `cycle_substitutions`, not in slice).

## Surprises
- Almost the entire slice is machinery whose output is path strings.
