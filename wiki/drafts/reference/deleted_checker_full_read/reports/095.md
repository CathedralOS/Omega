## What this code is for
This slice is the part of the old checker that tracks where reference values come from and what a call does to them, so the checker can refuse programs whose references would dangle, alias an exclusive reference, or outlive their storage. It keeps, for each local, a record of "stored origins" (`StoredLocalOrigins`: reference leaves with the place each reference points at, enum cases that are currently selected, and moved-out places). It updates those records when a statement runs: assignments (`assignments`, cals.rs:34884+), calls (`invocation_reference_effects`, calls.rs:34355), transitions (`prepare_normal_exits`, calls.rs:32265) and match/and/or joins (`expression_effects`, calls.rs:32207+). For calls it either walks the checked callee body (`state_effects`, called at calls.rs:34616) or builds the effect from the declared borrow contract of an opaque/boundary callee (`opaque_outputs`, `declared_outputs`, `dynamic_outputs`). It also decides whether a local's backing storage survives a jump to another state (`retention`, calls.rs:33938), where a destination address of an assignment lands (`captured_inputs::assignment_addresses`, calls.rs:30435), and whether a completed scalar read is backed by a known supplier (`value_reads`, calls.rs:31657). The type walker `type_origins::walk_declared_origins` (calls.rs:37621+) computes, from a declared type alone, which paths hold references, opaque regions, and enum cases. Almost every function returns `Option`/`Result<_, &'static str>` and answers `None` when it cannot finish, which the callers treat as refusal or as "unknown".

## Mechanisms
- **Slot-effect algebra** (calls.rs:33073-33210, 30283-30420). `SlotEffect` = (root, segments, kind, may_select, incoming, sources: `Option<Vec<SlotSource>>`). `accumulate` (33117) sequences effects; `join` (33161) merges alternatives (sources `None` if any alternative is `None`; `incoming = true` if an alternative lacks the slot); `apply` (30283) installs an effect on the stored records: covered descendant leaves are replaced or degraded to `origin = None`. `sources == None` means "unknown", and unknown makes descendants unknown (30310-30337). There is no fixpoint here; joins are one pass.
- **Expression walk with call-context graph** (calls.rs:32591-33058). One walker `Evaluation::expression/observe` evaluates a statement in source order, records `SlotArgumentCapture`s (context before each call), handles Match arms (cloning context per arm, `join(alternatives)`, stopping at the wildcard arm at 32879), short-circuit `And`/`Or` (32894-32976, skipping the right operand when the left is a static false/true), and builds `StoredReferenceCallContext` nodes (Entry, Invocation, Join, StatementCompletion) at 32503-32535. The same walker serves seven entry points (statement_effects, effects_at_expression, completed_value, assignment_destination, call_contexts, prepare_normal_exits) by switching `Capture` flags.
- **Recursion guard by active-state list** (calls.rs:32163-32174, 35648-35657). `inference.active_states` is pushed and popped around `summarize_complete_state_written_paths`; a state already active yields `None` (unknown writes).
- **Retention worklist** (calls.rs:34009-34083). A Vec used as a queue of `Arrival {machine, state, slots}` with a visited check by equality (`!pending.contains(&next)`, 34075) walks every reachable state from a jump, following ordinary transitions only, and checks at every exit that no destination leaf carries the backing local. No numeric budget; termination follows from the finite set of (machine, state, slots) values.
- **Reference resolution through stored slots** (calls.rs:36924-37111 `resolve_steps`, 36784-36878 `completed_reference_projection_reads`). Resolves a place through alias substitution then through the deepest stored reference leaf that the place reaches (`selected_depth`), repeating through a stack (`pending`) until a spatial origin is reached; cycle check by `(origin, crossed)` identity list (36831-36835).
- **Declared-type walk** (calls.rs:37534-37839). Explicit parent-indexed arena `TypeWalk.steps` (Vec of `WalkStep`) with an explicit stack instead of recursion; fixed arrays are expanded to one path per index via `paths()` (37597-37618), so a fixed array of length N yields N paths per leaf. Slices produce one `Index{default}` wildcard path. Scoped generic substitution through `DeclarationScopes`.
- **Storage projection cursor** (calls.rs:37173-37445). Walks a type along `PlaceSegment`s, checking field/case/index validity against the declared type; used for destination addresses, scalar reads and projected types.
- **Path prefix relations** (calls.rs:36440-36470, 37147-37162). `prefix_matches`, `path_covers`, `source_reaches_leaf` treat `Index` with an invalid expression handle as a wildcard that matches fixed or dynamic indices. Three slightly different matchers exist (they differ in which direction the wildcard is allowed).
- **Type-may-carry-selector closure** (calls.rs:33521-33607). Structural recursion over type reference nodes and data members with a `visiting` stack; used to decide whether a dynamic-trait selector could reach a caller.

## Accepts or skips without proof
- `may_replace = writes.as_ref().is_none_or(...)` (calls.rs:32175): unknown callee writes are assumed to replace (conservative, refuses more).
- `invalidates_descendants = effect.may_select && sources.is_none_or(...)` (30305-30309) and `incoming_unknown` (30343): unknown sources make descendants `origin = None` (conservative).
- `type_may_carry_selector`: invalid type reference returns `true` (33528-33530); `data_may_carry_selector`: data definition not found returns `true` (33580-33582); `visiting.contains` returns `false` (33577-33579, breaking recursion). Conservative except for the cycle case, which is sound as a fixpoint cut.
- `writes_may_replace_binding`: `writes` unknown => `true` (35567-35569); stored record with that name not found => `true` (35580-35585). Conservative.
- `target_replaces_*` with no binding source: returns "any stored local has cases/untracked refs" (35814-35816, 35879-35881). Conservative.
- `expression_exposes`: `!expression.is_valid()` returns `false` (35409-35411) so an invalid handle is treated as not exposing; cannot tell whether another check catches this.
- `Evaluation::expression`: invalid expression or `static_type_context_is_unreachable(expression)` returns `Some(())` (32800-32803), and unreachable match patterns/arm values are skipped (32834, 32847): the walker ignores code the typed program marks unreachable. It relies on that marking from an earlier stage; cannot tell here whether the marking is independently verified.
- `ExpressionNode::Match` loop stops at `MatchPattern::Wildcard` (32879-32881): later arms are not walked; relies on arm order being exhaustive.
- Calls with no parameter signature but a static call intrinsic (other than `BuildProviderSelection`) are treated as having complete empty effects (34459-34468): the intrinsic is trusted not to touch reference slots.
- asm intrinsics, `IntegerEmbed`, interrupt declarations that "preserve parameter descriptors", `call_preserves_reference_slots` and scalar accessors on primitive types all return empty effects (34369-34378, 34554-34562, 34441-34443, 35629-35643): trusted declarations, no check here.
- `caller_may_receive_selector` assumes any opaque machine or boundary trait whose signature may carry the interface could supply a selector (33469-33519); if false, the dynamic call is modeled by joining all registered realizations (34513-34518): relies on `collect_dynamic_implementation_selections` being complete.
- `prepare_normal_exits`: `TransitionTargetNode::Named { .. }` with no completed arrival returns `None` (32326): refusal, not acceptance.
- `check_exit` and `carries`: `origin.source.is_static()` => "does not carry" (34088-34090) without further check; `prefix_carries` ends with `carried |= slots.iter().any(|slot| slot.segments.is_empty())` (34121): a whole-value slot is always treated as carried (conservative).
- `assignment_origins` returns `Some(None)` (no stored change) when none of the "replaces" conditions hold (35002-35004): a plain scalar assignment does not touch origins; relies on `assignment_replaces_*` predicates being complete.
- `reference_leaves_with_projection` returns empty origins when the declared type of the projected place has no references, cases or moves (36126-36140): trusts the declared-type walk.
- `walk_declared_origins`: shared references are skipped unless `include_shared` (37673-37675); non-data named types become opaque regions (37733-37758). Opaque regions are modeled as written-through regions rather than refused.
- `retention::transferred_slots`: a parameter with no reference slots is skipped via `continue` (calls.rs:34211-34213): fine because no slot can carry.
- `ReferenceSource::Symbolic(_) => return None` (30977) refuses; `ReferenceSource::Symbolic` with static origin accepted without further check (30968-30976, 31964-31971).
- `project_stored_origins_with_sources`: `case_path_is_possible(...)?` returns `None` when no candidate case exists at all (36431) and `Some(false)` skips the leaf (36350-36352); leaves under impossible cases are dropped silently.

## Surprises
- The module is nested seven or more levels deep inside one file (`write_frames::stored_calls::{transfers, captured_inputs::destination_addresses, value_reads, case_generations, expression_effects, checked_alternatives, declared_outputs, dynamic_outputs, invocation_contract, opaque_outputs, retention}` and `write_frames::stored_origins::{assignments, frozen_bindings, projections, reference_values, storage_projection, type_origins}`), with `rustfmt`-skipped fragments with odd indentation (31558-31596, 34459-34473, 34489-34512, 35150-35176, 35192-35203, 37685-37708).
- The same model runs twice in parallel: structural `PlaceSegment` lists (by symbol handle) and string paths (`local_path`, `origin.path`) that are rebuilt together; the frozen-binding logic (35243-35846) uses only the strings, so a rename or a shadowing name could change its answer. Roots are looked up by `symbols.name(...)` in many places (see Identity by text). No check in this slice reconciles the two.
- `completed_effects` (32039-32204) calls `summarize_complete_state_written_paths` lazily and caches the result in `written_paths` across all parameters and cases of one call; the recursion guard `active_states` is pushed only around that call, so a callee that is already active at the outer level yields `None`, which then means "may replace" (32175). So a recursive call refreshes all case knowledge.
- Dynamic dispatch handling joins every implementation of an interface across the whole program (`collect_dynamic_implementation_selections`, 33412) when the caller "cannot receive a selector"; the proof relies on `boundary_may_supply_selector` scanning every machine, state and boundary trait in the program (33469-33519), a whole-program scan on each dynamic call.
- `walk_declared_origins` expands fixed arrays into one path per index (`paths()`, 37597-37618): an array of length N with M reference leaves produces N*M records, and arrays of arrays multiply.
- `reference_leaves_with_projection` (36053-36253) contains three different entry modes selected by `stored`, `inference` and `include_shared` all being `Option`/bool, and the declared-origins fallback for locals applies only `if tracked.is_none() && (parameter.is_some() || stored.is_none())` (36145): a local that is not tracked while `stored` is `Some` yields `None` (refusal), a parameter yields declared origins.
- `Index { expression: Default::default() }` (invalid handle) is used as an in-band marker for "any index" (35114-35118, 37728-37730) and `prefix_matches`/`path_covers`/`source_reaches_leaf` interpret it differently (36449-36453 vs 36464-36467 vs 37157-37159): `source_reaches_leaf` also lets `FixedIndex` in the source match `Index` in the leaf regardless of the expression handle's validity.
- `SymbolHandle::invalid()` used as root of aggregate origins with `local_symbol` invalid (31544, 36273, 37509) and `""` passed as the name (36120 area, 37510), so path strings for such records start with an empty root.
- `walk_declared_origins` pushes `Case { variant: SymbolHandle::invalid() }` as a placeholder when it builds `segments` (37578-37583) and relies on every slot being overwritten; a mismatch between `depth` and the number of real segments would leave invalid cases in a path.
- `TypeWalk::is_visiting` refuses (`return None`, 37657-37659) any type that appears twice on the parent chain, so a recursive data type makes `declared_origins_for_query` return `None` (callers then refuse or treat as unknown) rather than modeling recursion.
- Both `ExpressionNode::Call` outcomes with `invocation_effects` returning `None` are turned into `SlotRelationTransfer::unknown(...)` (32716-32728, 33033-33045), so refusal inside the effect builder is silently converted to "unknown effects", with a flag from `provider_output_relation_required`; whether the unknown is later refused depends on callers outside this slice.
