## What this code is for

`obligations.rs` walks the typed program (machines, states, statements, expressions) and builds a `ProofPlan`: a list of range obligations, one for every place where a value flows into a type that carries constraints (obligations.rs:42-194). It does not decide any obligation. It only collects them, attaches the "constraints" it can derive for the value by interval arithmetic over declared types and literals (obligations.rs:1363-1487), and computes a text key for each obligation "for caching" (obligations.rs:6, 1894-2066). The decision to accept or refuse is made by code outside this slice.

`contexts_and_places.rs` defines the data model of the old fact store: `ProgramPoint` (where a fact holds), `FactContext` (the facts at one point), the point-indexed storage `FactContexts` with pages that parallel workers can add and hand back (contexts_and_places.rs:765-980), and the storage-place model: `PlaceRoot`, `PlaceSegment`, `Place`, `FactPlace` (contexts_and_places.rs:1974-2113). It also resolves a member name to a field symbol, renders a place as a label string, composes array window coordinates, and normalises write frames, which are lists of path strings.

`evidence.rs` defines `Fact`, the 26-variant `FactPayload`, `FactOrigin`, the qualification evidence record with its provenance join, `FloatPredicate` with an implication test, and `FactTable`, an arena of facts with a lazily built index by program point.

About 1,800 of the 7,495 lines are tests and manual timing measurements, most of them for the storage containers.

## Mechanisms

- **Syntactic interval analysis** (`expression_constraints`, obligations.rs:1363-1487; `derived_binary_constraints`, 1670-1751). Bottom-up over one expression tree. Leaves take constraints from literals and from the declared type of the name, member or index. It uses no program-point facts: `collect_constraints_in_state` ignores its machine and state arguments (1596-1603). Integer ranges are unbounded `BigInt`; float ranges are `f64` pairs with an inclusive flag on the maximum only (3611-3616). No budget. Serves range-constrained types and arithmetic domains.
- **Constraint list** (`ConstraintBuffer`, obligations.rs:3257-3350). Four inline slots then a `Vec`. A value's knowledge is a flat list of `Named(Identifier)`, `IntegerRange`, `FloatRange`, `ArithmeticDomain` (3201-3213). Ranges are recovered by intersecting all entries (3706-3778).
- **Guard refinement for transition arguments** (obligations.rs:630-709). Recursion over member, binary, cast and unary nodes; a member under a case guard takes the payload field's declared constraints.
- **Refuted exit guards** (`prior_exit_guards`, obligations.rs:1005-1018). Collects the `when` guards of earlier transitions in the same state that have a target and no continuation. Attached to transition-argument and return obligations.
- **Incoming state guard** (obligations.rs:1167-1214). One pass over all states of the same machine per target state, cached once per state while collecting (384-389).
- **Structural expression equivalence** (obligations.rs:1255-1323). Borrow is transparent; names compare by identifier path; calls by target name, target symbol, receiver and arguments; literals by value. Everything else is unequal.
- **Ensures witness scan** (obligations.rs:464-515). For each assignment it rescans every earlier statement of the state, so collection is quadratic in state length. Witnesses are `(String, i64)`.
- **Canonical obligation key** (obligations.rs:1834-2776). A tagged, comma-separated, escaped text form, `obligation(schema:2,<body>)` (1858, 2060-2065). Symbols enter through `normalized_hermetic_symbol_identity`, falling back to the display path (2316-2324). Match captures are numbered by nesting depth (2358-2373). No hashing; the key is the full string (1874).
- **Point-indexed context storage** (contexts_and_places.rs:765-980). A paged arena plus a `HashMap<ProgramPoint, group>`. `share_pages` seals the current index into a shared `Arc` baseline (832-854); workers clone it, append on their own page generation, and the owner adopts the pages in any order (860-893). Lookups filter freed handles (978).
- **Lazy fact index** (evidence.rs:256-320). `FactTable` builds a `HashMap<ProgramPoint, Vec<Handle<Fact>>>` on first query, tied to the arena revision; any mutable access drops it (348-354). If an iterated handle does not read back the same row, queries fall back to a linear scan (283-296, 310-314).
- **Window coordinate composition** (contexts_and_places.rs:1649-1742). Folds adjacent range and index segments. A projection starting with `FixedRange { 0, usize::MAX }` is a sentinel for "the whole captured window" (1672-1684).
- **Element type lookup with a bound** (contexts_and_places.rs:1498-1520). Follows `generic_instance` origins at most 8 times, then gives up.
- **Place bucket index** (contexts_and_places.rs:2123-2180). Sorts `(hash, position)` pairs; groups equal places inside one hash bucket with a caller-supplied equality.
- **Float predicate order and join** (evidence.rs:80-131) and **provenance join** (evidence.rs:757-768, 828-847).

## Accepts or skips without proof

## Surprises

Evidence on the three properties:

1. **Own yes or no.** Nothing in the slice calls `proof_admission`, `ProofNode`, `verify_obligation` or any certificate API. obligations.rs only collects and derives. The `proves_*` methods answer by finding a fact row (contexts_and_places.rs:1007-1064). `FloatPredicate::implies` and the evidence joins are plain comparisons. `QualificationEvidence` has an `issuer` handle and an `AdmittedReceipt` origin (evidence.rs:736-743), but in this slice they are fields compared for equality (821-826), and the constructor that stamps them is unguarded (791-803).
2. **Text identity.** Strongly present in obligations.rs: named-tag knowledge, type-name ranges, string write paths. Mixed in the facts files: points and places are handle-based, but member resolution prefers the name over the recorded symbol, and write frames and instantiated contract expressions are strings.
3. **Per-placement copies.** Clear, and the copies differ in what they know (see Repetition).

Things that look wrong or that a reader would want checked:

- **Unary not keeps the operand's range.** `ExpressionNode::Unary` returns the operand's constraints as its own (obligations.rs:1464-1466), and the only unary operators are `BitwiseNot` and `LogicalNot` (2309-2313). For `~0` the derived constraints are `exact`, `non_negative`, range [0, 0]. I see nothing in this slice that corrects it.
- **Casts keep the source range.** A cast returns the source value's constraints unchanged except for the bool case (obligations.rs:1443-1463). The cast node has a `domain` and a `form` (2454, 2467) that this code does not read. For a cast that wraps, or a cast from float to integer, the source range and tags (`finite`, `exact`) do not describe the result.
- **F32 overflow is not modelled.** `derived_float_operator_constraints` discards the operator's float format (`_format`, obligations.rs:1776), and `float_binary_range` has no format parameter (3782-3786). It computes in host `f64`. Adding two F32 values with range up to `f32::MAX` gives a finite `f64` maximum, so the result is tagged `finite` (1738-1742), although the F32 sum is infinite. The overflow test (3954-3970) covers F64 magnitudes only.
- **Float bounds use round-to-nearest.** `float_binary_range` uses ordinary `f64` arithmetic with no outward rounding (3791-3829) and always marks the maximum inclusive. `FloatPredicate::comparison` rounds its bound to the format with `to_f32()` (evidence.rs:49-52) whether the predicate is a known fact or a requirement. Rounding a requirement's bound toward a weaker predicate would accept more than was asked. Whether an unrounded bound can reach this function is outside the slice.
- **A range expression gets the intersection of its two ends.** `2..5` yields constraints whose intersected integer range is [5, 2] (obligations.rs:1379-1393, 3722-3726). Nothing checks for an empty range.
- **Declared domains are treated differently by placement.** On the value side `collect_constraints` always converts a declared domain to an integer interval when it can (obligations.rs:1570). On the required side only assignments do (372). For arguments, returns and initializers an unknown-name domain disappears from what the obligation requires (600, 840, 926, 1111).
- **The incoming guard ignores entry from outside the machine.** See "Accepts or skips". The guard expression belongs to the source state and is attached to assignments in the target state (obligations.rs:392-399).
- **A call to a machine uses its first state's parameters** (obligations.rs:1136-1137).
- **Value constraints never use flow facts.** Collection reads declared types and literals only (1596-1603). The fact store in the other two files is not consulted by obligations.rs at all.
- **The cache key leaves out the statement index for four kinds but includes it for three.** Assignment, call argument, return and transition argument keys omit it, and a test pins that (obligations.rs:1906-2047, 2905-2925). `StateLocal`, `ConstructorField` and `ArrayElement` owners include it (2132, 2147, 2174). If the consumer's decision for the first four uses anything that depends on position and is not in the key, two statements would share a cached answer. The witness bounds, the one position-dependent input computed here, are in the key (1930-1938). Cannot tell about the consumer.
- **Constraint lists can hold duplicates, and order is identity.** `finite` can be pushed at 1690-1692 and again at 1739-1741; `augment_constraints_with_named_facts` runs once in `primitive_constraints` and again for each `Constrained` layer (1575, 1617). The key keeps order and duplicates (2205-2218, test at 2962-2978).
- **Named tags are not all the same kind of claim.** `non_negative` and `positive` are range facts; `exact` and `wrapping` describe the arithmetic; `finite` is a float property. All sit in one `Named(Identifier)` variant beside user-declared named constraints from `TypeConstraintNode::Named` (3228). A user constraint spelled `finite` or `exact` is indistinguishable from a derived tag.
- **Only unsigned fixed-width integers have built-in ranges** (obligations.rs:1607-1611). Signed types and any pointer-sized type get none from this function.
- **`data_member_symbol_by_name` returns the first match across all variants** (contexts_and_places.rs:1582-1597). Two variants with a payload field of the same name resolve to the first variant's field, and `effective_member_symbol` prefers this result over the symbol the earlier stage recorded (1213-1221).
- **`PlaceRoot::group_key` ignores part of the identity.** `InvocationOutput` is keyed by parameter symbol only; state, statement index and call ordinal are dropped (contexts_and_places.rs:2023-2026). `InvocationReferent` drops its type reference (2020-2022). The name says grouping, so this may be intended.
- **`FactContexts` equality and `Debug` ignore the index** (contexts_and_places.rs:806-818). Two stores with equal rows and different group membership compare equal.
- **Obligations appear as facts.** `FactPayload::ProofObligation { kind }` (evidence.rs:968-970) and `FactOrigin::ProofObligation` (700) put an obligation of a given kind into the same table as established facts. The payload holds nothing but the kind.
- **`ZeroCaseElements` is a range-quantified fact** over `first..end` array elements (evidence.rs:901-915). It is the only quantified fact form in `FactPayload`.
- **Hash maps keyed by `ProgramPoint`** index both stores (contexts_and_places.rs:9, 767, 776; evidence.rs:257).
- **Vestigial code.** `collect_constraints_in_state` ignores two parameters (obligations.rs:1596-1603). `callable_parameters` and `state_by_symbol` are one-line wrappers (1160-1165, 1325-1330). The `atom!` macro only calls `atom` (1852-1856). `collect_bounded_transition_argument_obligations` finds its statement index again by pointer comparison although the caller has it (175, 559-563). `ProofObligationOwner::Unknown` is the default and no code in this slice constructs it otherwise (3375-3376, 3363-3371).
- **Collection is quadratic per state.** `ensures_witness_bounds_at` rescans all earlier statements for each assignment (obligations.rs:335-342, 473), and each transition and return recomputes `prior_exit_guards` over the earlier statements (564, 1044).
