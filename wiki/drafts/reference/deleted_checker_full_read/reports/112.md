### mod call_summaries (8316-8419)
- `state_to_machine_index` (8323-8331): map state symbol -> machine symbol, first writer wins (`or_insert`).
- `collect_call_summaries` (8333-8418): walks an expression tree; for each `Call`, looks up the callee's machine by `call.target_symbol` and appends that machine's summary list of established place spellings (`Vec<String>`) to `call_established`. ### mod case_requirements (8420-8579)
- `selected_case_requirements` (8425-8445): for a data definition's `requires` facts, flatten on `And`, then for each clause `project_clause` for the selected case.
- `project_clause` (8483-8516): clause split on `Or`; each disjunct split on `And`; atoms that are `value is Case` (membership) are guards; a disjunct whose guards name another case is dropped; if two disjuncts remain live it gives up (returns, adds nothing, 8508-8510); only if the clause mentions a case and exactly one disjunct is live are its residual atoms added.
- `case_predicate_expressions` (8447-8466): selected-case requirements plus every clause that mentions no membership.
- `membership_case` (8518-8550): atom is membership if operator is `CaseMembership` or an authored selection occurrence says so; the case is found by the right-hand name path symbol / head symbol / last member symbol through `data_variant_position_for_symbol`.
- Non-expression facts are skipped with `continue` (8435-8437, 8454-8456).

### mod data_reads (8580-9513)
- `scan_statement_reads` (8599-8685): per statement kind, collects expressions that are read (assignment value, expression statement, local initial value, call arguments, transition guard/arguments), plus index expressions of an assignment target. Call statement with receiver path rooted at the state's data binding name (string compare `receiver[0].as_str() == root`, 8627-8628) validates read of `receiver[0].receiver[1]`. Assembly statements read nothing (8614). Prefixes each diagnostic with "machine `M` state `S` statement N:" (8679-8684).
- `scan_expression_use` (8712-9013): the read gate. Rules:
  - whole-value read of a name whose data type requires establishment -> `validate_data_read` with member `"<whole value>"` (8792-8804).
  - whole-value read overlapping any tracked place with an open window -> error "the next whole-value read of `X` occurs inside an OPEN invariant window ..." (8805-8819); or overlapping an inherited window -> error (8820-8828).
  - Name path with >1 members: receiver spelling is the dotted join of all but last (8836); validated against a tracked place covering it (8837-8846). Name path starting with `self` -> validate against machine attached data (8848-8857).
  - Member: receiver spelling; definition from the expression type or, failing that, from a tracked place with the same spelling (8861-8872); skipped when the child place is itself directly established (8873-8881) or is an "independently present scalar field" (8882-8890); else `validate_data_read` (8891-8905). Receiver is then scanned with `consumes_value = false` (8907-8918).
  - Borrow with `WriteOnly` access: only the index expressions are read; returns (8941-8946). Other borrows of `recv.member` where a tracked place covering recv has an open window -> validate read (8947-8962).
  - other nodes recurse; `_ => {}` (9011).
- `validate_qualified_place_read` (9015-9116): for Name/Member/Indexed/Borrow whose declared type requires establishment and is not a plain named data type: established if covering tracked place (longest spelling) is established or that exact field is in `established_fields` (compared via `place_label(place.spelling, field.name) == spelling`, a string, 9076-9079), or entry-established / declared root established, or call-established, or composed. Open if any tracked or inherited window overlaps in either direction. Error text 9112.
- `independently_present_scalar_field` (9118-9165).
- `validate_data_read` (9167-9234): three diagnostics (not established 9203-9210; open window 9215-9220; inherited window 9227-9232).
- `attached_value_established` (9236-9269), `composed_value_established` (9271-9408), `composed_carrier_established` (9410-9456), `direct_place_established` (9458-9469), `range_gates_hold` (9471-9512).
