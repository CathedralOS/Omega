## What this code is for

The slice is the second half of the module `proof_contracts::default_domains` and the whole of the module `domains`. The first part is the "default-domain window" analysis: a `data` type with `requires` facts has an invariant, a field store can break it ("open a window"), and the code tracks, statement by statement and state by state, which places are established and which windows are open (driver `analyze_default_domain_writes_with_frames`, 12794-13107, and `walk_state`, 13525-13992). It refuses reads, calls and returns that happen while a window is open, and records crash rows that abandon an open window as `OpenInvariantCrashSite` (12755-12779). Supporting sub-modules are the read gate (`data_reads`, 8580-9513), element stores (9514-9805), float predicates (9806-9985), call summaries (8316-8419), per-case requirement projection (8420-8579), place-spelling helpers and predicate read sets (`place_queries`, 9986-10790), the after-store predicate proof (`post_store_predicates`, 10791-11246), a pattern match for callee requirements already stated by a data type (`standing_requirements`, 11247-11392), the state-graph meet (`state_flow`, 11393-11475), a constant folder over field valuations (`symbolic_values`, 11476-12092) and interval extraction from `requires` facts (`requires_fact_intervals`, 12093-12691). The `domains` module (13995-16187) decides integer domain membership for closed instances, checks that a membership's subject has the domain's carrier type, turns scalar domain predicates into `CheckedBooleanExpression` trees for later stages, classifies predicate-free domains as "tags", and validates domain declarations (aliases, progress profiles, repeated declarations, cycles). Nothing in the slice calls a proof kernel; arithmetic questions go to `scoped_arithmetic_implication*` in another module, and everything else is decided here by direct comparison.

## Mechanisms

- **State-graph fixpoint, written twice.** Pass 1 (12804-12937) computes, per machine, the list of data-rooted place spellings established at every terminal state (the machine's "summary"). Pass 2 (12939-13091) recomputes each state with summaries available and three entry values: established spellings (intersection over predecessors), open windows (union, sorted), field valuations (`meet_valuations`, only over predecessors already reached). A `stale` flag per state drives re-walking until nothing changes. There is no iteration budget; termination relies on the sets shrinking or growing monotonically. Machines are processed in parallel with rayon (12807-12811, 12943-12947). Only state 0 is the entry; only states with no outgoing named edge are terminal (12907-12909, 12962). Serves `data ... requires` across states.
- **Per-state abstract interpretation** (`walk_state`, 13525-13992). State is a `Vec<TrackedPlace>` keyed by spelling string, with per-field `Option<LiteralValue>`, symbolic values, length/capacity measures, per-element integer sets, pending requirements and window flags. Calls poison: either the overlapping places (when write paths are known) or everything (`poisoned_all`).
- **Interprocedural re-walk** (`restore_parameter_write`, 13379-13523). The callee's first state is walked again with the caller's valuation renamed to the parameter name. Recursion is cut by `active_callees`; a recursive attempt is recorded as not proved.
- **Constant folder** (`fold`, 11654-11847). Three-valued (`Some(nonzero)`, `Some(0)`, `None`) evaluation of a `requires` expression over field literals in `i128` with checked add/sub/mul, short-circuit And/Or, case membership against the active case, `.length`/`.capacity` from tracked measures, const generic arguments, float comparisons delegated to `float_predicates`. `born_zero` treats every field without a known value as 0.
- **Symbolic equality** (`SymbolicValue`, 11645-11652, 11941-12034, 12077-12091). Sums and products are normalized by sorting two operands on a rendered string key (11959-12003); `a == a` and `a != a` are decided by structural equality (11800-11809). Only binary shapes are sorted, so `(a+b)+c` and `a+(b+c)` are different values.
- **Interval extraction** (12169-12231, 12404-12465). Splits `requires` on `And`, accepts `field op literal` and mirrored forms with `<=,<,>=,>,==`, intersects per field. `i64` only.
- **Predicate read set** (`predicate_read_set`, 10574-10753). Worklist over a fact's expression collecting which fields it reads and, when every read is an exact projection, canonical place-segment paths; `complete_paths` goes false when a read is rooted in the subject but has no exact projection. `fact_is_disjoint_from_store` (10392-10406) uses it with `canonical_place_segments_may_overlap`. This part works on symbols and `facts::PlaceSegment`, not strings.
- **Predicate projection** (`predicate_projection`, 10408-10518). Decides whether an expression inside a data `requires` is an inline coordinate of the subject; eleven distinct refusal reasons as `&'static str` (10417-10495), printed only under a trace flag (10500-10516).
- **Scalar domain predicate compiler** (`Predicate`, 14793-15269). Recursive translation with depth limit 128, inlining one-parameter single-statement helper machines by substituting the formal (`substituted_formal`, 14799, 15088-15097), and resolving `helper(x).field` by picking the field out of the helper's struct literal (14939-14993).
- **Integer domain membership** (14113-14233). Recursion over alias constituents and nested memberships with an `active_domains` stack; each expression fact is one call to `scoped_arithmetic_implication_for_declaration` with the index values and the subject bound.
- **Cycle detection** by depth-first path stack, written twice (15830-15874 for aliases, 16124-16168 for memberships).
- **Per-element value sets for collection fields** (`handle_element_store`, 9528-9702). Each tracked place keeps, per collection field, a `Vec<IntegerSet>` with one set per element. A store at a literal index replaces that element's set (9656); a store at a runtime index unions the stored set into every element (9657-9661); a store two or more indices deep resets the field to unknown (9662-9664). Starting sets come from the place's earlier stores, from `collection_predicates::standing_field_elements` when the receiver is established with no window (9769-9774), or from the carrier (9775). The affected `requires` facts are then decided by `collection_predicates::data_fact_decided` with these sets and, for other fields, a singleton of the known literal, 0 when `born_zero`, or the carrier (9778-9804).
- **Composed establishment** (`composed_value_established` / `composed_carrier_established`, 9271-9456). Recursion over a data type's fields and a fixed array's elements, building child spellings with `place_label` and `format!("{spelling}[{index}]")` (9340, 9432), enumerating every index of a literal-length array (9428). No budget other than the `active` stack; a large literal extent means that many recursive calls.
- **Case projection of a disjunctive `requires`** (`project_clause`, 8483-8516). Flattens on `And`, then `Or`, then `And`; atoms that are case memberships act as guards.
- **Hand-written expression walks.** `collect_call_summaries` (8354-8417) and `scan_expression_use` (8921-9011) each list the expression kinds they descend into and end in `_ => {}`; `visit_calls` (13362-13377) and `expression_contains_call` (12056-12075) use the generic `expression_traversal` instead.
- **Budgets**: 16 steps in `receiver_retains_declared_domain` (11165), 128 in `collection_observation_place` (11360), 8 alias hops in `stored_field_requires_interval` (12622), depth 128 in `Predicate` (14804, 15100, 15202).

## Accepts or skips without proof

- **Diagnostics dropped for a "proved" callee** (13092-13106). A machine's diagnostics and crash sites are discarded when at least one call attempt was recorded and all recorded attempts proved. A call whose argument is not a tracked place records nothing (13416-13432), and a machine entered from outside the program has no attempts for that entry. So one proving call site can silence the machine's standalone diagnostics for every other caller. I cannot see another check that would catch the other callers.
- **Parameters are established by declaration** (`declared_root_established`, 10005-10007): any state parameter root counts as established. A local with any initializer counts as established (10023-10031). The initializer's own reads are checked elsewhere in the gate; I cannot tell whether every initializer shape is.
- **Every assigned place is added to `call_established`** (13629-13635) regardless of what `handle_assignment` concluded, and `validate_data_read` accepts a `call_established` spelling when no tracked place covers the receiver (9183-9191). After a later call clears `tracked` (13595, 13671), the spelling stays in `call_established`. A window open at that call is reported by `refuse_open_windows`, so the common case is caught; I cannot tell for places whose requirement was never tracked.
- **Callee summaries are added verbatim** (8360-8362, 13678-13680): the callee's established spellings are in the callee's own names (rooted at its data binding) and are added to the caller's list with no mapping to the call's arguments. They take effect only when the caller uses the same spelling.
- **`restore_parameter_write` re-establishes on a first-state walk only** (13410, 13444-13461, 13485-13495): the callee's later states are not walked, and after "proved" the caller's place is set `established = true`, `window_open = false`, pending requirements cleared, with field values taken only from top-level literal assignments in the first state (13472-13484); a non-literal write sets the field to `None`.
- **Lookups that fail and continue**: target machine not found returns silently (13396-13402); unresolved transition target is dropped from the edge list (11466-11468), which can make a state look terminal or leave a successor unreached; `state_to_machine` miss becomes an invalid handle and the summary lookup misses (13674-13680); `seed_transported_initializer` has `continue`/`return` on every miss and `_ => {}` (13191-13209, 13239-13257, 13312); `walk_state` ignores other statement kinds with `_ => {}` (13911); assembly statements read nothing (8614).
- **`machine_states(machine).is_empty()` or no data binding** skips the machine (12813-12819, 12949-12952).
- **Carrier check returns `Ok` when a type is unknown** (14412-14426), when the domain's target mentions a type parameter (14449), or when a proof-fact subject mentions a type parameter (14450-14453); a domain that does not resolve is skipped with `continue` (14285-14287, 14306-14314). The comment at 14333-14335 says the generic case is judged on each specialized copy; that is another stage.
- **`validate_membership_carrier` retries with any other declaration sharing the semantic id** and accepts if one matches (14380-14399).
- **Alias constituents named `Carry::Portable` or any carry permission skip existence, type, index and visibility checks** (15739-15741).
- **`validate_domain_membership_targets` skips a membership whose domain is unknown** (16072-16076); the unknown-domain error, if any, is elsewhere.
- **Agreement checks swallow a peer's error as "equal"**: `Err(diagnostic) => { diagnostics.push(diagnostic); false }` (15920-15923, 15967-15970); the error is still reported, so compilation fails anyway.
- **`normalized_domain_facts` ignores fact payload kinds other than boolean and membership** (`_ => None`, 16054) and removes duplicates (16061).
- **`scalar_domain_local_predicate` returns `true` when all facts are memberships** (14602-14607) and skips membership facts otherwise (14630); the memberships are expected to be handled by `project`/the caller.
- **`scalar_domain_value_predicate` returns constant `true` for a tag** (15330-15332).
- **`born_zero`** (11679, 11702, 11714, 11789-11793): in the entry state with no incoming edge, every field with no recorded value is taken as integer 0 / float +0. That matches the language's zeroed start; it also applies to any place the walk has not tracked a value for, such as a parameter's field, if the caller passes `born_zero` for it. I cannot tell from this slice which places `handle_assignment` applies it to.
- **`binding_retains_declared_domain` trusts the declared type** (11188-11209): an immutable non-exclusive parameter or local is assumed to satisfy its data type's `requires` interval without checking establishment at that point.
- **`project_clause` gives up silently** when two disjuncts stay live (8508-8510): the case requirement is then not added, which removes an obligation rather than refusing. Non-expression facts are skipped with `continue` (8435-8437, 8454-8456). I cannot see another check for the dropped clause.
- **`call_established` overrides a covering tracked place in the qualified-place gate** (9090-9093): the `||` applies after the tracked-place branch, so a covering place that is not established is still accepted when any `call_established` spelling covers the read. Since `walk_state` puts every assigned spelling into `call_established` (13629-13635), any assignment to a constrained place makes it read as established here; only the separate `open` test (9103-9110) can still refuse. Whether the assigned value met the qualification is not decided in this slice.
- **A dotted name `a.b` with no tracked place covering `a`, and not starting with `self`, gets no field-read check** (8837-8847). The whole-value check (8792-8804) still runs on `a.b` if its own type needs establishment. `Member` nodes take a different path that does check (8859-8906). I cannot tell which of the two node shapes a given source `a.b` produces.
- **The qualified-place gate returns without checking** when the place has no declared type (9036-9043) or no spelling (9062-9064). `self_place_spelling` returns `None` for a non-literal index (10066-10069), so `a[i]` with a runtime `i` and a qualified element type is not checked by this gate.
- **Expression kinds not listed are not scanned** (`_ => {}` at 9011 and 8416). `expression_contains_call` uses the generic traversal, so a call inside an unlisted kind still clears the tracked places, but reads inside it are not gated and its callee summary is not added. I cannot tell from the slice which kinds exist beyond those listed.
- **Assembly statements read nothing** (8614).
- **A tracked place's `established` flag is taken as is** by `validate_data_read` (9183), and the first covering place in the vector wins (9180-9182), not the most specific one.
- **`independently_present_scalar_field`** (9118-9165) lets an unconstrained primitive field be read from an established tracked receiver even though the member read would otherwise be refused; the open-window diagnostics are skipped too, because the whole `validate_read!` call is skipped (8891-8905).
- **Element stores**: a store with no `requires` fact reading the field's contents is accepted at once (9610-9612); a stored value with no proved bounds is taken as the whole carrier (9645-9649), which is the cautious direction; when the element carrier is unknown the stored set is `IntegerSet::empty()` (9650), which is the incautious direction if any element list exists at that point. `current_elements` normally returns `None` in that case, making `all_hold` false; I cannot rule out `standing_field_elements` returning a list for such a field.
- **`born_zero` gives sibling fields the value 0** in element-store decisions (9801) and in composed establishment (9309).
- Places that refuse on doubt (evidence the other way): `standing_facts_prove_requirement` returns `false` on every miss (11273-11324); `integer_domain_membership` returns `Unknown` on every miss; `predicate_holds` returns `false` for non-expression facts (11560-11562); `field_intervals` returns `None` on one unrecognized conjunct; `same_number_interval` returns `None` unless fully inside both ranges; a missing `call_frames` records the attempt as not proved (13433-13439).

## Surprises

- **A proving caller silences the callee for everyone** (13092-13106, with 13430-13432). Described under "Accepts or skips". The attempt list is also filled during pass 1 and during every fixpoint re-walk, so the same call site contributes several entries; the decision is "all recorded attempts proved", not "all call sites proved".
- **The two read gates pick the covering place differently.** `validate_data_read` takes the first tracked place whose spelling covers the receiver (9180-9182); `validate_qualified_place_read` takes the longest (9065-9068). With `a` tracked as not established and `a.b` tracked as established, a read of `a.b.c` depends on vector order in the first gate.
- **One read can produce two diagnostics** ("not established" and "inside an OPEN window", 9202-9221), and none of the read-gate diagnostics carries a source span (8814, 8824, 9111, 9203, 9215, 9227); the location is only the text prefix "machine `M` state `S` statement N" (8679-8684). That prefix prints the 0-based ordinal, while `refuse_open_windows` prints `index + 1` (7328), so the same statement has two numbers.
- **The diagnostics call an unestablished value "an open default-domain invariant window"** (9204, 9112) and a broken invariant "default domain FALSE" (8816, 9217): two different conditions share the word "window".
- **`composed_value_established` refuses any type with variants** (9318-9324) after the `requires` facts already folded true, so a tagged data value can only be established directly, never by composition.
- **`composed_carrier_established` returns `true` for any type that does not require establishment and `false` for slices, references and non-literal array lengths that do** (9419-9455).
- **`float_field_literal_bound_meaning` returns the literal's meaning only for the exact shapes `literal op name` or `name op literal`** (9866-9873) and feeds every field as `+0` while checking the shape (9840); the operator itself is not returned, so the caller must read it again.
- **`collect_call_summaries` descends into a call's receiver and arguments but not into `machine_arguments` or other call parts** (8363-8366).
- **The assignment arm never calls `restore_parameter_write`.** Call statements, expression statements, local initializers and transitions snapshot the tracked places before clearing them (13643, 13695, 13735, 13848) and then replay the callee's parameter writes. The assignment arm does neither (13580-13613), so `x.f = g(&mut y)` gets no parameter transport while `let t = g(&mut y)` does (13758-13773). The expression-statement arm replays only when the whole statement is a call (13717-13732); the local and transition arms visit every nested call.
- **Exit valuations after a poisoning call.** `tracked.clear()` drops literal knowledge, but `restore_parameter_write` can push a place back from `saved_places` with its pre-call fields plus the callee's literal writes (13496-13519). The pre-call fields of that place are kept even though the callee may have written them non-literally in a later state or through a nested call; only first-state top-level assignments are replayed (13472-13484).
- **A field path longer than one segment becomes a field name containing dots** (13481-13489): `target.strip_prefix("param.")` yields e.g. `inner.x`, stored as a key in `place.fields`, where lookups by declared field name (10963) will never find it and `fold` (which uses the last path member, 11673) would look for `x`.
- **`fold` ignores the path prefix** (11673-11681): `other.count` and `count` both read the subject's `count`. In a data `requires` only the subject's fields should be nameable, so this may be harmless, but nothing here checks it.
- **`place_spellings_may_overlap` compares only the common prefix** (10124-10126): `a.b` and `a` overlap (correct), and so do `a.b` and `a.b.c`; fine as a may-overlap, but `zip` also makes the empty spelling overlap everything.
- **`segment_covers` accepts an empty place segment against any nested segment starting with `[`** (10134).
- **Trace output through `eprintln!`** in checker code, gated by `contract_entailment::struct_trace()` (10500-10516), with a fixed `DEFAULT predicate-projection-refused` prefix.
- **`impossible_variant` is purely syntactic** (12131-12153): only a literal `0` or `false` fact makes a variant impossible; a contradictory pair of bounds does not.
- **`!=` yields no interval and poisons all fields** (12447-12456 returns `None`, propagated by `?` at 12187): one `x != 0` conjunct in a data `requires` makes `data_requires_field_intervals` return `None` for every field of the type, unless it is an exact predicate application. The comment at 12574-12580 confirms the authors hit the float variant of this and wrote a second function rather than fix the first.
- **Interval bounds are `i64`** (12108, 12219) while `fold` uses `i128` and domain indices use `BigInt` (14010); a `u64` field bound above `i64::MAX` gives `None`.
- **`integer_domain_membership` passes `&[]` as arguments to alias constituents** (14152-14159), and `closed_integer_index_bindings` then requires zero parameters; consistent with the alias rule at 15785-15791.
- **`membership` treats a domain with `establishment_routes` as Unknown** (14129-14135) while `scalar_domain_value_predicate` deliberately ignores routes (15297-15350) and `scalar_type_routed_domains` (15467-15484) lists routed domains that still have a value predicate: the same domain is "unknown" to the prover and "has a runtime predicate" to the emitter.
- **`scalar_application` requires exactly one declaration row with the symbol** (14681-14686), while `validate_repeated_normalized_domain_identities` (15876-15932) exists because a domain can be declared more than once ("repeated capacity specializations"); those are keyed by name there and by symbol here.
- **`Scalar::IntegerBinary` is emitted with `formation_decided: false, trap_free: false`** (15251-15252): the predicate compiler hands unfinished obligations to a later stage.
- **Property 1**: confirmed for this slice. There is no reference to `proof_admission`, `ProofNode`, `verify_obligation`, a certificate or a kernel anywhere in the file (grep, whole file). The strongest reasoning step available is `scoped_arithmetic_implication` returning `Proven`; "proved" for a callee means "the walk produced no diagnostics" (13462).
- **Property 2**: strongly confirmed for the window analysis (strings for places, fields, parameters, states), and not confirmed for the read-set/projection code and the `domains` module, which use symbols and semantic ids, with string fallbacks at 11873-11878, 14979-14983 and name-keyed agreement at 15999, 15944.
- **Property 3**: confirmed in `walk_state` (five copies of call handling by statement kind) and the seeding functions (one per initializer shape); the two fixpoint passes are the same loop written twice with different payloads.
