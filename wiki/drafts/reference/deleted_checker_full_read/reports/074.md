## What this code is for

This slice is the second half of the "scalar values" part of the old typed-trees-to-checked-trees stage. It translates source expressions (typed-tree handles) into the closed `CheckedScalarExpression` / `CheckedBooleanExpression` language that later stages replay. It does not judge whether a contract holds; it decides whether an expression can be *expressed* in that closed language, and returns `None` when it cannot. It contains eight modules: `machine_parameter_booleans` (predicates over a machine's entry parameters, 5655-6191), `primitive_reference_read` (reads through `&T`/`&mut T` of a primitive, erased-parameter observations, 6192-6400), `result_contract` (lowering `requires`/`ensures` predicates, domain memberships and parameter ranges into the contract namespace where the result sits one position after the parameters, 6401-8431), `scalar_lowering` (the general scalar expression lowerer: storage reads with indexes, literals, casts, integer operators, recast views, 8432-10017), `selected_operator_operands` (operands of a boundary-operator `let`, 10018-10111), `semantic_casts` (which casts need "custody", 10112-10259), `structural_fields` (resolving `a.b[3].c` against data declarations into a parameter position plus a path, 10260-11423), and `subslice_endpoints` (finding range endpoints `x[a..b]` and listing every site where one can occur, 11424-11620). The file ends with re-exports (11621-11655). There are no tests and no diagnostic strings in the slice: every refusal is `None`, `false` or an empty `Vec`, and the caller decides what the user sees.

## Mechanisms

- **Shared work budget with depth cap.** `ContractBudget` copies the caller's `remaining` counter into a `Cell`, hands it to every reader, and writes it back in `Drop`, so failed attempts still consume budget (6947-6969). Readers decrement it per Boolean node (7781), per math term (7502), per predicate condition (6681-6682, 6745), per interval row (7704-7705) and per reference peel (10743). Every recursive function also stops at depth 64. Serves `requires`/`ensures` lowering. `numeric_term` itself does not spend budget.
- **Two-pass storage projection.** `storage_projection` walks an expression from the outside in, collecting `Field` and `Index` steps until it reaches a place with no index (8705-8741), then replays the steps from the root outward against the declared types, producing a root plus an ordered list of static steps and runtime selectors (8742-8797). `scalar_storage_read_projection` then classifies the result as a field read or an indexed read split at the first runtime index (8554-8685). The selector's value is supplied by a caller closure, so the same walk serves bodies, contracts and predicate expansion. `entry_bound` is always `None` here (8786).
- **Declaration walk with observer.** `resolve_structural_path` resolves a path of `Referent`/`FixedIndex`/`Case`/`Field` steps against a declared type, returns place segments, the selected type and a `frozen` flag, and calls an observer before each step (10808-10915). `readable_entry_parameter_path` supplies an observer that enforces readability (10741-10798); other callers pass a no-op.
- **Explicit reference crossings.** `predicate_referent_path` and `explicit_observation_path` insert a `Referent` step wherever the declared type crosses a readable reference, so consumers do not infer pointer loads (10545-10620). Cycle guard is a `visited` vector (10551-10556).
- **Logical capture stack.** A contract `match` pushes a binding of the matched record subject, lowers the arm, then truncates the stack (6622-6634); the numeric variant clones the stack into a scoped reader (6636-6656). Saved subjects resolve through `validation::logical_saved_subject_projection` (6539-6575).
- **Predicate expansion.** `exact_predicate` replaces a predicate application by a comparison, a conjunction of conditions, or `low <= subject <= high` rows as reported by the `validation` module, substituting actual arguments for formals (7677-7754, 6671-6829).
- **Anonymous literal landing.** Untyped integer expressions take their type from context: the expected result type (9141-9145), the peer operand's carrier (9233-9256, 9576-9589), `u64` for indexes (8811, 9110-9114, 7067), or the comparison's first typed operand (8043). `landed_integer_literal_fits` checks the bit range (8832-8859).
- **Fail-closed range rosters.** `ParameterRangeRequirements` keeps predicates, clauses and rosters; a failed integer range sets the integer roster to `None` so consumers do not read a partial roster (8301-8330).
- **Erased scalar lanes.** Erased parameters are addressed by a lane base plus lane offset, where a lane is identified by primitive type and field-symbol list (6299, 6342-6348).
- **Subslice site inventory.** `sites` lists every place a range can occur in a statement: the local initializer, structural call arguments, completing-transition arguments, then every expression in the statement by depth-first walk with a `visited` vector (11496-11577). The `visited.contains` check is linear, so the walk is quadratic in expression count.

## Identity by text

- A parameter is matched by **name text** when the symbol does not match: `name_text.is_some_and(|text| parameter.name == *text)` (5733-5737). For an immutable Bool parameter a text-only match is then lowered as that parameter's position (5751-5758); only the `mut` branch re-checks symbols (5745-5746).
- A data definition is found by **name** when the type reference has no valid symbol: `data_definition_positions_for_name(name.as_str()).first()` takes the first definition with that name (11109-11116).
- A member is resolved with its **spelling** as a key: `closed_data_member_field(reference, member.member_symbol, member.member.as_str())` (11198-11202).
- Every structural path step carries `CheckedMemberIdentity::of_member(identity, name.clone())`, so path equality compares an identity together with the member's name string (list of sites in the previous section).
- `ScalarLocal` keeps the local's name as an owned string (6368).
- The `self` receiver is recognised by spelling: `spelling.is_self_receiver()` (11216).
- A closed integer value is turned into a decimal string, split on a leading `-`, and parsed back into a literal (7291-7300).
- Operator choice is partly by spelling enum: `OperatorSpelling::Index` (10442), `OperatorSpelling::Range` (11470), and the Add/Subtract/Multiply/Equal/NotEqual spellings passed to `has_builtin_spelled_expression_meaning` (7351-7373, 7950-7961). These are enum values, not strings.
- Against the property: most identity here is by symbol handle and position. Parameters are matched by `parameter.symbol == ...` (6251-6253, 7219-7222, 8344-8346, 11229-11232), fields and cases by symbol in place segments (10872-10874, 10900-10902), locals by symbol (11410-11413). Author comments insist on this: "does not ... infer a subject from its spelling" (6983-6985), "selecting fields from a global name roster" is what `parameter_projection` avoids (10622-10625).

## Accepts or skips without proof

- **No proof kernel anywhere.** The slice contains no call to `proof_admission`, `ProofNode`, `verify_obligation` or any certificate type. Every acceptance is this code's own `Some(...)`. The authors say the output is not proof: "Its presence supplies no proof: final source admission must still establish type, scope, access, assumptions and every precondition" (6275-6280); "Projection does not prove any incoming value satisfies it" (8334-8335); "supplying a value never supplies an indexing proof" (8525-8527). Whether those later checks exist is outside this slice.
- **Empty conjunction becomes `true`.** `lower_callable_scalar_membership_value` returns `Constant(true)` when `validation::scalar_membership_value_predicates` gives an empty list (7035-7037). `exact_predicate` starts from `Constant(true)` and returns it unchanged if `exact_predicate_intervals` gives zero rows (7706, 7753). Cannot tell from here whether the validation functions can return empty lists.
- **Exact cast stamped as decided.** When an `ExactIntegerCastFact` row exists for the expression with matching types, `construct_integer_cast` emits `IntegerExactCast { formation_decided: true }` with the fact's range (9668-9686). The fact comes from the `validation` module; nothing here checks it.
- **Operator flags passed through.** `formation_decided` and `trap_free` on every integer binary come from `operators.formation_is_decided(expression)` and `operators.is_trap_free(expression)` (9515-9523); contract arithmetic passes `false, false` (7400-7408).
- **Selector cast.** Any name cast to a type whose primitive is `Selector` becomes `ImplementationSelection { implementation: name.symbol, .. }` with no check that the name is an implementation of that interface (9469-9479). Cannot tell whether the type checker guaranteed it.
- **Byte-region view trusts an earlier judgment.** A `u8` element selected at runtime may be viewed as any sized carrier; the comment says "the recast judgment proved the whole footprint in bounds" (9895-9900). No bound is checked here (9938-9947).
- **Constant index into a slice or const-call-length array.** `fixed_index_element_type` checks the index only against a literal length; for a `ConstCall` length with a valid recipe, and for a `Slice`, it returns the element type with no bound comparison (11051-11060). `readable_entry_parameter_path` refuses `FixedIndex` on anything but a literal-length array (10767-10778), but `parameter_projection` (10645-10653), `path_type_reference` (6018-6027) and `resolve_structural_path` (10846-10854) call `fixed_index_element_type` directly. Cannot tell whether every caller also goes through the readable-path gate.
- **Missing operator record counts as builtin.** `lower_integer_contract_comparison` refuses only when a record exists with a non-builtin status (8021-8026); `indexed_read_is_builtin` and `subslice_endpoints` test the record only `if let Some` / `is_some_and` (10441, 11467-11469). Each then asks a second question (`has_builtin_spelled_expression_meaning` 8048, `builtin_index_read_is_spelled` 10505); `subslice_endpoints` asks none after `validation::subslice_expression`.
- **Member without a symbol skips the agreement check.** In `structural_storage_place`, the comparison of the authored member against the canonical place's field runs only when `member.member_symbol.is_valid()` (11191). The later re-resolution (11261-11268) would still compare whole segment lists.
- **Dropped rows instead of refusals.** `lower_selected_operator_operands` uses `filter_map`, so a scalar operand that fails to lower simply has no row (10084-10108). `subslice_endpoints` does the same for an endpoint whose `lower` returns `None` (11487-11488), which makes a failed endpoint look the same as an omitted one; the header says an omitted endpoint means "zero and the source length are supplied by the range's consumer" (11431-11432). Cannot tell whether the consumer compares against the authored range.
- **Skipped constraints.** In `lower_callable_parameter_range_requirements`, a declared domain that is not an exact integer interval hits `continue` with no slot pushed (8283-8285); `ArithmeticDomain` and `Named` constraints are not looked at (8247-8291). A value domain on a non-primitive parameter pushes a `None` slot (8253-8267).
- **Skipped statements.** `unit_scalar_context` skips every non-local statement and every non-primitive local it cannot read (9050-9059), and does not refuse mutable locals; they become `StorageRead`s later (9433-9441).
- **Custody skipped on lookup failure.** `requires_custody` treats a cast whose operand type cannot be found as needing no custody (`is_some_and`, 10226-10227). Cannot tell whether another check catches it.
- **Sealed float operators.** A float comparison is lowered as an IEEE comparison before the `operator_is_builtin` gate (7875-7885), on `has_builtin_or_sealed_float_comparison_meaning` (8101-8107).
- **Trusting declared types.** `readable_type`, `contract_storage_root`, `exclusive_reference` and `storage_observation_is_frozen` decide access and immutability from declared type shape and `is_mutable` flags alone (6375-6399, 7986-8007, 10921-10934, 10942-11011). Comments defer liveness: "Access and live custody are independently checked when that read is lowered" (6355-6358); "Case validity remains the ordinary contract checker's obligation" (10723).
- **Fail-closed cases, for balance.** `storage_observation_is_frozen` returns `false` on every failed lookup (10967-10987). Integer roster voiding (8324-8328). Most `_ =>` arms return `None` (5863, 7473, 7974, 8739, 9525, 9882, 10681, 11337).

## Surprises

- **This slice is a translator, not a checker, and it says so.** Against property 1 in the strict sense: nothing here accepts a program. But the translator's output carries acceptance-like marks (`formation_decided: true` at 9682, `trap_free`/`formation_decided` at 9521-9522, `Constant(true)` at 7037 and 7706) that later stages may read as settled. No proof kernel object is produced or consulted.
- **Unreachable match arm.** In `readable_entry_parameter_path`, the arm at 10757-10764 (reference, `Referent` step, access not write-only) can never run: the arm at 10752-10756 already matches every reference whose access is not write-only. The intent appears to be "stop at a reference when the next step is `Referent`", but the code always peels through.
- **Partly dead arm in `boolean`.** For `Member` and `Indexed`, the arm at 7830-7841 can only return `None`: the block at 7819-7827 already tried `structural_observation`, which begins with the same `logical_saved_observation` call (7085). Only `SavedSubject` reaches it usefully. The arm also calls `logical_saved_observation` twice (7833, 7836).
- **Comment and code disagree on floating ranges.** The struct comments describe `FloatRange` clauses "carrying their IEEE endpoints verbatim" and a float roster that becomes `None` when incomplete (8173-8186, 8197-8201). The only producer in the slice never pushes a `FloatRange` clause and never touches `float_entry_ranges` after initialising it to `Some(Vec::new())` (8226-8298). A consumer following the comment would read "complete roster, no float ranges".
- **"One slot per authored constraint" does not hold.** The comment at 8166-8168 promises a slot per constraint; the `continue` at 8283-8285 and the unhandled constraint kinds push none, so slot index does not equal constraint index for parameters with declared non-interval domains.
- **Depth reset.** `boolean` calls `numeric_term(operand, 0)` (7874), restarting the depth count, and does so for both operands of every binary before it knows the operator, including `&&` and `||`. `numeric_term` spends no budget. The 64-deep cap inside `numeric_term` still bounds it.
- **Hard-coded `u64` contexts.** Selector literals inside a predicate read land as `U64` (6807, 7067); the type reference for a length is found by scanning all named type references for the first whose symbol is the builtin `u64` atom (7442-7448), and the Bool type the same way (7566-7573). If no such reference exists in the program, lowering fails.
- **Three meanings of "builtin operator".** Contract integer comparison accepts only `BuiltinFallback` (8023); index and range accept `Missing` or `BuiltinFallback` plus zero candidates and no selected symbol (10441-10449, 11469-11477); anonymous landing uses `BuiltinFallback` or a validation query (9196-9201). The same source operator can be builtin under one test and not another.
- **Text-only parameter match.** 5734-5758 can lower a name as a parameter read when only the spelling matches and the symbol does not. A shadowing name with the same text would be read as the parameter. Whether name resolution makes this impossible cannot be told from here.
- **Subtraction special case.** `construct_integer_binary` returns `None` for `literal - x` when the left literal is still untyped and is not zero (9572-9575), although the next statement would land any untyped left literal at the peer's carrier (9576-9582). Callers usually land the left operand first (9233-9244), so this may be unreachable in practice, but the function on its own refuses `5 - x` while accepting `5 + x`.
- **No unary minus.** `lower_scalar_expression` has an arm for bitwise not (9497-9503) and none for arithmetic negation. Negative values appear to arrive as landed literals or as `0 - x`.
- **Float casts are identity only.** A cast to F32/F64 lowers only if the operand already has that float type (9480-9484); integer-to-float and F32-to-F64 conversions are not expressible here.
- **Recast views allow integer/float reinterpretation.** Equal byte width is the only test (9941-9943), so `&u32 as &f32` and `&u8 as &bool` produce a `RepresentationView`. The Bool case is flagged in the comment as lacking native replay (9892-9893), and the Boolean-position path refuses non-Bool sources (10011-10013), so the two paths treat `u8`-as-`bool` differently.
- **Two prefix policies for the same job.** `lower_state_scalar_expression` refuses if any earlier statement is not an immutable initialised local (8919-8926); `unit_scalar_context` skips such statements (9050-9059). The result depends on which caller is used, not on the program.
- **"Entry state is the first state" is positional.** `program.machine_states(machine).first()` is used as the entry at 5880, 6104, 6773, 6877, 8207.
- **Direct indexing that would panic.** `declared_data_member` (10289-10290) and `whole_local_binding` (11414-11417) index tables with positions from lookup tables without bounds checks.
- **Owner discovery by symbol parent.** When a parameter list is not a state's, `indexed_read_has_builtin_meaning` infers the owning scope from the symbol-table parent of the first parameter and requires all parameters to share it (10473-10502).
- **Equality of enum values is lowered as case membership.** For `==` where validation does not report exact membership, the code still produces `StructuralCaseMembership` when the data type has no fields and the variant no payload (5910-5921).
- **Failed endpoint equals omitted endpoint.** See 11487-11488 against 11431-11432 above; this is the item in the slice most likely to hide a wrong bound if the consumer does not cross-check.
- **Capabilities not expected in a "scalar" file:** predicate inlining with argument substitution (6764-6829), unbounded-integer ("integer math") comparison terms (7477-7557), prepared mathematical applications (7783-7795), byte-sequence predicates (7843-7854), erased-parameter lanes (6281-6353), and implementation selection by cast (9469-9479).
