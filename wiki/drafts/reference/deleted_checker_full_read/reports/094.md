## What this code is for
This slice is the middle of the "write frames" machinery of the old call checker. For every machine state it computes, as plain Rust `Option` results, (a) which caller-visible places a call may write (`written: Vec<String>`), and (b) which storage place each returned or stored reference points at (an "origin"), so a caller can know what a callee's returned reference or stored reference borrows. It walks each state's statements in order, keeping a prefix of aliases (name-keyed), "divergent" alias sets, and "stored" reference-slot records per local (calls.rs:27678-28529). It then solves, over the graph of named state transitions, a set of equations: which parameters a result can come from (27199-25830), which reference slots a state fills at its exits (29165-29680), and what the instantiation at a call site is (29682-30069). Everything answers "known exactly" (Some) or "refuse" (None). The slice contains no diagnostic text of its own; refusal is `None`, and the reason is mostly only printed to stderr under trace flags. No call to the proof kernel appears anywhere in the 7,941 lines. No tests are in the slice.

## Mechanisms
- **Statement prefix walk** (27678-28529). One function (~850 lines) serving four query kinds: `None`, `Complete`, `OriginTransfer`, `StatementPrefixes` (27473-27477), plus an optional "assignment roster" mode. It walks `admitted_execution_order`, snapshotting `CollectedStatementPrefix` (27483-27490) before each statement. Serves: write-summary of calls and stored-reference transfer. No budget; recursion guards via `inference.active_states`.
- **Prefix cache** (27583-27637): `Mutex<HashMap<(machine, state, include_shared), Option<Arc<Vec<...>>>>>`. A failed build is cached too (27633, `or_insert(built)` with `built` possibly None).
- **Result reachability fixpoint** (25229-25601): repeats until nothing changes (25237-25252), over (state, boolean-argument-values) queries, with `active`/`visited` flags to cut cycles and an optimistic start of `Some(vec![])` roots. A `(Some, None)` merge sets roots to `None` (unknown). Uses `BoolTruth` and `ParameterValues` to fold guards `when ...` so statically false transitions do not contribute (25395-25440). Serves: which parameters can reach a call result.
- **State-equation solver** (25602-25830, 26382-26594): discovers states by worklist along named-transition edges, builds one `Equation` per state, then `propagate` (25778-25813), a queue-based fixpoint that pushes each state's relation back along edges until `same_relation`. Run twice: first only for `moves`, then full, checking moves introduced are contained in the first pass (25764-25773). No iteration cap.
- **Finite substitutions** (25946-26154, also 29452-29491): demand-driven set of (state, parameter) pairs; builds a `cycle_substitutions::Substitutions` and requires `is_finite()` to guarantee instantiation terminates through cycles. Serves recursion/mutual recursion among states.
- **Slot-exit fixpoint** (29208-29450): collects exits per state, iterates `loop { ... if !changed break }` accumulating `SlotEffect`s monotonically (adding sources, setting `incoming`); refines inventory with leaves found at exits (29358-29400). No cap. Cache `inference.cached_slot_effects`/`retain_slot_effects` (29179-29189).
- **Destination inventory DFS** (28875-29033): explicit stack walk of parameter types through exclusive references; `visited` vector refuses cycles (28912).
- **Type-parameter scan** `mentioned_type_parameters` (29118-29160): has the only explicit budget in the slice: `remaining = type_reference_count` decremented per step (29125-29134).
- **Read projection cursor walk** (22671-22781): cuts a source path at each reference crossing, then verifies each cut loads an independent descriptor (`complete_spans`).
- **Instantiation of relative origins at call sites** (27048-27197, 29690-29805, 29872-30054): maps callee-relative parameter places to caller actual places; includes a pending-stack expansion through exclusive references (29932-30052).

## Surprises
- The slice has no use of the proof kernel and no diagnostics; "acceptance" is that a function returns `Some`. Reasons for refusal are `None` with optional stderr traces behind flags (`struct_trace`, `check_sites`, `trace_installed_context`: 22867, 25108, 29222).
- Standard-library and toolchain special cases are hard coded inside the generic result-origin logic: access-view lifecycle machines with exactly `[storage, _profile]` parameters (24974), activation-storage `BorrowBytes` (25033), installed interrupt context (25077-25140, literal path 25128), and a refusal for "core vector surface" states (27688).
- One function `walk_state_write_prefix_body` (27678-28529) has four query modes, a roster mode, and booleans (`include_shared`, `origin_transfer_only`, `queried_assignment`, `summarizes_writes`, `cleanup_complete`) that change what it returns. `StatementPrefixes` mode returns `None` on purpose at the last statement (27773-27777) and `collect_state_write_prefixes` discards the result (27565-27576). The final `then_some` (28516-28528) returns Some only for `None`/`Complete`/`OriginTransfer`.
- Quadratic copying: `CollectedStatementPrefix` (three Vecs of Strings/origins plus `stored`) is cloned for every statement (27764-27771) and again for every `statement_effects` call (27902-27909).
- Negative cache: a failed prefix build is stored in the cache and returned forever for that `(machine, state, include_shared)` (27633).
- `validate_declaration_source_projection` takes an unused `_machine` and only forwards to `read_projection::validate_address` (24255-24264); `validate_operand_selectors` is a one-line wrapper (23159-23165); `destination_source` (29855) is exported though the slice shows no user.
- Code formatting breaks (e.g. `root: { parameter.symbol }` at 25977, 25995; misindented closures at 26109-26134, 26665-26677) suggest generated or pasted code.
- `reachable_value_parameters` starts every new query with `roots: Some(Vec::new())` and widens; combined with `active` returning current roots, recursion is handled as a least fixpoint, but `retain_reachable_sources` treats `None` as "keep everything" (25253), so imprecision is conservative.
- `propagate` (25778-25813) rescans every equation's edges per pending item, with no iteration cap; the slot fixpoint (29298-29448) also has none. The only counted budget is in `mentioned_type_parameters` (29125).
- The bool `builtin_coordinates` is carried on places and merged with `&=` (24594, 24609), and tested at about 20 sites as a gate (e.g. 22577, 23909, 23953, 29460, 29549).
- `unknown_readonly_origin` constructs an origin whose `path` is the local's name and whose `source` is default (23245-23249): a place identified by text with no symbolic source.
