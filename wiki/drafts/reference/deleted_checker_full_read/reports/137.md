## Mechanisms
- Digest-keyed memo for portable productions (13746-13946): `PortableProductions::produce` finds an entry by `ProductionKey::matches` (13791-13798): `Arc::ptr_eq` on the `CheckedTrees` plus equality of entry symbol, machine roots, boundary roots, toolchain source digests and optimization selections; `Arc<OnceLock<Production>>` ensures one production per key even under threads. Linear scan over a `Vec` under a `Mutex` (13826-13838). `TerminalMachineSelection::Name` or other selections produce no key and are never shared (13776-13780, test 13926-13944). Serves invocation-shared portable Terminal production.
- Library-slice key (14070-14176): a domain-separated digest (`omega-library-slice-v1\0`, 14087) over sorted per-file records (package digest, relative path with `\\` replaced by `/` at 14216, toolchain identity digest, scope, stratum, content hash), the completion admission, layout scopes with target facts, entry declaration paths, provider selections, opaque-representation commitments, asm authority and wire demands. Slice membership: toolchain file, or file whose package identity differs from the root package (14178-14183).
- On-disk checked slice (14404-14724): record = magic + key + length + payload + payload digest; limits 256 MiB bytes / 1 GiB allocation / 64 Mi elements / depth 512 (14427-14432); encoded "beside" the invocation source map with type identities renumbered canonically (14635-14643) so equal programs encode equal bytes. Not saved if the result holds a second source map (14615-14618). Store is a trait `CheckedSliceStore` (14436-14441) implemented by the host.
- Whole-program reuse (15180-15245): scan `previous` retained checks for one that matches layout evaluation and preparation admission, else matches the prepared input; hit counters `WHOLE_PROGRAM_REUSE_HITS`, `RETAINED_LAYOUT_MATCH_HITS`, `CHECKED_SLICE_LOADS/SAVES` as `AtomicU64` statics (14906-14941).
- Product-selection memo `ProductSelections` (15336-15416): vector of (input `Arc` ptr, roots, output) searched linearly with `Arc::ptr_eq`.
- No fixpoint, unification, interval analysis or search with a budget appears in the deleted lines of this slice.
