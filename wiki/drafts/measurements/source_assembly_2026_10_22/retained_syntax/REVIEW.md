# Retained syntax ownership review

Scope: the source/token/syntax ownership boundary and every affected consumer. This is a storage change; language semantics, source authority, diagnostics and runtime oracles remain fixed.

- Authored names retain a generational source-page handle plus the original full-width SourceSpan. Explicit owner access replaces contextless Deref/Display/equality. Zero remains absent; no raw pointer, global text registry or RefCell is introduced.
- Source pages are contiguous forest-owned records. Clone retains each page once; adoption moves page ownership. Cross-forest copy retains page ownership before copying any handle. Independently parsed forests may reuse SourceId without aliasing their backing pages.
- Speculative parser forests register the same retained source once. Parser Input borrows that owner; advancing/restarting cursors preserve it and the existing depth/split-token rules. Floating-point spellings still retain SourceText ownership separately.
- Generated/composed names own their actual spelling, independently of diagnostic coordinates. Consuming a generated name moves its Box bytes into String; explicit clones copy them. These allocations are included in the end-to-end comparison.
- Decoded literal views share the lexer buffer and range. Copy-on-write protects existing views if a public TokenStream is later appended to. Non-UTF8 and empty literals preserve their bytes. A view may retain the entire source-local decoded buffer; requested allocation measurements are not RSS.
- Logical syntax equality is owner-contextual and spelling-based as before. The derive walks every field and variant; arena comparison preserves vacant rows, dummy rows, generations and occupancy metadata. SyntaxTrees and DeferredResolvedFrontier destructure all fields so adding a field requires updating their equality. Build continuation comparison does not substitute root snapshots or handle identity for complete syntax equality.
- Public snapshots and logical Debug observations are compared across every parser input. The measurement adapter resolves source-backed names through the real owner and removes only the newly introduced owner metadata field; production comparison never formats Debug strings.
- Namespace collections keep their path buffers private. Their record_module/record_import methods retain the source pages together with the copied paths, so early constant selection and final resolution use the same ownership boundary. The corpus exposed the missing early-registration capture; its original panic is archived and a focused regression covers the early selection route.
- Existing fixtures/oracles remain unchanged. Focused tests exercise copy/clone/drop, independent source identities, generated spelling, detached-node equality and literal view lifetime/COW. Full assembly output digests include source maps, scoped bindings and generated-source custody.

The validation records beside the final report bind this review to the production source hashes and integrated base. No independent reviewer is claimed.
