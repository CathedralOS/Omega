## Precisely what work is avoided

The actual owner is `psi/compilation/pipeline/06_lowered-psi-to-lowered-psi/src/copy_propagation/{mod.rs,copies.rs}`.

- It inventories every ordinary incoming `Jump`/`Conditional` scalar argument list, keyed by target block and parameter position. Structural-case payload targets remain excluded.
- It resolves parameter-copy chains transitively. A parameter collapses only when all inventoried incoming values resolve to one source. Differing values remain distinct; recursive resolution encountering a value already being visited returns that value rather than assuming equality through a cycle.
- The source and removed parameter must have identical scalar type **and qualifications**. This is not arbitrary arithmetic simplification, merging equal local register numbers, or guessing equality from provenance.
- It substitutes the resolved source through direct scalar operation/terminator uses, removes those parameter declarations, and removes the corresponding positions on **every** incoming ordinary edge via `edge_arguments.rs::drop_removed_positions_across_edges`.
- It retains identities named by propositions, contracts, crash/erased continuations, source-call frontiers, recorded module sidecars and invariant predicates. `retained_identities/ranked_coverage.rs` freezes covered ranked component parameter tables and member uses; regions outside that coverage may still collapse. These fences constrain applicability; the measured result does not prove arbitrary loops or proof-named parameters can be erased.

This removes redundant *transport obligations* before selected registers exist. Stage 03 `selection/construction/scalar_graph.rs:243–263` creates registers for required block parameters. `selection/edge_transfers/construction.rs:73–83,194–293` emits scalar snapshot/transfer copies for active bindings and hands transfer registers to destination parameters. Fewer actual parameter/argument positions can therefore avoid those register/copy rows, live-edge home components and subsequent analyses, not merely erase a final machine move.

With fewer redundant carriers, the existing allocator has fewer pressure victims to spill. Each avoided recovery step also avoids its source-bound spill derivation, exact use/definition and storage-window scans, COW mutation, inserted frame-address/load/store rows, identity sealing and later reanalysis/frame/encoding work. This does not claim every removed parameter was itself a victim or that victim count predicts elapsed time linearly. Precise removed-parameter and copy counts were not established by the aggregate screen.

The source rule does not delete the arithmetic/checking performed by stack32 or change the authored program/helper bytes. It changes how already-established scalar values cross intermediate blocks. Final PSI/native behavior, reject obligations and resource checks still need the current qualification evidence; this mechanism explanation is not an independent semantic approval.
