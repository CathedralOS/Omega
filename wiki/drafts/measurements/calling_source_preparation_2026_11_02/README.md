# One-time Calling preparation

This increment removes per-target Calling Source preparation. It does not close
all provider settlement or the Cathedral boot goal.

## Ownership change

The shared Product publication's existing once-only owner now captures original
Calling request/review correspondence and inert target helper candidates beside
the Terminal artifact. Target preparation takes only the profile, current
package authority and retained Calling catalog. It no longer receives checked
trees, a Source service catalog, opaque Source selections or provider inputs.
The previous per-target Source walk is removed, not wrapped.

Canonical requests and the flattened ABI roster drive target preparation. The
companion retains independently formed full Source ABI keys, original lifetime
subjects, deferred errors and a weak owner association, never a strong Source
owner. Descriptive target membership uses canonical proof metadata without
granting Product selection or requiring executable availability early. Helper
selection still uses the ordinary canonical selector over the union of policy
invocation roots. Eight native profiles retain independently derived candidates;
Alpha's unsupported result remains inert until requested. Actual requester and
live package authority remain admission inputs.
