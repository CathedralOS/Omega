# L4 Preparation

Preparation computes local integer constant values and the integers used in closed type identities. If the selected `width` adds one, `const SIZE:u8 = width(7)` freezes at 8. Both `Buffer<SIZE>` and `Buffer<width(7)>` then have the same identity as `Buffer<8>`. Changing the body to add two changes both computed indices to 9. [Static identities](../../wiki/spec/language/evaluation.md#canonical-static-identities) · [Constant and index tests](tests/integer_constants.rs)

`prepare_source_package` drives typing of one admitted package. For a pending integer computation, L3 identifies the expression node, result carrier, selected machine, actual operands and any closed specialization arguments. L4 checks whether it supports that invocation, evaluates it, and returns the value for that request. L3 then rechecks the original resolved package. `PreparedTrees` is returned only when strict typing has accepted the resulting identities. Open generic templates still describe computations for future specializations. [Preparation entry point](src/lib.rs) · [Typed handoff](../03_symbol-resolved-trees-to-typed-trees/src/typing/typing_progress.rs)

L3 supplies each constant’s typed initializer, its numeric landings, and the declaration selected at each constant reference. L4 follows those references, including forward references, and refuses cycles. Preparation checks local integer initializers even when no type mentions them. A consumer can read a frozen value by declaration using `PreparedTrees::integer_constant`. [Constant evaluation](src/integer_constants.rs)

The evaluator handles plain signed and unsigned integer carriers 1 through 128 bits wide, exact numeric landings, and local direct calls with a single return expression. It evaluates addition, subtraction and multiplication using the primitive and overflow policy that L3 selected at each node. Exact results must fit, wrapping reduces modulo the carrier width’s power of two, and saturation clamps to the carrier’s endpoints. For example, on `i8`, `(n +% 1) -| 1` yields −128 at `n = 127`. Using exact `+` refuses the intermediate 128 before subtraction. [Integer arithmetic](src/integer_arithmetic.rs) · [Numeric specification](../../wiki/spec/language/numeric_values.md#overflow-policies)

A closed call may also take the enclosing machine’s single specialized integer parameter. General proof-backed invocation admission, target-dependent evaluation, other carriers and operations, and freezing the entire stage remain open. [Evaluator](src/integer_invocation.rs) · [Invocation admission](../../wiki/spec/language/evaluation.md#invocation-admission)

Run `omega source prepare <files>` from the package root. The command reports an evaluation or typing refusal with the source location. Successful preparation exits silently.
