# L5 Lowering

L5 turns an L4 prepared package into target-neutral Psi machine bodies and the declarations those bodies use. L4 supplies the selected declaration, operand occurrences, frozen constants and closed signature types. L5 assigns identities to machines, types, blocks, operations, values, places and edges. The lowered-form checker owns the verdict about the resulting program. [Psi product](../../../wiki/spec/terminal-psi/product.md) · [Control flow](../../../wiki/spec/terminal-psi/control_flow.md)

Consumers import `omega-psi` to inspect the owned package. Preparation and Psi replay use the same selected-target contract with their respective subject types. Replay reads a receiver built from independent target selections and compares each saved observation, including the selected plan. The consumer fixture builds against Psi alone. [Product manifest](../../representations/psi/Cargo.toml) · [Target contract](../../contracts/target/src/lib.rs) · [Consumer manifest](tests/psi-consumer/Cargo.toml)

A wholly anonymous numeric comparison supplies one prepared Boolean. A machine body emits a Boolean constant, and a clause retains a Boolean predicate step even when it is false. [Lowering and clause reader tests](tests/ieee_predicates.rs)

## First handoff

The initial implementation lowers single-block machines with a unit return, a scalar constant or parameter return, or a fixed array returned by value from a parameter. The type table records the exact signedness and width of each integer and the element type and count at each array dimension. An absent result has no carrier. Machine declarations retain their source identities and effective contract ceilings. A machine’s public flag comes from its resolved export status. A nested helper stays private even when written with a public modifier. [Machine visibility test](tests/calls.rs) Typing supplies the published defaults. An omitted public crash clause and an explicit empty crash clause therefore produce the same ceiling. Numeric and Boolean constants define scalar values in the entry block. Recursive arrays of the supported scalars permit copying. Nothing in these types requires a target layout to lower. [Type table](../../representations/psi/src/types.rs) · [Entry blocks](src/machines/body.rs)

A quoted literal in an owned byte-array result uses the bytes published by typing. Direct and named literals establish the same byte values in the same order, including for an empty array. [Byte-array results](tests/array_values.rs)

An explicit discard of a supported copyable value preserves the operations that produce it, including their call requirements. The caller continues after those operations. [Discarded calls](tests/calls.rs)

A return carries the identity of its scalar value or structural source place. Two parameters of the same fixed-array type still have different places. For example, changing the body of `choose(a, b)` from `a` to `b` changes the source place on the return edge. Changing a static width instead changes the corresponding shape in the type table. The consumer can make both observations after the prepared trees and source text are dropped. [Handoff tests](tests/handoff.rs)

`omega source lower <package-relative files>` runs preparation and lowering and reports the first refusal with a source location. The Rust API returns the owned package. Its IDs are scoped to the produced package or machine. Artifact encoding, publication and execution are later consumers. [Source command](../../application/src/source.rs) · [Encoding](../../../wiki/spec/terminal-psi/encoding.md)

## Operations and declarations

A zero-initialized nominal local carries its selected record type into Psi. The establishment operation names its storage at the binding site. Discarding that local at return identifies the same storage. A `requires` clause on the record does not stop the local: the schema keeps the clause, and the checker judges the binding's `ZeroValue` obligation by evaluating that clause with every field zero, so `Nonzero` and `Small` lower alike. When L4 supplies a `ZeroField` obligation for an omitted scalar field, the constructor puts a zero of the selected carrier in that field's declared slot. Written initializers still execute in source order. An omitted field whose type borrows one referent, such as `@u8`, makes the literal invalid because `..` supplies no borrowed reference, and lowering rejects it at the literal. [Explicit field omission](../../../wiki/spec/language/data_and_literals.md#explicit-field-omission) [Omitted field handoff](tests/formation_handoff.rs) [Zero-value handoff](tests/obligation_outputs.rs)

An executable record or case constructor owes every `requires` clause of its structural result's nominal data schema. At that operation, `self` is the value formed by the selected case (if any) and the complete, declaration-ordered field operands, including any scalar zero supplied for an omitted field. A zero operand does not discharge a clause about that field. L6 checks the clauses under this substitution; an `EstablishRecord` or `EstablishCase` operation in unchecked Psi is not a validity verdict. This handoff does not establish frozen constants or admit omitted reference fields without backing storage. [Formation inputs and Psi](tests/formation_handoff.rs) · [Record construction](tests/nominal_construction.rs)

A folded integer such as `-1` or `1 - 2` supplies its typed value to both executable comparisons and contract predicates. A negated runtime operand still emits the arithmetic operation and its proof obligation. A folded value with a fractional intermediate, such as `((5 / 2) * 2) as u32`, lowers only through the landing that typing checked; the explicit cast lands it as the constant 5. [Acknowledged landing](tests/arithmetic.rs) · [Literal landing](../../../wiki/spec/language/numeric_values.md#fractional-intermediate-diagnostics)

The current product also represents ordered integer operations, exact numeric casts, Boolean branches and joins, local scalar assignments, and ordinary and terminal direct calls. A terminal call forwards completion. An ordinary call can produce a scalar or a fresh structural result place, or return unit. Scalar requirements and guarantees refer to the formal parameter or result. Each call identifies the requirements its actual operands must establish. In a scalar predicate on a supported machine, domain, record or callable alias, a direct machine application retains its selected declaration, ordered arguments, result carrier and callee requirement indices at the authored call. The enclosing declaration owns the clause; an alias clause has no calling machine and its formals are the callable's own. The helper must have an empty crash row in L3's effects: an authored `crashes none`, or a private body without a crash clause whose operations and calls L3 finds route-free. Psi keeps the helper's authored ceiling, so the checker still owes its total denotation. The progress obligation identifies either a published promise or the body of an inspectable private helper. [Predicate calls](tests/predicate_call_handoff.rs) and [private progress](tests/private_predicate_progress.rs). A fixed-array read carries the root place, ordered selectors and a separate bounds obligation at each dimension. A contract path keeps each frozen fixed-array index exactly, even past the declared extent. The checker compares it with the extent in the formal's type. Canonical `f32` and `f64` operators lower to one `Float` operation that names the selected IEEE operation and its nearest-even contract. Its operands keep their source order and supply the format, and a comparison produces a Boolean. Lowering selects no realization: the selected target's realization table supplies one later, and a target that cannot realize an operation refuses the program there. An anonymous number that typing landed in a float format reaches Psi as the exact bits that preparation published, rounded once to nearest with ties to even. A frozen float constant keeps its bits; a NaN that preparation computed without exact bits is not materialized. A value-level cast between integer and float carriers, or between the two formats, is the same exact numeric cast as an integer cast and keeps the denoted value. The checker must prove that value representable in the result carrier. Such a cast is not a bit reinterpretation: `@bits as @f32` remains a recast view. [Floats](tests/floats.rs) · [Psi-only reader](tests/psi-consumer/src/floats.rs) · [Floating formats](../../../wiki/spec/language/numeric_values.md#floating-formats-and-operations) · [Carrier casts](../../../wiki/spec/language/domains.md#carrier-casts)

An IEEE comparison in a requirement, guarantee, crash guard or domain predicate is a typed proposition, not an executable operation. It consumes its two terms and names the format and one canonical kind: `Equal`, `NotEqual`, `LessThan` or `LessOrEqual`. `a > b` and `a >= b` read their operands in reverse, so they state the same proposition as `b < a` and `b <= a`; `!=` keeps `NotEqual`, and `!(a < b)` stays a Boolean negation of `LessThan`. A term is an unqualified float formal, `result`, `self`, a float field of a record subject, a frozen float constant, or the exact bits that preparation landed for a literal or anonymous number. Integer order laws and mathematical or `FloatMeaning` equality do not apply to these propositions. A user-selected operator remains a call, which a contract predicate refuses, and never becomes an IEEE comparison. The checker judges each proposition; lowering keeps a false premise or a broken guarantee exactly as written. [IEEE predicates](tests/ieee_predicates.rs) · [Psi-only reader](tests/psi-consumer/src/ieee_predicates.rs) · [IEEE comparison kinds](../../../wiki/spec/terminal-psi/encoding.md#ieee-comparison-kinds)

A runtime fixed-array read in a predicate consumes the receiver term and the `u64` selector term in order. It names the selected core read declaration and its occurrence. The checker must instantiate that declaration's requirements, including the bound against this receiver's fixed extent, before using the element. For `check(a[i])`, the element supplies the actual for `check`; the helper's own premises do not replace the read obligation. Literal and frozen in-bounds selectors still have exact fixed-index path segments. This form does not describe a live slice, authorize an owned move, or establish that a bound holds. [Array predicates](tests/structural_contracts.rs) · [Predicate arguments](tests/predicate_call_handoff.rs)

A shared byte view (`@[u8]`) is a descriptor for borrowed storage. Its length is a runtime observation. A byte read names the descriptor, its measured length, the index and the bounds obligation. A length in an entry contract refers to the exact formal it measures. The checker decides whether those premises establish the bound. [Byte views](../../../wiki/spec/terminal-psi/byte_views.md) · [View identity tests](tests/access.rs)

Fixed-array literals establish their elements once in source order. Frozen array constants use the same construction operations with the element values supplied by preparation. Reading a whole row copies it into a fresh place. The copy carries the source matrix, selectors and bounds obligations so a call or return can use the selected row. This covers fixed arrays of Booleans and fixed-width integers at any dimension. [Array construction and reads](tests/access.rs)

Binding or reassigning one of these arrays copies the whole value into a fresh place. A Boolean match used inside another expression sends the selected array to a structural parameter of the join block. A fixed array's length comes from its type. An executable length expression evaluates the receiver first, and a contract length expression retains the subject whose extent the checker must read. [Array value handoffs](tests/array_values.rs)

Record and sum declarations retain their field and case identities, order, multiplicity and carry restrictions. Each numbered record, sum or case payload carries its own stable numbers in canonical numeric order, their positions in the authored member list, and its retired numbers. [Numbering rules](../../../wiki/spec/layouts/plans.md) · [Schema handoff](tests/declarations.rs) Each supported default-domain `requires` clause stays on the data declaration. The checker decides whether a value satisfies the predicate when the value must be established. [Declarations](tests/declarations.rs) · [Default domains](../../../wiki/spec/language/data_and_literals.md#the-uninhabited-type-never)

A plain type-path alias retains its authored identity, site, visibility and direct target so a consumer can follow its expansion chain. A field that uses the alias carries the underlying type. At suspension the checker can follow a retained record through such a field to the selected nominal schema and its carry axes, even when another schema has identical fields. An unused fixed-array alias retains its complete shape in the package type table, including an extent computed during preparation. [Alias handoff](tests/declarations.rs)

A transparent alias with an explicit multiplicity assertion retains the checked `copy` or `linear` request alongside its target. An unmarked alias has no assertion. Its expansion supplies the ownership identity. The [alias rule](../../../wiki/spec/language/generics.md#transparent-type-aliases) makes the alias the same type as its expansion, so L3 refuses a carry list that adds a demand the expansion lacks: an alias of `u64` cannot forbid suspension. Any other carry list on the alias itself still stops at its attributes, for example one that repeats `u64`'s or its nominal target's exact policy. The [carry rule](../../../wiki/spec/resources/carry.md) composes a floor on ordinary data but does not say whether an alias may author a list that adds no demand. L5 neither installs the alias's floor on the shared carrier nor silently drops it. [Alias comparisons](tests/declarations.rs) [Owner question on carry declarations on aliases](../../../OWNER_QUESTIONS.md#transparent-alias-carry-assertions)

A plain named domain on a Boolean or fixed-width integer retains its declaration identity, visibility, source site, typed carrier and authored predicate. Two domains can share a carrier and predicate and still name different qualifications. An empty tag carries no predicate. A contradictory predicate stays attached to its declaration so the checker can judge it when a value must establish that qualification. A transparent alias on a supported scalar carrier retains the canonical set of constituent declaration identities. Nested aliases expand and repeated constituents appear once. A domain such as `AtMost<const Capacity: u64>` retains its binder and its predicate on `self`. A data template can refer to that exact domain application in a binder equation. An indexed scalar alias retains each constituent's arguments, including the owner of a forwarded binder. An inherited scalar domain names its qualified parent as its subject and keeps its own predicate. In a domain or machine predicate, a cast that only keeps or removes domains on the same carrier reads its operand's value, so the child's `(self as -Positive) < 100` compares its own subject and a guarantee can read a qualified formal through `-D`. Forwarding an already qualified scalar carries its domain declarations and their ordered static arguments from the formal to the result. Its entry requirement and result guarantee state each domain predicate with every index replaced by the application's closed argument: a formal in `Bound<5>` of `Bound<N> requires self > N` owes `x > 5`. Creating that membership by a cast requires a separate establishment obligation. [Qualification handoff](tests/domain_qualification_handoff.rs) A domain test in a contract, such as `requires volume in u8::Audible`, names the tested subject and the domain application. Like a case test, it states a fact and leaves the subject's declared type unchanged. [Domain tests in contracts](tests/published_audible.rs) Access policies, cleanup and general runtime qualification changes still require lowering. [Domain handoff tests](tests/domains.rs) · [Domain semantics](../../../wiki/spec/language/domains.md)

Only the explicit spelling writes `routes`, as the declared `[CallableInfo<'t>]` with no elements. A folded target observation retains the exact selected plan or property and can be replayed against a receiving target. Reference layout observations preserve the referent's integer signedness even when the two reference descriptors have identical geometry. [Target-dependent values](tests/target.rs)

A subjectless `match` or `transition` tests Boolean guards in source order. Each false edge reaches the next test or the final unconditional arm. A terminal call forwards completion, and a Unit-valued match used as a statement rejoins before the next statement. A lowered operator machine retains the checked token, its site, effective visibility and exact selected home. Root operators have no home declaration. A scalar parameter qualified by local route-free domains carries their identities in its Psi type. Each predicate on a scalar formal becomes an entry requirement for that parameter. Each predicate on a scalar result becomes a guarantee about that result. Calls reference the callee’s entry requirements by clause index. Returning an existing parameter forwards that same value and its qualifications. A fixed array retains each plain, non-generic, route-free scalar domain on its element type, whether or not the domain has predicates. An indexed read forwards that complete element type and records a bounds obligation for its selector; it does not establish a new membership. The predicate remains on the element's domain declaration, not on the whole array. L6 checks incoming memberships, the bound and the scalar result guarantee. Named calls and selected operator calls forward these qualified values through parameters, local bindings, joins and results. An explicit scalar cast that adds local predicate-free tags or erases local route-free scalar domains carries the change on a successor edge. Its argument identifies the source value and its destination is a fresh block parameter of the new qualified type. The edge retains the cast site. When the cast also changes integer width, the exact conversion produces a bare value before the qualification edge. Keeping the same domains forwards the existing value. A predicate-bearing scalar cast that introduces unrestricted base predicate domains uses completions on its jump instead of an ordinary tag change. Each completion identifies the argument ordinal, one added domain atom and that atom's origin: proved for a predicate domain, vacuous for a predicate-free tag added in the same cast. The atom is the destination type's own, with its ordered closed arguments, so for `Five = Above<5>` the row names `Above` with `5` and `Above<6>` is a different row. Every added atom has exactly one completion, in destination order. The fresh destination block parameter binds `self`, and each index binder to the atom's argument, for all of each proved declaration's requirements in a block invariant; a vacuous tag owes nothing. Every arrival owes the invariant; neither the destination type nor the completion supplies a proof. L6 judges it. Completions with required parent memberships and issuer routes remain unsupported. A closed const-integer record retains the values of its enclosing and immediate binders, in declaration order. L3 publishes its field types after L4 answers the specialized requests. Reading `Outer<2>::Inner<4>` copies the selected field of the parameter at its own fixed extent; the two `u64` arguments are not interchangeable. The open declaration retains the selected static calls and the owner of each forwarded binder. [Field readers](tests/preparation_handoff_gaps.rs)

A recursive const-indexed field behind a shared reference names its exact applied referent without materializing every later schema. For `Link<3>` with `next:@Link<N+1>; value:u<N>`, Psi retains the exact addition and the positive-width question of the template, and the recursive formation question for `Link<4>` at the formal. Keeping `N` unchanged does not produce that recursive question. These are checker inputs, not evidence that every index admits another successor. A shared reference read out of a field points where the stored reference points, not into the record. `read(x:Link<3>)->@Link<4>{x.next}` borrows the referent of `x.next`, so the loan stored in `Link::next` is the parent. The returned descriptor has that field's own type, which names `Link<4>` without its layout. A plain `@Leaf` field and a `let` binding of the read lower the same way. Returning a stored exclusive reference by value from an owned record, as in `read(x:Node)->@mut Leaf{x.next}`, transfers the stored loan out of the field: `MoveStructural` of `x.next` defines the result and the return disposes only the remaining fields. An implicit `move`, a nested record and a local binding transfer the same way, and nothing copies the reference. Through a `@mut` parent, the by-value read is a `BorrowedMove` whose open window the checker refuses at return. An explicit `@mut` borrow, a write or a call operand below the stored reference instead reborrows its referent. L3 decides whether the source may make that borrow or write, taking authority from the exclusive references the path crosses rather than from a `mut` owner; L5 does not decide it again, and publishes the access and every crossed loan so that L6 can judge the lineage. A whole-value store below a stored reference is a store into borrowed storage even when the path starts at an owned field: it fills the vacancy a `BorrowedMove` left, or extracts the old value through the same loan and disposes it first, and never disposes lent content as the owner's. A stored `@write T` transfers, opens a window and reborrows the same way with its own access; L3 lets a write through it follow `@mut` crossings but no later crossing. [Borrowed storage](tests/borrowed_storage.rs) L6 judges whether each result may outlive `x`. Data templates retain field and case declarations, binder equations, lifetime and witness identities, and default predicates. In a closed constructor, typing supplies the actual field types. For example, constructing `Envelope<u32>::Body::Value` and `Envelope<bool>::Body::Value` selects the same field declaration, but each value needs its own concrete data type. When a machine reads a frozen record or sum constant, L5 uses the prepared field values in declaration order and establishes the selected case. An owned field transfer names its original root and field path. Calls, constructors and match joins carry transferred operands. A second transfer of storage already moved, or of its whole ancestor, keeps both transfers in source order, each at its own site, and normal cleanup disposes only storage that no transfer claimed. Match arms that move different fields reach their join with their own transfers and without disposing the remainder; lowering schedules cleanup after such a join from its first arrival. The lowered-form checker refuses both programs. A normal exit disposes surviving ownership in reverse declaration order. After a partial move it disposes remaining fields, including calls to their selected cleanup machines. An intact subject in its own cleanup body produces that same call edge for termination analysis. A consuming record pattern publishes each independent child and schedules cleanup for ignored children. A field move out of a value whose declaration selects a cleanup machine publishes the exact moved path and the live complement as residual cleanup, and no action invokes the selected cleanup on the partially moved subject. L6 owns the refusal of that partition, using the cleanup target retained on the declaration. Replacing owned storage disposes its old live contents at the captured destination or fills the matching vacancy. A linear value without a selected cleanup that dies on a normal edge receives the same discard as its affine twin, and its schema records the linear multiplicity. The checker must refuse that discard because the exit has no authorized disposition. A linear value whose contents need a cleanup call or loan restoration still requires disposition evidence at the edge. An owned sum match identifies the original discriminator on its successors. A payload move records the selected case, and its residual contains only fields of that case. For owned fixed arrays, a frozen ordinal identifies the transferred element. A move with a runtime selector is invalid: an owned extraction must name its unique element, and a claim path rejects dynamic indexes. L5 refuses that move at the selector. Cleanup visits the surviving elements in reverse establishment order, including after a nested projection. ## Handoffs and remaining work

A compiler caller can supply its selected target’s instruction catalog when resolving a package. Typing selects an executable instruction variant and preparation preserves that selection. In Psi, each assembly region binds its register initializers simultaneously. Instructions identify their explicit operands, the locations their selected semantics reads and writes, and selected control transfer. Each location keeps its catalog role, register or other target state, and its lifetime, region or persistent, as separate facts. A jump to a local assembly machine targets a block in the same callable. An authored fallthrough edge requires physical adjacency. [Assembly handoff](tests/assembly_handoff.rs) · [Instruction effects](../../../wiki/spec/language/assembly.md)

A machine with only region binders retains their ordinals separately from runtime specialization. For direct scalar or nominal references, each binder lists its annotated parameter slots and whether it annotates the result. At an explicit returned borrow the body binds the newly formed descriptor to the destination region. Its defining operation names the actual projected backing; L6 judges whether it meets the declared relation. This does not cover region arguments at calls, binding a reference into a stored field, or carrying that binding across suspension. [Machine region handoff](tests/obligation_ownership.rs)

Moving a field of an owned record produces a place for that field. Normal cleanup names the remaining fields and any selected cleanup machine. An exclusive borrowed field retains its original root and path through extraction and restoration. Replacing an intact affine field also records cleanup of the value it displaced. [Ownership tests](tests/ownership.rs) · [Loan tests](tests/loans.rs)

A local member call records the selected requirement, its supplying implementation and its substituted service arguments. For a fixed-width integer const binder, the member selection and the selected implementation body carry the same canonical integer and carrier in binder order. Calls at different integers select distinct instances of the same declaration. This does not establish refinement for all applications, or lower arbitrary open const expressions. ## Evidence for sign-off

The [handoff evidence](LOCK_EVIDENCE.md) identifies which changes to a prepared input the tests can distinguish in Psi, which valid programs still stop, and which typed obligations still need an individual trace.

For each source operation assigned to L5, identify the Psi records a consumer needs and inspect them after lowering through the ordinary package entry point. The deciding operands, declarations, paths, edge destinations and obligations must survive after the prepared trees are dropped. For example, two branch destinations can both be legal while only one runs the next guard on failure. A regression for that decision must catch exchanging the destinations. [L5 to L7 in the architecture plan](../../PLAN.md#l5-to-l7)

Account for every open lowering gap against the spec before sign-off. Record separately the programs that stop before L5 and the examples that only produce declarations. The corpus samples the language and cannot establish completeness by counting successes. Where a prerequisite is missing, identify the first handoff that lacks it and the concrete consumer that needs it. [Corpus evidence](tests/spec_corpus.rs)

The control-flow invariant walks the published edges from entry. Each emitted block must be reachable through those edges, and every emitted operation must belong to exactly one reachable block. Tests exercise missing, duplicated and unreachable operations. Each scalar or structural result points back to the operation that returns it. The sample harness checks every machine in a lowered package, including helpers outside the sample-specific witness. [Sample invariant](tests/sample_baseline.rs) The plan also requires accept and reject fixtures for each contract rule, recorded suite timing, decisions on spec gaps and owner sign-off.
