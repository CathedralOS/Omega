# L5 Lowering

L5 turns an L4 prepared package into target-neutral Psi machine bodies and the declarations those bodies use. L4 supplies the selected declaration, operand occurrences, frozen constants and closed signature types. L5 assigns identities to machines, types, blocks, operations, values, places and edges. The lowered-form checker owns the verdict about the resulting program. [Psi product](../../../wiki/spec/terminal-psi/product.md) · [Control flow](../../../wiki/spec/terminal-psi/control_flow.md)

Consumers import `omega-psi` to inspect the owned package. Preparation and Psi replay use the same selected-target contract with their respective subject types. Replay reads a receiver built from independent target selections and compares each saved observation, including the selected plan. The consumer fixture builds against Psi alone. ## First handoff

The initial implementation lowers single-block machines with a unit return, a scalar constant or parameter return, or a fixed array returned by value from a parameter. The type table records the exact signedness and width of each integer and the element type and count at each array dimension. An absent result has no carrier. Machine declarations retain their source identities and effective contract ceilings. A machine’s public flag comes from its resolved export status. A nested helper stays private even when written with a public modifier. [Machine visibility test](tests/calls.rs) Typing supplies the published defaults. An omitted public crash clause and an explicit empty crash clause therefore produce the same ceiling. Numeric and Boolean constants define scalar values in the entry block. Recursive arrays of the supported scalars permit copying. Nothing in these types requires a target layout to lower. [Type table](../../representations/psi/src/types.rs) · [Entry blocks](src/machines/body.rs)

A quoted literal in an owned byte-array result uses the bytes published by typing. Direct and named literals establish the same byte values in the same order, including for an empty array. [Byte-array results](tests/array_values.rs)

An explicit discard of a supported copyable value preserves the operations that produce it, including their call requirements. The caller continues after those operations. [Discarded calls](tests/calls.rs)

A return carries the identity of its scalar value or structural source place. Two parameters of the same fixed-array type still have different places. For example, changing the body of `choose(a, b)` from `a` to `b` changes the source place on the return edge. Changing a static width instead changes the corresponding shape in the type table. The consumer can make both observations after the prepared trees and source text are dropped. [Handoff tests](tests/handoff.rs)

`omega source lower <package-relative files>` runs preparation and lowering and reports the first refusal with a source location. The Rust API returns the owned package. Its IDs are scoped to the produced package or machine. Artifact encoding, publication and execution are later consumers. [Source command](../../application/src/source.rs) · [Encoding](../../../wiki/spec/terminal-psi/encoding.md)

## Operations and declarations

A zero-initialized nominal local carries its selected record type into Psi. The establishment operation names its storage at the binding site. Discarding that local at return identifies the same storage. When L4 supplies a `ZeroField` obligation for an omitted scalar field, the constructor puts a zero of the selected carrier in that field's declared slot. Written initializers still execute in source order. [Omitted field handoff](tests/formation_handoff.rs) [Zero-value handoff](tests/obligation_outputs.rs)

A folded integer such as `-1` or `1 - 2` supplies its typed value to both executable comparisons and contract predicates. A negated runtime operand still emits the arithmetic operation and its proof obligation.

The current product also represents ordered integer operations, exact integer casts, Boolean branches and joins, local scalar assignments, and ordinary and terminal direct calls. A terminal call forwards completion. An ordinary call can produce a scalar or a fresh structural result place, or return unit. Scalar requirements and guarantees refer to the formal parameter or result. Each call identifies the requirements its actual operands must establish. In a scalar predicate on a supported machine, domain or record, a direct machine application retains its selected declaration, ordered arguments, result carrier and callee requirement indices at the authored call. The enclosing declaration owns the clause. The progress obligation identifies either a published promise or the body of an inspectable private helper. [Predicate calls](tests/predicate_call_handoff.rs) and [private progress](tests/private_predicate_progress.rs). A fixed-array read carries the root place, ordered selectors and a separate bounds obligation at each dimension. [Arithmetic](tests/arithmetic.rs) · [Branches](tests/branches.rs) · [Calls](tests/calls.rs) · [Contracts](tests/contracts.rs) · [Array access](tests/access.rs)

A shared byte view (`@[u8]`) is a descriptor for borrowed storage. Its length is a runtime observation. A byte read names the descriptor, its measured length, the index and the bounds obligation. A length in an entry contract refers to the exact formal it measures. The checker decides whether those premises establish the bound. [Byte views](../../../wiki/spec/terminal-psi/byte_views.md) · [View identity tests](tests/access.rs)

Fixed-array literals establish their elements once in source order. Frozen array constants use the same construction operations with the element values supplied by preparation. Reading a whole row copies it into a fresh place. The copy carries the source matrix, selectors and bounds obligations so a call or return can use the selected row. This covers fixed arrays of Booleans and fixed-width integers at any dimension. [Array construction and reads](tests/access.rs)

Binding or reassigning one of these arrays copies the whole value into a fresh place. A Boolean match used inside another expression sends the selected array to a structural parameter of the join block. A fixed array's length comes from its type. An executable length expression evaluates the receiver first, and a contract length expression retains the subject whose extent the checker must read. [Array value handoffs](tests/array_values.rs)

Record and sum declarations retain their field and case identities, order, multiplicity and carry restrictions. Each numbered record, sum or case payload carries its own stable numbers in canonical numeric order, their positions in the authored member list, and its retired numbers. [Numbering rules](../../../wiki/spec/layouts/plans.md) · [Schema handoff](tests/declarations.rs) Each supported default-domain `requires` clause stays on the data declaration. For example, the schema for `Never` carries the predicate `false`, and a predicate on `self.flags.allowed` identifies both selected fields. The checker decides whether a value satisfies the predicate when the value must be established. [Declarations](tests/declarations.rs) · [Default domains](../../../wiki/spec/language/data_and_literals.md#the-uninhabited-type-never)

A plain type-path alias retains its authored identity, site, visibility and direct target so a consumer can follow its expansion chain. A field that uses the alias carries the underlying type. An unused fixed-array alias retains its complete shape in the package type table, including an extent computed during preparation. [Alias handoff](tests/declarations.rs)

A transparent alias with an explicit multiplicity assertion retains the checked `copy` or `linear` request alongside its target. An unmarked alias has no assertion. Its expansion supplies the ownership identity. An authored carry policy still stops at its attribute list. [Alias comparisons](tests/declarations.rs)

A plain named domain on a Boolean or fixed-width integer retains its declaration identity, visibility, source site, typed carrier and authored predicate. Two domains can share a carrier and predicate and still name different qualifications. An empty tag carries no predicate. A contradictory predicate stays attached to its declaration so the checker can judge it when a value must establish that qualification. A transparent alias on a supported scalar carrier retains the canonical set of constituent declaration identities. Nested aliases expand and repeated constituents appear once. A domain such as `AtMost<const Capacity: u64>` retains its binder and its predicate on `self`. A data template can refer to that exact domain application in a binder equation. An indexed scalar alias retains each constituent's arguments, including the owner of a forwarded binder. An inherited scalar domain names its qualified parent as its subject and keeps its own predicate. Forwarding an already qualified scalar carries its domain declarations and their ordered static arguments from the formal to the result. Creating that membership by a cast requires a separate establishment obligation. [Qualification handoff](tests/domain_qualification_handoff.rs) Access policies, cleanup and general runtime qualification changes still require lowering. [Domain handoff tests](tests/domains.rs) · [Domain semantics](../../../wiki/spec/language/domains.md)

A folded target observation retains the exact selected plan or property and can be replayed against a receiving target. Reference layout observations preserve the referent's integer signedness even when the two reference descriptors have identical geometry. [Target-dependent values](tests/target.rs)

A subjectless `match` or `transition` tests Boolean guards in source order. Each false edge reaches the next test or the final unconditional arm. A terminal call forwards completion, and a Unit-valued match used as a statement rejoins before the next statement. For fixed-width integer literal arms with a final wildcard, each comparison uses the same evaluated subject. A borrowed case pattern tests the discriminator before reading a payload field. A tag or literal mismatch continues to the next alternative. After both tests succeed, each use of an integer payload binding reads the selected field at that occurrence in the arm expression. [Pattern products](tests/pattern_dispatch_products.rs) [Dispatch tests](tests/branches.rs)

A lowered operator machine retains the checked token, its site, effective visibility and exact selected home. Root operators have no home declaration. A scalar parameter qualified by local route-free domains carries their identities in its Psi type. Each predicate on a scalar formal becomes an entry requirement for that parameter. Each predicate on a scalar result becomes a guarantee about that result. Calls reference the callee’s entry requirements by clause index. Returning an existing parameter forwards that same value and its qualifications. A fixed array of predicate-free tags retains the membership on its element type. An indexed read forwards that element type and records a bounds obligation for its selector. Named calls and selected operator calls forward these qualified values through parameters, local bindings, joins and results. A transition arm that invokes a selected operator carries the callee, ordered operands and requirements on its terminal call edge. [Operator handoff tests](tests/operators.rs) · [Operator homes](../../../wiki/spec/language/expressions.md#operator-declarations)

An explicit scalar cast that adds local predicate-free tags or erases local route-free scalar domains carries the change on a successor edge. Its argument identifies the source value and its destination is a fresh block parameter of the new qualified type. The edge retains the cast site. When the cast also changes integer width, the exact conversion produces a bare value before the qualification edge. Keeping the same domains forwards the existing value. A simultaneous removal and addition has an open Psi form. Establishing a predicate-bearing or issuer-controlled membership still requires evidence that L5 cannot emit. [Domain cast tests](tests/domains.rs) · [Scalar qualification edges](../../../wiki/spec/terminal-psi/calls_and_outcomes.md)

A trait requirement carries its own identity, formal parameters, value indices, predicates and effect bounds. A finite list of index tuples preserves the correlations in the authored alternatives. An implementation must still satisfy the other predicates. Mathematical definitions carry their checked terms and the boundary assumptions those terms depend on. [Requirement tests](tests/requirement_interfaces.rs) · [Mathematical declarations](tests/mathematics.rs)

Data templates retain field and case declarations, binder equations, lifetime and witness identities, and default predicates. In a closed constructor, typing supplies the actual field types. For example, constructing `Envelope<u32>::Body::Value` and `Envelope<bool>::Body::Value` selects the same field declaration, but each value needs its own concrete data type. L5 evaluates the initializers in source order and labels each operand with its destination field. The constructor records whether each field receives a copied value or an owned transfer. When a machine reads a frozen record or sum constant, L5 uses the prepared field values in declaration order and establishes the selected case. [Frozen returns](tests/frozen_constants.rs) [Data template tests](tests/data_templates.rs) · [Construction tests](tests/nominal_construction.rs) · [Borrowed field and case tests](tests/nominal_references.rs)

An owned field transfer names its original root and field path. Calls, constructors and match joins carry transferred operands. A normal exit disposes surviving ownership in reverse declaration order. After a partial move it disposes remaining fields, including calls to their selected cleanup machines. An intact subject in its own cleanup body produces that same call edge for termination analysis. A consuming record pattern publishes each independent child and schedules cleanup for ignored children. Replacing owned storage disposes its old live contents at the captured destination or fills the matching vacancy. An owned sum match identifies the original discriminator on its successors. A payload move records the selected case, and its residual contains only fields of that case. For owned fixed arrays, a frozen ordinal identifies the transferred element. Cleanup visits the surviving elements in reverse establishment order, including after a nested projection. [Owned transfer and cleanup](tests/ownership.rs) · [Owned arrays](tests/owned_arrays.rs) · [Ownership and multiplicity](../../../wiki/spec/language/ownership.md)

Selected executable calls identify each closed generic machine by its declaration and ordered static arguments. Repeated selections share one body. A closed structural callback retains the selected machine and the callable interface it must refine. A non-pausing selection lowers the callback invocation to a direct call and retains the authored pause bound alongside its realized demand. [Specialization tests](tests/specializations.rs) · [Callback effects](../../../wiki/spec/language/effects.md) Open callback wrappers retain the bound, its operand mapping and their declared effect limits. A public wrapper can have both a reusable declaration and a closed body in one package.

A binary trapping integer operation retains its selected primitive, ordered scalar operands and result carrier. The primitive defines its failure condition, and the machine contract publishes its crash guard over the entry parameters. For unsigned division, a zero divisor stops at the operation with `Trap`. A nonzero divisor produces the quotient and reaches the ordinary return edge, which owns any outstanding cleanup. The checker compares the operation’s failure condition with the published guard. [Trapping integer handoff](tests/trapping_integers.rs) · [Integer policy operators](../../../wiki/spec/language/numeric_values.md#policy-operators)

## Handoffs and remaining work

A compiler caller can supply its selected target’s instruction catalog when resolving a package. Typing selects an executable instruction variant and preparation preserves that selection. In Psi, each assembly region binds its register initializers simultaneously. Instructions identify their explicit operands, implicit register reads and writes, and selected control transfer. A jump to a local assembly machine targets a block in the same callable. An authored fallthrough edge requires physical adjacency. [Assembly handoff](tests/assembly_handoff.rs) · [Instruction effects](../../../wiki/spec/language/assembly.md)

Moving a field of an owned record produces a place for that field. Normal cleanup names the remaining fields and any selected cleanup machine. An exclusive borrowed field retains its original root and path through extraction and restoration. Replacing an intact affine field also records cleanup of the value it displaced. [Ownership tests](tests/ownership.rs) · [Loan tests](tests/loans.rs)

A local member call records the selected requirement, its supplying implementation and its substituted service arguments. A boundary member call carries the requirement the provider must supply. [Member calls](tests/member_calls.rs)

An exclusive nominal-element view retains its evaluated selector, length and bounds obligation on each extraction or replacement. Filling a vacancy reuses the selected element. Replacing a provably distinct occupied element disposes that element and leaves the original vacancy identifiable. Assignment captures the destination before evaluating its replacement. [Exclusive element views](tests/view_loans.rs) · [Window and sibling tests](tests/loans.rs)

A read through a shared scalar element view carries the descriptor, evaluated index, length of that same descriptor and bounds obligation. A contract that mentions `items.len` also identifies the formal whose length it observes. A shared scalar view recast retains the source loan and the exact integer or Boolean carrier on each side. The checker uses the two carriers to compare their selected layouts and validity requirements at that place. A mutable recast still needs evidence for restoring the source view. [Element views](tests/element_views.rs) · [Recasts](tests/recasts.rs)

Guards on declared crash routes retain their cause and entry-formal predicate. Each direct invocation supplies its ordered actual arguments. A process exit names the canonical boundary requirement and has no successor or normal cleanup. Supported natural ranking declarations publish the source measure, its bounds and each represented in-component call. A terminal call names its edge. An ordinary call qualifies when a cleanup-free return immediately forwards its result; the claim names the operation, owning block, return edge, target and successor rank. When the role of a backed edge depends on an unresolved comparison, unchecked Psi retains that edge, its actual successor rank and a pending role. L6 owns the comparison and termination verdict. [Crash routes](tests/crash_routes.rs) · [Process exit](tests/process_exit.rs) · [Ranking](tests/ranking.rs)

A theorem with a machine-shaped hypothesis publishes its binders, premises and conclusions as proof data. An annotated hypothesis retains its mathematical result type. A guarantee projection takes the result subject after the inputs. A structural callable signature is written on a named alias. The typed package identifies its defining signature across files and libraries. Lowering uses that identity for the callable contract. Runtime dispatch uses the descriptor that arrived at the call, including a descriptor selected at a join. [Theorems](tests/hypotheses.rs) · [Runtime calls](tests/runtime_callable.rs)

The assembly handoff currently covers independent Boolean and fixed-width integer registers, copies, zero tests and local control flow with unit returns. Hosted target instruction catalogs, register aliases, memory and environment effects, register-valued returns and local block contracts remain open. The CLI has no selected catalog and reports unavailable target instructions. [Corpus outcomes](tests/spec_corpus.rs)

An open callback wrapper publishes its binder contract, normalized invocation dependencies, and the ordered calls that supply its result. Nominal binders name the exact trait member and substituted trait arguments. A projected guarantee names the selected binder and the ordered subjects of its relation. The public wrapper stays available when a local caller instantiates it. L5 currently supports straight-line calls on the wrapper’s formals. [Machine template and instance coverage](tests/spec_corpus.rs)

Generic aliases publish their own binders and the normalized target expression. A closed alias such as `data Bytes = Buffer<4>;` preserves the selected alias and its concrete expansion. Computed static arguments and binder equations still need lowering. [Transparent aliases](../../../wiki/spec/language/generics.md#transparent-type-aliases)

Matched sum payloads retain their case discriminator and the cleanup of their surviving fields. An intact sum with different cleanup obligations in different alternatives still needs case-dependent whole-value disposal. Suspending calls retain live scalars and incoming shared-view or reference parameters. Each retained loan names the caller’s descriptor, its type and access, and whether the incomplete callee, its continuation or both need it. The call operand identifies any reborrowed field. The checker must obtain lifetime and carry requirements from that incoming loan. Ordinary and terminal calls establish their result only on completion. At an acyclic branch join, the retained descriptor names the block parameter. Its argument on the arriving edge identifies the incoming view. A consumer can follow nested joins the same way. A completed local call returning a shared view retains its defining operation. Trace its selected return source through the ordered actual arguments, including through nested and terminal calls. The same lookup uses the selected implementation for a local conformance member. A boundary result without return-origin evidence and an open restoration window still need their backing or custody represented at the crossing. [Returned-view tests](tests/returned_view.rs) · [Nested calls](tests/returned_view_inputs.rs) [Joined loan handoff](tests/joined_loans.rs) · [Nested join inputs](tests/joined_loan_inputs.rs) [Incoming loan handoff](tests/parked_byte_views.rs) Trapping binary integer operations retain the originating instruction and separate successful cleanup from an immediate trap. Trapping integer conversions and floating-point result policies still need their executable operations. Runtime callable contracts with effects and proof steps inside theorem bodies also remain open. [Completion map](../../PLAN.md#l5-completion-map) · [Suspension](tests/suspension.rs) · [Trapping integers](tests/trapping_integers.rs)

At a suspending call, each retained owner names the source place and type, the paths already moved out, and the caller or callee argument that has custody. Fully transferred storage contributes no claim. The actual normal edge still owns cleanup of the caller’s remainder. The type and exact live contents expose declared carry restrictions, including an explicit prohibition on suspension. L6 checks these restrictions against the actual value. A direct borrow of an owned field identifies the argument position, exact projection and access mode on the linked call. Its caller-owned root must retain the entire selected subtree. A named loan refers back to its defining borrow and remains in the activation when the callee or continuation needs its descriptor. The checker judges aliasing and lifetime from these operations. For a reference stored inside an incoming record, the retained owner identifies the descriptor by its ordered field path, type and access. Its origin names the incoming formal and the path within that formal. A scalar read or store through `$at` retains the reference and its referent projection. The two spellings `@cell.mark` and `@($cell).mark` select the same field of a referenced record. [Explicit dereference handoff](tests/handoff.rs) For an immutable locally constructed record, the field initializer identifies the descriptor that was copied. A shared reborrow of an incoming reference also records each operation that formed the reborrow, in order. Replacing a writable record before suspension still needs the origin established by the store. [Constructed field handoff](tests/constructed_shared_fields.rs) · [Replacement tests](tests/replaced_descriptor_fields.rs) Moved subtrees contribute no descriptor. Discarding a shared reference to a resource ends that reference. Only an owned resource field schedules its cleanup machine. [Embedded cleanup tests](tests/embedded_cleanup.rs) · [Psi-only field reader](tests/psi-consumer/src/embedded_fields.rs) [Parked field loans](tests/parked_owner_borrows.rs) · [Prepared borrow inputs](tests/owned_borrow_inputs.rs) [Owned suspension handoff](tests/parked_handles.rs) · [Psi-only reader](tests/psi-consumer/src/parked_handles.rs)

## Evidence for sign-off

The [handoff evidence](LOCK_EVIDENCE.md) identifies which changes to a prepared input the tests can distinguish in Psi, which valid programs still stop, and which typed obligations still need an individual trace.

For each source operation assigned to L5, identify the Psi records a consumer needs and inspect them after lowering through the ordinary package entry point. The deciding operands, declarations, paths, edge destinations and obligations must survive after the prepared trees are dropped. For example, two branch destinations can both be legal while only one runs the next guard on failure. A regression for that decision must catch exchanging the destinations. [L5 to L7 in the architecture plan](../../PLAN.md#l5-to-l7)

Account for every open lowering gap against the spec before sign-off. Record separately the programs that stop before L5 and the examples that only produce declarations. The corpus samples the language and cannot establish completeness by counting successes. Where a prerequisite is missing, identify the first handoff that lacks it and the concrete consumer that needs it. [Corpus evidence](tests/spec_corpus.rs)

The control-flow invariant walks the published edges from entry. Each emitted block must be reachable through those edges, and every emitted operation must belong to exactly one reachable block. Tests exercise missing, duplicated and unreachable operations. The plan also requires accept and reject fixtures for each contract rule, recorded suite timing, decisions on spec gaps and owner sign-off. [Independent check](tests/support/control_flow.rs) · [Sign-off gate](../../PLAN.md#what-solid-means)
