# Settle and lock one V2 layer

Use the [handoff procedure](handoff.md) for the scoped layer. The deliverable for a repair is an owned decision that the next layer can read, with its source witness and consumer assertion. For a lock request, reconcile the layer’s complete readiness evidence with the owner’s sign-off in the plan. A passing repair can close its own case while the layer stays open.
