# CodeBlock

Code or a command on `surface`, under an `ink` rule across the top, set in `code`.

You provide the text as children, with its line breaks, and an optional `caption` that says what it is or what it should do ("Run on both engines", "Expected exit: 0"). Long lines scroll inside the block, never the page.

Do copy commands exactly as a person would type them. Don't color the code itself, and don't use a CodeBlock for prose.
