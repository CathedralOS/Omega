Omega pipeline map

Omega compiles every program through one linear pipeline. Each stage reads one representation and writes the next; nothing reaches back to an earlier stage, and nothing travels beside the pipeline. The Psi half is target-neutral and ends at Terminal Psi, where the lowered-form checker gives the compiler's only verdict. The Omega half takes Terminal Psi and the selected target's description and lowers them, stage by stage, to a native image. Foundation holds only primitives; there is no backend beside the pipeline.

What the foundation split changes

Today a type in a foundation crate can carry a stage's output to any later stage, so the representation in between never has to hold it. declaration_selection is the live example: stage 02 writes it, stage 05 reads it, and typed trees never sees it. In the target, the representation that produces it holds it and every stage carries it forward.
