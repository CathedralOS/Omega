# Interactive architecture

Read the snapshot in layers, from Build inputs through source checking
and provider selection to native or interpreted execution. Each layer expands
into stages and pinned evidence. Return paths are explained beside the
layer that causes them.

Open the full map for every relationship. Family colors identify ownership;
edge styles distinguish data, invocation, Cargo declarations, construction,
verification and normative contracts. A manifest dependency does not prove a
runtime call. Scroll or drag to pan; Ctrl/Meta-scroll zooms. Reset restores
readable labels; Fit all and the minimap locate the view. Current loops and late
code generation remain visible. Proposed changes belong to the
[complete migration plan](../plans/foundation-and-backend.md).

The [original authored map](pipeline-map/original.html) remains a historical
presentation. The [reviewed pipeline account](pipeline-map/map.md) corrects
historical claims and traces current handoffs. This view explores those observations.
