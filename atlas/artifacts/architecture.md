# Interactive architecture

This workspace maps the current compiler snapshot. Select a subsystem for its
incoming and outgoing relationships and evidence. Scroll or drag to pan, use
Ctrl/Meta-scroll to zoom, or jump to a named owner. Reset restores readable
labels; Fit all and the minimap show where that view sits in the whole map.

Family colors identify ownership. Edge styles distinguish data, invocation,
Cargo declarations, construction, verification and normative contracts. A
manifest dependency is not proof of a runtime call. Current loops and late
code generation remain visible; proposed changes belong to the
[complete migration plan](../plans/foundation-and-backend.md).

The [original authored map](pipeline-map/original.html) remains the primary
Atlas presentation. The [reviewed pipeline account](pipeline-map/map.md)
corrects historical claims and traces current handoffs. This interactive view
is a separate way to explore those observations, not a replacement design.
