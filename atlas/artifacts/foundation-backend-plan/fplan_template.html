Foundation and backend plan

Omega is one linear pipeline, yet about 318,000 lines sit beside it: 96,000 in foundation/ and 222,000 in omega/compilation/backend/. This plan moves nearly all of it into the pipeline. Foundation keeps about 14,800 lines of primitives. The backend disappears: its emission, object and image work becomes numbered stages 10–14, the selected target's description and the provider plans become inputs that Omega 00 receives, and packaging moves to products. No step changes what the compiler accepts or emits.

How far to trust it

Crate edges come from cargo metadata and are exact. Type-level usage comes from a regular-expression scan, not a Rust resolver, so a glob import or a path inside a macro can be missed, and each "declared but unused" dependency needs a type check before it is deleted. The 14.8k and 40–45k figures are estimates from module line ranges; the backend split was traced in native-compiler/src/pipeline.rs and its module scan sums exactly to the 221,793-line total. judgment marks classification choices; unverified marks claims nobody checked. I spot-checked three claims myself: the wire helpers really are defined twice, machine-code declares function-identity without using it, and pipeline.md carries the 2026-09-26 sentence this ruling supersedes.
