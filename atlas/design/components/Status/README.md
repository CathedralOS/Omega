# Status

One result, shown as an arch-topped pip with a word beside it: checked, trap or open.

You provide `state`. Children replace the default word when a more exact one exists, such as "Rejected" for a reject twin, or "Exit 0".

Do keep the word: the pip's shape (check, cross or empty arch) and the word carry the meaning, and the color only reinforces them. Don't use `checked` for anything that wasn't actually proved or run, and don't put a Status inside a Button.
