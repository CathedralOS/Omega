# PlaceGrid

One fact across the nine places, as a 3×3 grid of results in place order, with a count beneath it.

You provide `results`: nine values (`checked`, `trap` or `open`) in this order: local, field, parameter, call result, match join, const name, nested machine, another machine, another target. Missing entries show as open. `fact` names the fact folder. `size="compact"` draws the 48px emblem with no words, for favicons, table rows and headers; its grid still carries the count for screen readers.

Do pass real results from a run. Mark examples as examples. Don't reorder the places, don't show fewer than nine, and don't use the compact grid where it is the only place the count appears.
