# Source compilation

This owner prepares source through parsing, resolution, typing, evaluation and
lowered-form judgment. Its algorithms remain separately testable private
operations. Only the lowered-form checker accepts an executable program.

Package acquisition supplies admitted bytes and custody. Parsing still streams
each unit through its lexer and parser, reuses token scratch, and preserves
lexical-error precedence. Discovery receives authored import and declaration
summaries. `SourceSyntax`, `SourceItems` and `RetainedSourceParse` keep the trees
and parser-issued handles private; exact-byte adoption reuses retained pages.

`SourceCompilationRequest` selects Build helpers and the requested Build slice
before resolution. `SourceContinuation` owns deferred bodies and typing state;
Build can inspect that state but cannot mutate its tables or pending work.
Generated extensions enter as admitted bytes and are parsed by the same owner.

`SourcePreparationRequest::judge` prepares and judges one complete request,
including its actual evaluation charges. Product preparation closes selected
source and provider demands here. Explicit source inspection has its own request
and grants no acceptance. Published executable products retain canonical Psi,
evidence and narrow provenance; they do not retain this source owner.
